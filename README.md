# Python Learning

这是我的编程学习仓库，记录 Python 基础语法、流程控制、综合项目和 C 语言入门练习。仓库中的中文文件名保持不变，程序按照学习阶段和用途分类。

## 目录结构

```text
.
├── 01_基础练习/           基础语法、列表、字典和循环题目
├── 02_流程与输入练习/     输入校验、分支、循环和异常处理
├── 03_综合项目/           通讯录、计算器和学生成绩管理系统
├── 04_可视化项目/         使用 NumPy 与 Matplotlib 的 3D 动画
├── 05_Python文件读写练习/ Python 文件与文本读写练习
├── 06_C语言练习/          C 语言基础语法与控制流程
├── docs/
│   ├── 仓库结构说明.md    分类方法、修改时间与维护约定
│   └── 文件清单.md        所有文件的简介、功能、用途和最后修改时间
├── requirements.txt        可视化项目依赖
└── .gitignore              Python、macOS 和本地数据忽略规则
```

## 推荐学习顺序

1. **基础练习**：先运行打印图形、九九乘法表、成绩统计和字典查询。
2. **流程与输入练习**：再练习用户输入、随机数、登录校验和条件判断。
3. **综合项目**：观察菜单程序如何逐渐扩展为通讯录和成绩管理系统。
4. **可视化项目**：最后运行 `莲花.py`，综合使用数组、曲面绘制和动画。
5. **C 语言练习**：在 `06_C语言练习` 中练习输入输出、条件判断和基础算法。

## 快速开始

需要 Python 3.9 或更高版本。

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

运行任意脚本时，请使用整理后的完整路径，例如：

```bash
python3 "01_基础练习/输出久久乘法表.py"
python3 "02_流程与输入练习/猜数字游戏.py"
python3 "03_综合项目/学生成绩管理系统.py"
python3 "04_可视化项目/莲花.py"
```

如果不运行 3D 可视化，可以跳过第三方依赖安装，前面的控制台练习只使用 Python 标准库。

## 整理原则

- 保留原中文文件名，减少重命名带来的查找和引用成本。
- 按学习阶段和程序用途分类，而不是把所有 Python 文件平铺在根目录。
- 最后修改时间使用每个文件的最新 Git 提交日期，不依赖克隆后的本机文件时间。
- 只在文件顶部增加说明，不改变原有程序行为。
