## 每个文件怎么找说明

仓库里的文件和说明是一一对应的：

- **Python 文件**：多数文件开头有一段说明（简介、功能、用途、最后修改时间），所在目录的 `README.md` 里有这个文件的简介和它在学习顺序中的位置；`09` 号保留原始版本，`10` 号带逐行中文注释，两种写法共用 `09_..._简介与学习建议.md`。
- **C 语言文件**：每个源码旁边都有一份说明文档，写明程序结构、建议输入、预期输出和常见易错点。绝大多数是 `_简介与学习建议.md`；`14` 号和 `24` 号配的是更详细的 `_零基础教程.md`，按行号逐行讲解。
- **所有文件**：`docs/2026-09-12_文件清单.md` 里有一份完整索引，可以按目录查到每个文件的类型、简介、功能和用途。

文件名的规律是：**序号 + 日期 + 主题**。日期是**这个文件第一次上传到仓库的那一天**（格式 `YYYY-MM-DD`，取自 Git 提交记录），所以打开任意目录都能一眼看到每个文件的创建时间。`README.md` 和被程序按文件名读取的数据文件保持原名，原因写在 `docs/` 的仓库结构说明里。

## 运行方法

### Python

前五个目录的练习只用 Python 标准库，需要 Python 3.9 或更高版本。

```bash
python3 "01_Python基础练习/02_2026-08-23_九九乘法表.py"
python3 "02_Python流程与输入/07_2026-08-23_猜数字_随机答案版.py"
python3 "03_Python综合项目/06_2026-08-31_学生成绩管理系统_JSON持久化版.py"
```

`02`、`03`、`05` 里的程序会等待输入，需要在终端里交互操作。

### Python 可视化项目

`04_Python可视化项目` 需要 NumPy 和 Matplotlib，先安装依赖：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 "04_Python可视化项目/01_2026-09-09_3D莲花动画.py"
```

如果只是运行前面的控制台练习，可以跳过这一步。

### C 语言

用 `cc` 或 `clang` 编译，建议加上警告选项，让编译器帮你发现可疑写法：

```bash
cc -std=c17 -Wall -Wextra "06_C语言练习/01_2026-09-28_基础语法综合练习.c" -o /tmp/practice
/tmp/practice
```

## 学习方式

- **先读注释再运行**：每个文件运行前先猜一下输出，再对照实际结果。
- **一次只改一处**：改完立刻重新运行，才能判断是哪一处改动引起的效果。
- **至少测三类数据**：普通数据、边界数据（最大最小值、空输入）、特殊数据（全负数、全部相同）。
- **出错先定位**：看报错行号 → 判断错误类型 → 做最小修改 → 重新运行。不要一次改很多地方。
- **完成后记三件事**：用到的语法、容易出错的地方、下次怎么改进。
