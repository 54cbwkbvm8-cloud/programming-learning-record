# C、Python 与 Java 编程学习档案

这是一个持续更新的个人编程学习仓库，用来保存 C 语言、Python、Java、数据结构、算法和综合项目练习。仓库不只收集代码，也为重要练习记录运行示例、易错点和拓展方向，方便以后复习、重写和对比自己的进步。

当前已整理的内容以实际文件为准：

- **C 语言**：基础语法、变量与数据类型、分支与循环、函数、数组、字符串、指针、结构体、动态内存、链表、哈希表、算法练习和综合项目。
- **Python**：基础语法、分支与循环、列表与元组、字典、文件操作、异常处理、算法和综合项目。
- **Java**：类与 `main` 入口、基本类型、类型转换、运算符、短路求值、输入校验、条件分支、`switch`、单层与嵌套循环、循环统计、随机猜数字、方法拆分与重载、值传递与数组引用、字符串倒序、回文双指针、字母统计、GCD、素数/约数/数字拆位/第二大值/数对统计、冒泡排序、线性/二分查找、菜单式学生成绩管理（过程式与面向对象重构两版），以及类对象、构造方法、封装、`this`、`static`、`Object` 的 `toString` / `equals` / `hashCode`、空指针、对象数组、数组实现的栈、继承、构造顺序、方法重写、多态数组、安全类型转换、抽象类、接口与 `default` 方法、评测风格算法题（二分查找、冒泡、插入排序、第 k 大、去重计数、频次统计），以及校园人员管理系统。
- **辅助内容**：3D 莲花可视化项目、配套逐题说明，以及学习路线、环境配置和 Git 操作文档。

仓库采用“先按语言、再按知识点”的结构。每个源码文件保持原文件名，练习说明与源码放在同一目录，查找和理解代码不需要跨目录跳转。

## 推荐学习方式

整体顺序是：**理解概念 → 阅读示例 → 手动跟踪程序 → 独立重写 → 修改条件做变式 → 调试错误 → 完成整题 → 总结复习**。

1. 先学 Python 基础语法和流程控制，建立变量、循环、列表与字典的直觉。
2. 如果当前课程正在讲 Java，可以接着完成输出、基本类型、运算符、输入、条件分支、循环、方法与数组阶段，再用成绩管理系统复习菜单、函数和数组，随后进入类对象、封装、`Object` 通用方法、对象数组、继承与多态；先手写一遍排序和查找，再讨论内置工具。不要同时把三种语言的语法全部铺开。
3. 再学 C 语言基础语法，重点适应类型、格式符、数组和内存边界。
4. 学完 C 的分支、循环、函数和数组后，进入字符串与指针。
5. 数组、函数、字符串和指针不要孤立背诵，要反复比较“数组名怎样传参”“函数里为什么还要传长度”。
6. 完成基础练习后，进入动态内存、哈希表、单链表、两数之和、二分查找、巴什博弈和蓝桥杯入门题。
7. 综合项目放在算法基础之后阅读，也可以用项目反过来复习函数、菜单和数据结构。

完整阶段、先修关系、文件位置和检查点见 [综合学习路线](docs/2026-10-10_学习顺序.md)。

```bash
clang -std=c17 -Wall -Wextra -Wpedantic \
  "C/01_基础语法/01_2026-09-28_基础语法综合练习.c" \
  -o /tmp/c_practice
/tmp/c_practice
```

```bash
java_dir=$(mktemp -d /tmp/java-practice.XXXXXX)
javac -encoding UTF-8 -Xlint:all -d "$java_dir" "Java/01_基础语法/BasicTypes.java"
java -cp "$java_dir" BasicTypes
```

## 需要特别注意

- `C/08_指针/23_2026-10-15_指针初始化与数组参数校验练习.c` 保留了真实错误：空指针检查后漏写 `return;`。请先按说明自行定位，再阅读同目录的教程版。
- `C/06_数组/05_2026-09-30_数组统计.c` 曾存在极值比较错误，已于 2026-10-15 修复。它的说明保留了“程序能跑完但答案错误”的复盘价值。
- `C/14_综合项目/44_2026-10-30_软件协会入门考试五题综合练习_原始版.c` 与相邻的 `_修正版.c` 现在只差文件名注释两行：最早加入仓库时修正版比原始版多一个块注释结束符 `*/`，2026-11-01 的注释整理把原始版整体替换为带详细注释的版本，这个差异随之消失。两份文件在 `-DRUN_Q1`～`-DRUN_Q5` 下加 `-Werror` 均可通过编译，不再产生嵌套注释警告。
- `Java/01_基础语法/hellojava.java` 的可执行代码通过编译和运行；源码后半段注释里的文件名与类名说明存在两处旧描述，已在同目录简介中记录，没有擅自改源码。
- `Java/02_分支与循环/SwitchBreakDemo.java` 故意保留漏写 `break` 的反例，使用 `-Xlint:all` 时会产生 11 条预期 `[fallthrough]` 警告；使用 `-Werror` 会按设计失败，不能通过修改原始源码来掩盖。
- `Java/03_方法与数组/ArrayAndBubbleSort.java` 的二分查找要求数组已经有序，方法本身不会先排序；它的 `check()` 在教学输出中显示 `[失败]` 时不会改变进程退出码，因此不能把“退出码为 0”当成正式自动测试通过。
- `Java/03_方法与数组/SecondLargest.java` 早期版本有两个逻辑错误：数组读取从下标 1 开始、输出判断写反。该文件已于 2026-11-16 修正：现在从下标 0 读取全部元素、补上 `n < 1` 的空输入保护、按 `found` 输出；`5 / 8 3 8 6 1` 现在正确输出 `6`。同目录简介与零基础教程保留了当时的排查过程，可按历史案例阅读。
- `Java/03_方法与数组/Narcissistic.java` 固定按三位数拆位，并已把扫描范围限制在 `100～999`（`Math.max(a, 100)` 与 `Math.min(b, 999)`）。输入 `1 20` 现在输出 `NONE`；更早的版本没有这层限制，会输出 1。标准水仙花数测试仍建议使用 `100 999`。
- `Java/04_综合项目/GradeManager.java` 使用三个平行数组保存学生记录，数据只存在内存中；姓名和学号不能含空格。它适合练习菜单程序，但不要把它误认为已经使用面向对象、集合或文件持久化。
- `Java/05_面向对象/Student.java` 的字段没有 `private`，是为了先演示类和对象；它允许直接改字段，也不校验成绩。封装的安全版本由 `EncapsulationStaticDemo` 中的 `SafeStudent` 展示，不能把两份类混为同一实现。
