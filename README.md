# C 与 Python 编程学习档案

这是一个持续更新的个人编程学习仓库，用来保存 C 语言、Python、数据结构、算法和综合项目练习。仓库不只收集代码，也为重要练习记录运行示例、易错点和拓展方向，方便以后复习、重写和对比自己的进步。

当前已整理的内容以实际文件为准：

- **C 语言**：基础语法、变量与数据类型、分支与循环、函数、数组、字符串、指针、哈希表、算法练习和综合项目。
- **Python**：基础语法、分支与循环、列表与元组、字典、文件操作、异常处理、算法和综合项目。
- **辅助内容**：3D 莲花可视化项目、配套逐题说明，以及学习路线、环境配置和 Git 操作文档。

仓库采用“先按语言、再按知识点”的结构。每个源码文件保持原文件名，练习说明与源码放在同一目录，查找和理解代码不需要跨目录跳转。

## 推荐学习方式

整体顺序是：**理解概念 → 阅读示例 → 手动跟踪程序 → 独立重写 → 修改条件做变式 → 调试错误 → 完成整题 → 总结复习**。

1. 先学 Python 基础语法和流程控制，建立变量、循环、列表与字典的直觉。
2. 再学 C 语言基础语法，重点适应类型、格式符、数组和内存边界。
3. 学完 C 的分支、循环、函数和数组后，进入字符串与指针。
4. 数组、函数、字符串和指针不要孤立背诵，要反复比较“数组名怎样传参”“函数里为什么还要传长度”。
5. 完成基础练习后，进入哈希表、两数之和、巴什博弈和蓝桥杯入门题。
6. 综合项目放在算法基础之后阅读，也可以用项目反过来复习函数、菜单和数据结构。

完整阶段、先修关系、文件位置和检查点见 [综合学习路线](docs/2026-10-10_学习顺序.md)。

## 运行示例

在仓库根目录运行 Python 程序：

```bash
python3 "Python/01_基础语法/01_2026-08-23_输出偶数.py"
python3 "Python/13_综合项目/02_2026-09-09_简易计算器_函数版.py"
```

编译运行 C 程序：

```bash
clang -std=c17 -Wall -Wextra -Wpedantic \
  "C/01_基础语法/01_2026-09-28_基础语法综合练习.c" \
  -o /tmp/c_practice
/tmp/c_practice
```

可视化项目需要安装 `requirements.txt` 中的依赖，具体步骤见 [开发环境与 Git 操作指南](docs/开发环境与Git操作指南.md)。
