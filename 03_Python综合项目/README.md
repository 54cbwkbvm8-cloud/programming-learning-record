# 03 Python 综合项目

本目录收录**菜单式程序**：它们由多个函数组成，有完整的交互菜单，能反复操作直到用户主动退出。这是从"写一个练习"走向"写一个小项目"的过渡阶段，重点学科目是 **函数拆分、字典、菜单循环、异常处理和文件持久化**。

目录内的 6 个文件其实记录了三条成长线：

- **计算器线**：`02` → `03`，从函数版升级到带异常处理的健壮版。
- **成绩管理线**：`01` → `05` → `06`，从两个列表，到字典菜单版，再到能存盘的 JSON 持久化版。
- **通讯录线**：`04`，字典 + 菜单的综合应用。

## 文件一览

| 文件 | 简介 | 主要知识点 |
| --- | --- | --- |
| `01_学生成绩管理_列表雏形.py` | 成绩管理系统的早期版本，用两个列表分别存姓名和成绩 | 菜单循环、`zip` 配对遍历、平均分与及格判断 |
| `02_简易计算器_函数版.py` | 把加减乘除各写成一个函数的计算器 | 函数拆分与返回值、`while` 菜单、除零检查 |
| `03_简易计算器_异常处理版.py` | 支持小数、能拦住错误输入的加强版计算器 | `try / except`、`float()`、除零保护、连续计算 |
| `04_通讯录_字典版.py` | 用字典实现的内存版通讯录，支持双向查询 | 字典增删改查、函数组织、编号菜单 |
| `05_学生成绩管理_字典菜单版.py` | 用字典保存学生和成绩，带等级评定的菜单程序 | 字典嵌套、函数拆分、菜单循环、`try / except` |
| `06_学生成绩管理系统_JSON持久化版.py` | 数据能保存到文件、下次打开还在的成绩管理系统 | `json` 读写、`pathlib.Path`、数据校验、持久化 |
| `05_学生成绩管理_字典菜单版_简介与学习建议.md` | 05 号文件的详细讲解文档 | 配合源码阅读 |

## 每个文件在学什么

**`01_学生成绩管理_列表雏形.py`** 是这条线最早的样子：用一个列表存姓名，另一个列表存成绩，靠下标对应关系把两者配对。它能用，但一旦删掉一个学生，两个列表的对应关系就容易错乱——这个"不方便"正是后面改字典版的原因。

**`02_简易计算器_函数版.py`** 第一次把运算逻辑写成独立函数（`add`、`subtract` 等）。它的好处是 `main` 只需要读输入、选菜单、调用函数，逻辑清楚。除法里有一句"除数不能为 0"的检查，这是计算器类程序的必备判断。

**`03_简易计算器_异常处理版.py`** 补齐了上一个版本的短板：用 `try / except` 拦住"输入的不是数字"这种情况，只要输入非法就提示重新输入，程序不会崩。它支持小数连续计算，是"能真正用起来"的版本。

**`04_通讯录_字典版.py`** 用字典把姓名和手机号绑在一起，实现了添加、修改、删除、查看，以及"按姓名查手机号""按手机号查姓名"的**双向查询**。双向查询需要遍历字典的值，是字典专题里很有代表性的练习。

**`05_学生成绩管理_字典菜单版.py`** 用字典套字典的结构（`students[姓名] = 成绩`）保存数据，功能包括添加（检查重名）、删除、修改、查询、显示全部、计算平均分，并把成绩换算成 A～E 等级。140 行左右的代码，是本目录里最适合精读的主程序。详细讲解见同目录的 `05_学生成绩管理_字典菜单版_简介与学习建议.md`。

**`06_学生成绩管理系统_JSON持久化版.py`** 是整条线的终点：程序启动时从 `students.json` 读入之前的数据，操作结束后再写回文件，所以关掉程序数据也不会丢。这里用到 `json.dump` / `json.load`、`pathlib` 定位文件路径，以及 `ensure_ascii=False` 让中文不被转成乱码。程序运行时生成的 `students.json` 已被 `.gitignore` 排除，不会污染仓库。

## 推荐学习顺序

1. `02_简易计算器_函数版.py`：先用最短的代码理解"菜单 + 函数"的结构。
2. `03_简易计算器_异常处理版.py`：看同一个程序如何变得不怕输错。
3. `01_学生成绩管理_列表雏形.py`：感受列表版成绩管理的局限。
4. `04_通讯录_字典版.py`：练习字典的增删改查。
5. `05_学生成绩管理_字典菜单版.py`：读完整版菜单程序，配合讲解文档。
6. `06_学生成绩管理系统_JSON持久化版.py`：最后学数据持久化，让程序有"记忆"。

## 学习方法建议

- 读这六个文件时的重点是**结构**而不是语法：先看菜单是怎么循环的，再看每个功能是怎么拆成函数的，最后看数据存在哪里。
- 把两个计算器对比着读：`03` 只比 `02` 多了异常处理和小数支持，其余结构几乎一样。这种"增量改造"是今后工作里最常见的改动方式。
- 成绩管理三个版本最好按顺序读，边读边问自己："如果是列表版，这一步要怎么实现？换成字典呢？"这样能真正理解不同数据结构的取舍。
- 运行 `06` 时，操作几个学生后关掉程序再重新打开，就能亲眼看到数据被保存了下来。

运行方式：

```bash
python3 "03_Python综合项目/02_简易计算器_函数版.py"
python3 "03_Python综合项目/04_通讯录_字典版.py"
python3 "03_Python综合项目/06_学生成绩管理系统_JSON持久化版.py"
```
