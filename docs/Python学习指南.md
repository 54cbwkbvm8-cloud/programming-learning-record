# Python 学习指南

这份指南依据仓库现有 Python 代码编写。目标是把基础语法、容器、文件、异常和项目阅读连成一条可执行的学习路线，同时区分“仓库已经练过”和“建议以后补充”的内容。

分类入口见 [Python 学习区](../Python/README.md)。逐题运行数据和讲解以源码旁的说明或教程为准。

## 先修知识与学习循环

开始前只需要知道：

- 程序按顺序执行，遇到条件或循环会改变执行路径。
- 缩进是 Python 语法的一部分。
- 终端可以运行 `python3 文件名.py`。
- 报错信息会指出文件名、行号和错误类型。

每份练习建议按同一循环执行：

1. 读题目和输入输出。
2. 手工跟踪变量与容器内容。
3. 运行代码并对照输出。
4. 一次只改一个条件。
5. 制造空输入、非法输入和边界输入。
6. 合上代码独立重写。
7. 说明用了什么数据结构、为什么这样选。
8. 记录一个可以继续改进的方向。

## 阶段一：基础语法与循环

### 学习目标

能读懂并写出包含变量、输出、`for`、`while`、字符串运算和基本格式化的短脚本。

### 推荐练习

1. [输出偶数](../Python/01_基础语法/01_2026-08-23_输出偶数.py)
2. [星号三角形](../Python/01_基础语法/03_2026-08-23_星号三角形.py)
3. [九九乘法表](../Python/01_基础语法/02_2026-08-23_九九乘法表.py)
4. [成绩等级判断](../Python/03_分支与循环/04_2026-08-23_成绩等级判断.py)

### 重点

- `range(start, stop, step)` 的终点不包含。
- 字符串乘法与 f-string。
- 嵌套循环中“外层行、内层列”的关系。
- `if / elif / else` 的互斥顺序。

### 难点

`range(0, 101, 2)` 最容易把终点误认为包含。嵌套循环时，初学者常常只看输出结果，不记录 `i` 和 `j` 每轮的值。建议手写出前三行和前三次迭代。

### 掌握标准

- 能独立打印 0 到 100 的偶数与九九乘法表。
- 能解释循环变量如何控制行数和列数。
- 能修改边界并预测输出怎样变化。

## 阶段二：输入、分支与循环控制

### 学习目标

能处理字符串输入、类型转换、条件校验、循环重试和随机数，并让程序在非法输入时不清零或崩溃。

### 推荐练习

1. [基础登录验证](../Python/03_分支与循环/01_2026-08-23_登录验证.py)
2. [登录验证循环重试版](../Python/03_分支与循环/02_2026-08-23_登录验证_循环重试版.py)
3. [奖学金资格判断](../Python/03_分支与循环/04_2026-08-24_奖学金资格判断.py)
4. [大学奖金资格判定](../Python/03_分支与循环/05_2026-08-24_大学奖金资格判定.py)
5. `Python/03_分支与循环` 中以 `06_`、`07_`、`08_` 开头的猜数字练习

### 重点

- `input()` 永远返回字符串。
- `int()`、`float()` 转换失败会抛出 `ValueError`。
- `while True` 必须有明确的 `break`。
- `continue` 只结束本次迭代。
- `random.randint` 生成随机整数。

### 难点

程序“卡住”常常不是 Python 的问题，而是循环条件永远不结束。输入校验需要同时考虑“类型正确”和“范围正确”，例如成绩既能转成数字，又必须在 0～100。

### 掌握标准

- 能写出可反复重试的登录或猜数字程序。
- 能处理空输入、字母、负数和超范围数字。
- 能指出哪条分支负责退出，哪条分支负责重试。

## 阶段三：列表与元组

### 学习目标

能用列表保存一组数据，完成添加、删除、下标访问、遍历、筛选、排序和统计。

### 推荐练习

1. [列表增删与索引](../Python/05_列表与元组/06_2026-08-27_列表增删与索引.py)
2. [成绩统计与及格人数](../Python/05_列表与元组/05_2026-08-30_成绩统计与及格人数.py)
3. [成绩录入与统计复习](../Python/05_列表与元组/08_2026-09-28_复习题_成绩录入与统计.py)

### 重点

- 下标从 0 开始，负下标从末尾计数。
- `append`、`remove`、`len`、`sum`、`max`、`min`。
- 遍历时记录数量和累计值。
- 元组适合表示不应随意修改的一组值。

### 难点

`remove(value)` 按值删除，不是按下标删除；删除不存在的值会抛异常。用两个平行列表保存姓名和成绩时，一旦顺序错位，关系就会混乱。

### 掌握标准

- 能手写输入成绩、统计平均分、最大值、最小值和及格人数。
- 能解释 `IndexError` 的来源。
- 能判断什么时候应该使用列表、字典或两个平行列表。

## 阶段四：字典与集合

### 学习目标

能用键值对保存有明确对应关系的数据，使用存在性检查、遍历、排序和计数。

### 推荐练习

1. [字典成绩统计与查询](../Python/06_字典与集合/07_2026-09-09_字典成绩统计与查询.py)
2. [两数之和字典优化](../Python/12_算法练习/10_2026-10-18_两数之和_哈希表优化.py)

### 重点

- `d[key]` 按键取值，找不到键会抛出 `KeyError`。
- `key in d` 先检查存在性。
- `items()` 遍历键和值。
- 字典适合“姓名 → 成绩”“数字 → 下标”等映射。
- 集合适合去重和成员判断，目前仓库还没有独立集合练习。

### 难点

列表按位置访问，字典按键访问，两者不能用同一种思路。两数之和的字典版本必须在查补数之后再保存当前数字，否则同一个下标可能被使用两次。

### 掌握标准

- 能解释 `students[name]["score"]` 为什么有两层取值。
- 能安全查询不存在的键。
- 能用字典把两数之和的查找从嵌套循环改成一次遍历。

## 阶段五：函数与程序拆分

### 学习目标

能把重复逻辑抽成函数，理解参数、返回值、局部变量和函数调用顺序。

### 推荐项目

1. [简易计算器函数版](../Python/13_综合项目/02_2026-09-09_简易计算器_函数版.py)
2. [成绩管理函数版](../Python/13_综合项目/07_2026-10-11_学生成绩管理_函数版.py)

### 重点

- `def` 定义函数，`return` 返回结果。
- 参数把数据传入函数，返回值把结果带回调用处。
- 函数内部变量默认是局部变量。
- `main` 只负责整体流程，具体功能交给小函数。

### 难点

初学者常把“打印结果”与“返回结果”混为一谈。函数如果只打印，调用者拿不到结果；函数如果返回，调用者才能继续计算或测试。另一个问题是函数职责过多，既读输入、又计算、又打印。

### 掌握标准

- 能把一段重复的成绩等级判断抽成函数。
- 能设计输入、处理和输出职责清楚的函数。
- 能解释函数定义顺序为什么有时不影响运行。

## 阶段六：文件操作

### 学习目标

能用文本文件和 JSON 保存数据，读回后恢复成合适的 Python 数据结构。

### 推荐练习

1. [四道基础题零基础教程](../Python/08_文件操作/2026-09-13_四道基础题_零基础教程.md)
2. [四道基础题逐行注释](../Python/08_文件操作/02_2026-09-13_四道基础题_逐行注释.py)
3. [文件读写复习](../Python/08_文件操作/01_2026-09-13_文件读写复习_成绩统计.py)
4. [学生成绩写入与读回](../Python/08_文件操作/06_2026-10-14_学生成绩写入文件并读回.py)

### 重点

- `with open(...) as f` 自动关闭文件。
- `"r"` 读取，`"w"` 清空后写入，`"a"` 追加。
- `encoding="utf-8"` 避免中文乱码。
- `json.dump`、`json.load`、`ensure_ascii=False`。
- `Path(__file__)` 定位脚本所在目录。

### 难点

相对路径依赖“当前工作目录”，不是脚本所在目录。使用 `"w"` 会覆盖原文件。从文本读回的成绩仍然是字符串，参与计算前必须转成数字。

### 掌握标准

- 能写出文本和 JSON 的写入、读取、解析流程。
- 能解释 `strip`、`split` 和元组解包。
- 能判断什么时候会覆盖文件，什么时候会追加。
- 能避免把运行时生成的数据误提交到 Git。

## 阶段七：异常处理

### 学习目标

能预测可能失败的转换或输入，使用 `try / except` 给出可恢复的处理，而不是让程序直接崩溃。

### 推荐练习

1. [随机数与输入异常处理](../Python/10_异常处理/10_2026-09-09_随机数与输入异常处理.py)
2. [带异常处理的计算器](../Python/13_综合项目/03_2026-08-30_简易计算器_异常处理版.py)

### 重点

- `try` 放入可能失败的操作。
- `except ValueError` 处理无法转换的输入。
- 捕获异常后可以 `continue` 重新输入。
- 不要用一个过宽的 `except` 掩盖所有错误。

### 掌握标准

- 能区分语法错误、运行异常和逻辑错误。
- 能说明一次 `ValueError` 是由哪个转换产生的。
- 能在异常后保程序继续运行，并给出明确提示。

## 阶段八：算法练习

### 学习目标

能比较暴力解和优化解，理解时间复杂度、空间换时间和边界数据。

### 推荐练习

1. [两数之和暴力枚举](../Python/12_算法练习/09_2026-10-18_两数之和_暴力枚举.py)
2. [两数之和字典优化](../Python/12_算法练习/10_2026-10-18_两数之和_哈希表优化.py)

### 重点

- 双层循环不会重复检查同一对下标。

### 掌握标准

- 能解释为什么字典解法需要额外内存。
- 能独立写出两种算法并对比结果。
- 能用多组数据自动比较实际结果和预期结果，并在失败时抛出异常。
- 能解释当前哈希版返回任意一组合法答案，不保证最早配对。

## Python 与 C 的关键差异

| 主题 | Python | C |
| --- | --- | --- |
| 类型 | 运行时自动处理，变量可重新绑定 | 编译时确定，格式符和类型必须匹配 |
| 容器 | 列表、字典直接使用 | 通常用数组并自己管理长度 |
| 内存 | 由解释器管理 | 数组边界和动态内存由程序员负责 |
| 字符串 | 常用不可变 `str` | 字符数组加 `'\0'` |
| 错误 | 抛异常，可 `try / except` | 常见为编译错误、越界、空指针和未定义行为 |
| 项目结构 | 函数拆分，后续可进入模块和包 | 函数和头文件拆分，后续可进入多模块编译 |

比较两种语言时，重点看“数据放在哪里、长度从哪里知道、错误怎样暴露”，不要只背语法差异。

## 当前未覆盖与后续方向

当前仓库没有充分的独立练习证明已经掌握：

- 面向对象：类、对象、继承、组合和封装。
- 模块与包：多文件导入、包结构和依赖管理。
- 集合类型：除字典外的 `set` 操作。
- 正式数据结构：链表、栈、队列、树。
- 自动测试：`pytest`、断言和测试数据组织。

这些主题适合后续新增真实练习，并在新增时同时补充说明和测试，不把“推荐学习”写成“已经完成”。

## 复习方法

1. 用一句话说明程序保存了什么数据。
2. 不看源码重写核心流程。
3. 用普通、空、边界、非法输入测试。
4. 对比列表、字典、文件三种存储方式。
5. 把打印函数改成返回值的函数。
6. 一周后只保留题意，再实现一次。
