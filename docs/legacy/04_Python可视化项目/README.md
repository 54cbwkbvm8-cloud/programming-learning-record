## 这个文件在学什么

`01_2026-09-09_3D莲花动画.py` 做的事情是"用数学画出花"：

1. **参数化生成花瓣**：用角度和半径的数组算出每一片花瓣的曲面坐标，多层花瓣按不同的弯曲程度叠起来。
2. **画出花蕊和微粒**：除了花瓣，还画了花蕊、雄蕊，以及花瓣上闪烁的微粒。
3. **让画面动起来**：通过 `FuncAnimation` 不断更新视角、粒子大小和颜色，形成旋转的动画效果。
4. **保证结果可重复**：文件里设置了 `np.random.seed(42)`，所以每次运行生成的随机微粒位置都是一样的。想看到不同的粒子分布，改这个数字就行。

这份代码用到的语法多半超出目前的入门范围（数组广播、旋转矩阵、四元数等）。**现阶段不需要全部看懂**，重点是：

- 感受"数组可以一次性对所有数字做运算"，这是 NumPy 和 Python 列表最大的区别。
- 认识 `import` 第三方库的写法，以及"依赖需要先安装"这件事。
- 知道一个完整项目通常由"准备数据 → 计算 → 绘制 → 动画"几步组成。

## 运行准备

这个文件依赖 NumPy 和 Matplotlib，需要先安装依赖（在仓库根目录执行）：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

然后运行：

```bash
python3 "Python/14_可视化项目/01_2026-09-09_3D莲花动画.py"
```

如果弹出的是空白窗口或者报错 `ModuleNotFoundError`，说明依赖没装上，回到上面两步重新安装即可。

## 学习方法建议

- **先跑通再研究**：这个文件的正确打开方式是先看到旋转的莲花，产生兴趣，再回头挑一小段去理解。
- 挑三个小地方动手改一改，比通读全文有效得多：

  1. 把 `GLOBAL_SCALE = 0.6` 改成 `1.2`，看整朵花变大。
  2. 把 `np.random.seed(42)` 里的 42 换成别的数字，看粒子分布变化。
  3. 找到控制花瓣层数或片数的地方，把数量调小，观察画面变化。

- 不要一开始就研究旋转矩阵。等以后学过线性代数里的矩阵乘法，再回来看这段代码会轻松很多。
- 学完这一份，可以试着用同样的思路画更简单的东西，比如正弦曲线、心形线或三维球面——从一个能跑通的小图开始，比直接改造这个大文件容易。
