# 仓库结构说明

## 整理目标

本仓库原先把全部脚本平铺在根目录。现在按照“学习阶段和程序用途”进行分类，同时保留所有中文文件名和原有程序行为。目录结构优先服务于查找、复习和后续继续添加练习。

## 整理依据

1. **文件类型**：Python 脚本进入四个学习分类，Markdown 进入 `docs`，依赖和忽略规则保留在根目录。
2. **代码内容**：根据脚本使用的知识点、依赖关系和完成度判断所属阶段，而不是只按文件名分类。
3. **最后修改时间**：使用 Git 历史中每个文件最近一次提交的日期，避免使用克隆后产生的本机时间。
4. **依赖关系**：`莲花.py` 依赖 NumPy 和 Matplotlib，因此单独放入可视化项目，并在根目录提供 `requirements.txt`。

## 分类规则

### 01_基础练习

适合刚学习 Python 时反复运行的短脚本，主要包含循环、列表、字典、成绩分级和统计。这些文件通常不依赖其他模块，运行后直接输出结果或进行简单输入。

### 02_流程与输入练习

重点是接收用户输入并根据输入改变程序流程，包含随机数、猜数字、登录验证、奖学金判断、异常处理和循环控制。部分程序会持续等待输入，适合使用交互式终端运行。

### 03_综合项目

包含多个函数、菜单和较完整的数据操作流程，包括早期列表版学生成绩练习、两个计算器、通讯录以及带 JSON 持久化的成绩管理系统。它们适合作为从单点语法走向小型项目的复习材料。

### 04_可视化项目

需要第三方库，使用 NumPy 计算三维网格，使用 Matplotlib 绘制曲面、粒子、花蕊和动画。所有可视化相关依赖统一列在根目录 `requirements.txt`。

### docs

保存仓库级说明，不作为程序运行入口。`文件清单.md` 提供逐文件说明，本文件说明分类和维护约定。

## 后续维护约定

- 新增基础题目时，优先放入 `01_基础练习`。
- 新增需要输入、条件或循环交互的脚本时，放入 `02_流程与输入练习`。
- 当一个练习包含多个功能、菜单或数据保存时，放入 `03_综合项目`。
- 新增绘图、动画或需要第三方库的脚本时，放入 `04_可视化项目`，并同步更新依赖。
- 每次移动或新增文件后，更新 `docs/文件清单.md`。
- 继续保留中文文件名；新增脚本时建议在文件顶部写清简介、功能和用途。
