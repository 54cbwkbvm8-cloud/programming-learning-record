# 推荐学习顺序

这份文档把仓库里的全部练习排成一条推荐路线，分 6 个阶段。每个阶段都写明了**学什么、用哪些文件、大概花多久、学完怎么判断自己掌握了**。

如果只想按顺序往下做，按照这里的编号走就不会乱；每个目录自己的 `README.md` 里还有更细的单目录顺序。

## 怎么用这份顺序

- **一次只做一件事。** 一个文件没跑通，不要跳到下一个。
- **先跑再改。** 每个文件先用文档里的示例数据运行一次，看到输出之后再开始改代码。
- **改一个地方就跑一次。** 一次改多处，出错时无法判断是哪一处引起的。
- **每完成一个阶段做一次回顾。** 关上文件，凭记忆写出这个阶段学过的主要语法，写不出来的地方回头补。

时间估算是按"每个文件认真做完"来算的，仅供参考，不用严格卡时间。

## 常见问题的处理顺序

写代码时遇到问题，按这个顺序排查，能省下大量时间：

1. **程序编译不过**：看编译器的报错行号和错误类型，通常是拼写、缺少分号、类型不匹配。
2. **程序能跑但结果不对**：先在关键位置加 `printf` 打印中间变量，看看哪一步开始不对。
3. **程序卡住不动**：检查循环有没有让条件趋向结束的动作（比如 `i++` 漏写）。
4. **输入之后程序行为异常**：检查 `scanf` 的 `&` 有没有漏，格式符和变量类型是否匹配。
5. **Python 报错**：看最后一行错误类型，`SyntaxError` 是语法问题，`ValueError` 多半是 `int()`/`float()` 转换失败，`IndexError` 是下标越界。

## 学完之后

走完这六个阶段，你就具备了：

- 用 Python 写带菜单、能存数据的小程序的能力；
- 用 C 语言写循环、数组、函数类题目的能力；
- 自己定位和修复简单错误的能力。

接下来的方向可以按兴趣选：继续刷算法题（蓝桥杯真题）、学面向对象（类与对象）、学数据结构（链表、栈、队列），或者用一个完整的小项目把已有知识串起来。
