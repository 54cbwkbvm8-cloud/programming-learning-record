# 综合学习路线

这份路线只负责安排阶段、先修关系和检查点。具体语法、难点和练习方法分别放在 [C 语言学习指南](C语言学习指南.md) 与 [Python 学习指南](Python学习指南.md) 中，避免同一套理论重复出现。

## 使用原则

1. 一次只主攻一个阶段，不要同时补五个知识点。
2. 每个源码先运行，再手算变量变化，最后独立重写。
3. 每阶段至少测试正常、边界和特殊数据。
4. 完成检查点后再进入下一阶段；没通过时只补当前薄弱点。
5. 算法和综合项目必须建立在前置语法已经能独立完成的基础上。

## 默认顺序

对于当前仓库，建议采用：

```text
Python 基础语法
→ Python 分支、循环与容器
→ C 基础语法
→ C 分支、循环、函数与数组
→ C 字符串与指针
→ Python/C 基础算法
→ Python 综合项目
→ C 综合项目与数据结构入门
→ 后续算法专题
```

如果课程安排先学 C，也可以先完成 C 的“基础到数组”阶段，再回到 Python。不要跳过数组和函数直接学指针。

## Python 路线

### Python 阶段 1：基础输出与循环

- **学习内容**：变量、`print`、`for`、`while`、`range`、缩进、字符串运算。
- **推荐文件**：
  - `Python/01_基础语法/01_2026-08-23_输出偶数.py`
  - `Python/01_基础语法/03_2026-08-23_星号三角形.py`
  - `Python/01_基础语法/02_2026-08-23_九九乘法表.py`
- **检查点**：能独立写出九九乘法表，并能解释外层和内层循环变量。

### Python 阶段 2：输入、分支与循环控制

- **学习内容**：`input`、类型转换、条件判断、`while True`、`break`、`continue`、随机数。
- **推荐目录**：[Python 分支与循环](../Python/03_分支与循环/)
- **检查点**：能写一个反复登录或猜数字程序，输入非法时能重试或清楚退出。
- **重点难点**：循环必须趋向结束；`input()` 返回字符串；字符串比较和数字比较不同。

### Python 阶段 3：列表与字典

- **学习内容**：下标、列表增删、遍历、统计、字典键值对、存在性检查。
- **推荐文件**：
  - `Python/05_列表与元组/06_2026-08-27_列表增删与索引.py`
  - `Python/05_列表与元组/05_2026-08-30_成绩统计与及格人数.py`
  - `Python/06_字典与集合/07_2026-09-09_字典成绩统计与查询.py`
- **检查点**：能完成成绩录入、统计和查询，并能解释 `IndexError` 与 `KeyError`。

### Python 阶段 4：文件、异常与函数拆分

- **学习内容**：`try / except`、文本文件、JSON、`pathlib`、函数参数和返回值。
- **推荐文件**：
  - `Python/10_异常处理/10_2026-09-09_随机数与输入异常处理.py`
  - `Python/08_文件操作/2026-09-13_四道基础题_零基础教程.md`
  - `Python/08_文件操作/06_2026-10-14_学生成绩写入文件并读回.py`
- **检查点**：能把字典列表保存为 JSON 并读回；能解释相对路径和 `Path(__file__)` 的差别。

### Python 阶段 5：综合项目

- **前置知识**：循环、容器、函数、异常、文件中的至少四项。
- **推荐顺序**：函数计算器 → 成绩管理函数版 → 输入校验版 → 字典菜单版 → JSON 持久化版。
- **入口**：[Python 综合项目](../Python/13_综合项目/)
- **检查点**：能画出菜单程序流程，说明数据存在哪里，并复制一套自己的版本增加一个功能。

### Python 阶段 6：算法与可视化

- **算法**：两数之和暴力解 → 两数之和字典优化 → 带 6 组自动测试的哈希表优化测试版 → 正确接入结果展示函数的版本。
- **可视化**：3D 莲花动画，建立在安装 NumPy、Matplotlib 和理解列表/数组操作的基础上。
- **检查点**：能比较两种两数之和算法；能说明测试列表、预期值和失败断言的作用，并知道重复数字可能让哈希版返回较晚但仍合法的下标；能检查 `main → run_test → two_sum → print` 的调用链，并说明只调用 `two_sum` 且丢弃返回值为何会静默无输出；能说明可视化项目用到的库和主要输入参数。

## C 语言路线

### C 阶段 1：基础语法与输入输出

- **学习内容**：`main`、变量、类型、`scanf`、`printf`、格式符、算术运算。
- **推荐文件**：
  - `C/01_基础语法/01_2026-09-28_基础语法综合练习.c`
  - `C/02_变量与数据类型/26_2026-10-16_强制类型转换与printf格式控制练习.c`
- **检查点**：能根据变量类型选择格式符，能解释整数除法截断和浮点转换。

### C 阶段 2：分支与循环

- **学习内容**：`if`、`switch`、`for`、`while`、累加、筛选、嵌套循环、输入检查。
- **推荐目录**：[C 分支与循环](../C/04_分支与循环/)
- **检查点**：能独立完成奇偶、闰年、九九乘法表和输入重试逻辑。
- **重点难点**：循环变量更新、数组下标边界、`switch` 穿透。

### C 阶段 3：函数与作用域

- **学习内容**：函数声明、参数、返回值、局部变量、代码块作用域。
- **推荐文件**：
  - `C/05_函数/07_2026-10-02_函数基础练习.c`
  - `C/05_函数/14_2026-09-13_两数比较与成绩等级_教程版.c`
  - `C/08_指针/32_2026-10-19_变量作用域与数组传参复习.c`
- **检查点**：能把一段功能拆成函数，能解释形参和实参、局部变量遮蔽。

### C 阶段 4：数组

- **学习内容**：一维数组、遍历、统计、逆序、极值、数组作函数参数。
- **推荐目录**：[C 数组](../C/06_数组/)
- **检查点**：能独立输入一组数并输出总和、平均、最大、最小；能用全负数测试初值是否正确。
- **重点难点**：不能越界；求极值要取首元素作初值；函数里必须另传长度。

### C 阶段 5：字符串

- **学习内容**：字符数组、`\0`、`fgets`、`strlen`、`sizeof`、ASCII。
- **推荐目录**：[C 字符串](../C/07_字符串/)
- **检查点**：能读取一行、去除换行、逐个字符统计字母和数字。
- **重点难点**：中文在 UTF-8 中占多个字节；`strlen` 与 `sizeof` 不是同一个量。

### C 阶段 6：指针与数组传参

- **前置知识**：变量、函数、数组、字符串。
- **推荐起步**：`C/08_指针/34_2026-10-20_指针交换与值传递对比.c`
- **推荐目录**：[C 指针](../C/08_指针/)
- **检查点**：能解释 `*p`、`p[0]`、`*(p + 1)`、`p[-1]`，能判断偏移是否在数组范围内，并能说明 `swapByValue` 和 `swap(&x, &y)` 的结果为什么不同。
- **重点难点**：普通参数按值复制，指针参数通过地址修改调用者变量；数组名传参后变成指针；空指针检查后必须真正结束错误路径；越界不保证立刻报错。

### C 阶段 7：结构体、动态内存与数据结构

- **学习内容**：`struct` 类型定义、结构体变量初始化、`.` 成员访问、结构体数组、结构体指针、`&`、`->`、固定容量哈希表、冲突、线性探测、`malloc`、`calloc`、`free`、容量和数值溢出、动态数组、自引用结构体、单链表遍历、尾插、按值删除、固定测试、哈希函数和删除标记。
- **推荐文件**：

  - `C/13_算法练习/27_2026-10-18_两数之和_暴力枚举.c`
  - `C/12_数据结构/28_2026-10-18_两数之和_哈希表优化.c`

- **检查点**：能定义和初始化结构体，通过 `.` 修改字段；能解释结构体指针、`&s`、`p->score`、`(*p).score`；能手工跟踪固定哈希表；能说明动态数组的元素数、字节数、内存申请和释放；能画出三个链表节点及 `next` 连接并沿链遍历、释放；能实现空链表和非空链表的尾插；能处理删除头节点、中间节点和尾节点，并说明返回新头指针与输出参数的作用。

## 算法与项目的安排

### 什么时候进入算法

至少满足：

- 能独立写循环、函数和数组统计。
- 能解释常见下标越界。
- 能用一组小数据手工跟踪程序。

### 推荐算法顺序

1. 一维统计、极值和循环输入。
2. 两数之和暴力解。
3. 第二大不同值与固定测试。
4. 两数之和哈希优化。
5. 巴什博弈和固定测试。
6. 蓝桥杯风格整题训练。

### 什么时候进入综合项目

Python 项目至少需要函数、容器和输入校验；C 项目至少需要函数、数组和循环。不要通过“逐行照抄项目”代替基础练习。项目阅读的目标是学会结构和调试，不是背下所有代码。

## 每周练习流程

建议每周安排一个主主题：

1. 读概念和学习指南。
2. 运行两个相关源码。
3. 手算一组输入。
4. 独立重写其中一题。
5. 自己设计两个边界数据。
6. 记录一个错误原因。
7. 周末关闭源码重写一次。

## 进入下一阶段的判断

满足以下四项再继续：

1. 能解释当前阶段的核心概念，不只背语法。
2. 能独立重写至少一个代表程序。
3. 能说明至少三个常见错误及原因。
4. 能用正常、边界和特殊数据验证结果。

没满足时不要通过增加文件数量解决，优先把当前练习再做一遍并记录错误。
