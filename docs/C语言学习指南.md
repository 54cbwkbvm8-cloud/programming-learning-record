# C 语言学习指南

这份指南依据仓库现有的 C 练习编写，目标不是把所有知识一次讲完，而是帮助你判断“下一步学什么、为什么学、用哪些代码练、学到什么程度可以继续”。

仓库对应的分类入口是 [C 语言学习区](../C/README.md)。具体程序的输入、输出和逐行解释仍以源码旁的学习说明为准。

## 先修知识与学习边界

开始 C 语言之前，至少需要：

- 知道程序由语句组成，语句按顺序执行。
- 能使用终端进入目录、查看文件、运行命令。
- 理解变量只是保存数据的名字。
- 知道出现报错时先阅读错误信息，而不是随机改代码。

当前仓库已经涉及的基础、数组、函数、字符串、指针、结构体、动态内存和基础算法都可以按本指南学习。C 文件操作、递归、链表、栈、队列和树还没有独立练习，不属于当前已覆盖范围。

## 每一道练习的学习循环

不要只运行一次源码。建议固定使用下面八步：

1. **理解概念**：先用一句话说清这道题要解决什么。
2. **阅读示例**：找出输入、处理、输出三个部分。
3. **手动跟踪**：选一组小数据，在纸上或注释里记录变量变化。
4. **编译运行**：对照学习说明检查实际输出。
5. **只改一处**：改初值、条件或边界，观察结果怎么变。
6. **制造错误**：输入非法值、空值、边界值，看程序怎样失败。
7. **独立重写**：关闭源码，自己重新写一版。
8. **总结复习**：记录语法、错误原因、修改方法和下一次练习目标。

## 阶段一：基础语法、类型和输入输出

### 学习目标

能读懂并写出顺序执行的小程序，正确使用变量、`scanf`、`printf`、算术运算和格式符；能解释整数与浮点数的差别。

### 前置知识

知道 `main` 是程序入口，知道头文件用于声明标准库函数。

### 推荐练习

1. [基础语法综合练习](../C/01_基础语法/01_2026-09-28_基础语法综合练习.c)
2. [强制类型转换与格式控制](../C/02_变量与数据类型/26_2026-10-16_强制类型转换与printf格式控制练习.c)

### 重点

- `int`、`float`、`double` 的基本区别。
- `%d`、`%f`、`%lf`、`%.2f`、`%02d` 等格式。
- `scanf` 的地址参数 `&`。
- 整数除法会截断小数。
- `(double)a / b` 与 `(double)(a / b)` 的结果不同。

### 难点

初学者容易把“变量的类型、输入格式、输出格式”当成三件互不相关的事。实际上三者必须匹配：变量是 `double`，输入要使用正确的读取方式，输出也要选对格式。另一个难点是 `7 / 2` 得到 `3`，不是 `3.5`。

### 掌握标准

- 看到变量声明能说出适合的格式符。
- 能解释为什么 `b == 0` 时除法不能执行。
- 能独立写出整数与浮点数格式控制的对照小程序。
- 能检查 `scanf` 返回值，知道读取失败时程序不应继续使用错误数据。

## 阶段二：分支与循环

### 学习目标

能根据条件选择分支，用 `for` 和 `while` 完成计数、累加、筛选、嵌套和输入循环，并能判断循环是否会结束。

### 前置知识

变量、算术运算、比较运算、输入输出。

### 推荐练习

1. [正负奇偶与闰年](../C/04_分支与循环/02_2026-10-10_正负奇偶与闰年_简介与学习建议.md)
2. [循环与九九乘法表](../C/04_分支与循环/03_2026-09-29_循环与九九乘法表.c)
3. [循环综合与猜数字](../C/04_分支与循环/04_2026-09-30_循环综合与猜数字.c)
4. [循环求和与奇偶分类](../C/04_分支与循环/18_2026-10-12_循环求和与奇偶分类.c)
5. [switch 分支与输入](../C/04_分支与循环/25_2026-10-16_switch分支与scanf输入练习.c)

### 重点

- `if / else if / else` 的条件顺序。
- `&&`、`||`、`!` 的作用。
- `for` 的初始化、条件、更新三部分。
- `while` 中循环变量必须向结束条件靠近。
- `break` 结束整个循环，`continue` 结束本次迭代。
- `switch` 中漏写 `break` 会发生穿透。

### 难点

数组越界通常从 `i <= n` 这类边界条件开始；无限循环通常来自循环变量没有更新；多分支题容易出现条件重叠。不要把 `=` 当作比较运算，也不要只测试一组数据。

### 常见错误

- `for (i = 1; i <= n; i++)` 访问长度固定为 `n` 的数组时越界。
- 累加变量在下一轮计算前没有清零。
- 闰年条件的优先级写错。
- `scanf` 读取失败后继续使用旧值。

### 掌握标准

- 能手写九九乘法表、奇偶筛选和输入重试循环。
- 能画出循环变量每轮的值。
- 能用正常、边界、特殊数据解释每个分支是否被执行。

## 阶段三：函数与作用域

### 学习目标

能把重复逻辑拆成函数，正确设计参数和返回值，知道形参与实参、局部变量、代码块作用域和数组参数的区别。

### 前置知识

变量、分支、循环和一维数组。

### 推荐练习

1. [函数基础练习](../C/05_函数/07_2026-10-02_函数基础练习.c)
2. [函数最值、平方与奇偶判断](../C/05_函数/17_2026-10-12_函数最值平方与奇偶判断.c)
3. [两数比较零基础教程](../C/05_函数/14_2026-09-13_两数比较与成绩等级_零基础教程.md)
4. [数组函数统计](../C/05_函数/09_2026-10-05_数组函数统计.c)
5. [变量作用域与数组传参复习](../C/08_指针/32_2026-10-19_变量作用域与数组传参复习.c)

### 重点

- 函数声明、定义和调用的关系。
- `return` 返回计算结果并立即结束函数。
- 参数按值传递，数组名作为参数时传入的是首元素地址。
- 局部变量只在其代码块中有效。
- 内层代码块可以定义同名变量，但会遮蔽外层变量。

### 难点

“函数返回一个值”和“函数通过参数修改外部数组”是两种不同机制。数组进入函数后，函数只知道首地址，不知道真实长度，因此必须额外传入 `n`。

### 掌握标准

- 能根据需求决定返回值类型和参数列表。
- 能解释 `sizeof(a)` 在 `main` 和数组形参中的结果为什么不同。
- 能把一段重复逻辑改成函数，并保持程序结果不变。
- 能用小函数分别完成输入、计算、输出，避免把所有逻辑堆进 `main`。

## 阶段四：数组

### 学习目标

能使用一维数组保存一批数据，完成遍历、求和、平均值、最大值、最小值和逆序输出，并正确处理空数组和边界。

### 前置知识

分支、循环、函数参数。

### 推荐练习

1. [数组统计](../C/06_数组/05_2026-09-30_数组统计.c)
2. [数组统计与逆序输出](../C/06_数组/06_2026-10-01_数组统计与逆序输出.c)
3. [数组输入校验与成绩统计](../C/06_数组/13_2026-10-10_数组输入校验与成绩统计.c)
4. [奇偶组合与数组最值](../C/06_数组/16_2026-10-11_奇偶组合与数组最值.c)
5. [旧版数组练习说明](../C/06_数组/2026-10-01_C语言数组练习_旧版说明.md)

### 重点

- 下标从 `0` 开始，合法范围是 `0` 到 `n - 1`。
- 求最大值、最小值时先取第一个元素作初值。
- 求和与计数变量必须初始化。
- 平均值需要浮点转换，例如 `(double)sum / n`。
- 数组与函数配合时，长度必须另行传递。

### 难点

最大值初始化为 `0` 在“全部为负数”时会得到错误答案。数组越界不一定会立即报错，可能只是覆盖其他数据。输入校验不完整时，程序会把旧数据或错误数据继续计算。

### 掌握标准

- 能独立写出数组输入、总和、平均、最大值和最小值。
- 能解释为什么循环条件是 `i < n`。
- 能测试全负数、全部相同、长度为 1 和空输入。
- 能发现并解释 05 号历史练习中的极值错误。

## 阶段五：字符串

### 学习目标

能使用字符数组保存文本，知道字符串以 `'\0'` 结尾；能读取一行、去除换行并遍历字符。

### 前置知识

数组、循环、函数、指针基本概念。

### 推荐练习

1. [字符串输入与常用函数](../C/07_字符串/19_2026-10-13_字符串输入与常用函数练习.c)
2. [字符串统计与大小写转换](../C/07_字符串/20_2026-10-14_字符串统计与大小写转换练习.c)

### 重点

- `fgets` 会保留换行，需要处理 `'\n'`。
- `strlen` 返回第一个 `'\0'` 前的字节数。
- `sizeof` 返回数组或对象的字节容量。
- `strcpy`、`strncmp` 和 `string.h` 的用途。
- 字符可以按 ASCII 码比较和运算。

### 难点

UTF-8 中文一个字通常占多个字节，所以 `strlen` 不一定是“字符数”。字符串数组必须给结尾 `'\0'` 留空间。`string.h` 中的部分函数不会自动检查目标缓冲区大小。

### 掌握标准

- 能说清 `char s[10]` 最多能安全保存多长的普通 ASCII 文本。
- 能读完一行文字并删除行尾换行。
- 能逐字符统计字母、数字并转换大小写。
- 能解释 `strlen(s)` 和 `sizeof(s)` 的差异。

## 阶段六：指针与数组指针关系

### 学习目标

能解释地址、指针、解引用和指针偏移；能区分普通值传递和通过指针修改调用者变量；能把数组传入函数；能识别空指针、越界和 `sizeof` 误用。

### 前置知识

变量、函数、数组、字符串，以及基本的计算机内存概念。

### 推荐练习

1. [指针基础读写与 switch 穿透](../C/08_指针/22_2026-10-15_指针基础读写与switch穿透练习.c)
2. [指针交换与值传递对比](../C/08_指针/34_2026-10-20_指针交换与值传递对比.c)
3. [指针偏移与数组传参](../C/08_指针/21_2026-10-15_指针偏移与数组传参练习.c)
4. [指针初始化与数组参数校验](../C/08_指针/23_2026-10-15_指针初始化与数组参数校验练习.c)
5. [指针教程版](../C/08_指针/24_2026-10-15_指针初始化与数组参数校验_零基础教程.md)
6. [指针算术与数组偏移](../C/08_指针/31_2026-10-19_指针算术与数组偏移练习.c)
7. [变量作用域与数组传参复习](../C/08_指针/32_2026-10-19_变量作用域与数组传参复习.c)

### 重点

- `&x` 取得变量地址，`*p` 访问地址中的数据。
- 普通整数参数按值复制；只有通过指针参数解引用，才能修改调用者的变量。
- 交换两个整数必须先保存一个旧值，再覆盖两个位置，最后写回临时变量。
- 指针加 1 会移动到“下一个同类型元素”。
- `p[0]` 等价于 `*p`。
- 数组名在多数表达式中退化为首元素地址。
- `NULL` 指针检查后必须立即 `return`、`continue` 或采取其他终止路径。
- 指针偏移只有在数组有效范围内才有意义。

### 难点

数组名和指针“相似但不完全相同”：数组对象有固定大小，函数形参中的数组名却已经是指针。`sizeof(arr)` 在函数里通常只得到指针大小。指针越界不一定崩溃，但不代表安全。

### 常见错误

- 参数检查只打印错误却继续访问空指针。
- 调用指针交换函数时忘记传地址，或在函数中交换指针变量本身而没有使用 `*a`、`*b`。
- 交换三步漏掉临时变量，导致一个值被覆盖。
- 使用 `*(p - 1)` 时 `p` 已经指向首元素。
- 把节点地址、元素值、下标三者混为一谈。
- 函数里用 `sizeof(a) / sizeof(a[0])` 计算数组长度。

### 掌握标准

- 能画出一维数组和指针的位置关系。
- 能解释 `a`、`&a[0]`、`a + 1`、`*(a + 1)` 和 `a[1]`。
- 能解释 `swapByValue` 为什么不能改变 `main` 中的变量，`swap(&x, &y)` 为什么可以。
- 能写出接收数组和长度的函数，并检查非法参数。
- 能说明 23 号为什么会崩溃，24 号的最小修复是什么。

## 阶段七：结构体、动态内存与数据结构入门

### 学习目标

能定义并初始化由多个相关字段组成的结构体，使用 `.` 读写成员；在掌握普通结构体变量后，再理解动态内存的申请与释放，以及哈希表如何用空间换时间。

### 前置知识

指针、数组、函数、循环和基本的复杂度概念。

### 推荐练习

1. [结构体学生信息与成绩输入校验](../C/09_结构体与自定义类型/37_2026-10-23_结构体学生信息与成绩输入校验.c)
2. [两数之和暴力解](../C/13_算法练习/27_2026-10-18_两数之和_暴力枚举.c)
3. [两数之和哈希表优化](../C/12_数据结构/28_2026-10-18_两数之和_哈希表优化.c)

### 重点

- `struct Student` 定义一种包含多个成员的自定义类型，变量通过 `.` 访问成员。
- 结构体初始化列表按成员声明顺序赋值；成员类型要与输入、输出格式匹配。
- `char name[50]` 是结构体内部的字符数组，中文按 UTF-8 编码会占多个字节。
- 输入合法数字后还要检查数字后是否有多余字符，以及成绩是否在 `0～100` 内。
- `typedef struct` 定义条目类型。
- `calloc` 申请并清零内存，`free` 释放内存。
- 哈希函数把键映射到槽位。
- 线性探测处理冲突。
- 哈希表必须在所有返回路径释放。

### 难点

第一层难点是把“结构体类型”和“结构体变量”分开，并理解每个成员属于同一条学生记录；输入校验还要同时处理读取失败、尾部多余字符和业务范围。

第二层难点才是哈希表：它同时用到结构体、动态内存、指针、取余和溢出检查。初学者容易只看“查找更快”，忽略容量、冲突、空槽和释放内存四个必要条件。两层要按顺序学习，不要因为见过哈希表中的 `typedef struct`，就跳过普通结构体变量。

### 掌握标准

- 能定义包含姓名、年龄和成绩的结构体，正确初始化并输出每个成员。
- 能解释为什么修改前要先验证输入，以及 `student1.score = a` 只改变一个字段。
- 能独立测试正常小数、`0`、`100`、越界值、字母和 `90abc` 这类尾部多余字符。
- 能把两名学生的数据改造成结构体数组，并用循环访问。
- 能解释 `HashEntry` 的每个字段。
- 能画出一次插入、一次命中、一次冲突探测。
- 能说明哈希版为什么平均更快，以及为什么有额外内存代价。
- 能独立完成基本的两数之和哈希查找流程。

## 阶段八：算法和博弈论入门

### 学习目标

能把题目拆成输入、状态变化、判断和输出，比较不同算法的代价，并用固定数据验证结果。

### 推荐练习

1. `C/13_算法练习` 中以 `01_` 到 `07_` 开头的蓝桥杯入门题
2. [两数之和暴力解](../C/13_算法练习/27_2026-10-18_两数之和_暴力枚举.c)
3. [第二大不同值算法与测试](../C/13_算法练习/36_2026-10-22_第二大不同值算法与测试.c)
4. [两数之和与水仙花数](../C/13_算法练习/35_2026-10-21_两数之和与水仙花数练习.c)
5. [巴什博弈](../C/13_算法练习/29_2026-10-18_巴什博弈.c)
6. [巴什博弈函数与测试](../C/13_算法练习/33_2026-10-19_巴什博弈函数与测试用例.c)

### 重点

- 先明确输入输出格式，再写逻辑。
- 双重循环的重复检查与边界。
- 一次遍历维护最大值、第二大不同值和“是否已经找到第二值”的状态标记。
- 用整除和取余拆出三位数的百位、十位和个位。
- 用函数返回布尔式结果，再由 `main` 决定是否输出。
- `n % (m + 1)` 的余数策略。
- 计算函数和打印函数分离。
- 用三组固定测试检查正常、边界和特殊局面。

### 难点

两数之和要明确“找到一组就返回”还是“打印所有满足条件的组合”。本仓库的 27 号练习返回第一组下标，35 号练习使用 `found` 标记并打印所有匹配项，两者的停止条件不同。

水仙花数练习中的 `isNarcissistic` 只按三位数拆分。`n / 100`、`(n / 10) % 10`、`n % 10` 分别对应百位、十位、个位，不能直接用于四位数或负数。程序把调用范围限定在 `100～999`，这是当前函数的明确使用边界。

第二大不同值不能用“排序后取倒数第二个”掩盖下标问题，也不能把重复最大值当成不同值。本题用 `hasSecond` 保存状态，避免把初始化时的 `0` 误当成真实答案；新最大值出现时还必须先保存旧最大值，再覆盖 `largest`。

### 掌握标准

- 能说出暴力解和优化解的时间、空间取舍。
- 能解释 `found` 的初始化、置位和最终判断。
- 能手工推演 `largest`、`second`、`hasSecond` 的更新，并解释全负数数组为什么不会得到 `0`。
- 能手算验证 `153`、`370`、`371`、`407` 这四个三位水仙花数。
- 能说明当前 `isNarcissistic` 为什么不适合直接处理四位数。
- 能手工推演巴什博弈的余数和补数。
- 能把核心判断抽成函数，并为函数设计测试输入。
- 不把“代码能运行”当作“答案正确”。

## 调试与复习

### 编译错误

先读第一条错误信息和行号。检查拼写、分号、括号、变量声明、类型和头文件。不要一次改十处。

### 运行错误

如果程序崩溃，优先检查空指针、越界、未初始化变量和 `scanf` 读取失败。macOS 可以用：

```bash
clang -std=c17 -g -Wall -Wextra -Wpedantic program.c -o /tmp/program
lldb /tmp/program
```

### 结果错误

在关键分支输出中间变量，确认“从哪一步开始与手算结果不一致”。打印不是最终修复，但能缩小问题范围。

### 复习方法

1. 合上源码，用自己的话写出题目目标和数据变化。
2. 重新写一版最小可运行程序。
3. 用正常、边界、特殊三组数据测试。
4. 对比原版，记录差异而不是立即照抄。
5. 一周后只保留题目要求，再写一遍。
