# Java 学习指南

这份指南负责 Java 知识体系、学习顺序、重点难点和掌握标准。具体程序的功能、运行结果和易错点以源码旁的逐题说明为准，仓库目录入口见 [Java 学习区](../Java/README.md)。

当前仓库有六份真实 Java 入门资源，已经覆盖程序入口、控制台输出、基本类型、主要运算符、输入校验和条件分支。循环、方法、数组、类和对象等仍未形成足够独立的练习，不能因为本指南提到就视为已经掌握。

## 先修知识

开始当前六份练习前，最好已经知道：

- 终端里什么是当前目录，怎样执行命令。
- 变量表示一个可以存放数据的命名位置。
- 整数和小数是不同的数。
- 程序通常按语句顺序执行。

不要求先学完 C 或 Python。Java 可以独立入门，但三种语言同时铺开容易把格式和类型规则混在一起。课程正在讲 Java 时，可以先完成 Java 入门阶段，再安排其他语言复习。

## 阶段一：程序结构与控制台输出

### 学习目标

- 认识 Java 源文件、类和 `main` 方法。
- 知道 `javac` 负责编译，`java` 负责启动类。
- 能使用 `System.out.println` 输出文字和变量。
- 区分语句末尾的英文分号与代码块的大括号。
- 理解 `public class` 的类名必须与源文件名大小写完全一致。

4. 把输出命令移到 `main` 外面，观察编译错误，并说明原因。

## 阶段二：基本数据类型与字面量

### 学习目标

- 区分八种基本类型：`byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。
- 知道 `String` 是引用类型，不是八种基本类型之一。
- 能为不同数据选择合理的类型，而不是一律使用 `int` 或 `double`。
- 认识 `L` 和 `F` 后缀的作用。
- 知道 `char` 使用单引号，`String` 使用双引号。

### 基本类型概览

| 类型 | 常见字节数 | 用途 | 本次程序中的值 |
| --- | ---: | --- | --- |
| `byte` | 1 | 很小的整数 | `100` |
| `short` | 2 | 小整数 | `30000` |
| `int` | 4 | 最常用的整数 | `2000000000` |
| `long` | 8 | 更大范围的整数 | `1000000000L` |
| `float` | 4 | 单精度小数 | `3` 自动转成 `3.0F` 的数值 |
| `double` | 8 | 默认小数类型 | `3.14159265358979` |
| `char` | 2 | 单个 UTF-16 代码单元 | `'A'` |
| `boolean` | 虚拟机相关 | 真或假 | `true` |

“常见字节数”不是建议靠背尺寸来判断容量；初学阶段更重要的是理解每种类型有固定范围，超出范围可能编译失败或溢出。`String` 用双引号保存文本，例如 `"Java"`。

### 检查点

1. 为年龄、人口、价格、单个字母和是否通过分别选一种类型，并说明理由。
2. 解释 `char` 与 `String` 的两个直接区别。
3. 解释 `10000000000` 与 `10000000000L` 为什么可能产生不同结果。

## 阶段三：转换、运算符与数值运算

### 学习目标

- 理解小范围数值自动转成大范围数值通常安全。
- 知道小数转整数、整数转较小整数需要强制转换，可能丢失数据。
- 掌握整数除法会截断小数部分。
- 理解字符参与算术运算时使用对应数值。
- 理解 `int` 溢出和宽化后再溢出是两件不同的事。
- 能使用算术、关系、逻辑和三元运算符。
- 区分 `&&` / `||` 的短路行为与 `&` / `|` 的双边求值。
- 知道 `i++` 与 `++i` 交出的值不同，并能跟踪简单表达式中的变量变化。

### 转换关系

常见的安全宽化方向：

```text
byte -> short -> int -> long -> float -> double
char -> int -> long -> float -> double
```

这不是说 `float` 能精确表示所有 `long` 整数。`float` 只有约 7 位有效十进制数字，数值很大时仍可能丢失精度。

强制转换只改变当前表达式的类型。例如：

```java
double price = 3.99;
int cut = (int) price;  // 结果是 3，直接舍弃小数部分
```

`(int) price` 不四舍五入。`(byte) 130` 只保留低 8 位，按二进制补码解释后得到 `-126`。

### 整数溢出

```java
int maxInt = Integer.MAX_VALUE;
int overflow = maxInt + 1;
```

`int` 最大值是 `2147483647`，加一后变成 `-2147483648`。Java 的整数运算会发生回绕，并不把这次普通算术溢出自动变成异常。

另一种常见陷阱是：

```java
long wrongLong = 2147483647 + 1;
long rightLong = 2147483647L + 1;
```

第一行先按两个 `int` 字面量计算，得到已经溢出的 `-2147483648`，然后才存进 `long`。第二行中有一个操作数是 `long`，整个加法按 `long` 计算，结果是 `2147483648`。

## 阶段四：输入、条件分支与 switch

### 学习目标

- 使用 `Scanner` 读取整数，并先用 `hasNextInt()` 检查输入类型。
- 在类型正确后继续检查数值范围，不把业务错误和输入类型错误混在一起。
- 使用 `if / else if` 处理区间和多个边界。
- 使用 `switch` 处理离散值，理解 `case` 入口、`break` 出口和 `default`。
- 能判断穿透是故意复用还是漏写出口。
- 为边界值设计测试，包括阈值两侧、满值和非法输入。

### 重点与难点

- `switch` 找到匹配入口后会一直向下执行，直到 `break` 或结构结束。
- `default` 只表示从哪里开始，不保证执行完就停止。
- 相邻 case 共用代码是可控穿透，忘记 `break` 才是常见错误。
- 闰年判断要覆盖普通闰年、普通平年、1900 和 2000。
- 成绩等级要测试 59、60、89、90、100 和超范围输入。
- `score / 10` 把分数范围变成整数入口，但必须处理 100 得到的 10。

### 检查点

1. 给定一个 `switch` 和输入，能按文本顺序写出全部输出。
2. 能解释为什么 1900 是平年、2000 是闰年。
3. 能用 59、60、89、90、100 验证成绩边界。
4. 能分别处理 `abc` 与 `101`，说明它们属于不同类型的错误。
5. 能独立写出一个带输入校验、使用 `if / else if` 的成绩等级程序。

## 与 C/Python 的关系

| 主题 | Java 特点 | 学习提醒 |
| --- | --- | --- |
| 程序入口 | 通常进入某个类的 `main` 方法 | 文件、类、运行命令三者要分清 |
| 整数 | 固定宽度，默认 `int` | 不会像 Python 整数一样自动扩展到任意大小 |
| 小数 | 默认 `double`，`float` 要加 `F` | 浮点数存在精度限制 |
| 布尔值 | `true` / `false` | 不能把数字直接当成布尔值 |
| 字符串 | `String` 是类，不是基本类型 | 双引号表示字符串，单引号表示字符 |
| 类型转换 | 宽化可自动，窄化常需强制 | 强制转换不等于安全检查 |
| 逻辑运算符 | `&&` / `||` 支持短路 | `&` / `|` 会计算两边，副作用不同 |
| 多分支 | `if / else if` 适合区间，`switch` 适合离散值 | `break` 决定是否继续穿透 |

不要只比较语法。重点是思考“这个值是什么类型、能表示多大、计算在哪个类型中完成”。

## 推荐学习流程

每个 Java 程序都按以下顺序使用：

1. 先读题目或程序目标，不急着逐行抄代码。
2. 运行程序，记录真实输出。
3. 按变量声明、类型转换、运算符、输入校验和分支分段阅读。
4. 手工写下关键变量的类型和值。
5. 只修改一个值，预测结果后再运行。
6. 故意制造一个编译错误和一个逻辑偏差，练习读错误信息。
7. 关闭源码，重新写一个小程序。
8. 用正常值、类型边界和容易溢出的值验证。

## 当前掌握标准

完成六份练习后，至少应能做到：

- 独立编写并编译一个包含 `main` 的 Java 类。
- 解释 `javac` 与 `java` 的分工。
- 列出八种基本类型，并说明 `String` 的区别。
- 根据数值范围选择 `int`、`long`、`float` 或 `double`。
- 解释自动转换、强制转换、整数除法和一次整数溢出。
- 知道 `long wrongLong = 2147483647 + 1` 为什么仍会得到负数。
- 解释短路与非短路的区别，并能跟踪一次自增表达式。
- 使用 `Scanner` 校验整数和范围。
- 追踪 `switch` 穿透，正确选择 `if / else if` 或 `switch`。
- 用边界数据验证闰年和成绩等级。

如果只能复述输出，不能手算变量类型和结果，说明还没有完成这一阶段。
