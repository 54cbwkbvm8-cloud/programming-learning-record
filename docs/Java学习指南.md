# Java 学习指南

这份指南负责 Java 知识体系、学习顺序、重点难点和掌握标准。具体程序的功能、运行结果和易错点以源码旁的逐题说明为准，仓库目录入口见 [Java 学习区](../Java/README.md)。

当前仓库有二十七份真实 Java 资源，已经覆盖程序入口、控制台输出、基本类型、主要运算符、输入校验、条件分支、循环、方法拆分与重载、值传递、数组引用、入门算法、内存版成绩管理项目，以及类与对象、构造方法、封装、`this`、`static` 和对象引用传参。继承、多态、接口、集合、文件持久化、二维数组、正式自动测试和工程构建仍未形成足够独立的练习，不能因为本指南提到就视为已经掌握。

## 先修知识

开始当前二十七份练习前，最好已经知道：

- 终端里什么是当前目录，怎样执行命令。
- 变量表示一个可以存放数据的命名位置。
- 整数和小数是不同的数。
- 程序通常按语句顺序执行。

不要求先学完 C 或 Python。Java 可以独立入门，但三种语言同时铺开容易把格式和类型规则混在一起。课程正在讲 Java 时，可以先完成 Java 入门阶段，再安排其他语言复习。

## 阶段二：基本数据类型与字面量

### 学习目标

- 区分八种基本类型：`byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。
- 知道 `String` 是引用类型，不是八种基本类型之一。
- 能为不同数据选择合理的类型，而不是一律使用 `int` 或 `double`。
- 认识 `L` 和 `F` 后缀的作用。
- 知道 `char` 使用单引号，`String` 使用双引号。

### 基本类型概览

| 类型 | 常见字节数 | 用途 | 本次程序中的值 |
| --- | ---: | --- | --- |
| `byte` | 1 | 很小的整数 | `100` |
| `short` | 2 | 小整数 | `30000` |
| `int` | 4 | 最常用的整数 | `2000000000` |
| `long` | 8 | 更大范围的整数 | `1000000000L` |
| `float` | 4 | 单精度小数 | `3` 自动转成 `3.0F` 的数值 |
| `double` | 8 | 默认小数类型 | `3.14159265358979` |
| `char` | 2 | 单个 UTF-16 代码单元 | `'A'` |
| `boolean` | 虚拟机相关 | 真或假 | `true` |

“常见字节数”不是建议靠背尺寸来判断容量；初学阶段更重要的是理解每种类型有固定范围，超出范围可能编译失败或溢出。`String` 用双引号保存文本，例如 `"Java"`。

### 检查点

1. 为年龄、人口、价格、单个字母和是否通过分别选一种类型，并说明理由。
2. 解释 `char` 与 `String` 的两个直接区别。
3. 解释 `10000000000` 与 `10000000000L` 为什么可能产生不同结果。

## 阶段三：转换、运算符与数值运算

### 学习目标

- 理解小范围数值自动转成大范围数值通常安全。
- 知道小数转整数、整数转较小整数需要强制转换，可能丢失数据。
- 掌握整数除法会截断小数部分。
- 理解字符参与算术运算时使用对应数值。
- 理解 `int` 溢出和宽化后再溢出是两件不同的事。
- 能使用算术、关系、逻辑和三元运算符。
- 区分 `&&` / `||` 的短路行为与 `&` / `|` 的双边求值。
- 知道 `i++` 与 `++i` 交出的值不同，并能跟踪简单表达式中的变量变化。

### 转换关系

常见的安全宽化方向：

```text
byte -> short -> int -> long -> float -> double
char -> int -> long -> float -> double
```

这不是说 `float` 能精确表示所有 `long` 整数。`float` 只有约 7 位有效十进制数字，数值很大时仍可能丢失精度。

强制转换只改变当前表达式的类型。例如：

```java
double price = 3.99;
int cut = (int) price;  // 结果是 3，直接舍弃小数部分
```

`(int) price` 不四舍五入。`(byte) 130` 只保留低 8 位，按二进制补码解释后得到 `-126`。

### 整数溢出

```java
int maxInt = Integer.MAX_VALUE;
int overflow = maxInt + 1;
```

`int` 最大值是 `2147483647`，加一后变成 `-2147483648`。Java 的整数运算会发生回绕，并不把这次普通算术溢出自动变成异常。

另一种常见陷阱是：

```java
long wrongLong = 2147483647 + 1;
long rightLong = 2147483647L + 1;
```

第一行先按两个 `int` 字面量计算，得到已经溢出的 `-2147483648`，然后才存进 `long`。第二行中有一个操作数是 `long`，整个加法按 `long` 计算，结果是 `2147483648`。

## 阶段五：循环、嵌套与重复处理

### 学习目标

- 理解 `for` 的初始化、条件、循环体和更新语句。
- 使用 `while` 表达“只知道停止条件、不固定次数”的循环。
- 区分 `while` 与 `do-while` 的首次判断时机和最少执行次数。
- 使用 `break` 结束整个循环，使用 `continue` 跳过当前一轮。
- 理解外层循环控制行、内层循环控制一行中的重复动作。
- 在循环中正确维护累加器、计数器、当前最大值和当前最小值。
- 让循环条件和变量更新共同保证程序最终能够结束。

### 循环选择

| 场景 | 推荐结构 | 原因 |
| --- | --- | --- |
| 明确知道执行次数 | `for` | 初始化、条件、更新集中在一个位置 |
| 不知道次数，只知道何时停 | `while` | 停止条件可以来自输入或状态变化 |
| 至少要先执行一次 | `do-while` | 先执行循环体，再判断是否继续 |
| 逐行处理二维形状 | 双层 `for` | 外层行变量可以限制内层列变量 |
| 满足条件时立即结束 | `while (true)` + `break` | 出口可以分散在循环体内部 |

### 重点与难点

- 循环条件为真不代表循环一定会结束，循环体必须让状态逐步离开继续条件。

### 重点与难点

- 数组变量保存引用。`int[] b = a;` 后两个变量指向同一数组，不产生第二组元素。
- 增强 `for` 的循环变量是元素值的副本。修改 `value` 不会替换数组中的元素。
- 下标合法范围是 `0` 到 `length - 1`。冒泡排序还要同时保证 `j + 1` 不越界。
- 冒泡排序每轮把当前最大值送到右端，所以内层上界应从 `n - 1` 再减去已经完成的轮数。
- `swapped` 只在本轮发生交换时变为 `true`；整轮没有交换说明数组已经有序。
- 数组参数可以修改元素，但把形参重新指向新数组不会替换调用者的数组变量。
- 二分查找必须先满足有序前提，并维护 `low <= high` 的闭区间。
- 二分查找遇到重复值时通常只保证返回某一个匹配下标，第一个或最后一个重复值需要专门设计。
- 当前 `check()` 只是打印教学检查结果，失败不会改变进程退出码，不能当作正式测试框架。
- 重载由方法名和参数列表共同决定；只有返回类型不同不能构成合法重载。
- Java 的参数都是按值复制。数组复制的是引用值，所以能通过共同引用改元素，但给形参重新赋新数组不会替换调用者变量。
- 素数判断只检查到约 `sqrt(n)`，用 `i <= n / i` 比 `i * i <= n` 更不容易在 `int` 上限附近溢出。
- 三位水仙花数算法固定拆百、十、个位，调用前必须限定三位数范围；能运行不代表输入边界已被校验。
- 数字拆位通常用 `% 10` 取末位、`/ 10` 去掉末位，循环处理未知位数时要使用临时变量。
- 求第二大不同值必须用状态区分“还没有第二值”和“第二值恰好是 0”，并完整读取所有元素。
- 数对统计的内层下标从 `i + 1` 开始，既避免自我配对，也避免交换顺序后重复计数。
- `SecondLargest.java` 当前保留两个真实逻辑错误：读取循环漏下标 0，`found` 输出分支写反。它适合练习调试，不是已修正标准答案。

## 阶段八：类、对象、封装与 static

### 学习目标

- 区分类与对象，使用 `new` 创建具体实例。
- 定义成员变量、无参构造、有参构造和实例方法。
- 理解有参构造会取消自动无参构造，需要通过显式无参构造或传入参数解决。
- 使用 `this` 区分同名字段与构造参数。
- 理解对象变量保存引用，引用赋值不会复制对象。
- 区分引用比较 `==` 与未来内容比较 `equals` 的职责。
- 使用 `private` 隐藏字段，通过 getter/setter 控制读写。
- 让构造方法和 setter 共用同一套合法性规则，避免绕过封装。
- 区分实例字段与 `static` 字段、实例方法与 `static` 方法。
- 理解对象作为参数时复制引用值：可修改共同对象，但重新赋值形参不影响调用者变量。

### 重点与难点

- 类只是模板，`new` 才创建对象；对象变量保存引用地址。
- `Student s3 = s2` 没有创建第三个对象，只是一个对象有两个引用变量。
- `this.name = name` 左边是当前对象字段，右边是构造参数；漏写 `this` 会让参数给自己赋值。
- 公开字段无法阻止非法值；封装不是简单增加 getter/setter，而是确保所有修改入口都经过规则。
- 构造方法如果绕过校验，对象可以在创建时直接进入非法状态。
- `static` 字段属于类，所有对象共享；普通字段属于每个对象。
- 静态方法不能直接访问具体实例字段。
- 对象参数复制的是引用值，方法能修改共同对象，但重新给参数赋新对象不会替换调用者的变量。
- `SafeStudent.count` 统计创建次数；`reassign` 中的临时对象也计入，因此最终为 4。
- 当前 `Student` 是未封装基础版，`SafeStudent` 是演示版，不能把两者当成同一个类。

## 与 C/Python 的关系

| 主题 | Java 特点 | 学习提醒 |
| --- | --- | --- |
| 程序入口 | 通常进入某个类的 `main` 方法 | 文件、类、运行命令三者要分清 |
| 整数 | 固定宽度，默认 `int` | 不会像 Python 整数一样自动扩展到任意大小 |
| 小数 | 默认 `double`，`float` 要加 `F` | 浮点数存在精度限制 |
| 布尔值 | `true` / `false` | 不能把数字直接当成布尔值 |
| 字符串 | `String` 是类，不是基本类型 | 双引号表示字符串，单引号表示字符 |
| 类型转换 | 宽化可自动，窄化常需强制 | 强制转换不等于安全检查 |
| 逻辑运算符 | `&&` / `||` 支持短路 | `&` / `|` 会计算两边，副作用不同 |
| 多分支 | `if / else if` 适合区间，`switch` 适合离散值 | `break` 决定是否继续穿透 |
| 循环 | `for / while / do-while` 结构与 C 接近，但条件必须是 `boolean` | 不能把整数 `1` 直接写成循环条件 |
| 随机数 | `Random.nextInt(bound)` 的下界为 0，上界不包含 | 需要 1 到 100 时要写 `nextInt(100) + 1` |
| 数组 | 数组是对象，长度通过 `arr.length` 获取 | 不能直接打印内容，使用 `Arrays.toString()` |
| 数组参数 | 参数按值传递，但复制的是引用值 | 方法能修改元素，重新给形参赋值不会替换调用者数组 |
| 查找与排序 | Java 自带 `Arrays.sort()` 和 `Arrays.binarySearch()` | 初学阶段先手写，理解前提、边界和算法行为 |

不要只比较语法。重点是思考“这个值是什么类型、能表示多大、计算在哪个类型中完成”。

## 推荐学习流程

每个 Java 程序都按以下顺序使用：

1. 先读题目或程序目标，不急着逐行抄代码。
2. 运行程序，记录真实输出。
3. 按变量声明、类型转换、运算符、输入校验、分支、循环、方法和数组分段阅读。
4. 手工写下关键变量的类型和值。
5. 只修改一个值，预测结果后再运行。
6. 故意制造一个编译错误和一个逻辑偏差，练习读错误信息。
7. 对数组画出引用关系，对排序和查找列出每轮下标与元素变化。
8. 关闭源码，重新写一个小程序。
9. 用正常值、类型边界、空数组、单元素和重复元素验证。
