## 01_基础练习

| 文件 | 类型 | 简介 | 功能 | 用途 |
| --- | --- | --- | --- | --- |
| `Python字典学习.py` | Python 脚本 | 字典成绩查询练习 | 创建学生成绩字典，统计平均分、最高分、最低分和及格情况，按姓名查询成绩 | 练习字典、列表推导式、排序和统计函数 |
| `代码三角形.py` | Python 脚本 | 星号三角形打印练习 | 根据 height 控制行数，并使用字符串乘法逐行打印三角形 | 练习 range、for 循环和字符串运算 |
| `列表学生名单.py` | Python 脚本 | 学生列表操作练习 | 添加和删除学生，读取指定位置并统计人数 | 练习列表 append、remove、索引和 len |
| `成绩评分.py` | Python 脚本 | 分数等级判断 | 读取 score，按区间输出 C、B、A、SSS 或范围提示 | 练习 input、类型转换和多分支判断 |
| `统计人数表，成绩，不及格，及格数.py` | Python 脚本 | 成绩统计脚本 | 计算总分、平均分、最高分、最低分，并分别统计及格和不及格人数与列表 | 练习列表遍历和常用聚合函数 |
| `输出久久乘法表.py` | Python 脚本 | 九九乘法表 | 使用双重循环输出 1 到 9 的完整乘法表 | 练习嵌套循环、range 和 f-string |
| `输出偶数.py` | Python 脚本 | 偶数输出练习 | 使用步长为 2 的 range 输出 0 到 100 的全部偶数 | 理解 range 的起点、终点和步长 |
| `复习题.py` | Python 脚本 | 学生成绩录入与统计练习 | 循环录入学生姓名和成绩，校验分数范围并分级，最后列出成绩、最高分和平均分 | 练习 while、条件分支、列表、循环和聚合函数 |
