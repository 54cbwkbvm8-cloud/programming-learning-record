## 逐题说明命名

- `名称_简介与学习建议.md`：一般练习的详细说明。
- `名称_零基础教程.md`：按行或按阶段逐步讲解。
- `名称_早期版.py`、`名称_旧版.c`：保留下来的历史版本，不参与正式学习顺序。
- `docs/legacy/`：迁移前的目录 README。它们保留当时的内容，用于历史对照，不作为当前导航。

## 查询示例

想学习“指针和数组”：

1. 在 [C 语言学习指南](C语言学习指南.md#阶段六指针与数组指针关系) 读取概念、难点和掌握标准。
2. 打开 [C/08_指针](../C/08_指针/) 按推荐顺序读源码。
3. 在每份源码旁打开对应的 `_简介与学习建议.md` 查看运行数据和常见错误。
4. 完成练习后回到指南检查掌握标准，再决定是否进入结构体、动态内存和哈希表。

想学习“成绩管理系统”：

1. 先完成 Python 列表、字典和输入校验阶段。
2. 按 [Python 学习指南](Python学习指南.md#阶段九综合项目) 的项目路线阅读。
3. 从列表雏形开始，逐步比较函数版、输入校验版、字典菜单版和 JSON 持久化版。

想查看某个具体源码的说明：

1. 打开源码所在目录。
2. 查找同主题名的 `_简介与学习建议.md` 或 `_零基础教程.md`。
3. 如果文件名没有完全一致，先根据同一前缀编号和时间判断对应关系。

## 文件移动与新增规则

详细规则见 [仓库结构说明](2026-09-12_仓库结构说明.md)。核心原则是：

- 先按语言，再按主要学习目标分类。
- 源码与对应说明保持同目录。
- 综合项目不拆散。
- 不创建没有实际文件的空目录。
- 不修改历史源码来配合文档结构调整。
