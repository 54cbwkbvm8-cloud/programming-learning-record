## 程序在做什么

链表节点由两部分组成：

```text
[data | next]
```

- `data` 保存整数。
- `next` 保存下一个节点的地址。
- 最后一个节点的 `next` 是 `NULL`。

程序先创建空链表：

```c
Node *head = NULL;
```

然后执行四次尾插：

```text
空链表
→ 10 → NULL
→ 10 → 20 → NULL
→ 10 → 20 → 30 → NULL
→ 10 → 20 → 30 → 40 → NULL
```

每插入一个节点，`traverse()` 都从 `head` 出发，沿 `next` 打印整条链表。

## 关键函数

### `creat_node`

该函数申请一个节点，写入数据，把 `next` 设为 `NULL`，最后返回节点地址。

```c
Node *new_node = (Node *)malloc(sizeof(Node));
```

其中：

- `sizeof(Node)` 表示一个节点需要多少字节。
- `malloc` 申请失败时返回 `NULL`。
- 只有申请成功后才能访问 `new_node->data` 和 `new_node->next`。

函数名中的 `creat` 是当前源码的拼写，标准写法通常是 `create`。本次不修改用户原始代码；单独重写练习时可以一并改正。

### `traverse`

```c
Node *current = head;
while (current != NULL) {
    printf("%d->", current->data);
    current = current->next;
}
```

变量变化示例：

| 轮次 | `current` 指向 | 输出 | 下一轮 |
| --- | --- | --- | --- |
| 1 | 节点 10 | `10->` | 节点 20 |
| 2 | 节点 20 | `20->` | 节点 30 |
| 3 | 节点 30 | `30->` | 节点 40 |
| 4 | 节点 40 | `40->` | `NULL` |
| 结束 | `NULL` | `NULL` | 退出循环 |

如果漏写：

```c
current = current->next;
```

`current` 会一直停在同一个节点，程序进入死循环。

### `insert_tall`

该函数完成尾插，核心过程是：

1. 先创建新节点。
2. 如果原链表为空，新节点就是新的头节点。
3. 如果原链表非空，从 `head` 开始走到最后一个节点。
4. 把最后一个节点的 `next` 接到新节点。
5. 返回原来的头指针。

寻找尾节点：

```c
Node *current = head;
while (current->next != NULL) {
    current = current->next;
}
current->next = new_node;
```

这里检查的是 `current->next`，不是 `current`。当 `current->next == NULL` 时，`current` 正好停在最后一个节点，下一句才能把新节点接在它后面。

函数名中的 `insert_tall` 是当前源码的拼写，通常应写成 `insert_tail`。本次保留源码原样，并在学习说明中记录这一可读性问题。

## 学习重点

1. **头指针是入口。** 遍历必须从 `head` 开始，不能从任意节点开始访问整条链。
2. **空链表要单独处理。** 原链表为空时没有尾节点可找，新节点直接成为头节点。
3. **尾插要先找尾。** 非空链表必须沿 `next` 走到最后一个节点。
4. **尾插通常返回头指针。** 非空链表头节点不变；空链表时返回的新头指针必须赋回 `head`。
5. **遍历条件用当前节点。** `while (current != NULL)` 在访问节点前后都会按预期结束。
6. **释放时先保存后继。** 释放当前节点后不能再读取它的 `next`。
7. **每次尾插都从头找尾。** 当前实现容易理解，但插入一次需要遍历已有节点，总时间复杂度是 `O(n²)`。

## 学习难点

### 难点 1：为什么要返回 `Node *`

尾插调用写成：

```c
head = insert_tall(head, 10);
```

原因是空链表时，新节点会成为新的头节点。即使普通参数按值传递，函数返回的新地址也可以交回 `main` 并写回 `head`。

### 难点 2：为什么判断 `current->next != NULL`

如果写成：

```c
while (current != NULL) {
    current = current->next;
}
```

循环结束后 `current` 是 `NULL`，无法再写：

```c
current->next = new_node;
```

尾插需要停在最后一个真实节点，因此检查最后一个节点的 `next` 是否为空。

### 难点 3：内存申请失败时如何通知调用者

当前 `insert_tall()` 在创建节点失败时只返回原来的 `head`：

```c
if (new_node == NULL) {
    return head;
}
```

所以调用者无法直接区分“插入成功”和“插入失败”。当前固定数据下不会触发内存申请失败，但真实项目应增加成功标志、错误码或空指针返回值等反馈方式。未经明确要求，本次不修改原始算法。

### 难点 4：全局变量与局部变量同名

源码第 7 行定义了全局指针 `new_node`，第 10 行又在函数内部定义同名局部变量。局部变量会遮蔽全局变量，所以链表操作实际使用的是函数内的局部变量。

这不会影响当前输出，却容易让读者误以为两个变量是同一个对象。重写版本应删除未使用的全局变量，并给局部变量使用清晰的名字。
