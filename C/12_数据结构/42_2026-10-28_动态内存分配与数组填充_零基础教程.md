# 动态内存分配与数组填充：零基础教程

## 1. 最终要完成什么

程序先问用户要多少个整数，然后在运行时申请一块刚好够用的内存，填入平方数，打印结果，最后释放这块内存。

例如输入 5：

```text
数组内容：1 4 9 16 25
```

## 2. 开始前要认识的概念

### 普通数组和动态数组

普通数组：

```c
int a[5];
```

容量在写代码时已经确定。

动态数组：

```c
int *a = malloc(n * sizeof(int));
```

容量要等程序运行、读到 `n` 后才确定。

### `malloc` 是什么

`malloc` 是 C 标准库函数：

```c
void *malloc(size_t bytes);
```

它向系统申请一块连续内存，并返回首地址。

当 `n=5` 时，可以画成：

```text
a
│
▼
[a[0]][a[1]][a[2]][a[3]][a[4]]
```

`a` 保存第一位地址，所以 `a[0]` 访问第一位。

### `free` 是什么

```c
free(a);
```

它告诉系统：“这块动态内存不再使用，可以回收。”

申请一次、释放一次。释放后不能继续访问 `a[0]`。

### `size_t` 是什么

`size_t` 是无符号的容量类型，适合表示元素数量和字节数。

```c
size_t n;
```

它不能表示负容量。输入/输出格式使用 `%zu`。

## 3. 完整程序的五个部分

1. 读取 `n`。
2. 检查 `n` 和乘法溢出。
3. `malloc` 申请内存并检查失败。
4. 填充和打印数组。
5. `free` 释放内存并置空。

## 4. 逐段讲解

### 第 1～4 行：头文件

```c
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
```

- `stdint.h` 提供 `SIZE_MAX`。
- `stdio.h` 提供输入输出。
- `stdlib.h` 提供 `malloc`、`free` 和 `EXIT` 相关功能。

### 第 6～11 行：读取容量

```c
size_t n;
scanf("%zu", &n)
```

`%zu` 读取 `size_t`。

条件：

```c
scanf(...) != 1 || n == 0
```

表示：

- 没读到一个有效无符号数；
- 或者读到了 0。

两种情况都退出。

### 第 12～15 行：检查乘法溢出

```c
n > SIZE_MAX / sizeof(int)
```

要申请的总字节数是：

```text
n * sizeof(int)
```

如果 `n` 太大，乘法可能超过 `SIZE_MAX`。先做除法比较，可以判断乘法是否安全。

### 第 16～20 行：申请内存

```c
int *a = malloc(n * sizeof(int));
if (a == NULL) {
    perror("malloc");
    return 1;
}
```

`malloc` 可能失败，例如内存不足。失败时返回 `NULL`。

`perror("malloc")` 会输出类似：

```text
malloc: Cannot allocate memory
```

实际错误文本随系统变化。

### 第 21～23 行：填充平方数

```c
for (size_t i = 0; i < n; i++) {
    a[i] = (int)((i + 1) * (i + 1));
}
```

下标从 0 到 `n - 1`。

下标的平方关系：

| 下标 | `i + 1` | 值 |
| --- | --- | --- |
| 0 | 1 | 1 |
| 1 | 2 | 4 |
| 2 | 3 | 9 |
| 3 | 4 | 16 |
| 4 | 5 | 25 |

### 第 24～27 行：输出

```c
printf("a[%zu] = %d ", i, a[i]);
```

`%zu` 对应 `i`，`%d` 对应数组元素。

### 第 28～29 行：释放

```c
free(a);
a = NULL;
```

`free` 归还整块内存。`a = NULL` 让指针不再保存旧地址，降低误用风险。

## 7. 边界与当前限制

### `0` 和读取失败

`0`、`abc` 会退出，状态为 1。

### `-1`

`%zu` 读取负号时会进行无符号转换，得到的容量极大；后面的乘法检查会拒绝。

### `3abc`

`scanf("%zu")` 会成功解析 3，留下 `abc`。因为程序后面不再读取输入，这次运行仍然完成。

如果以后加入“继续输入”或“再输入一个数”，残留的 `abc` 会造成下一次读取失败。更严格的写法是先读整行，再检查整行确实只有一个数字。

### 大平方数

`malloc` 只负责申请内存，不会检查存入的数值是否超出 `int`。

```text
46340² = 2,147,395,600   仍在 INT_MAX 内
46341² = 2,147,488,281   超过 INT_MAX
```

当前代码把平方数转换成 `int`。超过范围后结果不再可靠，本次实测已经看到负数。

解决办法不是修改 `malloc`，而是：

- 使用更宽的元素类型；
- 限制 `n`；
- 或在转换前检查数值范围。

## 8. 常见错误和调试方法

### 错误 1：分配字节数不足

```c
malloc(n)
```

这只申请了 `n` 字节，不是 `n` 个整数。

正确：

```c
malloc(n * sizeof(int))
```

### 错误 2：不检查 `NULL`

申请失败后继续写 `a[i]` 会解引用空指针，通常导致崩溃。

### 错误 3：忘记 `free`

程序结束后系统会回收全部进程内存，但长期运行或函数反复调用时会形成泄漏。规则仍然是“申请一次、释放一次”。

### 错误 4：释放后继续访问

```c
free(a);
a[0] = 10;    // 错误
```

这是悬空指针访问，属于未定义行为。

### 错误 5：只看编译是否通过

类型匹配只能说明代码能编译。元素值越界、`3abc` 的残留输入和释放后访问都要通过运行测试或静态分析发现。

### 调试顺序

1. 先打印 `n` 和 `sizeof(int)`。
2. 打印 `n * sizeof(int)`，但先确保乘法不会溢出。
3. 检查 `a` 是否为 `NULL`。
4. 用 `n=5` 检查填充和遍历。
5. 用 `n=0`、`abc`、`-1` 检查错误路径。
6. 最后在 AddressSanitizer 下检查越界和释放问题。
