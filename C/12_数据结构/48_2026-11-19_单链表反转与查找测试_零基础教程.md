# 单链表反转零基础教程

本教程配合 [48_2026-11-19_单链表反转与查找测试.c](48_2026-11-19_单链表反转与查找测试.c) 使用。第一次接触链表时，建议先读 [45 号零基础教程](45_2026-10-29_单链表尾插遍历删除与测试_零基础教程.md)，再来学习反转。

## 一、先明确目标

程序里有一条链表：

```text
10 -> 20 -> 30 -> NULL
```

反转后要变成：

```text
30 -> 20 -> 10 -> NULL
```

限制条件：

- 不申请新节点。
- 不交换节点里的 `data`。
- 只修改每个节点的 `next` 指针。

也就是说，节点还是原来那三个节点，只是“谁指向谁”全部反过来。

## 二、看代码前必须知道的概念

### 1. 节点

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

每个节点有两部分：

```text
+------+------+
| data | next |
+------+------+
```

`data` 存数据，`next` 存“下一个节点的地址”。最后一个节点的 `next` 是 `NULL`，表示后面没有了。

### 2. 头指针

`head` 不是节点，它保存第一个节点的地址：

```text
head
 |
 v
+----+----+     +----+----+     +----+------+
| 10 |  * | --> | 20 |  * | --> | 30 | NULL |
+----+----+     +----+----+     +----+------+
```

只要拿到 `head`，就能顺着每个节点的 `next` 找到整条链表。丢失 `head`，通常就再也找不回链表开头。

### 3. 指针变量保存的是地址

```c
Node *prev = NULL;
Node *current = head;
```

这两行不是复制节点，只是让两个指针变量保存地址：

```text
head ─┐
      v
     [10] -> [20] -> [30] -> NULL
      ^
current
```

`current = current->next;` 也只是让 `current` 改存下一个节点的地址，节点本身没有移动。

### 4. `malloc` 与 `free`

节点是用 `malloc` 申请的，函数结束后不会自动消失；用完后必须由 `free` 归还。反转过程不需要申请新节点，但整条链表最后仍要逐个释放。

## 三、反转需要三个指针

只看一个节点，反转要做的事是：

```text
让 current->next 改为指向 prev
```

例如处理 20 时：

```text
反转前：10 -> 20 -> 30
反转后：10 <- 20      30
```

但这里有一个危险：20 原来指向 30，一旦把 `20->next` 改成 10，就找不到 30 了。所以必须提前记住 30。

三个指针的分工：

| 指针 | 含义 |
| --- | --- |
| `prev` | 已经反转好的部分的头，也就是当前节点的“前一个” |
| `current` | 正在处理的节点 |
| `next` | 当前节点原来的下一个节点，也就是尚未处理部分的开头 |

对应到代码：

```c
Node *prev = NULL;
Node *current = head;
Node *next = NULL;
```

一开始还没有任何节点被反转，所以 `prev` 是 `NULL`；`current` 从原头节点开始。

## 四、用 10 -> 20 -> 30 走一遍

### 初始状态

```text
prev = NULL
current = 10

NULL     10 -> 20 -> 30 -> NULL
```

### 第 1 轮

四步：

```c
next = current->next;   // next = 20
current->next = prev;   // 10 的 next 改成 NULL
prev = current;         // prev = 10
current = next;         // current = 20
```

结果：

```text
NULL <- 10      20 -> 30 -> NULL
        ^       ^
       prev   current
```

10 已经掉头，成为反转部分的头；20 和 30 还没有处理。

### 第 2 轮

```c
next = current->next;   // next = 30
current->next = prev;   // 20 的 next 改成 10
prev = current;         // prev = 20
current = next;         // current = 30
```

结果：

```text
NULL <- 10 <- 20      30 -> NULL
               ^      ^
              prev  current
```

### 第 3 轮

```c
next = current->next;   // next = NULL
current->next = prev;   // 30 的 next 改成 20
prev = current;         // prev = 30
current = next;         // current = NULL
```

结果：

```text
NULL <- 10 <- 20 <- 30
                     ^
                    prev
current = NULL
```

`current` 变成 `NULL`，循环结束。此时 `prev` 指向 30，它就是反转后的新头。

### 汇总表

| 轮次 | 开始时的 `current` | `next` | 修改后的 `next` | 结束时的 `prev` | 结束时的 `current` |
| --- | --- | --- | --- | --- | --- |
| 开始 | 10 | — | — | `NULL` | 10 |
| 1 | 10 | 20 | 10 指向 `NULL` | 10 | 20 |
| 2 | 20 | 30 | 20 指向 10 | 20 | 30 |
| 3 | 30 | `NULL` | 30 指向 20 | 30 | `NULL` |

## 五、逐段读代码

### 1. 创建节点（第 7～16 行）

```c
Node *create_node(int value) {
    Node *node = (Node *)malloc(sizeof(Node));
    if (node == NULL) {
        printf("Memory allocation failed\n");
        exit(1);
    }
    node->data = value;
    node->next = NULL;
    return node;
}
```

要点：

- `sizeof(Node)` 是一个节点占多少字节。
- `malloc` 失败返回 `NULL`，所以必须检查。
- 新节点的 `next` 必须主动设为 `NULL`，不能假设它已经是 0。
- 失败时 `exit(1)` 直接结束程序，因此本函数不会把 `NULL` 返回给调用者。

### 2. 尾插（第 17～28 行）

```c
Node *push_back(Node *head, int value) {
    Node *new_node = create_node(value);
    if (head == NULL) {
        return new_node;
    }
    Node *tail = head;
    while (tail->next != NULL) {
        tail = tail->next;
    }
    tail->next = new_node;
    return head;
}
```

- 空链表：新节点就是头节点，必须 `return new_node`。
- 非空链表：`tail` 走到最后一个节点，把它的 `next` 接到新节点。
- 不直接移动 `head`，否则会丢失链表开头。

### 3. 从数组构建（第 29～35 行）

```c
Node *build_list(const int value[], int count) {
    Node *head = NULL;
    for (int i = 0; i < count; i++) {
        head = push_back(head, value[i]);
    }
    return head;
}
```

`head` 初始为 `NULL`，每次用返回值更新。`count == 0` 时循环不执行，返回空链表。

注意：每次尾插都要从头走到尾，构建长度为 `n` 的链表总代价接近 `O(n²)`。教学程序优先保证步骤清楚，暂不优化。

### 4. 打印、长度、查找（第 36～62 行）

```c
void print_list(Node *head) {
    Node *current = head;
    while (current != NULL) {
        printf("%d ", current->data);
        current = current->next;
    }
    printf("\n");
}
```

遍历三件套：

1. 用游标 `current` 从 `head` 开始。
2. 条件是 `current != NULL`。
3. 每轮末尾 `current = current->next`。

`list_length` 只是把“打印”换成“计数”。

`find_value` 找到匹配值时立即 `return current`，所以只返回第一个匹配节点；走完整条链表还没找到才返回 `NULL`。返回的是链表内部节点的地址，不能单独 `free`。

### 5. 反转（第 63～74 行）

```c
Node *reverse_list(Node *head) {
    Node *prev = NULL;
    Node *current = head;
    Node *next = NULL;
    while (current != NULL) {
        next = current->next;
        current->next = prev;
        prev = current;
        current = next;
    }
    return prev;
}
```

四步的顺序不能乱：

1. `next = current->next;`：先记住后半条链表。
2. `current->next = prev;`：当前节点掉头。
3. `prev = current;`：反转部分的头向前移动。
4. `current = next;`：处理下一个节点。

最容易犯的错误是把第 1 步和第 2 步调换。调换后 `current->next` 已经被改成 `prev`，再执行 `next = current->next` 只会得到 `prev`，后半条链表彻底丢失。

### 6. 释放（第 75～82 行）

```c
void free_list(Node *head) {
    Node *current = head;
    while (current != NULL) {
        Node *next = current->next;
        free(current);
        current = next;
    }
}
```

同样是“先保存后继，再释放当前”。释放后不能再访问 `current->data` 或 `current->next`。

### 7. 测试函数（第 83～101 行）

```c
void test_case(const char *name, const int value[], int count, int target) {
    printf("=============== 测试：%s ===============\n", name);
    Node *head = build_list(value, count);
    printf("原始链表：");
    print_list(head);
    printf("长度：%d\n", list_length(head));
    Node *found = find_value(head, target);
    if (found != NULL) {
        printf("查找节点：%d，找到了，节点值是：%d\n", target, found->data);
    } else {
        printf("查找节点：%d，没找到\n", target);
    }
    head = reverse_list(head);
    printf("反转后链表：");
    print_list(head);
    free_list(head);
    head = NULL;
    printf("释放链表：head 已置为 NULL，之后不再访问\n\n");
}
```

`test_case` 接收“名字、数组、元素个数、查找目标”四个参数，把整套流程封装一次。四组测试共用同一段逻辑，避免复制粘贴。

`head = reverse_list(head);` 很重要：反转后头节点变成原来的尾节点，必须用返回值更新 `head`。

`free_list(head); head = NULL;` 中的置空只影响 `test_case` 自己的局部变量，但能把“释放后不再使用”的习惯写清楚。

### 8. 主函数（第 102～111 行）

```c
int main(void) {
    int one[] = {5};
    int two[] = {1, 2};
    int three[] = {10, 20, 30};
    test_case("空链表", NULL, 0, 1);
    test_case("单节点", one, 1, 5);
    test_case("两节点", two, 2, 2);
    test_case("三节点(查找中间节点)", three, 3, 20);
    return 0;
}
```

空链表传入 `NULL` 和 `0` 是安全的，因为 `build_list` 在 `count == 0` 时不会访问数组。其余三组分别覆盖单节点、两节点和三节点。

## 六、边界情况为什么不用特殊处理

### 空链表

```text
head = NULL
current = NULL
循环一次也不执行
返回 prev = NULL
```

反转空链表仍为空，正确。

### 单节点

```text
prev = NULL
current = 5
第 1 轮：next = NULL；5->next = NULL；prev = 5；current = NULL
返回 prev = 5
```

单节点反转后仍是自己，正确。

这两个边界不需要写 `if (head == NULL)` 或 `if (head->next == NULL)`，因为循环条件已经自然处理了。

## 七、常见错误与排查方法

### 错误 1：先改 `next`，后保存后继

```c
current->next = prev;
next = current->next;   // 错：此时 next 等于 prev
```

现象：反转后只剩前一两个节点，后面的链表丢失，甚至形成环。

排查：在循环里打印 `current->data`、`next` 是否为空、`prev->data`，确认四步顺序。

### 错误 2：返回 `head`

```c
return head;   // 错
```

`head` 仍指向原来的第一个节点，而现在它已经是尾节点，`head->next` 可能是 `NULL` 或指向前一个节点。调用者会以为链表只有很短一截，甚至形成环。

正确：返回 `prev`。

### 错误 3：循环结束后返回 `current`

循环结束时 `current == NULL`，返回它等于返回空链表。

### 错误 4：忘记推进 `prev` 或 `current`

会导致死循环或反复处理同一个节点。每轮结束前检查四个变量是否都按预期变化。

### 错误 5：释放顺序错误

```c
free(current);
current = current->next;   // 错：读取已释放内存
```

必须先保存 `next`，再释放。

### 错误 6：把查找返回的指针单独释放

`find_value` 返回的是链表内部节点。单独 `free(found)` 会让链表中间出现悬空指针，后续遍历或整表释放会重复释放。
