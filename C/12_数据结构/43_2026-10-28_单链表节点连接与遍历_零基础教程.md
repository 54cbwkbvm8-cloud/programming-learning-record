# 单链表节点连接与遍历：零基础教程

## 1. 最终要完成什么

程序要创建三个彼此独立的动态节点，把它们连接成：

```text
10 → 20 → 30 → NULL
```

然后：

1. 输出三个节点的地址、数据和下一个地址。
2. 从第一个节点开始遍历。
3. 依次输出 10、20、30。
4. 释放三个节点，避免内存泄漏。

源码在同目录：

[43_2026-10-28_单链表节点连接与遍历.c](43_2026-10-28_单链表节点连接与遍历.c)

原文件名“数组链接”容易让人以为是数组。实际代码使用的是 `Node` 和 `next`，属于单链表。

## 2. 开始前要认识的概念

### 一个节点是什么

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

每个节点有两个字段：

| 字段 | 作用 |
| --- | --- |
| `data` | 保存数据，这里是整数 |
| `next` | 保存下一个节点的地址 |

`struct Node *next` 表示 `next` 指向“和自己是同一种类型”的结构体，这叫自引用结构体。

### `NULL` 是什么

`NULL` 表示“没有指向有效对象”。

链尾使用：

```c
next = NULL;
```

表示后面没有节点。

### `node1` 是什么

`node1` 是保存第一个节点地址的指针。它是访问整条链表的入口，可以把它看作“头指针”。

```text
node1 ──> [10|next] ──> [20|next] ──> [30|NULL]
```

### 为什么不用普通数组

数组元素连续排列；链表节点由多次 `malloc` 分配，不保证连续。

数组可以按下标直接访问；单链表只能从头沿 `next` 一个个走。

## 4. 逐段讲解

### 第 1～6 行：头文件和节点类型

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

`stdlib.h` 用于 `malloc` 和 `free`。

结构体内部不能直接写：

```c
Node *next;
```

因为此时 `typedef` 别名 `Node` 还没有完成。可写成：

```c
struct Node *next;
```

### 第 7～16 行：创建一个节点

```c
Node *new_node = (Node *)malloc(sizeof(Node));
```

`sizeof(Node)` 等于一个节点占用的字节数，通常是：

```text
4 字节 data + 填充 + 8 字节指针
```

具体大小由编译器和平台决定，不需要手算固定值。

申请后：

```c
new_node->data = value;
new_node->next = NULL;
```

这两句很重要：

- `data` 写入调用者给的值。
- `next` 必须明确为空，不能保留未初始化垃圾值。

最后返回地址：

```c
return new_node;
```

如果申请失败：

```c
if (new_node == NULL) {
    return NULL;
}
```

不能对 `NULL` 执行 `new_node->data`。

### 第 18～20 行：创建三个节点

```c
Node *node1 = create_node(10);
Node *node2 = create_node(20);
Node *node3 = create_node(30);
```

此时三个节点互相独立：

```text
node1 → [10|NULL]
node2 → [20|NULL]
node3 → [30|NULL]
```

还没有形成链表，因为它们的 `next` 都是空。

### 第 21～27 行：失败清理

```c
if (node1 == NULL || node2 == NULL || node3 == NULL)
```

只要任意一个为空，就清理已经申请成功的节点。

`free(NULL)` 是安全的，因此可以统一写：

```c
free(node1);
free(node2);
free(node3);
```

### 第 28～29 行：连接

```c
node1->next = node2;
node2->next = node3;
```

第一句把 node2 的地址写进 node1 的 `next`。第二句同理。

连接后：

```text
node1 ──> node2 ──> node3 ──> NULL
```

注意：不是把 node2 整块复制进 node1，而是 node1 的 `next` 保存 node2 的地址。

### 第 30～36 行：输出结构

```c
(void *)node1
```

表示 node1 自己指向的节点地址。

```c
(void *)node1->next
```

表示 node1 记录的下一个节点地址。

理想关系：

```text
node1->next == node2
node2->next == node3
node3->next == NULL
```

实际打印出来的地址每次运行都可能变化，所以不要背某个十六进制数。

### 第 37～40 行：判断链尾和连续访问

```c
node3->next == NULL
```

说明 node3 是链尾。

```c
node1->next->next->data
```

按顺序拆：

```text
node1
→ node2
→ node3
→ node3.data
```

结果是 30。

这段能工作，前提是连接完整，而且中间所有指针都不为空。

### 第 42～48 行：用 `while` 正式遍历

```c
Node *current = node1;
while (current != NULL) {
    printf("%d\n", current->data);
    current = current->next;
}
```

`current` 不复制节点，只保存节点地址。

移动过程：

| 轮次 | `current` | 输出 | 下一步 |
| --- | --- | --- | --- |
| 1 | node1 | 10 | node1->next |
| 2 | node2 | 20 | node2->next |
| 3 | node3 | 30 | node3->next |
| 4 | NULL | 停止 | 无 |

如果忘记：

```c
current = current->next;
```

会永远打印同一个节点，形成无限循环。

### 第 49～54 行：释放节点

```c
while (current != NULL) {
    Node *next_node = current->next;
    free(current);
    current = next_node;
}
```

顺序必须这样：

1. 读取并保存当前节点的 `next`。
2. 释放当前节点。
3. 把当前指针移动到保存的后继。

不能写成：

```c
free(current);
current = current->next;  // 错误：current 已失效
```

释放后节点内存不再属于本程序的有效数据，继续访问是未定义行为。

关键输出：


## 6. 手工跟踪一次链表

假设三个节点地址分别记为 A、B、C：

| 节点指针 | 节点地址 | `data` | `next` |
| --- | --- | --- | --- |
| `node1` | A | 10 | B |
| `node2` | B | 20 | C |
| `node3` | C | 30 | NULL |

访问表达式：

| 表达式 | 结果 |
| --- | --- |
| `node1->data` | 10 |
| `node1->next` | B |
| `node1->next->data` | 20 |
| `node1->next->next` | C |
| `node1->next->next->data` | 30 |
| `node1->next->next->next` | NULL |

## 7. 边界和当前版本范围

当前链表固定为三个节点：

- 支持创建、连接、输出、遍历和释放。
- 不支持插入新节点。
- 不支持删除任意节点。
- 不支持查找。
- 不支持成环检测。
- 没有单独的链表结构体保存长度。

这些不是当前程序的错误，而是版本边界。

三个节点对应三次 `malloc`，因此也有三次 `free`。创建失败清理路径同样会释放所有非空节点。

## 8. 常见错误和调试方法

### 错误 1：忘记初始化 `next`

```c
new_node->data = value;
return new_node;
```

此时 `next` 是垃圾值，遍历可能跳到无效地址。必须写 `new_node->next = NULL`。

### 错误 2：用 `.` 访问指针节点

```c
node1.data   // 错误：node1 是指针
```

正确：

```c
node1->data
```

### 错误 3：忘记移动 `current`

遍历会卡在第一个节点。

### 错误 4：先释放再读 `next`

释放后的节点不可访问。必须先保存 `next_node`。

### 错误 5：只释放头节点

那只释放一块节点，后两个节点泄漏。

### 错误 6：认为地址连续

链表节点可能相隔很远。它们只靠指针连接，不靠索引相邻。

### 调试顺序

1. 每次 `create_node` 后打印地址、data 和 next。
2. 设置连接后打印 `node1->next == node2`。
3. 检查 `node3->next == NULL`。
4. 单独遍历一次，不释放。
5. 在 AddressSanitizer 下运行完整程序。
6. 故意重复 `free` 一次，在临时版本中观察工具报告。
