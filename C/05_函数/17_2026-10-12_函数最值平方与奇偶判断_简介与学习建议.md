# C 语言 10 月 12 日函数练习：文件简介与学习建议

## 文件简介

- **源码文件：** `17_2026-10-12_函数最值平方与奇偶判断.c`
- **类型：** C 语言函数基础练习
- **功能：** 输入两个整数 `a`、`b`，调用三个自写函数依次输出：`max(a, b)` 求两者中的最大值、`square(a)` 求 `a` 的平方、`is_even(a)` 判断 `a` 是不是偶数（返回 `1` 表示偶数，`0` 表示奇数）。
- **主要知识点：** **函数声明（原型）**、函数定义与调用、参数与返回值、`if / else` 与 `return`、取余运算 `%`、格式符 `%d`。

这份练习和 `07_2026-10-02_函数基础练习.c` 是同一组函数，但有两个明显不同，值得对照着读：

1. **多了函数声明。** 文件开头三行 `int max(int a, int b);` 只告诉编译器"有这么三个函数"，真正的定义写在后面。这叫**函数原型**，它的作用是让 `main` 可以放心地写在前面，不必担心"函数还没定义就被调用"。
2. **平方和奇偶判断的对象是 `a`，不是最大值。** `07` 号文件是对"较大的那个数"求平方和判奇偶，这一份直接作用于输入的 `a`，`max` 只用来输出最大值。两份代码只差几个字母，读懂这点区别，才算真正看清函数参数是怎么传进去的。

## 建议运行数据

程序只需要输入一次，两个整数用空格或回车分开：

```text
5 8
```

主要预期结果：

```text
请输入a和b的值：最大值为：8
a的平方为：25
a是否为偶数：0  (1为偶数，0为奇数)
```

（在终端里交互运行时，`5 8` 会出现在"请输入a和b的值："后面；上面是把输入单独列一行，方便对照。）

换几组数据核对每个函数：

| 输入 | 最大值 `max(a,b)` | `a` 的平方 `square(a)` | `a` 是否为偶数 `is_even(a)` |
| --- | --- | --- | --- |
| `5 8` | 8 | 25 | 0（奇数） |
| `4 9` | 9 | 16 | 1（偶数） |
| `-3 7` | 7 | 9 | 0（奇数） |
| `6 -2` | 6 | 36 | 1（偶数） |

注意最后两行：负数也能正常求平方（`-3 × -3 = 9`），而 `-3` 会被判成奇数——原因见下面第 5 条。

## 零基础学习建议

1. **先认清"声明"和"定义"。** 开头三行是函数声明，只带分号、没有大括号，作用是"提前打个招呼"；后面带大括号、写了具体步骤的才是定义。声明里参数名可以省略，例如写成 `int max(int, int);` 也完全合法，因为编译器只关心类型和个数。
2. **三个函数各代表一种常见套路。**

   ```c
   int max(int a, int b) {          /* 用 if/else 挑出较大的一个 */
       if (a > b) { return a; } else { return b; }
   }
   int square(int a) { return a * a; }              /* 一行算完 */
   int is_even(int a) { ... return 1; ... return 0; }  /* 返回 1 或 0 */
   ```

   它们刚好覆盖了函数的三种典型写法：多分支返回、直接返回表达式、把"是/否"编码成 `1/0`。
3. **`is_even` 返回的是数字，不是文字。** 它用 `1` 表示"是"，`0` 表示"否"，所以 `printf` 才用 `%d` 打印。这种写法以后可以直接当条件用，例如 `if (is_even(a))`，比在函数里打印中文提示更灵活。
4. **看 `main` 里这三行调用：**

   ```c
   printf("最大值为：%d\n", max(a, b));    /* 把 a、b 传进去 */
   printf("a的平方为：%d\n", square(a));   /* 只传 a */
   printf("a是否为偶数：%d  (1为偶数，0为奇数)\n", is_even(a));
   ```

   调用时括号里的东西叫**实参**，函数定义里括号里的叫**形参**。`max` 要两个参数，所以写 `max(a, b)`；`square`、`is_even` 只要一个，所以只写 `(a)`。个数对不上，编译就会报错。
5. **为什么 `-3` 被判成奇数？** C 语言里 `-3 % 2` 的结果是 `-1`，它不等于 `0`，所以 `is_even(-3)` 返回 `0`。而 Python 里 `-3 % 2` 等于 `1`，同样不等于 `0`。两个语言算出的中间值不一样，但"`-3` 是奇数"的结论一致——这是对比 C 和 Python 时很值得留意的一个点。

## 常见易错点

- **只写定义、想调用时却报"未声明"。** 如果函数定义放在 `main` 之后，就必须像本文件这样在最前面写上声明。C99 以后不再允许"隐式声明"，所以这一步不能省。
- **把函数名当成变量用。** `printf("%d", max)` 打印的不是最大值，而是函数地址；一定要写成 `max(a, b)` 才是调用。这类错误编译器通常会给出明显警告（如 `%d` 期望 `int`），别忽略它。
- **声明和定义的签名要一致。** 返回类型、参数个数、参数类型必须对上。写成 `int max(int a);` 声明、`int max(int a, int b)` 定义，就是"声明与定义冲突"。
- **只对 `a` 求平方和判奇偶。** 本文件输出的是 `square(a)`、`is_even(a)`，和输入的 `b` 无关。想让结果跟着最大值走，就要改成 `square(max(a, b))`——这也正好是 `07` 号文件的写法。
- **`scanf("%d %d", &a, &b)` 的两个 `&` 不能丢。** 少了 `&` 会写进错误的内存地址，程序可能崩溃或输出乱码。
- **输入不是整数时不会自动重来。** 这里没有像 `13_2026-10-10_数组输入校验与成绩统计.c` 那样检查 `scanf` 的返回值，输入字母会让 `a`、`b` 变成不确定的值，结果全错。想更稳，可以加上返回值判断。

## 可以继续尝试

1. 照葫芦画瓢加一个 `int min(int a, int b)`，输出最小值，把"求极值"这一对函数凑齐。
2. 把 `is_even` 化简成一行 `return a % 2 == 0;`，体会"比较表达式本身就是结果"的写法，再想想和现在的 `if/else` 版哪个更好读。
3. 新增 `int cube(int a) { return a * a * a; }`，练习三个函数之间互相调用。
4. 让 `square` 和 `is_even` 作用于**较大的那个数**，也就是改写为 `square(max(a, b))`，然后和 `07_2026-10-02_函数基础练习.c` 对照，说说哪种更符合题目要求。
5. 把参数换成 `double`、格式符换成 `%f`（或用 `%g`），让平方能算小数，顺便比较 `int` 和 `double` 的区别。
6. 把三个函数的定义整体移到 `main` 后面，只保留开头的声明，重新编译——亲眼看一遍"声明的作用"。
