# C 语言 10 月 18 日两数之和暴力枚举：文件简介与学习建议

## 文件简介

- **源码文件：** `27_2026-10-18_两数之和_暴力枚举.c`
- **类型：** C 语言函数、数组和嵌套循环算法练习。
- **功能：** 在整数数组 `num` 中查找两个不同下标，使两个元素之和等于 `target`；找到时把两个下标写入 `result[2]` 并返回 `1`，没找到时返回 `0`。
- **当前示例：** `nums = {2, 7, 11, 15}`，`target = 9`，答案下标为 `0` 和 `1`。
- **主要知识点：** 数组作函数参数、显式传入数组长度、双层 `for` 循环、结果通过数组带回、返回状态码、`sizeof` 求数组元素个数。

程序先由 `main` 创建固定的测试数组，再调用 `two_sum`。函数开始时把结果初始化为 `-1`，找到答案后立即填入下标并返回，因此示例只检查到第一组解就结束。

## 零基础学习建议

1. **先分清“数组”和“数组长度”。** `num[]` 进入函数后会退化为指向首元素的指针，所以函数还必须接收 `n`，否则它无法知道有多少个元素。
2. **盯住两个循环的起点。** 外层 `i` 从 `0` 走到 `n - 1`，内层 `j` 从 `i + 1` 开始。这样每一对下标只检查一次，也避免同一个元素被使用两次。
3. **理解返回值的含义。** `two_sum` 返回的不是两个下标本身，而是“有没有找到”的状态：`1` 表示找到，`0` 表示没找到。真正的答案放在 `result` 数组中。
4. **为什么 `result` 可以带回答案？** 因为 `main` 把数组首地址传给了函数，函数通过 `result[0]`、`result[1]` 写入的是 `main` 里同一块内存。
5. **先算概率，再学复杂度。** 最坏情况下每一对元素都要比较一次，元素数量是 `n` 时大约做 `n(n - 1) / 2` 次判断，所以时间复杂度是 `O(n²)`。
6. **能自己写出版本。** 合上文件后，应该能独立写出函数签名、把结果初始化为 `-1`、使用 `i + 1` 起步的双层循环，并在找到时立即返回。

## 常见易错点

- 忘记 `result[0] = -1` 和 `result[1] = -1`，没找到时调用者可能读到旧数据。
- 当前函数没有检查 `result` 是否为 `NULL`，调用者必须提供可写的两个整数位置。若以后要写通用函数，应像 `28` 号那样先做参数校验。
- 内层从 `j = 0` 开始，造成重复检查和元素自配。
- 用 `num[i] == target - num[j]` 时思路没错，但要保证比较的是两个不同下标。
- 把数组下标当作元素值返回。题目要求的是下标 `[i, j]`。
- 在函数里写 `sizeof(num)` 求元素个数。数组参数已经变成指针，结果通常是指针大小，不是整个数组大小。
- 示例数字很小，因此 `num[i] + num[j]` 没有溢出；如果输入可能接近 `int` 最大值，加法本身也可能溢出，可以改成 `(long long)num[i] + num[j]` 后再比较。
- 当前函数按“题目只有一组答案”的约定，找到第一组就返回，不会继续搜集其他答案。
