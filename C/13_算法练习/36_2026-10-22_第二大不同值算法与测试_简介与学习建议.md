## 程序功能说明

### 核心函数

```c
int findSecondLargestDistinct(const int arr[], int n, int *answer);
```

这个函数通过返回值表示“是否找到答案”：

- 返回 `1`：数组至少有两个不同值，`*answer` 保存第二大不同值。
- 返回 `0`：参数无效，或者所有元素都相同，没有第二大不同值。

不能用普通返回值直接表示“找到的值”，因为所有整数都可能是合法答案，单独返回 `0` 无法区分“答案是 0”和“没有得到答案”。因此本题使用状态码作为返回值，再通过 `answer` 指针带回真正结果。

### 参数检查

```c
if (arr == NULL || answer == NULL || n < 2) {
    return 0;
}
```

`arr` 或 `answer` 为空时不能解引用；元素少于两个时也不可能存在两个不同值。把检查放在读取 `arr[0]` 之前，避免空数组访问第一个元素。

### 三个状态变量

```c
int largest = arr[0];
int second = 0;
int hasSecond = 0;
```

- `largest` 记录目前见到的最大值。
- `second` 准备保存目前见到的第二大不同值。
- `hasSecond` 表示 `second` 是否已经有意义。

`second` 临时写成 `0` 只是为了初始化，真正是否可使用由 `hasSecond` 决定。这样数组全部为负数时，程序不会错误地认为 `0` 是答案。

### 一次遍历怎样更新

遍历从 `arr[1]` 开始，每个元素只有几类情况：

1. `arr[i] > largest`：原来的最大值退为第二大值，新元素成为最大值。
2. `arr[i] == largest`：重复的最大值不算新的不同值，直接忽略。
3. `arr[i] < largest` 且还没有第二大值：当前元素先成为第二大值。
4. 已经存在第二大值：只有 `arr[i] > second` 时才替换它。

以题目示例 `{4, 8, 8, 3, 6}` 为例：

| 处理到 | `largest` | `second` | `hasSecond` | 说明 |
| --- | --- | --- | --- | --- |
| 初始 | `4` | 未确定 | `0` | 先取首元素 |
| `8` | `8` | `4` | `1` | 新最大值出现，旧最大值退到第二 |
| `8` | `8` | `4` | `1` | 与最大值相同，忽略 |
| `3` | `8` | `4` | `1` | `3 > 4` 不成立，不替换 |
| `6` | `8` | `6` | `1` | `6 > 4`，更新第二 |

最终输出 `6`。整个过程只扫描一遍数组，时间复杂度是 `O(n)`；只保存两个候选值和标记，额外空间复杂度是 `O(1)`。

### 全负数为什么也正确

对 `{-8, -2, -2, -5}`：

- 首元素 `-8` 成为 `largest`；
- `-2` 比 `-8` 大，所以 `second = -8`，`largest = -2`；
- 第二个 `-2` 与最大值相同，忽略；
- `-5` 小于 `-2`，但大于当前的 `-8`，所以 `second` 更新成 `-5`。

答案不是 `0`，而是 `-5`。这正是 `hasSecond` 标记不可省略的原因。

### 输出与测试框架

`printArray` 负责统一打印中括号数组，并对空指针或非正长度输出 `[]`。`runTest` 每次重新把 `answer` 初始化为 `0`，再根据函数返回值选择成功或失败提示。

固定测试覆盖：

- 题目示例；
- 全部元素相同；
- 最大值重复；
- 全负数；
- 只有两个不同元素；
- 只有一个元素；
- 空数组。

## 学习重点

1. **先分清“最大值”和“第二大不同值”。** 数组中可以有多个相同的最大值，但它们只算一个不同的最大数值。
2. **理解 `hasSecond`。** 它回答“第二候选是否已经出现”，不能只用 `second == 0` 判断，因为 `0` 本身可能是合法答案。
3. **理解更新顺序。** 新最大值出现时，必须先让旧最大值退为第二，再覆盖 `largest`；顺序写反会丢失旧值。
4. **理解参数 `answer`。** 函数返回值表示成功或失败，真正的整数答案写进调用者提供的变量地址。调用时传入 `&answer`。
5. **理解空指针检查的位置。** `arr[0]` 必须在确认 `arr != NULL` 且 `n >= 2` 之后才能访问。
6. **理解测试覆盖。** 全相同检查“没有第二值”，重复最大值检查“重复不算不同值”，全负数检查“初始化 0 的陷阱”。
7. **理解复杂度。** 不需要排序，单次遍历即可，`O(n)` 时间、`O(1)` 额外空间。

## 学习难点

- 只会求最大值，没有意识到还需要一个独立的第二候选。
- 用 `second = 0` 直接当作“未找到”状态，导致负数数组或答案 `0` 出错。
- 遇到重复最大值时把它当成第二值，错误地输出同一个数值。
- 在 `arr[i] > largest` 分支中先改 `largest`，再写 `second = largest`，结果两个变量都变成新最大值。
- 忘记检查 `answer == NULL`，或者调用函数时传入 `answer` 而不是 `&answer`。
- 在 `n < 2` 检查前读取 `arr[0]`，空数组会越界。
- 认为“代码能运行”就代表所有输入正确，没有测试全相同、重复最大值、全负数和空数组。
- 题目虽然简单，但只比较返回值不看 `answer`，仍可能漏掉输出结果是否正确。

## 零基础学习流程

1. **先手工做示例。** 不运行程序，写出 `[4, 8, 8, 3, 6]` 每一步的 `largest`、`second` 和 `hasSecond`。
2. **再手算负数。** 解释为什么 `second` 初始值是 `0`，最终答案却是 `-5`。
3. **分段阅读函数。** 第一段看参数检查，第二段看初始值，第三段看三个更新分支，第四段看返回结果。
4. **运行并核对七组输出。** 每一组都先说预期，再看实际结果。
5. **只改一处。** 把题目示例中的第一个 `8` 改成 `9`，预测答案并运行。
6. **制造边界。** 增加 `{0, -1}`、`{0, 0, 1}`、`{-1, 0}` 三组数据，重点检查 `0` 能否作为第二大值。
7. **关闭源码重写。** 先写出只处理合法数组的版本，再加入空指针、长度不足和全相同检查。
8. **用自己的话总结。** 能说明为什么这题需要“两个候选值 + 一个状态标记”，才算真正理解。
