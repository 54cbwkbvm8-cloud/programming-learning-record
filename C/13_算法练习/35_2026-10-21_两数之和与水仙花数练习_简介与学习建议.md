# C 语言 10 月 21 日两数之和与水仙花数：文件简介与学习建议

## 文件简介

- **源码文件：** `35_2026-10-21_两数之和与水仙花数练习.c`
- **所属分类：** `C/13_算法练习`
- **程序用途：** 用固定数据完成两个小算法任务：
  1. 在数组 `{4, 1, 8, 7, 3}` 中寻找和为 `10` 的两个元素；
  2. 输出 `100` 到 `999` 之间的全部水仙花数。
- **主要知识点：** 一维数组、双层循环、`sizeof` 求数组长度、`found` 标记、函数定义与调用、整数除法、取余、三位数拆分、`for` 遍历固定范围。
- **前置知识：** 变量、函数、数组、`for` 循环、`if` 判断、整数除法与取余。
- **相关练习：** [两数之和暴力枚举](27_2026-10-18_两数之和_暴力枚举.c) 专门研究两数之和并返回第一组下标；本文件的第一个任务改为直接打印所有和为目标的组合，第二个任务再练习三位数拆分和水仙花数判断，因此两文件不是重复版本。

程序不需要输入，所有数据写在 `main` 中，适合先手算、再运行、最后改数据验证。

## 程序功能说明

### 任务一：两数之和

程序先保存数组和目标值：

```c
int nums[] = {4, 1, 8, 7, 3};
int target = 10;
int size = sizeof(nums) / sizeof(nums[0]);
```

`size` 通过“数组总字节数除以单个元素字节数”得到元素个数。外层 `i` 固定第一个下标，内层 `j` 从 `i + 1` 开始，保证两个下标不同，也不重复检查同一对组合。

```c
for (int i = 0; i < size; i++) {
    for (int j = i + 1; j < size; j++) {
        if (nums[i] + nums[j] == target) {
            printf("找到：%d + %d = %d\n", nums[i], nums[j], target);
            found = 1;
        }
    }
}
```

找到组合后把 `found` 设为 `1`，循环结束后再用 `if (!found)` 输出“未找到”。当前数组中只有 `7 + 3` 等于 `10`。

### 任务二：水仙花数

水仙花数在这里指三位数，满足“百位、十位、个位的立方和等于原数”。函数先用整数运算拆出三个数字：

```c
int hundreds = n / 100;
int tens = (n / 10) % 10;
int ones = n % 10;
```

例如 `153`：

- `153 / 100` 得到百位 `1`；
- `153 / 10` 得到 `15`，再 `% 10` 得到十位 `5`；
- `153 % 10` 得到个位 `3`；
- `1³ + 5³ + 3³ = 153`，所以 `153` 是水仙花数。

`main` 用 `for (int n = 100; n <= 999; n++)` 遍历所有三位数，每次调用 `isNarcissistic(n)`，条件为真就打印。

这个函数的分位算法只针对三位数，程序也只在 `100～999` 范围内调用它。把它直接用于两位数、四位数或负数，不能得到通用的水仙花数判断。

## 学习重点

1. **先分清两个任务。** 两数之和使用双层循环和数组下标；水仙花数使用函数和整数拆位。它们共享循环和判断，但解决的问题不同。
2. **理解 `sizeof(nums) / sizeof(nums[0])`。** 这只在数组定义仍然完整可见时可靠；数组一旦作为函数参数传入，通常需要另外传入长度。
3. **理解内层循环从 `i + 1` 开始。** 这样避免同一元素和自己配对，也避免把 `(4, 7)` 和 `(7, 4)` 当成两组重复组合。
4. **理解 `found` 的作用。** 它记录是否至少找到一组答案。不能在循环中直接判断“找到”后退出，因为本程序希望继续检查并打印所有组合。
5. **把整数除法与取余结合起来。** 百位、十位、个位的拆法来自十进制位置关系，不只是背公式；手算 `153`、`370` 的拆分过程能帮助理解。
6. **知道函数把判断和打印分开。** `isNarcissistic` 只回答“是不是”，是否输出由 `main` 决定，这让函数更容易单独测试和复用。

## 学习难点

- 把 `size` 算成数组字节数而不是元素个数，或者误把 `sizeof(nums)` 当作元素数量。
- 内层循环写成 `j = 0`，导致同一元素自配和重复组合。
- `found` 没有初始化为 `0`，或在找到一组后错误地提前结束，导致无法输出全部组合。
- 十位公式写错。`n / 10 % 10` 才是十位；只写 `n % 10` 会再次得到个位。
- 水仙花数公式漏掉一个数字的立方，或者把 `==` 写成 `=`。
- 把 `isNarcissistic` 拿去判断任意位数的整数。当前函数固定按三位数拆位，应该有明确的使用边界。
- 只看程序有没有输出，不检查输出是否完整。水仙花数的标准结果应包含 `153、370、371、407` 四个数。

## 零基础学习流程

1. **先手算任务一。** 在数组 `[4, 1, 8, 7, 3]` 中找出所有和等于 `10` 的下标对，不运行程序。
2. **手算任务二。** 分别拆出 `153`、`370`、`371`、`407` 的百位、十位和个位，验证立方和。
3. **按函数分段阅读。** 先读 `isNarcissistic`，再读 `main` 的两数之和部分，最后读水仙花数循环。
4. **运行程序。** 对照自己手算的结果，确认两数之和只打印 `7 + 3`，水仙花数打印四个数。
5. **只改一处。** 先把 `target` 改成 `9` 或 `11`，观察两数之和的 `found` 分支；再修改数组中的某个元素，记录输出怎样变化。
6. **测试边界。** 把水仙花数循环暂时改成 `100～101`，确认不会误报；再恢复原范围。
7. **独立重写。** 关闭源码，分别重写两数之和和三位水仙花数判断，不要先看答案。
8. **总结复盘。** 用自己的话解释为什么内层从 `i + 1` 开始、为什么 `153` 是水仙花数，以及为什么当前拆位算法不能处理四位数。
