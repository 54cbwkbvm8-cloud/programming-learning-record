# C 语言 10 月 19 日指针算术与数组偏移练习：文件简介与学习建议

## 文件简介

- **源码文件：** `31_2026-10-19_指针算术与数组偏移练习.c`
- **类型：** C 语言指针与一维数组基础练习。
- **功能：** 用两组固定整数数组演示指针加上偏移量后，怎样通过 `*p`、`p[0]`、`*(p - 1)`、`*(p + 1)` 和 `p[-1]` 取得相邻元素。
- **主要知识点：** 一维数组、指针初始化、指针加减、数组下标与指针解引用的等价关系、指针的有效访问范围。

程序不需要输入。第一组数组是 `{10, 20, 30, 40, 50}`，指针 `p = a + 2` 指向 `a[2]`；第二组数组是 `{3, 6, 9, 12}`，指针 `q = b + 2` 指向 `b[2]`。两次演示的结构相同，第二组用于确认结果不是照抄第一组输出。

## 核心理解

### 1. `a + 2` 不是把地址数值直接加 2

`a` 在这里参与指针运算，会变成指向首元素 `a[0]` 的地址。因为 `a` 的元素类型是 `int`，所以 `a + 2` 会向后移动两个 `int` 元素，而不是只移动两个字节。

```c
int *p = a + 2;  /* p 指向 a[2] */
```

### 2. 下标和解引用可以互相改写

`p[0]` 等价于 `*(p + 0)`，也就是 `*p`。同理，`p[-1]` 等价于 `*(p - 1)`。

| 表达式 | 第一组的结果 | 对应元素 |
| --- | --- | --- |
| `*p` | `30` | `a[2]` |
| `p[0]` | `30` | `a[2]` |
| `*(p - 1)` | `20` | `a[1]` |
| `p[-1]` | `20` | `a[1]` |
| `*(p + 1)` | `40` | `a[3]` |

第二组把同样的关系套到 `{3, 6, 9, 12}` 上：

| 表达式 | 第二组的结果 | 对应元素 |
| --- | --- | --- |
| `*q` | `9` | `b[2]` |
| `q[0]` | `9` | `b[2]` |
| `*(q - 1)` | `6` | `b[1]` |
| `q[-1]` | `6` | `b[1]` |
| `*(q + 1)` | `12` | `b[3]` |

### 3. 指针加减会改变“看哪个元素”，但不会自动检查边界

这组练习里的 `p - 1`、`p + 1`、`q - 1`、`q + 1` 都在数组范围内，因此结果是确定的。若继续取 `p + 3`，就已经越过 `a` 的最后一个元素，程序不会因为语法正确就保证访问安全。

## 零基础学习建议

1. **先画内存格子。** 在纸上写出 `a[0]` 到 `a[4]` 五个格子，把 `p` 的箭头画到 `a[2]`。每次看到 `p - 1` 或 `p + 1`，先移动箭头再取值。
2. **把下标改成指针表达式。** 读到 `p[0]` 时改写成 `*(p + 0)`，读到 `p[-1]` 时改写成 `*(p - 1)`。反复对照后，会明白下标只是解引用的一种写法。
3. **重点区分 `*p + 1` 和 `*(p + 1)`。** `*p + 1` 是“当前元素的值加 1”，本练习没有写这个表达式；`*(p + 1)` 是“下一个元素的值”。先算括号里的指针移动，再解引用。
4. **检查左右边界。** 对 `p = a + 2` 来说，合法的相邻格子是 `a[0]` 到 `a[4]`。超过这个范围即使能编译，也不应当访问。
5. **自己替换数据验算。** 把第一组数组改成 `{2, 4, 6, 8, 10}`，先手算 `*p`、`p[-1]`、`*(p + 1)`，再编译运行。能预测结果，才算真正掌握指针移动。
6. **达到独立解释的程度。** 合上程序后，能回答为什么 `p[0]`、`*p` 和 `*(a + 2)` 得到同一个值，也能说明 `int *` 加 1 会跨过一个完整的 `int`。

## 常见易错点

- 把 `a + 2` 理解成“地址数值加 2 个字节”。指针加减的单位是它指向的元素类型。
- 把 `p[0]` 误认为数组第一个元素。`p[0]` 表示“`p` 当前指向的元素”，这里是 `a[2]`。
- 把 `p[-1]` 当成非法语法。只要 `p - 1` 仍在有效数组范围内，它和 `*(p - 1)` 等价。
- 把 `*(p + 1)` 写成 `*p + 1`。前者取下一个元素，后者把当前元素加 1。
- 只检查等号左边是否像指针，却没有检查右边是否仍指向有效元素。
- 修改数组大小后仍固定写 `a + 2`，却不检查下标 `2` 是否还存在。
