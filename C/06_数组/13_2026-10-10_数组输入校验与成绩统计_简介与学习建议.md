# c 语言练习 10 月 10 日：文件简介与学习建议

## 文件简介

- **源码文件：** `13_2026-10-10_数组输入校验与成绩统计.c`
- **类型：** C 语言数组 + 输入校验 + 统计综合练习
- **功能：** 固定录入 5 个学生成绩，逐个检查输入是否合法，最后输出平均分、最高分和最低分。
- **主要知识点：** `#define` 定义常量、`float` 数组、`scanf` 返回值检查、用 `getchar` 清空输入缓冲区、`i--` 回退重读、累加器初始化、以数组第一个元素作为最大值和最小值的初值、下标从 0 开始。

程序可以分成三段阅读：

1. **输入阶段**：用 `#define N 5` 控制人数，循环提示并读入成绩。`scanf("%f", &scores[i]) != 1` 表示这次读取失败，于是打印提示、清空缓冲区、`i--` 后重新读同一个位置。
2. **求和阶段**：单独的 `for` 循环把 5 个成绩累加到 `sum`，再用 `average = sum / N` 计算平均分。
3. **求极值阶段**：先把 `max` 和 `min` 都设成 `scores[0]`，再从下标 1 开始逐个比较，大于 `max` 就更新 `max`，小于 `min` 就更新 `min`。

和前几天相比，这份代码有两处明显进步：一是把"输入错误直接结束程序"改成了"提示后重新输入"，二是最大值和最小值用第一个元素作初值，不再用 0 起步。这两点都是上一份练习里专门提醒过的。

## 零基础学习建议

1. 先看 `#define N 5`：它给 5 起了个名字 `N`。以后想统计 10 个学生，只要把这一行改成 `#define N 10`，输入循环和平均值计算 `sum / N` 都会一起生效，不用再去改好几处数字。
2. 数组 `float scores[N];` 开辟了 5 个能存小数的格子，下标是 `scores[0]` 到 `scores[4]`。提示语里显示的是"第 i + 1 个学生"，因为给人看的序号从 1 开始，而给数组用的下标从 0 开始，这个差 1 的关系一定要分清。
3. 输入校验这一段是本次的重点，逐句读：
   - `if (scanf("%f", &scores[i]) != 1)`：`scanf` 返回成功读到的项数，读到 0 项就是失败。
   - `while ((c = getchar()) != '\n' && c != EOF);`：把缓冲区里剩下的字符一直读到换行为止，否则残留的字符会立刻让下一次读取再次失败。
   - `i--;`：让循环变量退回去一步，`continue` 之后再执行 `i++`，等于重新读同一个下标。
4. 统计最大值和最小值时，`max = scores[0]; min = scores[0];` 写在循环之前，循环从下标 1 开始。这样做的好处是无论成绩全是正数、全是负数还是全相同，结果都正确。
5. 注意 `max` 和 `min` 两个 `if` 是彼此独立的，一个成绩可以同时让最大和最小发生变化（比如 5 个成绩全相同时）；不要改成 `else if`。
6. `average = sum / N;` 里 `sum` 是 `float`，`N` 是整数常量，相除得到的是小数除法，所以结果是 80.8 而不是 80。如果写成 `int sum = 0;`，这里就会变成整数除法，丢掉小数部分。
7. 输出用 `%.2f` 保留两位小数，输入用 `%f`。两者的区别是：`%f` 只管读，`%.2f` 才控制显示几位。

## 常见易错点

- `float max; float min;` 声明时没有赋初值，靠后面的 `max = scores[0];` 补上。如果循环写在赋值之前，就会用到不确定的值。声明和初始化尽量靠近，读代码时更清楚。
- 输入校验里 `i--;` 是配合 `for (i = 0; i < N; i++)` 的 `i++` 使用的。如果把循环改成 `while`，这段"回退"的写法就要跟着调整，不能直接照搬。
- 清空缓冲区的写法是空循环体 `while (...) ;`，末尾的分号很容易被当成笔误删掉。删掉之后循环体就变成了后面的语句，行为会完全不同。
- 提示语 `printf("请输入%d 个学生的成绩:\n", N);` 和单条提示 `printf("请输入第%d 个学生的成绩:", i + 1);` 末尾没有换行，所以 5 条提示会和输入挤在同一行显示，这是原文件的写法。
- 成绩只存在数组里，程序结束后就没了。想保存下来，需要学习文件读写（Python 那边已经用 `students.json` 练过，C 语言对应的是 `fopen`/`fprintf`）。
- 平均分用的是 5 个成绩，如果以后允许中途减少人数，`sum / N` 里的除数就要换成实际录入的个数，否则平均分会算错。
- 代码里没有判断成绩是否在 0～100 之间。输入 `666` 或 `-10` 程序照样接受，这类范围校验属于业务规则，需要自己补上。

## 进阶练习

1. 增加 0～100 的范围校验：读取成功后用 `if (scores[i] < 0 || scores[i] > 100)` 判断，超出范围就提示并 `i--` 重读，复用现在的回退思路。
2. 把统计逻辑封装成函数，例如 `float average(float a[], int n)`、`float max_of(float a[], int n)`、`float min_of(float a[], int n)`，让 `main` 只负责输入和输出。数组作参数时必须同时传长度 `n`。
3. 让用户先输入人数 `n`，用 `float scores[100];` 这样一个足够大的数组接收，再检查 `n` 是否在 1～100 之间。
4. 在输出里加上"及格人数"和"不及格人数"，练习在循环里配合计数器。
5. 把成绩按从高到低排序后输出，把前几天的双重循环排序和今天的统计结合起来。
6. 把 `float` 改成 `double` 并把 `scanf` 的 `%f` 换成 `%lf`，观察输出精度变化，理解 `float` 和 `double` 的区别。
7. 增加一个"输入 0 结束录入"的版本：不用固定 `N`，读一个存一个，直到输入 0 为止，练习"数量不确定的输入"该怎么写循环。
