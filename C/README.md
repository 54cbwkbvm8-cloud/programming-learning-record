完整的知识体系、难点分析、掌握标准和复习方法见 [C 语言学习指南](../docs/C语言学习指南.md)。本页只负责分类导航和练习顺序。

## 每份练习怎么用

1. 先阅读源码，遇到不认识的语句先查对应知识点说明。
2. 手工跟踪一组输入，写下每个变量在循环或函数调用中的变化。
3. 编译并运行，对照学习说明中的建议输入和预期输出。
4. 单独修改一个条件或初值，观察结果怎样变化。
5. 合上源码独立重写，至少测试正常、边界和特殊数据。
6. 最后阅读同目录的易错点与拓展练习，把没有解决的问题记录到自己的复习笔记。

在仓库根目录编译：

```bash
clang -std=c17 -Wall -Wextra -Wpedantic \
  "C/01_基础语法/01_2026-09-28_基础语法综合练习.c" \
  -o /tmp/c_practice
/tmp/c_practice
```

macOS 环境检查、调试和 Git 操作见 [开发环境与 Git 操作指南](../docs/开发环境与Git操作指南.md)。

## 学习说明的组织方式

- `_简介与学习建议.md`：文件用途、运行数据、重点、易错点和拓展练习。
- `_零基础教程.md`：按行号逐步解释代码，适合第一次阅读较长程序。
- 同一道题有多个版本时，源码和说明保持相邻，不拆到不同目录。

## 维护规则

新增 C 练习时：

1. 根据主要学习目标选择现有目录；结构体成为独立学习主题并有真实练习支撑时，按仓库结构说明新增分类。
2. 文件名使用 `NN_YYYY-MM-DD_主题.c`，日期填首次进入仓库的日期。
3. 同目录新增学习说明，至少包含文件简介、运行数据、学习建议和易错点。
4. 涉及数组、指针、结构体等复合知识时，按“主要学习目标”归类，不重复存放。
5. 综合性练习放入 `14_综合项目`，不要把同一项目拆到多个知识点目录。
