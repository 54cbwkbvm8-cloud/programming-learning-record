# 99 早期版本归档

这个目录保存**早期版本**的文件：它们是同一个程序在加注释、改写法之前的原始样子，或者是被后来的版本取代的旧文件。

放在这里而不是删除，是因为它们有对照价值：把早期版和现在的正式版放在一起看，能直观看到"加了注释、改了写法之后"到底变了什么。

**这一目录不参与正式学习顺序**，想看的时候再翻。

## 为什么单独放一个目录

- **根目录要干净。** 一个学习仓库的根目录只应该放仓库说明和目录，散落的文件会让人不知道从哪看起。
- **正式版本和早期版本不要混在一起。** 否则打开目录时会看到两份很像的文件，容易拿错。
- **历史不要丢。** 早期版记录了当时的写法，是"自己进步了多少"的最好证据。

## 怎么看这些归档文件

1. 先读正式版，理解程序要做什么。
2. 再打开对应的早期版，比较两版的差别。
3. 问自己一个问题：如果现在让你重写一遍，你会保留早期版的哪些写法，又会改掉哪些？
