# 练习题 10 月 10 日：文件简介与学习建议

## 文件简介

- **源码文件：** `06_10-10_菜单式五题练习.c`
- **类型：** 蓝桥杯基础题菜单式练习，一题一个函数，共五道题
- **功能：** 程序先让用户输入题号（1～5），再用 `if / else if` 分发到对应的函数：

  1. **题 1 A+B：** 读入两个整数并输出它们的和。
  2. **题 2 数列求和：** 读入 `n`，用公式 `n * (n + 1) / 2` 输出 1～n 的和。
  3. **题 3 闰年判断：** 读入年份，输出 `yes` 或 `no`。
  4. **题 4 水仙花数：** 输出 100～999 中所有各位数字立方和等于自身的数。
  5. **题 5 排序：** 读入 `n` 和 `n` 个整数，从小到大排序后输出。

- **主要知识点：** 函数定义与调用（`void` 无返回值、`int` 返回 1/0）、菜单式程序结构、`if / else if` 多分支分发、`long long` 与 `%lld`、算术公式求和、逻辑运算 `&&` 与 `||` 的优先级、多重循环求水仙花数、双重循环排序与变量交换。

这份代码是第一次把五道独立的题目"打包"进同一个程序：`main` 只负责读题号和分发，具体逻辑各自写在 `p1_abc`、`p2_sequence_sum` 等函数里。这种"一问一答、一题一函数"的写法，正是后面写更复杂程序要用的拆分思路。

## 建议运行数据

运行后先输入题号，再按题目要求输入数据。下面这组数据已经实测过：

| 题号 | 输入 | 预期输出 |
| --- | --- | --- |
| 1 | `3 4` | `7` |
| 2 | `100` | `5050` |
| 2 | `1000000000` | `500000000500000000` |
| 3 | `2024` | `yes` |
| 3 | `2023` | `no` |
| 3 | `1900` | `no` |
| 4 | 无需输入 | `153`、`370`、`371`、`407`，最后一行空行 |
| 5 | 先输 `5`，再输 `3 1 4 1 5` | `1 1 3 4 5` |
| 6（或其他数字） | 任意 | `输入错误！请输入1～5之间的整数。` |

几组值得自己算一遍的对照数据：

| 检查点 | 输入 | 结果 | 说明 |
| --- | --- | --- | --- |
| 闰年 | 2024 | `yes` | 能被 4 整除且不能被 100 整除 |
| 整百年 | 1900 | `no` | 能被 100 整除但不能被 400 整除，不算闰年 |
| 整百年 | 2000 | `yes` | 能被 400 整除，算闰年 |
| 排序 | `1 1 4 3 5` | `1 1 3 4 5` | 有重复数据也要能排对 |
| 排序 | `-3 0 -9` | `-9 -3 0` | 负数同样适用 |

由于题 2 用的是除法公式，输入很大的 `n` 时 `n * (n + 1)` 也可能溢出，这也是本题故意使用 `long long` 的原因：`1000000000` 的和是 `500000000500000000`，已经远远超出 `int` 能表示的范围。

## 零基础学习建议

1. 先只看 `main`：它读入一个 `choice`，然后用一串 `if / else if` 判断题号。理解"分发"这个词——`main` 本身不解决问题，只负责把任务转交给对应的函数。
2. 题 1 和题 2 是最基础的输入输出，先跑通这两题建立信心。题 2 的公式 `n * (n + 1) / 2` 就是等差数列求和公式，先乘后除的顺序不能反。
3. 题 3 的闰年条件是 `(year % 4 == 0 && year % 100 != 0) || year % 400 == 0`。括号很重要：它把"普通闰年"和"整百年闰年"分成两组，中间用 `||` 连接。建议用 2023、2024、1900、2000 四个年份各跑一次，把这四个分支都覆盖到。
4. 题 4 值得重点看结构：先写一个 `int is_narcissistic(int x)`，用 `if (cube_sum == x) return 1; else return 0;` 返回判断结果；再在 `p4_narcissistic` 里循环 100～999，用 `if (is_narcissistic(i))` 直接当条件用。这就是"函数返回值可以当作条件"的典型写法，以后会经常用到。
5. 题 5 是双重循环排序：外层 `i` 固定一个位置，内层 `j` 从 `i + 1` 往后找，发现更小的就交换。交换三步是 `temp = a[i]; a[i] = a[j]; a[j] = temp;`，`temp` 是临时中转站，缺了它两个数会互相覆盖。
6. 在纸上跟踪一遍排序：以 `3 1 4 1 5` 为例，写出每一轮 `i`、`j` 的值和数组当下的样子。跟踪完这一遍，比看十遍代码都有用。
7. 输出部分用了 `if (i > 0) printf(" ");` 来控制空格，这样最后一个数字后面不会多出空格。可以先改成"每个数字后面都加空格"，对比两种输出格式的差别。

## 常见易错点

- `scanf("%d", &choice)` 没有检查返回值。如果输入字母而不是数字，`choice` 会保持 0，程序走到最后的 `else` 打印"输入错误"，这算是歪打正着；但更严谨的写法是 `if (scanf("%d", &choice) != 1) { ... }`。
- 题 5 的数组写死成 `int a[205];`，但 `n` 没有范围校验。如果输入的 `n` 大于 205，就会越界写入，结果不可预测。正式比赛中要先读题目给的数据范围，再把数组开够。
- 题 5 里 `int a[205];` 写在 `scanf` 语句之后，属于 C99 及以后支持的"变量声明可以在语句中间"的写法。用很老的编译器（C89/C90）时，所有声明要放在函数开头。
- `printf("请输入题号（1～5）：");` 末尾没有换行，所以提示语和后面的输入、结果会挤在同一行。这是本程序保留的写法，想要界面更整齐可以在末尾补 `\n`。
- 题 2 的公式是"先乘后除"。如果写成 `n / 2 * (n + 1)`，当 `n` 是奇数时 `n / 2` 会先被截断成整数，结果就错了。整数除法只在除得尽的时候才安全。
- 水仙花数判断里的 `hundreds * hundreds * hundreds` 也可以用 `pow`，但初学者用连乘更清楚，也避免了 `pow` 返回 `double` 再比较的精度问题。
- 五道题共用同一个 `main`，所以每次运行只能做一题。想连续做多题，需要在 `main` 外面再套一层循环（见下面的进阶练习）。

## 可以继续尝试

1. 把菜单改成循环：在 `main` 外面套 `while (1)`，做完一题后提示"是否继续"，输入 0 退出，练习菜单程序的完整结构。
2. 给每道题补上输入校验。例如题 5 里判断 `n` 是否在 1～205 之间，超出范围就提示重新输入。
3. 题 4 改成"输入两个整数 `a` 和 `b`，输出它们之间所有的水仙花数"，把固定范围 100～999 换成用户输入的范围。
4. 题 5 的输出加一个选项：让用户选择升序还是降序。降序只要把 `if (a[i] > a[j])` 改成 `if (a[i] < a[j])`，比较一次符号就能体会排序方向由谁决定。
5. 给题 5 增加"去重"功能：排序完成后输出时跳过和前一个相同的数字，得到 `1 3 4 5`。
6. 把题 2 改写成循环累加版本 `for (i = 1; i <= n; i++) sum += i;`，再和公式版本对比：同一个结果，两种思路，一个快一个直观。
7. 增加题 6：判断一个整数是否为质数，写出 `int is_prime(int x)`，用和 `is_narcissistic` 相同的方式返回 1/0。
