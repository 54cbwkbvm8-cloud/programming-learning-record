## 推荐学习顺序

1. `01_09-29_十个整数统计练习.c` — 先练"读入一批数字再统计"的基本套路，重点理解最大值为什么不能用 0 作初值。
2. `02_10-02_基础综合练习.c` — 把分支、循环、数组串起来。
3. `03_10-03_基础题综合练习.c` — 综合题，**注意里面的最小值 bug 需要按文档自行修正**。
4. `04_10-06_算法综合练习.c` — 再做一遍综合练习，检查熟练度。
5. `05_10-09_循环输入与统计.c` — 学会用 `#define` 管理数量，以及用 `scanf` 返回值检查输入。
6. `06_10-10_菜单式五题练习.c` — 最新、也最完整的一份：一题一个函数，用菜单分发，是这一目录的收尾练习。

## 练习方法

1. **先自己写，再看代码。** 拿到题目先用自己的思路写一版，哪怕跑不过也没关系，再对照仓库里的实现找差距。
2. **至少测三类数据**：普通数据、边界数据（最大值、最小值、空输入）、特殊数据（全负数、全部相同）。
3. **出错先定位再修改。** 找到具体是哪一行、哪一个分支的问题，只改那一处，改完立刻重新编译运行。
4. **完成后记录三件事**：本题用到的语法、容易出错的地方、下次可以怎么改进。这三条记录下来，复习时比重新读一遍代码更有效。
5. **关注"初值陷阱"。** 求最大值、最小值、求和时，初值选错是最常见的失分点。这一目录里 `01` 和 `05` 都用了"第一个元素作初值"的正确写法，值得反复看。
