# 蓝桥杯 10-11 数组统计与三的倍数：文件简介与学习建议

## 文件简介

- **源码文件：** `07_10-11_数组统计与三的倍数.c`
- **类型：** 蓝桥杯基础训练，输入个数由用户决定的一维数组统计题
- **功能：** 程序分两段完成任务：

  1. **数组统计**：先输入数字个数 `num`，再输入 `num` 个整数，然后输出这些数字的和、偶数个数、最大值和最小值。
  2. **输出三的倍数**：输出 1～100 之间所有能被 3 整除的数。

- **主要知识点：** `#define` 定义数组容量上限、用变量控制数组实际使用长度、`scanf` 返回值检查、输入范围检查、以数组首元素初始化最大值和最小值、`long long` 与 `%lld`、一次遍历同时完成多项统计。

这份练习是"数组大小不再写死"的第一步：数组容量用常量 `N` 开好，实际处理几个元素由用户输入的 `num` 决定。这种写法在算法题里非常常见。

## 建议运行数据

### 普通数据

```text
5
4 9 12 7 20
```

实测输出：

```text
这5个数字的和为：52
这5个数字中偶数的个数为：3
这5个数字中最大的数为：20
这5个数字中最小的数为：4
```

其中的三的倍数段会输出（节选）：`3 6 9 12 15 … 99`，共 33 个数。

### 再测几组

| 输入个数与数字 | 和 | 偶数个数 | 最大值 | 最小值 |
| --- | --- | --- | --- | --- |
| `5` + `4 9 12 7 20` | 52 | 3 | 20 | 4 |
| `3` + `-5 -8 0` | -13 | 2 | 0 | -8 |
| `1` + `7` | 7 | 0 | 7 | 7 |
| `4` + `-1 -2 -3 -4` | -10 | 2 | -1 | -4 |

第三组是单元素边界：只有一个数字时，最大值和最小值都应该是它自己。

第二组里 `-8` 和 `0` 都算偶数（`-8 % 2` 等于 0），所以偶数个数是 2。

### 输入错误的情况

| 输入 | 结果 |
| --- | --- |
| 个数输入 `0` 或 `1001` | 提示"数字个数必须在1到1000之间！"并结束 |
| 个数输入字母 | 提示"输入错误！"并结束 |
| 数字列表里输入字母 | 提示"输入错误！"并结束 |

这三条都是靠 `scanf(...) != 1` 和范围判断实现的，是本文件的亮点。

## 零基础学习建议

1. `#define N 1000` 给 1000 起了名字 `N`，数组写成 `int a[N]`。以后想改成最多 5000 个数，只改这一行就够了。这就是"用常量管理容量"的好处。
2. **容量和实际长度是两回事**：`a[N]` 是能装 1000 个数的空盒子，实际用了几个由 `num` 决定。所以后面所有循环写的是 `i < num`，而不是 `i < N`。这是本文件最值得记住的一点。
3. `if (scanf("%d", &num) != 1)` 判断读取是否成功。`scanf` 返回成功读到的项数，读到字母会返回 0，程序就打印错误并 `return 1` 结束。先检查再使用，是稳妥的写法。
4. 读完 `num` 之后马上检查范围 `num < 1 || num > N`。如果不检查，输入 2000 就会让循环写到数组外面去（越界），结果不可预测。**先检查、后使用**，这个顺序要养成习惯。
5. 最大值和最小值都用 `a[0]` 初始化：

   ```c
   int max = a[0];
   int min = a[0];
   ```

   这样即使输入的全部是负数也不出错。如果用 `max = 0` 起手，全负数时最大值会错误地变成 0。
6. 求和用的是 `long long sum`，输出用 `%lld`。`int` 大约只能装到 21 亿，当数字多或者数字很大时，总和会溢出，所以求和变量习惯上开大一点。
7. 四个统计放在**同一个循环**里完成：

   ```c
   for (int i = 0; i < num; i++) {
       sum = sum + a[i];
       if (a[i] < min) { min = a[i]; }
       if (a[i] > max) { max = a[i]; }
       if (a[i] % 2 == 0) { count++; }
   }
   ```

   一次遍历就把四件事都做了，比写四个循环高效。注意这几个 `if` 是**互相独立**的，不是 `else if`：同一个数字可以既更新最大值、又让偶数计数加一。
8. 第二段的"三的倍数"是独立的小任务，用另一个变量 `m` 从 1 数到 100，遇到 `m % 3 == 0` 就打印。它和前面输入的 `num` 个数字**没有任何关系**，读代码时要分清这两段。

## 常见易错点

- 三的倍数那一段容易看混：它输出的是 1～100 中所有的 3 的倍数，不是"你输入的数字里哪些是 3 的倍数"。想要后者，需要把循环改成遍历数组，判断 `a[i] % 3 == 0`。
- 三的倍数只做了输出，没有统计个数。想练习的话，可以在那段里再加一个计数器，最后输出"共有 33 个"。
- 提示语 `printf("三的倍数有：")` 末尾没有换行，所以这行会和前面的输入挤在一起显示；`printf("请输入%d个数字：", num)` 也一样。
- `int num;` 写在 `main` 外面，是一个全局变量。它只在本文件里用，放在 `main` 里面更清楚。全局变量在整个程序运行期间一直存在，用多了容易搞不清谁改了它。
- 数组 `int a[N]` 写在 `main` 里面，开的是栈空间。按 `N = 1000` 计算占 4KB，没问题；但如果把 `N` 改成几百万，栈会放不下，那时要把数组移到函数外面（变成全局变量）或加上 `static`。
- 输入错误时程序直接 `return 1` 结束，不会让你重新输入。更友好的做法是把输入包在 `while` 里，读到合法值才继续。
- 循环里 `if (a[i] % 2 == 0)` 判断的是偶数，因为 `% 2` 余数为 0。负数同样适用，`-8 % 2` 等于 0。

## 可以继续尝试

1. 把"三的倍数"改成"你输入的 `num` 个数字里，有几个是 3 的倍数"，并输出这些数字。
2. 增加统计项：奇数个数、负数个数、大于平均值的数字个数。平均值用 `(double)sum / num` 计算。
3. 增加输入重试：把 `return 1` 改成打印提示后重新读取，直到输入合法为止。
4. 把统计逻辑封装成函数，例如 `int max_of(int a[], int n)`、`long long sum_of(int a[], int n)`，体会数组作参数时为什么必须同时传长度。
5. 从 1～100 扩展到"用户输入区间 `[L, R]`，输出其中所有 3 的倍数"，练习两个变量的循环起点和终点。
6. 增加排序：把输入的 `num` 个数字从小到大输出，验证排序后的第一个就是最小值、最后一个就是最大值。
