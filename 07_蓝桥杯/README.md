# 蓝桥杯练习

本目录用于记录蓝桥杯基础训练和日常算法练习。练习按日期保存，建议每次完成后补充输入示例、输出结果和易错点，方便后续复习。

## 最新练习

### `10 月 9 日做题.c`

**简介：** 循环输入 + 统计 + 整除判断的基础题练习。

**内容：** 循环读入 5 个整数，统计它们的和、偶数个数、最大值和最小值；再用另一个循环输出 1～30 中能被 7 整除的数。

**学习建议：** 重点看三处细节：`#define N 5` 如何统一控制循环次数；`i == 1` 时为什么要把第一个数字同时赋给 `max` 和 `min`；`scanf(...) != 1` 如何检查输入是否成功。用全是负数的数据（例如 -8 -8 0 0 3）测试一次，就能理解最大值为什么不能用 0 作初值。

完整说明见 [10 月 9 日做题_文件简介与学习建议.md](10%20月%209%20日做题_文件简介与学习建议.md)。

**简介：** C 语言基础综合复习，集中练习整数输入、奇偶判断、最大值比较、循环累加和数组统计。

## 推荐练习方法

1. 先根据题目写出自己的判断条件，再运行程序核对结果。
2. 至少测试普通数据、边界数据和重复数据。
3. 出错时先定位具体分支或循环，再做最小修改。
4. 完成后记录本题使用的语法、边界条件和改进方向。
