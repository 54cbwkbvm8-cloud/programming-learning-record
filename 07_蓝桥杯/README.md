# 蓝桥杯练习

本目录用于记录蓝桥杯基础训练和日常算法练习。练习按日期保存，建议每次完成后补充输入示例、输出结果和易错点，方便后续复习。

## 最新练习

### `10.2练习.c`

**简介：** C 语言基础综合复习，集中练习整数输入、奇偶判断、最大值比较、循环累加和数组统计。

**内容：** 读取两个整数并判断奇偶关系，再读取第三个整数比较最大值；计算 1 到 100 的和；最后读取 5 个整数，计算最大值、最小值和平均值。

**学习建议：** 先分别运行程序的三个部分，再重点检查最大值判断中的唯一最大、并列最大和三个数相同三类情况。数组部分应使用升序、降序、负数和重复值进行测试。

完整说明见 [10.2练习_文件简介与学习建议.md](10.2练习_文件简介与学习建议.md)。

## 推荐练习方法

1. 先根据题目写出自己的判断条件，再运行程序核对结果。
2. 至少测试普通数据、边界数据和重复数据。
3. 出错时先定位具体分支或循环，再做最小修改。
4. 完成后记录本题使用的语法、边界条件和改进方向。
