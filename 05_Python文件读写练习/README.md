# 05 Python 文件读写练习

本目录收录**文件读写**专题：把内存里的数据写进文本文件或 JSON 文件，再从中读回来。这是程序从"关掉就忘"变成"有记忆"的关键一步，也是 `03_Python综合项目` 里 JSON 持久化版本的基础。

## 四道题分别是什么

这组练习的"四道题"指的是四件小事：

1. **题目 1**：写一个函数，传入一个数字列表，返回其中的最大值。
2. **题目 2**：统计一组成绩的最大值、最小值、平均值和及格人数。
3. **题目 3**：读取同目录下的文本文件，把内容打印出来。
4. **题目 4**：把学生信息写入 JSON 文件，保留中文并让格式易读。

`02` 和 `03` 用的是写死在代码里的数据，`04` 改成让用户逐个输入，并让文件路径变成函数参数——这样同一个函数就能处理不同的文件，是"让代码更通用"的典型做法。

## 文件读写要点

- **文本文件**：用 `open(路径, "r", encoding="utf-8")` 读，`encoding="utf-8"` 不能省，否则中文可能读成乱码。
- **JSON 文件**：写入用 `json.dump(数据, 文件对象, ensure_ascii=False, indent=4)`，读取用 `json.load(文件对象)`。`ensure_ascii=False` 保留中文，`indent=4` 让文件缩进好看、方便人工查看。
- **路径定位**：用 `Path(__file__).resolve().parent` 拿到当前脚本所在目录，再拼上文件名。这样不管从哪里运行脚本，都能找到数据文件，不会因为工作目录不同而报错。
- **`with` 语句**：`with open(...) as file:` 会在代码块结束时自动关闭文件，比手动 `close()` 更安全。

## 推荐学习顺序

1. `四道基础题_零基础教程.md` + `02_四道基础题_逐行注释.py`：先读教程的前半部分概念讲解，再对照原稿代码。
2. `03_四道基础题_修正版_逐行注释.py`：看修正了什么、为什么要修正。
3. `04_四道基础题_输入版_逐行注释.py`：完整的输入版，功能最全。
4. `05_题目1和2_输入版_逐行注释.py`：只做前两题的精简版，用于对比。
5. `01_文件读写复习_成绩统计.py`：独立的复习版，把函数和文件读写再走一遍。

## 学习方法建议

- 这一目录最重要的是**动手改数据**：把 `学生成绩示例.txt` 改成自己的成绩，再运行一遍，看输出有没有跟着变。
- 打开 `学生信息.json` 看看它的格式。JSON 是"键值对 + 缩进"的文本，能直接读懂，这也是它流行的重要原因。
- 运行 `02` 或 `03` 之后，用文本编辑器打开 `学生信息.json`，观察程序写进去的内容，理解"写入"到底做了什么。
- 四个版本的差异都写在注释里，读的时候注意找 `【新增】` 这类标记，它们记录了改动的理由。

运行方式：

```bash
python3 "05_Python文件读写练习/01_文件读写复习_成绩统计.py"
python3 "05_Python文件读写练习/04_四道基础题_输入版_逐行注释.py"
```
