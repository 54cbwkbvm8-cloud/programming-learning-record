# Python 10 月 14 日文件读写练习：文件简介与学习建议

## 文件简介

- **源码文件：** `06_2026-10-14_学生成绩写入文件并读回.py`
- **类型：** Python 文本文件读写（`05_Python文件读写练习` 里第一份"自己录入 → 写文件 → 读回来"的完整小程序）
- **功能：** 依次录入 3 名学生的姓名和成绩，存进一个列表；把这份数据写进 `students.txt`（每行一条，格式是 `姓名,成绩`）；再把文件重新读出来，逐行解析并打印"某某 的成绩是 多少"。
- **主要知识点：** 列表装字典、`for` 循环录入、`input()` 与 `float()`、`with open(...)` 自动关闭文件、`"w"` 与 `"r"` 两种打开模式、`encoding="utf-8"`、`f-string`、`strip()` 去换行、`split(",")` 切分字符串、元组解包。

程序按三段读：

1. **录入阶段**：循环 3 次，每次用 `input` 拿姓名、用 `float(input(...))` 拿成绩，然后用 `students.append({"name": name, "score": score})` 存进列表——列表装字典，是这门课反复出现的结构。
2. **写入阶段**：`with open("students.txt", "w", encoding="utf-8") as f:`，循环把每个学生写成一行 `姓名,成绩`。
3. **读回阶段**：再 `open` 一次，这次用 `"r"` 模式，逐行 `line.strip().split(",")` 切开，用 `name, score = ...` 一次取两个值，然后打印。

和前几份练习相比，这份的进步在于：**录入的数据不只留在内存里，而是先存进文件、再读出来验证**。这正是"程序从关掉就忘变成有记忆"的第一步。

## 零基础学习建议

1. **`with open(...) as f:` 是推荐的固定写法。** 它会在代码块结束时自动关闭文件，即使中途出错也会关。手动 `open` + `close` 一旦忘了写 `close`，数据可能还在缓冲区里没真正落盘。
2. **`"w"` 和 `"r"` 的区别要记牢：**

   | 模式 | 含义 | 危险点 |
   | --- | --- | --- |
   | `"w"` | 写入（write） | **会清空原文件**，从零开始写；想追加要用 `"a"` |
   | `"r"` | 读取（read） | 文件不存在会报 `FileNotFoundError` |

3. **`encoding="utf-8"` 别省。** 里面有中文姓名，不写编码在 Windows 上容易出现乱码。macOS 和 Linux 的默认编码通常就是 UTF-8，所以在本机不写往往也看不出问题——这正是"本地能跑、换台电脑就坏"的典型案例。
4. **写进去的每一行都带一个 `\n`：** `f.write(f"{s['name']},{s['score']}\n")` 末尾这个 `\n` 是换行符，没有它三行会挤成一行。读回来时用 `line.strip()` 把这个 `\n` 去掉，再 `split(",")` 切开。
5. **`name, score = line.strip().split(",")` 是"解包"。** `split(",")` 返回一个列表 `["张三", "88.5"]`，左边写两个变量，Python 会按顺序把两项分别赋过去。变量个数和列表长度必须一致，否则会报 `ValueError`。
6. **读回来的 `score` 是字符串。** 文件里存的是文字，读出来就是 `"88.5"`（带引号的字符串），不是数字。要拿它做加减乘除，得先 `float(score)`。程序里直接用 `f"{name} 的成绩是 {score}"` 打印，所以看起来没差别——这个区别在你想算平均分时就会立刻暴露。
7. **"先用列表收集、再统一写文件"是一种清晰的结构。** 录入和保存分成两段，好处是录入阶段改规则（比如加校验、改成任意人数）时不用动写文件的代码。也可以用另一种结构：边录边写。两种都能用，想清楚各自的取舍。
8. **`f"..."` 是 f-string。** 字符串前面加 `f`，就能在 `{}` 里直接写变量或表达式，例如 `f"\n第{i + 1} 名学生"`。它比 `%` 或 `"".format()` 更短也更好读。

## 常见易错点

- **文件写在"当前工作目录"，不是"脚本所在目录"。** 程序里写的是 `open("students.txt", ...)`，没有路径。你在哪个目录敲 `python3`，`students.txt` 就生成在哪个目录；换个目录运行，读到的也是那个目录里的文件。仓库里 `01_2026-09-13_文件读写复习_成绩统计.py` 用的是 `Path(__file__).resolve().parent`，先算出脚本自己的位置再拼文件名，那样才不受工作目录影响——这是更稳的写法，值得对照。
- **成绩会变成 `92.0`。** 因为用了 `float(input(...))`，整数 `92` 也变成浮点数，写进文件就是 `92.0`。想保持输入的原样，可以存字符串（不做 `float`），或者用 `f"{score:g}"` 让 `92.0` 显示成 `92`。
- **姓名里带逗号会出错。** `split(",")` 是按所有逗号切；如果姓名写成 `张,三`，切出 3 段，`name, score = ...` 就会报"解包数量不匹配"。想稳妥可以写 `line.strip().split(",", 1)`，只从左边切一刀。
- **重复运行会覆盖上一次的数据。** 打开模式是 `"w"`，每次运行都会把 `students.txt` 清空重写。如果想累积记录，要改成 `"a"`（追加），并注意读回时会读到所有历史数据。
- **没有做输入校验。** 在"请输入成绩"那里输入 `abc`，`float("abc")` 会直接抛 `ValueError` 让程序崩掉。`08_2026-10-11_学生成绩管理_输入校验版.py` 里演示了怎么校验，可以参考。
- **人数是写死的 3。** `range(3)` 决定录几个学生。想改成任意人数，可以用 `while` 循环 + 输入 `exit` 结束（`07_2026-10-11_学生成绩管理_函数版.py` 就是这么做的）。
- **别用 `s['score']` 之外的写法去拿成绩。** 列表里装的是字典，取值要写 `s["score"]`；写成 `s.score` 或 `s[1]` 都会报错——这是"列表用下标、字典用键"最容易混淆的地方。
- **文件句柄用完就关。** 如果不用 `with`，读完之后文件对象会一直占着；虽然 Python 迟早会回收，但显式用 `with` 才是专业写法。
- **运行时生成的 `students.txt` 不要提交到仓库。** 它是程序的输出，不是学习文件；本次已经把 `students.txt` 加进 `.gitignore`。

## 可以继续尝试

1. **改成任意人数**：用 `while True` 循环录入，输入 `exit` 时结束，然后统计一共录了几个人。
2. **加输入校验**：成绩必须能转成数字、并且在 0～100 之间；姓名不能是空字符串。非法就提示重新输入。
3. **读回来后做统计**：把 `score` 转成 `float`，算出平均分、最高分、最低分和及格人数，直接在读文件那一段输出。
4. **改写 `students.txt` 让格式更好看**：例如写成 `张三,88.5,等级A`，或者给文件加一行表头。改格式时记得同时改读取时的 `split` 逻辑。
5. **用 `csv` 模块代替手写 `split`**：`import csv` 之后用 `csv.writer` / `csv.reader`，体会标准库帮你处理了哪些细节（比如带逗号的姓名）。
6. **再做一份 JSON 版本**：把 `students` 列表直接存成 `students.json`（`json.dump(students, f, ensure_ascii=False, indent=4)`），再读回来。和文本版本对比：文本版适合人看，JSON 版适合程序读。
7. **统计文件信息**：打印 `students.txt` 一共有几行、占多少字节（`len(open(...).readlines())`、`Path("students.txt").stat().st_size`）。
8. **把录入和保存拆成函数**：`input_students(n)` 负责录入，`save_students(students, path)` 负责写，`load_students(path)` 负责读，`main` 只做调度——这正是 `03_Python综合项目` 里的组织方式。
