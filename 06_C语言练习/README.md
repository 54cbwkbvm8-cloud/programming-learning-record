## 推荐学习顺序

按下面的顺序走，每一步都建立在上一步的基础上：

**第一阶段：语法与判断（01、02、14、15）**

1. `01_09-28_基础语法综合练习.c` — 用五道小题把变量、输入输出、格式符过一遍。
2. `02_09-28_正负奇偶与闰年.c` — 判断专题，重点看第五题的闰年条件。
3. `14_两数比较与成绩等级_教程版.c` + `14_两数比较与成绩等级_零基础教程.md` — 先读教程再看代码，理解函数是怎么拆出来的。
4. `15_两数比较与成绩等级_修正版.c` — 对照 14 号，看"两个数相等"这种边界情况为什么要单独处理。

**第二阶段：循环（03、04）**

5. `03_09-29_循环与九九乘法表.c` — 先把 `for` 循环和累加器用熟。
6. `04_09-30_循环综合与猜数字.c` — 换成 `while`，体会"循环变量必须自己更新"。

**第三阶段：数组（05、06）**

7. `05_09-30_数组统计.c` — **先自己找出并修好最大值/最小值的 bug**，再和文档里的最小修改对照。
8. `06_10-01_数组统计与逆序输出.c` — 数组遍历的综合运用。

**第四阶段：函数（07、09、14 回顾）**

9. `07_10-02_函数基础练习.c` — 函数定义、返回值、函数互相调用。
10. `09_10-04_数组函数统计.c` — 数组作参数时为什么必须同时传长度 `n`。

**第五阶段：综合与实战（10、11、12、08、13）**

11. `10_10-05_分支循环数组模拟练习.c` — 把前面学的串成一次完整运行。
12. `11_10-06_分支循环数组复习.c` — 用一次综合复习检查掌握情况。
13. `12_10-09_取余与两种循环练习.c` — 对照 `for` 与 `while` 的写法差异。
14. `08_10-03_菜单式计算器.c` — 学会用 `while (1)` 写菜单，这是后面写小程序的常用结构。
15. `13_10-10_数组输入校验与成绩统计.c` — 最新的练习，学会"输入错误后重新输入"的写法。

## 学习方法建议

- 每一份都**先编译、再运行、再改**。用下面这条命令编译（把文件名换成你要练的）：

  ```bash
  cc -std=c17 -Wall -Wextra "06_C语言练习/01_09-28_基础语法综合练习.c" -o /tmp/practice && /tmp/practice
  ```

  加上 `-Wall -Wextra` 会让编译器把可疑写法都提示出来，是非常值得养成的习惯。
- 先用文档里的"建议运行数据"跑一遍，再自己另外准备三组数据：**正常数据、边界数据、特殊数据**（全负数、全部相同、空输入）。这三类数据最容易暴露逻辑错误。
- 出错时的顺序是：先看编译器的报错行号 → 再看是哪一类错误（拼写、分号、类型、下标）→ 做最小修改再编译。不要一次改很多地方。
- `05_09-30_数组统计.c` 是这一目录里唯一**故意留了错误**的文件，先自己找出来再对照文档。找出真实 bug 的经验比多做十道题都有用。
- 每一份源码旁边都有对应的「简介与学习建议」，读完源码再看文档，能发现自己漏掉的细节。
