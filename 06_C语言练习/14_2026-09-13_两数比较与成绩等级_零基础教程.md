# C 语言零基础教程：比较两个数字并判断成绩等级

这份教程对应同目录下的 `14_2026-09-13_两数比较与成绩等级_教程版.c`。代码中的每一个实际代码行都带有注释，本文档后面还会按照行号逐行解释。

## 一、最终要完成什么

这个程序会按顺序完成两件事：

1. 让你输入两个数字，然后输出其中较大的数字。
2. 让你输入一个成绩，然后输出对应的等级。

完整运行过程大致如下：

```text
请输入两个数字，中间用空格分开：
3 5
较大的数字是：5.00

请输入一个成绩（0 到 100）：
86
等级：B（良好）
```

第一题的流程是：

```text
开始
  |
输入两个数字
  |
判断第一个数字是否大于第二个数字
  |
保存较大的数字
  |
输出较大的数字
  |
结束
```

第二题的流程是：

```text
开始
  |
输入成绩
  |
成绩是否在 0 到 100 之间
  |
按从高到低的分数段判断
  |
输出 A、B、C、D、E 或错误提示
  |
结束
```

## 二、开始前要认识的基本符号

- `#include`：把其他功能库“引入”当前程序。
- `stdio.h`：标准输入输出库，里面有 `printf` 和 `scanf`。
- `printf`：把文字或数字输出到屏幕。
- `scanf`：从键盘读取用户输入。
- `;`：英文分号，表示一条语句结束。
- `{` 和 `}`：一对英文大括号，用来围住一段代码。
- `//`：单行注释，编译器不会执行注释内容。
- `double`：一种变量类型，可以保存整数和小数。
- `if`：如果某个条件成立，就执行某段代码。
- `else`：如果前面的条件不成立，就执行另一段代码。
- `int`：整数类型，`main` 函数使用它返回程序运行状态。
- `return 0`：表示程序正常结束。

注意：代码中的引号、分号、括号、逗号都要使用英文半角符号。中文标点通常不能直接当作 C 语法符号使用。

## 三、完整代码

以下代码与 `14_2026-09-13_两数比较与成绩等级_教程版.c` 文件一致，而且每一行代码都有注释：

```c
#include <stdio.h>  // 引入标准输入输出库，这样才能使用 printf 和 scanf。

void compare_two_numbers(void)  // 定义函数，完成第一题：输入两个数字并输出较大者。
{  // 函数体开始。
    double first_number;  // 声明第一个数字变量，double 类型可以保存整数和小数。
    double second_number;  // 声明第二个数字变量，double 类型可以保存整数和小数。
    double larger_number;  // 声明较大数字变量，用来保存比较后的结果。

    printf("请输入两个数字，中间用空格分开：\n");  // 输出提示文字，告诉用户怎样输入。
    scanf("%lf %lf", &first_number, &second_number);  // 按 double 类型读取两个数字，并存入两个变量。

    if (first_number > second_number)  // 判断第一个数字是否大于第二个数字。
    {  // if 代码块开始。
        larger_number = first_number;  // 条件成立时，把第一个数字保存到较大数字变量。
    }  // if 代码块结束。
    else  // 如果上面的条件不成立，就执行下面的代码。
    {  // else 代码块开始。
        larger_number = second_number;  // 把第二个数字保存到较大数字变量；两数相等时它也同样正确。
    }  // else 代码块结束。

    printf("较大的数字是：%.2f\n", larger_number);  // 输出较大数字，%.2f 表示保留两位小数。
}  // compare_two_numbers 函数结束。

void check_grade(void)  // 定义函数，完成第二题：输入一个成绩并输出等级。
{  // 函数体开始。
    double score;  // 声明成绩变量，double 类型允许输入 85.5 这样的小数成绩。

    printf("请输入一个成绩（0 到 100）：\n");  // 输出提示文字，说明合法的成绩范围。
    scanf("%lf", &score);  // 按 double 类型读取一个成绩，并存入 score 变量。

    if (score < 0.0 || score > 100.0)  // 如果成绩小于 0 或大于 100，说明输入不在有效范围。
    {  // 无效成绩代码块开始。
        printf("成绩必须在 0 到 100 之间。\n");  // 输出错误提示，不继续判断等级。
    }  // 无效成绩代码块结束。
    else if (score >= 90.0)  // 否则，如果成绩大于或等于 90 分。
    {  // A 等级代码块开始。
        printf("等级：A（优秀）\n");  // 输出 A 等级。
    }  // A 等级代码块结束。
    else if (score >= 80.0)  // 否则，如果成绩大于或等于 80 分；前面的条件已经排除了 90 分以上。
    {  // B 等级代码块开始。
        printf("等级：B（良好）\n");  // 输出 B 等级。
    }  // B 等级代码块结束。
    else if (score >= 70.0)  // 否则，如果成绩大于或等于 70 分；前面的条件已经排除了 80 分以上。
    {  // C 等级代码块开始。
        printf("等级：C（中等）\n");  // 输出 C 等级。
    }  // C 等级代码块结束。
    else if (score >= 60.0)  // 否则，如果成绩大于或等于 60 分；前面的条件已经排除了 70 分以上。
    {  // D 等级代码块开始。
        printf("等级：D（及格）\n");  // 输出 D 等级。
    }  // D 等级代码块结束。
    else  // 前面所有条件都不成立，也就是成绩低于 60 分。
    {  // E 等级代码块开始。
        printf("等级：E（不及格）\n");  // 输出 E 等级。
    }  // E 等级代码块结束。
}  // check_grade 函数结束。

int main(void)  // 定义主函数，程序从 main 开始运行。
{  // main 函数体开始。
    compare_two_numbers();  // 调用第一题函数，完成两个数字的比较。
    printf("\n");  // 输出一个空行，把两道题的运行结果分开。
    check_grade();  // 调用第二题函数，完成成绩等级判断。

    return 0;  // 返回 0，表示程序正常结束。
}  // main 函数结束。
```

### 第 1 行


`#include` 叫做预处理指令。它会在真正编译前，把 `stdio.h` 文件的内容引入进来。

`stdio` 是“standard input/output”的缩写，意思是标准输入输出。引入它以后，程序才能使用下面两个重要工具：

- `printf`：向屏幕输出内容。
- `scanf`：从键盘读取内容。

尖括号 `< >` 表示去系统标准位置查找这个头文件。这一行末尾不需要写分号。

```c
空行
```

空行不会被执行，它的作用是让代码更容易阅读。不同功能之间可以留空行。

### 第 3 行

```c
void compare_two_numbers(void)
```

这一行定义了第一题使用的函数。

- `void` 写在最前面，表示这个函数不返回任何结果。
- `compare_two_numbers` 是函数名，意思是“比较两个数字”。
- `(void)` 表示这个函数不需要接收参数。
- 函数名后面的内容会被下面的大括号包起来。

C 程序通常把相关的代码放进函数，这样结构更清楚。

### 第 10 行

```c

```

`scanf` 用来读取用户输入的两个数字。

- `&second_number` 表示第二个值要存到 `second_number` 变量的地址。
- `&` 叫做取地址符，使用 `scanf` 读取基本类型变量时通常不能忘记它。

例如用户输入：

```text

```

执行后，`first_number` 中保存 `3.0`，`second_number` 中保存 `5.0`。

## 七、等级边界

| 成绩范围 | 等级 |
| --- | --- |
| 小于 0 或大于 100 | 输入错误 |
| 0.0 到小于 60.0 | E（不及格） |
| 60.0 到小于 70.0 | D（及格） |
| 70.0 到小于 80.0 | C（中等） |
| 80.0 到小于 90.0 | B（良好） |
| 90.0 到 100.0 | A（优秀） |

几组重要边界：

- `59.99`：E。
- `60`：D。
- `69.99`：D。
- `70`：C。
- `79.99`：C。
- `80`：B。
- `89.99`：B。
- `90`：A。
- `100`：A。
- `101`：输入错误。

等级判断必须从高分往低分写。若先判断 `score >= 60`，那么 95 也会先满足这个条件，从而错误地输出 D。现在这种从高到低的 `else if` 顺序可以避免该问题。

## 八、常见错误

### 1. 忘记写分号

错误：

```c
double score
```

正确：

```c
double score;
```

C 语言中的普通语句通常要以英文分号结束。

### 2. 使用了中文分号

错误：

```c
double score；
```

正确：

```c
double score;
```

中文分号与英文分号外形相近，但编译器只接受英文符号。

### 3. 忘记 `scanf` 中的 `&`

错误：

```c
scanf("%lf", score);
```

正确：

```c
scanf("%lf", &score);
```

读取基本类型变量时，要告诉 `scanf` 变量在内存中的地址。

### 4. `double` 输入时误用 `%f`

错误：

```c
double score;
scanf("%f", &score);
```

正确：

```c
double score;
scanf("%lf", &score);
```

`scanf` 读取 `double` 时使用 `%lf`。`printf` 输出 `double` 时使用 `%f`，例如 `%.2f`。

### 5. 大括号没有配对

每一个 `{` 都必须有对应的 `}`。建议写代码时先写一对大括号，再在中间填写内容。

### 6. 使用旧程序测试

修改源代码后必须重新编译：

```bash
cc -std=c11 -Wall -Wextra -pedantic "14_2026-09-13_两数比较与成绩等级_教程版.c" -o "两数比较与成绩等级"
```

如果不重新编译，运行到的仍然是修改前的旧程序。

### 7. 输入了非数字内容

这份入门程序只接收数字。如果输入的是字母、汉字或其他非数字内容，`scanf` 无法正确完成读取，后面的结果也就不再可靠。

运行程序时，两个数字之间使用空格或换行，成绩单独输入。例如：

```text
3 5
86
```

5. 把等级判断单独写成另一个函数，让每个函数只负责一件事情。
