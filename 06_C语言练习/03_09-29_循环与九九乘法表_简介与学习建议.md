# C 语言 09-29 循环与九九乘法表：文件简介与学习建议

## 文件简介

- **源码文件：** `03_09-29_循环与九九乘法表.c`
- **类型：** C 语言 `for` 循环五段练习，从单层循环过渡到嵌套循环
- **功能：** 程序依次完成五段任务：

  1. **输出 1～100**：用 `for` 循环把所有数字连续打印在一行。
  2. **求 1～100 的和**：累加器写法，输出 5050。
  3. **输出 1～100 的偶数**：循环里加 `if` 筛选。
  4. **求 1～100 的偶数和**：筛选 + 累加组合，输出 2550。
  5. **输出九九乘法表**：双重 `for` 循环，行号与列号配合。

- **主要知识点：** `for` 循环的三段式写法、循环里放 `if`、累加器初始化、双重循环的行列关系、循环变量的作用域。

这份文件是"循环专题"的第一份练习。前四段都是单层循环，第五段的九九乘法表才第一次出现双重循环，节奏安排得很合理。

## 零基础学习建议

1. 先只看第一段循环的三段式：`for (int i = 1; i <= 100; i++)`，三部分分别是"从几开始""到什么时候停""每次怎么变"。把 `<=` 改成 `<`，输出就会少掉 100，这是最好的边界实验。
2. 第二段引入累加器：`int sum = 0;` 起手必须是 0，然后循环里写 `sum += i;`。累加器的初始化位置很重要——放在循环外面是"累加全部"，放在循环里面就每次都从 0 重新开始。
3. 第三段是"循环 + 判断"的组合：循环负责走访每个数字，`if (i % 2 == 0)` 负责只留下偶数。这四段其实是同一种思路的四种变形，对比着看能很快理解。
4. 第五段是嵌套循环，重点看两个变量谁管什么：

   ```c
   for (i = 1; i <= 9; i++) {        // i 是行号，控制"打几行"
       for (j = 1; j <= i; j++) {    // j 是列号，控制"这一行打几列"
           printf("%d*%d=%d ", i, j, i * j);
       }
       printf("\n");                 // 一整行打完后才换行
   }
   ```

   内层循环的上限写成 `j <= i` 而不是 `j <= 9`，这正是三角形形状的来源。把它改成 `j <= 9`，乘法表就变成完整的 9×9 方阵，可以试一下。
5. 注意内层循环结束后 `j` 会重新从 1 开始（因为 `j = 1` 写在每一轮外层循环里）。如果 `j = 1` 写在外层循环外面，第二行开始就会接着上一行的数字继续，结果是错的。
6. 打印时 `printf("%d*%d=%d ", i, j, i * j)` 的顺序是先行号、后列号，所以第二行输出的是 `2*1=2 2*2=4`。写成 `printf("%d*%d=%d ", j, i, i * j)` 就是常见的"1*2=2 2*2=4"顺序，两种都对，看你想要哪种排版。

## 常见易错点

- 文件里出现了两次 `i` 的声明：第一段循环用的是 `for (int i = 1; ...)`，`i` 的作用范围只在这个循环内部；后面又写了一句 `int i, sum = 0;` 重新声明了一个作用于整个 `main` 的 `i`。程序能正常运行，但读代码时要清楚"这是两个不同的 i"。想避免混淆，可以把第一个也改成 `for (i = 1; ...)` 并统一在函数开头声明。
- 累加变量忘记初始化（只写 `int sum;`）会带着不确定的值开始累加。这个错误有时不报错但结果完全不对。
- 循环条件里的边界最容易出错：`i <= 100` 包含 100，`i < 100` 不包含。写循环时先问自己"最后一个要处理的数字是几"。
- 打印 100 个数字时全部挤在一行。想让它更整齐，可以在循环里加 `if (i % 10 == 0) printf("\n");`，每行输出 10 个。
- 九九乘法表的内层循环如果用 `j <= 9`，会打印出重复的算式（`2*1` 和 `1*2` 都出现）。三角形写法靠 `j <= i` 去掉重复。
- 嵌套循环里的变量名不要重复：外层用 `i`、内层用 `j`，是通用的命名习惯。
