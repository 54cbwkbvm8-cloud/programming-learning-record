## 文件简介

- **源码文件：** `01_2026-09-28_基础语法综合练习.c`
- **类型：** C 语言入门五连练，变量、输入输出、判断和运算的第一次综合
- **功能：** 程序依次完成五个小练习：

  1. **个人信息输入与输出**：读取姓名、年龄、身高和一个字符，再打印其中三项。

## 零基础学习建议

1. 先看变量声明区：`char name[50];` 是一段能装 49 个字符的"名字袋子"，`int` 存整数，`float` 存小数，`char` 存单个字符。不同类型的变量要用不同的格式符读写。
2. 重点理解 `&`：`scanf("%d", &age)` 里的 `&` 表示"把数据存到这个变量的地址里"。忘了写 `&` 程序可能不报错但结果是错的，这是初学者最常见的坑。
3. `scanf("%49s", name)` 中的 `49` 是宽度限制，表示最多读 49 个字符，第 50 个位置留给字符串结束符。字符数组读字符串时加宽度是很稳的习惯，`name` 本身是数组名，不需要再加 `&`。
4. `scanf(" %c", &initial)` 里 `%c` 前面的那个空格很关键：它会先跳过回车、空格等空白字符，再读取字符。如果写成 `"%c"`，上一次输入留下的回车就会被当成要读的字符。
5. 练习三的三元运算符 `maximum = number1 > number2 ? number1 : number2;` 读法是"条件 ? 成立时的值 : 不成立时的值"，等价于一个完整的 `if / else`。写法短，但条件复杂时还是用 `if` 更清楚。
6. 练习五是标准的等级判断：从高分往低分排列 `else if`，只要前面的条件不成立才继续往下判断，所以 `score >= 80` 那一句不用再写 `score < 90`。自己用 59、60、89、90 各测一次，确认边界归属。

## 常见易错点

- 变量 `initial` 读入了一个字符，但程序从头到尾没有把它打印出来。这是"读了没用"的典型情况：练习一要求输出个人信息，实际只输出了名字、年龄和身高。想补齐就在个人信息那一段加上 `printf("你的个人信息是：%c\n", initial);`。
- 注释里夹着几个多余的大括号，例如 `// 存两个数字的和}`、`// 存入两个数字的最大值}`。这只是注释，不影响运行，但读代码时容易误会。
- 练习五的成绩不合法时，程序会打印"成绩不合法"，然后用 `if (score >= 0 && score <= 100)` 跳过等级输出。可是最后那句 `printf("五个练习已全部完美完成。恭喜你！！！")` 仍然会打印，让人误以为整份练习都成功了。更合理的做法是把这句放进合法分支里。
- `scanf("%f", &score)` 需要输入小数或整数都可以，但如果输入的是字母，`score` 不会被赋值，后面的判断就会拿到不确定的值。可以练习用 `scanf` 的返回值做输入检查。
- 连续输入时，提示语末尾没有换行，所以"请输入你的名字："和实际输入会挤在同一行，这是本程序保留的写法。
- 练习四和练习五之间没有清空输入缓冲区的动作。本程序里都是"数值型"读取，所以不会出问题；一旦混入 `%c`，就要像练习一那样在 `%c` 前加空格。

## 可以继续尝试

1. 把 `initial` 补进个人信息输出，让练习一真正完整。
2. 把练习五从 A～E 五级扩展成"优秀 / 良好 / 中等 / 及格 / 不及格"的文字等级，并检查 60、70、80、90 四个边界。
3. 用 `if / else` 重写练习三的三元运算符版本，对比两种写法哪个更容易读。
4. 把五个练习分别封装成 `void practice1(void)`、`void practice2(void)` 这样的函数，让 `main` 只负责依次调用。
5. 给每个输入都加上 `scanf` 返回值检查，输入非法时提示重新输入。
6. 把练习四改成"读一个数字，输出它是奇数还是偶数，再输出它是几位数"，练习取余和整除配合。
