# C 语言 09-28 正负奇偶与闰年：文件简介与学习建议

## 文件简介

- **源码文件：** `02_09-28_正负奇偶与闰年.c`
- **类型：** C 语言分支结构综合练习，五道判断题串成一条线
- **功能：** 程序连续完成五道小题：

  1. **正负判断**：大于 0 输出"正数"，小于 0 输出"负数"，等于 0 输出"这是0"。
  2. **奇偶判断**：用 `%` 取余判断奇偶。
  3. **三数最大值**：用逐步比较的写法找最大值。
  4. **成绩分级**：90 优秀、80 良好、70 中等、60 及格，其余不及格。
  5. **闰年判断**：用完整的闰年条件判断年份。

- **主要知识点：** `if / else if / else` 三分支、取余运算 `%`、"先假设第一个最大，再逐个比较"的求最大值套路、多个条件用 `&&` 和 `||` 组合、逻辑运算的括号优先级。

这份文件的价值在于：五道题用的是同一种"判断"思维，但每道题的判断条件难度递增。第五题的闰年条件是本文件最值得反复看的地方。

## 零基础学习建议

1. 第一题是 `if / else if / else` 的完整形态：三个分支互斥，程序只会执行其中一个。想清楚"为什么 0 要单独一个分支"，就不会把它归到正数或负数里。
2. 第二题只有两个分支，用 `if / else` 就够。`number % 2 == 0` 表示除以 2 余数为 0，也就是偶数；负数同样适用，`-3 % 2` 得到 -1，不等于 0，所以 -3 被判为奇数。
3. 第三题的求最大值套路值得背下来：

   ```c
   max = a;
   if (b > max) { max = b; }
   if (c > max) { max = c; }
   ```

   先把第一个数当成"当前最大值"，后面每读一个就和它比一次，比它大就换掉。想求四个数、五个数的最大值，只要继续加 `if` 就行。
4. 第四题的关键是 `else if` 的排列顺序：从高到低写，就不必在每个条件里都写上下界。`score >= 90` 不成立时，程序已经知道分数小于 90，所以下一句只写 `score >= 80` 就是"80 到 89"。
5. 第五题的闰年条件是全文件最值得记的一行：

   ```c
   if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
   ```

   括号把条件分成两组：左边管"普通年份里的闰年"，右边管"整百年里的闰年"。`||` 表示两组满足任意一组就算闰年。少了任意一层括号，判断结果都会变。
6. 自己动手把 1900、2000、2023、2024 四个年份都跑一遍，这四组刚好覆盖四种情况，比只看解释有用得多。

## 常见易错点

- 最后一句 `printf("%d年不是闰年", year);` 末尾漏了 `\n`，所以"不是闰年"这行会紧贴下一个提示。补上 `\n` 输出会整齐很多。
- 第一题和第四题都没有检查输入范围：第四题输入 `150` 会落入 `score >= 90` 输出"优秀"，输入 `-20` 会输出"不及格"。真实成绩必须限制在 0～100。
- `scanf("%d %d %d", &a, &b, &c)` 要求三个数用空格或回车分开。输入 `3,9,5` 这种逗号分隔，只有第一个数能读到，后两个会沿用上一题留下的数值。
- 第三题的 `max` 变量在比较前必须先赋值（`max = a;`）。如果直接把 `b`、`c` 和未赋值的 `max` 比较，结果就是不确定的。
- 第四题用 `int score` 接收分数，所以只能输入整数。想支持 86.5 这种成绩，要把 `score` 改成 `float`，并把 `scanf` 的格式符换成 `%f`。
- 判断语句中 `=` 和 `==` 是两件事：`if (number = 0)` 是赋值（而且条件是 0，永远为假），`if (number == 0)` 才是比较。

## 可以继续尝试

1. 给第四题加上 0～100 的范围校验，输入越界时提示重新输入。
2. 把第三题改写成函数 `int max_of_three(int a, int b, int c)`，让 `main` 只负责输入输出。
3. 把第五题的闰年判断封装成 `int is_leap_year(int year)`，返回 1 或 0，然后用 `if (is_leap_year(year))` 调用。
4. 在第一题里补上"输入 0 时同时输出它是偶数"的判断，体会同一份输入可以被多个互不影响的判断处理。
5. 增加第六题：输入一个月号（1～12），输出这个月有多少天，并额外处理闰年二月是 29 天。
6. 把五道题分别写成函数，`main` 里用菜单让用户选择做哪一题。
