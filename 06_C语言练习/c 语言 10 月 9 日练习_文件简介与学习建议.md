# C 语言 10 月 9 日练习：文件简介与学习建议

## 文件简介

- **源码文件：** `c 语言 10 月 9 日练习.c`
- **类型：** C 语言分支、循环、比较和累加综合练习
- **功能：** 输入一个分数，先用取余判断奇偶，再判断是否及格；用 `for` 输出 1～10，用 `while` 输出 11～20；然后输入三个整数并求出最大值；最后分别用 `for` 和 `while` 计算 1～100 的和。
- **主要知识点：** `scanf`/`printf`、取余运算 `%`、`if/else` 双分支、`for` 循环、`while` 循环、循环变量重新赋值、多次比较求最大值、累加器初始化。

程序可以分成五小段阅读：

1. 读取一个分数 `score`，用 `score % 2 == 0` 判断奇偶。
2. 用同一个 `score` 判断是否及格（60 分及以上及格）。
3. 用 `for` 循环输出 1～10，再用 `while` 循环接着输出 11～20。
4. 读取三个整数 `a`、`b`、`c`，通过两次比较求出最大值。
5. 分别用 `for` 和 `while` 把 1～100 累加一次，验证两种循环结果一致。

这五段彼此独立，可以分段运行、分段检查，非常适合用来确认自己是否已经掌握"条件判断 + 两种循环"的基本套路。

## 零基础学习建议

1. 第一遍照着提示逐个输入数据，观察程序从 `main` 开始按从上到下的顺序执行。
2. 重点看奇偶判断：`score % 2 == 0` 说明除以 2 余数为 0，也就是偶数；`else` 分支处理剩下的奇数情况。负数同样成立，例如 `-3 % 2` 得到 `-1`，不等于 0，所以 -3 被判为奇数。
3. 同一个 `score` 参与了两个 `if`：第一次判断奇偶，第二次判断及格。这说明一次输入可以让多个互不影响的判断分别得出结果，这种写法和 `else if` 的"多选一"不一样。
4. 对比两种循环：`for (i = 1; i <= 10; i++)` 把初始化、判断、更新集中在一行；`while (i <= 20)` 只写判断，更新语句 `i++;` 必须自己在循环体里写。写漏 `i++;` 就会出现死循环。
5. 在纸上跟踪 `i` 的变化：`for` 循环结束时 `i` 的值是 11，所以 `while` 循环从 11 数到 20 之后 `i` 变成 21。循环变量在循环结束后仍然保留最后的值，这一点很值得记住。
6. 三数求最大值用的是"先比较前两个，再把结果和第三个比"的思路：先让 `max` 取 `a` 和 `b` 中较大的一个，再用 `if (max < c)` 把 `c` 补进来。想清楚这个套路，就能推广到四个、五个数。
7. 两个求和循环里的 `sum` 和 `sum2` 都初始化为 0。累加变量不初始化就会带着不确定的值开始计算，这是初学者最常见的错误之一。

## 常见易错点

- 提示语句 `printf("请输入你的分数:");` 末尾没有 `\n`，所以"请输入你的分数:"和后面的结果会挤在同一行，这是本程序保留的原始写法；如果想让界面更整齐，可以在提示末尾补上 `\n`。
- `scanf("%d %d %d", &a, &b, &c)` 要求三个数字用空格或换行分隔。如果输入 `3,9,5` 这样用逗号分隔，`b` 和 `c` 就读不到正确的值，程序会沿用上一次的数字继续运行。
- `int i;` 写在语句之后，是 C99 及以后支持的写法；如果使用很老的编译器（C89/C90），所有变量声明都要放在函数开头。
- 循环变量 `i` 可以重复使用：`for` 循环用完之后，`while` 之前必须重新写 `i = 11;`。每次进入新循环都要重新赋初值，不能依赖上一个循环留下的数字。
- 本程序用 `%` 判断的是"分数"的奇偶，只是练习取余运算；真实场景里更常见的是判断学生序号或数字型数据的奇偶。
- 程序没有检查 `scanf` 的返回值。输入字母、空格混排或直接回车时，变量可能没有被成功读入，程序仍会继续执行，后续可以学习输入校验。
- 三数比较默认 `a`、`b`、`c` 都已经成功读入；如果要处理"输入不合法"的情况，需要配合 `scanf` 返回值增加判断。

## 进阶练习

1. 把三数求最大值封装成 `int max3(int a, int b, int c)` 函数，让 `main` 只负责输入和输出。
2. 用同样的思路写出三数求最小值，体会"求最大"和"求最小"在比较符号上的对称写法。
3. 把 1～100 的求和改成由用户输入终点 `n`，并在 `n` 为 0 或负数时给出提示。
4. 把及格判断扩展成 90 优秀、80 良好、70 中等、60 及格、不及格的多分支，检查边界 60、70、80、90 的归属。
5. 把奇偶判断和及格判断各自写成函数，例如 `int is_even(int value)` 和 `void print_pass(int score)`，让主程序更清晰。
6. 在 `while` 循环里故意删掉 `i++;`，观察程序一直输出同一个数字的现象，再把循环改成带 `break` 的安全版本，理解"循环必须有让条件趋向结束的动作"。
