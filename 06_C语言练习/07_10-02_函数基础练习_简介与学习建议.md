# C 语言函数练习：文件简介与学习建议

## 文件简介

- **源码文件：** `07_10-02_函数基础练习.c`
- **类型：** C 语言函数基础练习
- **主要知识点：** 函数定义、参数传递、返回值、函数调用、条件判断和代码复用。

程序定义了四个函数：

- `max`：返回两个整数中较大的一个。
- `isEven`：判断整数是否为偶数，偶数返回 `1`，奇数返回 `0`。
- `square`：返回整数的平方。
- `max3`：复用 `max`，返回三个整数中较大的一个。

主函数先读取两个整数，输出较大值、奇偶判断和平方；再读取三个整数，输出三数中的最大值、奇偶判断和平方。

## 建议运行数据

可以依次输入：

```text
4 9
1 7 5
```

主要预期结果：

```text
这两个数中较大的一个是：9
这个数是奇数
这个数的平方是：81
这三个数中较大的一个是：7
这个数是奇数
这个最大数的平方是：49
```

## 零基础学习建议

1. 先单独理解 `max` 函数，明确参数 `a`、`b` 和 `return` 分别是什么。
2. 观察 `isEven` 为什么返回 `int`，并理解 `1` 和 `0` 在主函数中怎样参与判断。
3. 比较 `max` 与 `max3`，体会函数调用另一个函数可以减少重复逻辑。
4. 在纸上记录每次函数调用的输入和返回值，再与程序输出核对。
5. 给几个输出语句的末尾补上 `\n`，让每条结果单独占一行，观察终端显示效果。

## 常见易错点

- 函数有返回值时，调用位置需要接收结果，例如 `result = max(a, b);`。
- 参数名只在函数内部有效，主函数的同名变量和函数参数是不同位置的数据。
- `isEven` 返回的是整数 `1` 或 `0`，不是字符串“偶数”或“奇数”。
- `max3` 中重复调用 `max(a, b)`，可以先保存结果，再与 `c` 比较，减少重复计算。
- `printf` 是逐字输出，前一条输出没有 `\n` 时，下一条会紧跟在同一行。

## 进阶练习

1. 编写 `min` 和 `min3` 函数，返回两个或三个整数中的最小值。
2. 编写 `isPositive` 函数，判断整数是否为正数。
3. 编写 `average` 函数，返回两个整数的平均值，并正确处理小数。
4. 修改 `max3`，只调用一次 `max(a, b)`，用变量保存结果后再继续比较。
