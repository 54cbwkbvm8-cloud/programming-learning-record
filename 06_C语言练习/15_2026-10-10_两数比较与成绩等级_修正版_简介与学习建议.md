# C 语言 15 两数比较与成绩等级（修正版）：文件简介与学习建议

## 文件简介

- **源码文件：** `15_2026-09-13_两数比较与成绩等级_修正版.c`
- **配套教程：** `14_2026-09-13_两数比较与成绩等级_零基础教程.md`（教程对应的是 `14_2026-09-13_两数比较与成绩等级_教程版.c`）
- **类型：** C 语言函数拆分 + 双精度浮点输入 + 多分支判断
- **功能：** 程序按顺序完成两件事：

  1. 输入两个数字，输出其中较大的那个；**如果两个数字一样大，会单独提示**。
  2. 输入一个 0～100 的成绩，输出等级。

- **主要知识点：** `void` 函数与函数调用、`double` 与 `%lf`、`if / else if / else` 三分支、"两数相等"这种边界情况的专门处理、`return` 提前结束函数。

这份文件是 `14_2026-09-13_两数比较与成绩等级_教程版.c` 的**改进版**，改进点集中在第一题：教程版只写了"第一个大"和"否则取第二个"，相等时虽然结果也对，但用户看不到"两个数一样大"的提示；修正版把三种情况分开处理，边界更清楚。

## 零基础学习建议

1. 先看函数是怎么拆的：`void compare_two_numbers(void)` 负责第一题，`void check_grade(void)` 负责第二题，`main` 只负责依次调用。括号里的 `void` 表示"这个函数不需要参数"，前面的 `void` 表示"这个函数不返回结果"。
2. 两个数字用 `double` 而不是 `int`，所以能处理小数。注意 `double` 的输入格式符是 `%lf`，输出格式符是 `%.2f`——输入要带 `l`，输出不带，这一点很容易记混。
3. 第一题的改进值得对照教程版看：

   ```c
   if (first_number > second_number) {
       larger_number = first_number;
   } else if (first_number < second_number) {
       larger_number = second_number;
   } else {
       printf("两个数字一样大：%.2f\n", first_number);
       return;                       // 提前结束这个函数
   }
   ```

   `else` 分支里直接 `return`，表示"相等的情况已经处理完了，后面那句输出较大值的语句不用再执行"。这种"提前返回"的写法能让后面的代码少一层缩进，读起来更顺。
4. 教程版写的是 `if / else` 两个分支，相等时走 `else` 取第二个数。因为两个数相等，取哪个都一样，所以结果也是对的——这说明**程序结果正确不等于处理完整**，把相等情况单独写出来，代码的意图更清楚。
5. 第二题的等级判断是从高到低排 `else if`，所以每一条只需要写一个下界。用 60、70、80、90 四个数字各测一次，确认边界分数归属于更高级别。
6. 建议把两个函数分别单独调用一次（比如在 `main` 里先注释掉一个），这样能分别观察每个函数的输入输出，而不是一口气跑完两题。

## 常见易错点

- `scanf("%lf %lf", &first_number, &second_number)` 要求两个数字之间用空格或回车分开。用逗号分隔（`3,5`）会读不全。
- `double` 用 `%lf` 输入、`%f` 或 `%.2f` 输出，写反了会读出错误的数值。这是本文件最容易踩的坑。
- `larger_number` 在"相等"分支里没有被赋值，但因为那一支直接 `return` 了，程序不会读到它的值。如果去掉 `return`，就会输出一个不确定的数。
- 函数声明写作 `void compare_two_numbers(void)`，调用时写 `compare_two_numbers();`——括号不能省。
- 成绩输入没有做范围校验：输入 `150` 会直接落到"优秀"。真实场景需要先判断 `score < 0 || score > 100`。
- 提示语句前面加空行（`printf("\n请输入一个成绩…")`）会让两题的输出分开，读起来清楚；如果去掉，两题结果会挤在一起。
- `printf` 里的 `%.2f` 只控制**显示**两位小数，变量内部仍然是完整的 `double` 值，不影响比较结果。

## 可以继续尝试

1. 给成绩加上 0～100 的范围校验，输入越界时提示重新输入（可以用 `while` 循环包住输入）。
2. 把"两数比较"扩展成 `double max_of_two(double a, double b)`，**返回**较大值而不是直接打印，然后在 `main` 里输出，体会"有返回值"和"没有返回值"两种函数的区别。
3. 增加一道题：输入三个数字，输出最大值，复用并嵌套调用 `max_of_two`。
4. 把成绩等级改成返回字符串的函数 `const char *grade_of(double score)`，让判断和输出分开。
5. 增加一道题：输入两个数字，同时输出较大值、较小值和它们的差，练习同一个函数里的多个分支和多条输出。
6. 给两题都加上"是否继续"的循环（输入 `y` 继续），练习把函数放在循环里反复调用。
