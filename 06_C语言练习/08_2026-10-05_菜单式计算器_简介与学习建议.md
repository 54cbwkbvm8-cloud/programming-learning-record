# C 语言简易计算器练习：文件简介与学习建议

## 文件简介

- **源码文件：** `08_2026-10-05_菜单式计算器.c`
- **类型：** C 语言菜单式交互程序
- **功能：** 循环显示菜单，提供加、减、乘、除四种运算和退出选项，除法会先检查除数是否为 0。
- **主要知识点：** `while (1)` 循环、`if / else if / else` 多分支、`float` 与 `%f`、`scanf` 输入、`printf` 格式化输出、`break` 退出循环。

程序用 `while (1)` 反复回到菜单，用整数变量 `choice` 记录用户选择，再用多分支决定执行哪种运算。两个操作数用 `float` 保存，输出时用 `%.2f` 保留两位小数。文件里的 `// 修改：` 注释记录了从错误写法改到正确写法的过程，是这份练习最有价值的部分。

## 建议运行数据

选择 1（加法），依次输入：

```text
3.5
2.25
```

预期结果：

```text
3.50 + 2.25 = 5.75
```

再选择 4（除法），先输入 `8` 和 `2`，应得到 `4.00`；再输入 `8` 和 `0`，应看到“除数不能为 0”。

## 零基础学习建议

1. 先运行一遍，按菜单把 1～5 全部试一次，观察每种选择走哪条分支。
2. 在纸上记录每轮循环里 `choice`、`a`、`b` 的取值，理解 `while (1)` 为什么能一直回到菜单，又为什么必须靠 `break` 才能退出。
3. 把重点放在输入和输出的区别上：`scanf` 读 `float` 必须写 `%f`，`%.2f` 只能用在 `printf` 里控制小数位数。这正是文件里标注的修改点。
4. 故意输入菜单以外的数字（例如 6 或 7），观察 `else` 分支的提示，理解为什么多一个 `else` 程序会友好很多。
5. 测试 `8 除以 0`，理解程序为什么要在计算前先判断 `b == 0`，而不是等出错再说。

## 常见易错点

- 读入 `float` 时写成 `scanf("%.2f", &a)` 是错的，`%.2f` 是输出格式，输入只能用 `%f`。
- 忘记写取地址符 `&`，例如写成 `scanf("%d", choice)`，会让程序行为不可预测。
- 除法要先判断 `b == 0`，否则会出现除零问题。
- 菜单循环里选择 5 之后忘记 `break`，程序就无法退出。
- `choice` 是整数，输入 `1.5` 时 `scanf("%d")` 只会读到 `1`，剩下的小数会留在输入缓冲区影响下一次读取。

## 进阶练习

1. 增加取余运算，并注意取余只能用于整数类型。
2. 增加“连续计算”功能，让上一次的结果直接参与下一次运算。
3. 把每种运算拆成独立函数，例如 `float add(float a, float b)`。
4. 用 `switch` 改写菜单分支，比较 `if` 和 `switch` 两种写法的差别。
5. 让程序在输入非法字符时给出提示，而不是陷入反复读取同一段错误输入的循环。
