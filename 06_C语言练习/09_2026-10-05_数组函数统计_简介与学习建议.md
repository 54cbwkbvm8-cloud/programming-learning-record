# C 语言数组函数统计：文件简介与学习建议

## 文件简介

- **源码文件：** `09_2026-10-05_数组函数统计.c`
- **类型：** C 语言函数与一维数组综合练习
- **功能：** 输入 5 个整数，用四个独立函数分别求总和、最大值、最小值和平均值。
- **主要知识点：** 函数声明与定义、数组作函数参数、`for` 循环、累加变量、最大值与最小值比较、强制类型转换。

和 10 月 1 日的练习相比，这次把统计逻辑拆成了 `sum`、`max`、`min`、`average` 四个函数，`main` 只负责读数据和打印结果。四个函数都接收 `int a[], int n` 两个参数，用长度 `n` 控制循环次数，而不是把 5 写死在函数里。这是从“全部都写在 main 里”走向“分而治之”的第一步。

## 建议运行数据

第一次运行可以输入：

```text
7 2 9 4 6
```

主要预期结果：

```text
五个数的和为：28
最大值是：9
最小值是：2
平均数是：5.60
```

## 零基础学习建议

1. 先运行程序，在纸上记录每次调用函数时传入的数组名 `a` 和长度 `5`，理解“数组名作为参数”是什么意思。
2. 在 `sum`、`max`、`min`、`average` 里各加一句打印 `i` 和 `a[i]`，观察每个函数是如何各自把数组遍历一遍的。
3. 思考为什么四个函数都写成 `int a[], int n`：`n` 让函数知道数组里真正有几个元素，只写 `int a[]` 是拿不到长度的。
4. 把 `average` 里的 `(float)sum / n` 改成 `sum / n`，运行后比较结果，理解整数除法会丢掉小数部分。
5. 用升序、降序、负数和重复值各测一次，检查最大值和最小值是否仍然正确。

## 常见易错点

- 函数定义写在 `main` 之后时，前面必须先写函数声明，本文件在开头声明了这四个函数。
- 函数内部的 `max`、`min`、`sum` 是局部变量，和 `main` 里的同名变量互相独立。
- 最大值和最小值的初值要取 `a[0]`，循环从下标 `1` 开始；如果循环从 `0` 开始，结果相同但容易看晕。
- `average` 的返回类型是 `float`，函数声明和定义必须一致，写成 `int` 会直接截断小数部分。
- 数组作为参数传递时传的是首地址，函数内部如果修改数组元素会影响到调用方；本文件只读不写，所以是安全的。

## 进阶练习

1. 增加 `int count_above(int a[], int n, int value)` 函数，统计大于指定值的元素个数。
2. 增加排序函数把数组从小到大排序，再重新求最大值、最小值和平均值。
3. 用 `#define N 10` 统一管理数组长度，把长度从 5 改成 10 时只改一处。
4. 让函数在数组为空（`n == 0`）时给出提示，避免除零。
5. 试着把四个函数合并成一次遍历，比较“多遍历一遍但代码清晰”和“少遍历但代码复杂”的取舍。
