## 程序功能说明

程序用两个下标变量表示“指针”：

```java
int left = 0;
int right = s.length() - 1;
while (left < right) {
    if (s.charAt(left) != s.charAt(right)) {
        isPalin = false;
        break;
    }
    left++;
    right--;
}
```

`left` 从第一个字符向右走，`right` 从最后一个字符向左走。每一轮比较它们指向的字符：只要有一对不相等，就能确定不是回文，把 `isPalin` 改成 `false` 并立刻跳出循环；如果相等，两个指针各向中间走一步。

当 `left == right` 时，两个指针指向同一个字符（奇数长度字符串的中间字符），这个字符和它自己比较必然相等，不需要再比；当 `left > right` 时，所有字符对都比较完了。两种情况都会让 `left < right` 不成立，循环结束。

以 `level` 为例：比较 `l` 与 `l`、`e` 与 `e`，然后 `left` 和 `right` 都到下标 2，循环结束，输出 `YES`。以 `abc` 为例：第一轮 `a` 与 `c` 不相等，立刻输出 `NO`。

## 学习重点

- 双指针把比较次数从“生成倒序再整体比较”的 `O(n)` 额外空间，降为只使用两个整数变量。
- 循环条件是 `left < right`，不是 `left <= right`。中间字符不需要比较，而且 `left == right` 时再走一步会变成 `left > right`，没有意义。
- `break` 只跳出当前 `while`，跳到循环后面的输出判断。
- 布尔标记 `isPalin` 要先假设为 `true`，只有发现反例才改成 `false`。
- 空字符串和单字符字符串都满足“正读反读相同”，输出 `YES`。

## 学习难点

### 比较规则必须先明确

本题按字符原样比较，因此区分大小写，空格也算字符。`Aba` 不是回文，因为 `A` 和 `a` 不相等；`ab ba` 是回文，因为中间的空格正好在对称位置。如果题目要求“忽略大小写”或“只比较字母和数字”，必须先统一大小写、过滤其他字符，再调用同样的双指针逻辑。不要在没有看清题目时擅自加过滤，否则会改变评测答案。

### 空输入与空行

`String s = "";` 加上 `hasNextLine()` 判断，保证没有输入时也能得到确定结果。空字符串的 `right` 是 -1，`left < right` 一开始就是 `0 < -1`，不成立，循环不执行，`isPalin` 保持 `true`，输出 `YES`。这符合“空串按回文处理”的约定；如果题目另有规定，应在说明中写清。

### 提前结束与完整比较

发现第一对不相等就 `break`，后面的字符对不再检查。这是正确的，因为回文要求所有对称位置都相等，一个反例就足够否定。但如果题目要求统计“有多少对不相等”，就不能提前结束。

## 建议学习流程

1. 对 `level` 写出每轮的 `left`、`right`、两个字符和比较结果。
2. 对 `abc` 写出第一轮就失败的过程。
3. 运行 `level`、`abba`、`abc`，核对 `YES`、`YES`、`NO`。
4. 把输入改成 `Aba`，预测结果并解释大小写规则。
5. 把 `while` 条件改成 `left <= right`，观察中间字符被多比一次，确认结果不变但多做了一次无用比较。
6. 关闭源码，自己写出“忽略大小写”的版本，并用 `Aba` 验证输出变为 `YES`。

## 易错点与测试用例

| 输入 | 真实输出 | 检查目标 |
| --- | --- | --- |
| `level` | `YES` | 奇数长度回文 |
| `abba` | `YES` | 偶数长度回文 |
| `abc` | `NO` | 第一对就不相等 |
| `Aba` | `NO` | 区分大小写 |
| 空行 | `YES` | 空串约定 |
| `a` | `YES` | 单字符 |
| `ab ba` | `YES` | 空格参与比较 |

以上结果已于 2026-11-16 实际运行验证（`a`、`ab ba` 为按同一逻辑推导的预期结果，未单独运行）。

常见错误包括：`right` 初始值写成 `s.length()` 导致越界；循环条件用 `<=` 后忘记指针移动造成死循环；忘记 `break` 继续比较后面的字符；把 `!` 写成 `=`；用 `next()` 读取导致带空格文本被截断。
