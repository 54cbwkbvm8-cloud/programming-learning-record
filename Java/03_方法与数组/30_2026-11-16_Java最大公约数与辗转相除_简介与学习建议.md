## 程序功能说明

最大公约数是能同时整除两个整数的最大正整数。例如 12 和 18 的公约数有 1、2、3、6，最大的是 6。

程序使用欧几里得算法（辗转相除法），核心恒等式是：

```text
gcd(a, b) = gcd(b, a % b)
```

`gcd` 方法先用 `Math.abs` 把两个参数变成非负数，然后循环：

```java
while (b != 0) {
    long r = a % b;
    a = b;
    b = r;
}
return a;
```

每一轮把“原来的除数”变成新的被除数，把“余数”变成新的除数。余数一定比除数小，所以两个数会不断变小，最终 `b` 变成 0，此时的 `a` 就是最大公约数。

以 `gcd(12, 18)` 为例：

| 轮次 | `a` | `b` | `a % b` | 下一轮 |
| --- | ---: | ---: | ---: | --- |
| 1 | 12 | 18 | 12 | `a=18, b=12` |
| 2 | 18 | 12 | 6 | `a=12, b=6` |
| 3 | 12 | 6 | 0 | `a=6, b=0` |
| 结束 | 6 | 0 | — | 返回 6 |

第一步 `12 % 18 = 12` 看起来没有缩小，但它实际上把两个数交换了位置，所以不需要在开头特意判断 `a` 和 `b` 的大小。

## 学习重点

- `gcd` 是 `static` 方法，`main` 可以直接调用，不需要创建对象。
- 参数 `long a, long b` 是调用者传入值的副本；方法内部修改 `a`、`b` 不会影响 `main` 中的变量。
- `%` 是取余，不是除法。循环结束时 `b == 0`，`a` 保存的就是公约数。
- `Math.abs` 把负数变成正数。最大公约数按定义是非负的，负数输入应先取绝对值。
- 使用 `long` 而不是 `int`，可以容纳更大的输入；`Scanner.nextLong()` 与参数类型保持一致。
- 时间复杂度是 `O(log min(a, b))`，比从 1 枚举到较小数快得多。

## 学习难点

### 为什么负数会出问题

Java 中负数取余的结果可能带负号。例如 `-4 % -6` 是 `-4`，辗转过程中符号会一直保留，最后可能返回 `-2`。数学上的最大公约数应为 `2`。在方法开头统一取绝对值，可以避免符号干扰。`gcd(-4, -6)` 和 `gcd(4, -6)` 都应得到 `2`。

### 两个数都是 0

`gcd(0, 0)` 时 `b` 一开始就是 0，循环不执行，返回 `a = 0`。数学上“0 和 0 的最大公约数”没有通常意义上的最大值，很多教材约定为 0。程序采用这一约定，遇到题目有特殊规定时应按题目处理。

### `Long.MIN_VALUE` 的极端情况

`long` 能表示的最小值 `Long.MIN_VALUE` 没有对应的正数，`Math.abs(Long.MIN_VALUE)` 仍然是负数。这是二进制补码的范围不对称造成的。普通题目不会给出这种输入；如果要求完整处理，需要在取绝对值前单独判断，或改用 `BigInteger`。

### 输入没有校验

程序直接调用两次 `nextLong()`。如果输入字母、空输入或只给一个数，会抛出 `InputMismatchException` 或 `NoSuchElementException`，程序终止。这是评测题常见的“输入保证合法”写法，不代表已经处理了所有错误输入。

## 建议学习流程

1. 用 12 和 18 手工填写上面的轮次表。
2. 运行 `12 18`，核对输出 6。
3. 用 `-4 -6` 运行，核对输出 2，再删除 `Math.abs` 两行，观察负数结果，最后恢复。
4. 用 `5 0` 和 `0 0` 测试边界。
5. 把 `long` 全部改成 `int`，思考范围变小后哪些输入会失败。
6. 关闭源码，自己写出递归版 `gcd(a, b)`：`b == 0 ? a : gcd(b, a % b)`。
