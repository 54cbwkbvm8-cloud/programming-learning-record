# Java 第二大不同值零基础教程

本教程配合 [SecondLargest.java](SecondLargest.java) 使用。目标不是只记住两行修改，而是学会按“输入是否完整、计算是否可信、输出分支是否正确”三个层次定位逻辑错误。

## 一、先把题目说清楚

输入形式是：

```text
n
a0 a1 a2 ... a(n-1)
```

例如：

```text
5
8 3 8 6 1
```

表示 5 个整数：8、3、8、6、1。最大值是 8，重复的 8 不算“第二大的不同值”，第二大的不同值是 6。

本文采用以下约定：

- `n >= 1` 时才访问第一个元素。
- 没有第二大的不同值时输出 `NO`。
- 负数也是有效数据，不能默认答案一定大于 0。

## 二、认识数组默认值

```java
int[] a = new int[n];
```

创建后，每个位置先放默认值 0：

```text
下标：  0  1  2  3  4
初值：  0  0  0  0  0
```

默认值不是用户输入。如果后面的读取循环漏掉某个下标，那个位置仍然保持 0，程序不会主动报“这里没读到数据”。

## 三、定位第一个错误：读取范围

当前源码：

```java
for (int i = 1; i < n; i++) {
    a[i] = sc.nextInt();
}
```

Java 数组下标从 0 开始，合法范围是 `0` 到 `n - 1`。这段循环只写了下标 1 到 `n - 1`，共有 `n - 1` 次。

输入 `5 / 8 3 8 6 1` 后，实际读取过程是：

| 下标 | 读取哪个数 | 读后数组 |
| ---: | ---: | --- |
| 0 | 没有读取 | `0` |
| 1 | 8 | `[0, 8, 0, 0, 0]` |
| 2 | 3 | `[0, 8, 3, 0, 0]` |
| 3 | 8 | `[0, 8, 3, 8, 0]` |
| 4 | 6 | `[0, 8, 3, 8, 6]` |

最后一个输入 1 没有进入数组，`a[0]` 也不是 8，而是默认 0。

正确读取：

```java
for (int i = 0; i < n; i++) {
    a[i] = sc.nextInt();
}
```

检查方法不是“看代码感觉像对”，而是读完后让数组长度、输入数量、下标范围三者一致。

## 四、定位第二个错误：输出分支写反

找第二值的循环使用 `found`：

```java
if (a[i] < max) {
    if (!found || a[i] > second) {
        second = a[i];
        found = true;
    }
}
```

`found == true` 表示已经找到一个比最大值小、并且当前最大的不同值。循环结束后应输出它。

当前输出：

```java
if (!found) {
    System.out.println(second);
} else {
    System.out.println("NO");
}
```

这是反方向：

- 没找到时，反而打印 `second`。
- 找到时，反而打印 `NO`。

正确分支：

```java
if (found) {
    System.out.println(second);
} else {
    System.out.println("NO");
}
```

可以把 `found` 读成一句自然语言：“找到了吗？” 找到就输出答案，没找到就输出 `NO`，顺序与代码完全一致。

## 五、为什么 `second = 0` 不适合表示“没有”

假设修正读取后又写成：

```java
int second = 0;
if (second == 0) {
    System.out.println("NO");
}
```

若真实数组是 `[3, 0, -1]`，第二大值就是 0。把 0 当成“没有值”会误报。

`found` 保存的是状态，`second` 保存的是数值。状态和数值分开后，0、正数、负数都能正常处理。

## 六、修正后的核心流程

在不覆盖原文件的前提下，可以把完整逻辑写成下面的独立修正版：

```java
import java.util.Scanner;

public class SecondLargestFixed {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();

        if (n <= 0) {
            System.out.println("NO");
            sc.close();
            return;
        }

        int[] a = new int[n];
        for (int i = 0; i < n; i++) {
            a[i] = sc.nextInt();
        }

        int max = a[0];
        for (int i = 1; i < n; i++) {
            if (a[i] > max) {
                max = a[i];
            }
        }

        boolean found = false;
        int second = 0;
        for (int i = 0; i < n; i++) {
            if (a[i] < max) {
                if (!found || a[i] > second) {
                    second = a[i];
                    found = true;
                }
            }
        }

        if (found) {
            System.out.println(second);
        } else {
            System.out.println("NO");
        }
        sc.close();
    }
}
```

这份代码只用于解释，不应直接覆盖上传的 `SecondLargest.java`。若要在仓库练习修正版，应另存为 `SecondLargestFixed.java`，再补充自己的测试记录。

## 七、用变量表验证

对 `[8, 3, 8, 6, 1]`：

第一遍求最大值：

| `i` | `a[i]` | 操作后的 `max` |
| ---: | ---: | ---: |
| 0 | 8 | 8 |
| 1 | 3 | 8 |
| 2 | 8 | 8 |
| 3 | 6 | 8 |
| 4 | 1 | 8 |

第二遍求第二值：

| `i` | `a[i]` | `found` | `second` |
| ---: | ---: | --- | ---: |
| 0 | 8 | false | 0 |
| 1 | 3 | true | 3 |
| 2 | 8 | true | 3 |
| 3 | 6 | true | 6 |
| 4 | 1 | true | 6 |

最终 `found == true`，输出 6。

## 八、测试设计

| 输入 | 预期 | 目的 |
| --- | --- | --- |
| `5 / 8 3 8 6 1` | `6` | 重复最大值 |
| `3 / 7 7 7` | `NO` | 没有第二值 |
| `3 / -1 -2 -3` | `-2` | 全负数 |
| `1 / 9` | `NO` | 单元素 |
| `0` | 受控提示，不崩溃 | 空输入边界 |
| `5 / 2 1 9 9 5` | `5` | 第二值在末尾附近 |

预期结果必须与“题目定义”一致，不能拿当前错误程序的输出当标准答案。

## 九、练习怎样检查自己真的理解

1. 不看教程，指出读取循环的下标错误。
2. 用一句话解释 `found` 表示什么。
3. 对 `[4, 4, 3, 2]` 手工写出最大、第二值和最终输出。
4. 解释为什么 `[0, -1]` 的第二值是 -1，而不是 0。
5. 自己设计一组能证明输出分支被写反的数据。
6. 把修正版改为一次遍历同时维护最大值和第二值，再重新测试全部边界。
