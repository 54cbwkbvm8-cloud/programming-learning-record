# Java 方法定义与返回值简介

## 文件基本信息

- 源码：[MethodBasic.java](MethodBasic.java)
- 首次整理日期：2026-11-08
- 所属分类：`Java/03_方法与数组`
- 程序用途：用一个短程序比较无参数无返回值、有参数无返回值、有参数有返回值三种常见方法。
- 主要问题：怎样把重复逻辑放进方法；调用方法时数据怎样传进去；返回值怎样交回 `main`；方法之间怎样嵌套调用。
- 核心知识点：`static` 方法、方法签名、形参、实参、`void`、`return`、局部变量、返回值、方法调用链。
- 前置知识：类、`main`、变量、`if`、字符串拼接、`System.out.println`。
- 相关练习：先完成 [14 号方法与数组综合练习](14_2026-11-07_Java方法与数组综合练习_简介与学习建议.md)；随后用 [MaxOverload.java](MaxOverload.java) 学习方法重载，用 [PassByValue.java](PassByValue.java) 理解参数传递。

## 程序功能说明

源码定义四个工具方法：

1. `sayHello()` 不接收参数，也不返回数据，只输出一行文字。
2. `printSquare(int n)` 接收一个整数，在方法内部计算平方并直接打印，返回类型是 `void`。
3. `add(int a, int b)` 接收两个整数，返回它们的和。
4. `level(int score)` 根据分数返回“及格”或“不及格”。

`main` 依次调用这些方法。`add(add(1, 2), 10)` 展示了嵌套调用：先执行内层 `add(1, 2)` 得到 3，再把 3 和 10 交给外层 `add`，最终得到 13。

方法的主要作用是分工。若把全部打印、计算和判断都塞进 `main`，程序短时还能读；功能一多，就难以判断问题出在输入、计算还是输出。拆成方法后，每个方法只负责一件明确的事。

## 运行方式

本程序不需要输入。Windows、macOS 或 Linux 只要安装了 JDK，都可以在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-method.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/03_方法与数组/MethodBasic.java"
java -cp "$java_dir" MethodBasic
```

已在 OpenJDK 21.0.13 下实际编译运行，退出码为 0，真实输出为：

```text
Hello, method !
5 的平方是 25
add(3,4) = 7
add(add(1, 2)), 10) = 13
level(60) = 及格
level(59) = 不及格
```

第四行输出字符串中多了一个右括号，是显示文字的一部分，不影响 Java 表达式 `add(add(1, 2), 10)` 的计算。源码按要求保留原样，没有为美化输出修改算法。

## 学习重点

| 知识点 | 需要理解什么 | 为什么重要 |
| --- | --- | --- |
| 方法声明 | 修饰符、返回类型、方法名、参数列表和方法体 | 读方法时先知道它接收什么、交回什么 |
| 参数 | 调用时实参的值复制给形参 | 方法内部使用的是形参这份局部数据 |
| `void` | 方法只执行动作，不交回可用结果 | 不能把 `void` 方法直接写进算术表达式 |
| `return` | 立即结束当前方法，并把值交给调用处 | 有返回值的方法必须保证每条正常路径都有返回值 |
| 方法调用 | 方法可以调用另一个方法，也可以嵌套调用 | 大问题可以拆成多个可单独验证的小步骤 |
| 局部变量 | `sum` 只在 `add` 方法体中存在 | 不同方法中的同名变量通常互不影响 |

最值得观察的是 `printSquare` 与 `add` 的差别。两者都接收参数，但 `printSquare` 把结果直接输出，`add` 把结果返回。返回值的优势是调用者还能继续使用结果，例如再传给另一个方法或参加运算。

## 学习难点

### 难点一：打印结果不等于返回结果

`printSquare` 输出平方后，调用者拿不到这个平方值。`add` 使用 `return sum`，调用处才能写：

```java
int result = add(3, 4);
```

如果方法声明返回 `int`，却只在方法里打印而不写 `return`，编译会失败。

### 难点二：实参与形参是两个位置

调用 `add(3, 4)` 时，3 和 4 是实参；方法声明中的 `a` 和 `b` 是形参。执行时，3 复制给 `a`，4 复制给 `b`。方法结束后，形参 `a`、`b` 和局部变量 `sum` 都不再属于调用者。

### 难点三：返回后方法立即结束

`return` 不是“顺便交一个值再继续执行”，而是直接离开当前方法。后面的语句即使有代码，也不会在本轮调用中执行。

## 建议学习流程

1. 先只看 `main`，写出程序会调用的四个方法名。
2. 找到每个方法的返回类型、参数列表和一个最小调用例子。
3. 手工执行 `add(add(1, 2), 10)`，写出两层调用的输入与输出。
4. 运行源码，对照真实输出。
5. 把 `printSquare(5)` 临时改成 `printSquare(-3)`，预测后运行。
6. 不看源码，自己写 `static int square(int n)`，让它返回平方而不是打印。
7. 再写 `static boolean isPass(int score)`，返回是否及格。

## 易错点与测试用例

| 输入或修改 | 预期结果 | 检查目标 |
| --- | --- | --- |
| `printSquare(5)` | 输出 25 | 有参数、无返回值 |
| `printSquare(-3)` | 输出 9 | 负数平方 |
| `add(3, 4)` | 返回 7 | 基本返回值 |
| `add(add(1, 2), 10)` | 返回 13 | 嵌套调用顺序 |
| `level(60)` | `及格` | 等于阈值 |
| `level(59)` | `不及格` | 阈值下方 |
| 把 `return sum;` 删掉 | 编译失败 | 有返回值方法缺少返回 |
| 尝试 `int x = printSquare(5);` | 编译失败 | `void` 方法没有值可赋给变量 |

当前源码没有检查分数是否在 `0～100` 之间。`level(-1)` 会返回“不及格”，`level(101)` 会返回“及格”，这只是现有二分支的结果，不代表程序完成了成绩范围校验。

## 拓展练习

4. 给 `add` 增加三个整数版本，观察方法重载怎样选择。
