# Java 数字出现次数统计简介

## 文件基本信息

- 源码：[DigitCount.java](DigitCount.java)
- 首次整理日期：2026-11-08
- 所属分类：`Java/03_方法与数组`
- 程序用途：统计从 1 到 `n` 的所有整数中，数字 `x` 出现了多少次。
- 主要问题：怎样遍历多个整数，又对每个整数逐位拆解并累计匹配次数。
- 核心知识点：嵌套循环、`while`、`% 10`、`/ 10`、计数器、循环终止条件、输入边界。
- 前置知识：`for`、`while`、整数拆位、计数器、`Scanner`。
- 相关练习：与本组中的 [Narcissistic.java](Narcissistic.java) 都使用三位拆位；本练习用 `while` 处理未知位数。

## 程序功能说明

外层 `for` 从 1 遍历到 `n`。对每个 `num`，把值复制到临时变量 `temp`：

```java
while (temp > 0) {
    int digit = temp % 10;
    temp = temp / 10;
}
```

每轮取得最低位，检查是否等于 `x`，再删掉最低位。`temp` 最终变为 0 时停止。不能直接反复除以 `num`，否则会丢失当前整数，也会影响外层循环需要的值。

例如 1 到 100 中数字 0 出现 11 次：10、20、30、40、50、60、70、80、90 各一次，100 中出现两次。

## 运行方式

编译：

```bash
java_dir=$(mktemp -d /tmp/java-digit.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/03_方法与数组/DigitCount.java"
```

统计 1 到 100 中 0 的次数：

```bash
printf '100 0\n' | java -cp "$java_dir" DigitCount
```

真实输出为 `11`。另外实际测试：

| 输入 | 真实输出 |
| --- | --- |
| `100 1` | `21` |
| `20 9` | `2` |

## 学习重点

- `% 10` 取当前最低位，`/ 10` 删除最低位，两者必须成对使用。
- `while (temp > 0)` 适合不知道一个整数有几位的情况。
- `count` 在整个外层循环外初始化，才能累计所有整数的结果。
- 0 需要特别关注：数值 0 本身不进入 `while`，但 10、20、100 中的 0 可以正常被拆出。

## 学习难点

### 为什么 1 到 100 中 0 的次数不是 10

100 含有两个 0，因此除了 10 到 90 的 9 次，还要再加 2 次，共 11 次。只粗略举例“每个整十数一个 0”会漏掉 100。

### 为什么不统计数值 0

循环从 1 开始，题目当前范围不包含 0。若题目改成从 0 开始，`temp = 0` 的 `while` 一次也不执行，会漏掉 0 这一位，需要单独处理或改用 `do-while`。

### 输入范围未被检查

源码直接读取 `n` 和 `x`，没有检查 `n >= 1`，也没有检查 `x` 是否在 `0～9`。`x = 10` 会得到 0，但这个结果可能掩盖输入错误，而不是证明“数字 10 出现 0 次”。

## 建议学习流程

1. 手算 1 到 20 中每个数字出现次数。
2. 对 `num = 100` 逐轮写出 `digit` 和 `temp`。
3. 运行 `100 0`、`100 1` 验证。
4. 修改 `x` 为 9，预测再运行。
5. 测试 `n = 0`、负数或 `x = 10`，记录当前程序行为。
6. 关闭源码，自己写 `countDigit(int n, int x)` 方法。

## 易错点与测试用例

| 输入 | 当前真实输出 | 检查目标 |
| --- | --- | --- |
| `100 0` | `11` | 0 和多零数字 |
| `100 1` | `21` | 普通非零数字 |
| `20 9` | `2` | 9、19 |
| `0 0` | `0` | 当前范围不含 0 |
| `20 10` | `0` | 缺少数字范围校验 |

常见错误包括把 `temp / 10` 写成 `temp / 100`、忘记更新 `temp` 造成死循环、把计数器放进外层循环内部导致每轮重置，以及用 `num` 本身参与除法和取余后继续错误的遍历。

## 拓展练习

1. 把核心逻辑拆成 `static int countDigit(int n, int x)`，返回计数。
2. 增加输入校验，要求 `n >= 0`、`0 <= x <= 9`。
3. 统计每个数字 0 到 9 的出现次数，使用长度 10 的数组。
4. 处理负数时，说明负号不算数字，数字部分怎样取绝对值。
5. 完成后对照 [Narcissistic.java](Narcissistic.java)，比较固定三位拆位与 `while` 通用拆位。
