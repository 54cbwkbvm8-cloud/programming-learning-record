## 程序功能说明

质数是大于 1、且只能被 1 和自身整除的整数。2、3、5、7、11 是质数；1、0、负数和 4、9 不是。

程序分两步：

```java
if (n < 2) {
    return false;
}
for (long i = 2; i <= n / i; i++) {
    if (n % i == 0) {
        return false;
    }
}
return true;
```

第一步排除所有小于 2 的数。第二步从 2 开始试除，只要发现一个能整除 `n` 的 `i`，就立刻返回 `false`；循环结束都没有找到因数，返回 `true`。

`main` 读取一个 `long`，用三元运算符把布尔结果转换成题目要求的文字：

```java
System.out.println(isPrime(n) ? "Yes" : "No");
```

## 学习重点

- 质数定义包含“大于 1”，所以 `n < 2` 必须直接返回 `false`。
- 如果 `n = a × b` 且 `a`、`b` 都大于 1，那么其中至少有一个不超过 `sqrt(n)`。因此试除到平方根即可，不需要试到 `n - 1`。
- `i <= n / i` 与 `i * i <= n` 在数学上等价，但前者只做除法，不会让 `i * i` 超出 `long` 的范围。
- `i` 也声明为 `long`。如果 `n` 很大而 `i` 是 `int`，`i` 可能在试除结束前就超出 `int` 范围。
- `return` 会立刻结束方法，所以找到一个因数后不需要继续循环。
- 2 是最小的质数，也是唯一的偶数质数。循环从 2 开始，`2 <= 2 / 2 = 1` 不成立，直接返回 `true`。

## 学习难点

### 为什么 `i * i <= n` 会溢出

`long` 的最大值约为 `9.22 × 10^18`。当 `n` 接近这个范围时，`i` 也可能达到约 `3.04 × 10^9`，此时 `i * i` 约为 `9.22 × 10^18`，已经接近或超过 `long` 的上限。溢出后结果变成负数，`负数 <= n` 永远成立，循环会继续跑，判断出错。`i <= n / i` 只做除法，商一定不大于 `n`，不会溢出。

同理，如果参数是 `int`，`i * i` 在 `n` 接近 `Integer.MAX_VALUE` 时也会溢出。现有 [PrimeDemo.java](PrimeDemo.java) 已经使用 `int` 版的 `i <= n / i`，本题进一步把类型扩展到 `long`。

### 为什么只试到平方根

假设 `n = 36`，因数是 `1×36、2×18、3×12、4×9、6×6`。每一对因数中，较小的那个都不超过 6，而 6 是 `sqrt(36)`。如果试到 6 都没有发现因数，那么更大的因数也不可能单独存在，因为它的配对因数会更小。这样把试除次数从 `n` 降到约 `sqrt(n)`。

### 大数的性能限制

即使写法正确，试除次数仍约为 `sqrt(n)`。`n` 是十几位数时还能很快完成；到十八九位数时，无论怎样优化这个循环都会很慢，这是试除法本身的限制，不是代码错误。更大范围通常需要米勒-拉宾等概率素性测试。

### 输入没有校验

`nextLong()` 遇到字母或空输入会抛出异常，程序不会提示重试。这是评测题“输入保证合法”的写法。若要做交互程序，应先用 `hasNextLong()` 检查并处理 EOF。

## 建议学习流程

1. 用 97 手工计算 `sqrt(97)` 约等于 9.8，列出需要试除的 `i`。
2. 运行 `97`，核对 `Yes`。
3. 分别运行 `1`、`2`、`4`、`-7`，解释每个结果。
4. 把条件改成 `i * i <= n`，用普通数据确认结果相同，再思考大数时的差异。
5. 把 `long` 改成 `int`，用 `2147483647` 测试，观察是否仍能正确判断。
6. 关闭源码，自己写出“输出 1 到 100 中所有质数”的版本。

| `1000000007` | `Yes` | 十位数质数 |
| `abc` | 抛出 `InputMismatchException` | 未做输入校验 |

以上前七行已于 2026-11-16 实际运行验证；异常行为为按 `Scanner` 规则推导的预期结果，未单独运行。

常见错误包括：忘记排除 1；循环条件写成 `i < n` 导致大数极慢；用 `i * i <= n` 且类型不够宽导致溢出；把 `n % i == 0` 写成 `n / i == 0`；找到因数后只 `break` 而不返回值，导致后续逻辑混乱；输出大小写与题目要求不一致（本题是 `Yes` / `No`，首字母大写）。
