# Java 约数枚举简介

## 文件基本信息

- 源码：[Divisors.java](Divisors.java)
- 首次整理日期：2026-11-08
- 所属分类：`Java/03_方法与数组`
- 程序用途：读取正整数 `n`，按从小到大输出它的所有正约数。
- 主要问题：怎样枚举并判断整除；怎样让多个结果同行输出且不产生多余空格。
- 核心知识点：`Scanner`、`for`、取余、整除、布尔标记、同行输出、边界条件。
- 前置知识：循环、取余、`if`、`System.out.print` 和 `println`。
- 相关练习：可与 [PrimeDemo.java](PrimeDemo.java) 对照：素数判断只关心是否存在 2 到平方根范围内的真约数。

## 程序功能说明

对每个 `i = 1` 到 `n`，执行 `n % i == 0`。成立时 `i` 是 `n` 的正约数。

`isFirst` 控制空格：第一个约数前不输出空格，之后的每个约数前先输出一个空格。循环结束后执行一次 `println()`，把整行收尾。

程序按 `i` 从小到大遍历，因此输出天然升序。

## 运行方式

编译：

```bash
java_dir=$(mktemp -d /tmp/java-divisors.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/03_方法与数组/Divisors.java"
```

测试 36：

```bash
printf '36\n' | java -cp "$java_dir" Divisors
```

真实输出：

```text
1 2 3 4 6 9 12 18 36
```

测试素数 17，实际输出 `1 17`。

## 学习重点

- 约数必须整除原数，`%` 的余数为 0。
- `i` 的上界是 `n`，因为 1 和 `n` 也都是正约数。
- 布尔变量可以作为“是否是第一个输出项”的状态。
- 同行输出使用 `print`，最后只用一次 `println` 控制换行。

## 学习难点

### 空格通常要放在分隔位置

如果在每个数后面都打印空格，最后一个数后也会留下尾随空格。虽然多数题目能容忍，严格输出检查可能不接受。本程序在非首个数字前打印空格，能避免尾随空格。

### 负数和 0 没有正确定义

题目预期是正整数。源码没有输入校验：`n = 0` 时循环不执行，只输出一个空行；`n = -12` 时连第一次 `i <= n` 都不成立，也只会输出一个空行。学习时应先明确“正整数”前提，不能把空输出误认为负数已经正确处理。

### 效率不是本练习重点

检查 1 到 `n` 的复杂度是 `O(n)`，适合入门。以后可以只检查到平方根，再成对加入约数，但这会改变输出顺序和数据结构要求。

## 建议学习流程

1. 手写 12 的正约数，再运行验证。
2. 跟踪 `isFirst` 在 1、2、3 三个约数上的变化。
3. 运行 36 和 17，观察结果数量。
4. 测试 0，记录空行和缺少校验的问题。
5. 把代码改成核心方法 `static void printDivisors(int n)`。
6. 关闭源码，自己写一个从大到小输出约数的版本。

## 易错点与测试用例

| 输入 | 真实结果 | 检查目标 |
| --- | --- | --- |
| `12` | `1 2 3 4 6 12` | 普通合数 |
| `17` | `1 17` | 素数只有两个正约数 |
| `1` | `1` | 最小正整数 |
| `0` | 空行 | 缺失输入校验 |
| `-12` | 空行 | `i <= n` 首次为假，缺少输入校验 |

常见错误包括从 0 开始导致除以 0、把 `n % i` 写成 `i % n`、把所有结果换行输出，以及最后一个数字后留下多余空格。

## 拓展练习

1. 增加 `n >= 1` 检查。
2. 改成只检查到平方根，并保持升序输出。
3. 统计约数个数，并据此判断完全数。
4. 输入多个正整数，逐个输出约数。
5. 与 [PrimeDemo.java](PrimeDemo.java) 比较：为什么素数判断找到第一个真约数就能提前结束，而输出全部约数不能提前结束。
