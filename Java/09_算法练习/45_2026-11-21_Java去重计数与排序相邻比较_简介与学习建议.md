# Java 去重计数与排序相邻比较：简介与学习建议

## 1. 文件基本信息

- **源码**：`P4_DistinctCount.java`
- **分类**：`Java/09_算法练习`
- **程序用途**：评测题——读入 n 个整数，输出其中不同数值的个数（重复只算一个）。
- **核心知识点**：`Arrays.sort`（本仓库 Java 源码首次调用内置排序）、"排序后相同元素必相邻"的性质、相邻比较计数、`n = 0` 边界的提前返回。
- **前置知识**：数组、循环、`import`（01、14 号已用）、评测题输入格式（22 号）。
- **相关练习**：43、44 号练过手写排序；本题第一次使用 `Arrays.sort`。29 号字母统计是"计数数组"思路，本题是"排序比较"思路，45 号会把两者对照。

## 2. 程序功能说明

思路分三步：先 `Arrays.sort(arr)` 升序排序，相同元素就一定挨在一起（如 `3 1 3 2 1` → `1 1 2 3 3`）；然后从下标 1 起逐个和前一个比较，第一个数算一个新数，之后每次"和前面不一样"就计数加一；`1 1 2 3 3` 数出 3 个。

`n = 0` 被单独处理：计数器 `count` 从 1 起步（默认第一个数算一个），没有元素时会错误地输出 1，所以提前打印 0 并 `return`。这是"初始化假设与空输入冲突"的典型边界。

## 3. 编译与运行

在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-algo3.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \

```

已使用 OpenJDK 21.0.13 严格编译并实际运行，输出 `3`。

## 4. 学习重点与难点

- **排序的性质用法**：本题不是"为了排序而排序"，而是利用"排序让相等元素相邻"，把"和谁比"从"所有其他元素"降为"前一个元素"，复杂度从平方降为线性（不计排序本身）。
- **手写排序与工具排序的分工**：43、44 号手写排序是为了理解算法；本题用 `Arrays.sort` 是工程上正确的选择。仓库文档此前多次强调"先手写再讨论内置工具"（见根 README 学习建议），本题标志着 Java 侧走到了"使用工具"这一步。
- **`count` 从 1 起步的含义**：它隐含假设"下标 0 一定是一个新数"。这个假设只在 `n >= 1` 时成立，所以必须有 `n == 0` 分支。理解假设何时失效，比背边界情况更重要。
- **循环从下标 1 开始**：下标 0 前面没有元素，`arr[i - 1]` 在 `i = 0` 时是 `arr[-1]`，越界。

## 5. 推荐学习流程

1. 手工把 `3 1 3 2 1` 排序成 `1 1 2 3 3`，逐个标记"新数/重复"，数出 3。
2. 运行程序核对，再试 `5\n7 7 7 7 7\n`（全相同，预期 1）。
3. 遮住 `if (n == 0)` 分支，推理 `0` 作为输入时为什么会输出 1，再恢复分支验证。
4. 对照 29 号：字母统计用 26 格计数数组，本题用排序，两法各适合什么数据范围？（45 号会给出答案。）
5. 合上源码重写，注意 `import java.util.Arrays` 和从下标 1 开始的循环。
