# Java 文本分析与命令行参数：简介与学习建议

## 1. 文件基本信息

- **源码**：`TextAnalyzer.java`
- **分类**：`Java/09_算法练习`
- **程序用途**：读一行文本做词级分析——正则分词、26 个字母的出现次数、最长单词、所有回文词；可选通过命令行参数限制列出前 N 个单词，并对参数做完整校验。
- **核心知识点**：`replaceAll("[^a-z]+", " ")` 分词、`trim` 与空串判断、`split(" +")`、最长值维护、回文双指针复用、`args[0]` 命令行参数与 `try-catch` 校验、`print` 控制行内输出。
- **前置知识**：26 格计数（29 号）、双指针回文（28 号）、`String` API（49 号）、`NumberFormatException`（52 号）。
- **相关练习**：本题是 53 号 `StringAlgorithms` 的延伸（从"方法演示"升级为"小工具"），也是 27–29 号字符串练习的综合运用。

## 2. 程序功能说明

流程分五步：

1. 读一行（`hasNextLine` 保护），转小写（`Locale.ROOT`）。
2. 统计 26 个字母频次（`c - 'a'` 映射）。
3. 分词：先把**所有非小写字母**替换成空格（`[^a-z]+`），`trim` 后按 `" +"` 切分；空文本得到空数组而不是 `[""]`。
4. 遍历单词：维护最长词；长度大于 1 且是回文的收集起来（用 `, ` 连接）。
5. 输出：`words=` 数量、a~z 一行频次（`print` 拼接，最后加换行）、`longest=`、`palindromes=`，再按 `limit` 列出单词。

`limit` 默认等于单词数；若命令行给了参数，`Integer.parseInt(args[0])` 解析并校验范围（负数或超总数 → `invalid limit`、`limit = 0`），非整数 → `invalid integer limit`。

源码后半段保留附件注释教程。

## 3. 编译与运行

在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-algo4.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/09_算法练习/TextAnalyzer.java"
printf 'level radar test\n' | java -cp "$java_dir" TextAnalyzer
printf 'level radar test\n' | java -cp "$java_dir" TextAnalyzer 2
printf 'level radar test\n' | java -cp "$java_dir" TextAnalyzer abc
```

已使用 OpenJDK 21.0.13 严格编译并实际运行。无参数时输出：

```text
words=3
a:2 b:0 c:0 d:1 e:3 ... z:0
longest=level
palindromes=level, radar
word[0]=level
word[1]=radar
word[2]=test
```

参数 `2` 时只列出前两个单词（`word[0]`、`word[1]`）；参数 `abc` 时输出 `invalid integer limit` 且不列单词；参数 `99`（超过单词数）时输出 `invalid limit`。

## 4. 学习重点与难点

- **正则分词是本程序的核心技巧**：`[^a-z]+` 把"非字母的一切"（标点、数字、空格、中文）都当作分隔符，比 `split(" ")` 稳健得多。它同时解释了为什么中文不会产生单词——中文不在 `a-z` 范围内。
- **空文本的分词陷阱**：`"".split(" +")` 返回 `[""]`（长度 1），会把单词数算成 1；先 `clean.isEmpty()` 判断再返回空数组，是"边界决定正确性"的典型。
- **`print` 与 `println` 配合**：26 个字母在同一行，用 `print` 逐段拼接、最后一项用 `println` 收尾，避免 27 行输出。
- **最长词的同长约定**：只有 `>` 才更新，`==` 保留先出现的词——`level(5)` 与 `panama(5)` 并存时，答案是 `level`。
- **命令行参数与标准输入是两条通道**：`args` 来自启动命令，`Scanner` 读标准输入。参数校验必须自己做（类型 + 范围），`args.length` 判断是否存在。
- **回文收词的顺序与重复**：`palindromes` 按出现顺序保留重复词（这里没有去重），要理解这是"约定"而非漏洞。

## 5. 推荐学习流程

1. 用 `level radar test` 运行，核对频次与回文列表。
2. 换一段含标点和数字的文本（如 `A man, a plan, a canal: Panama.`），预测分词结果再运行。
3. 分别用参数 `0`、`2`、`99`、`abc` 运行，观察三种校验分支。
4. 手工计算 `longest` 与 `palindromes`：哪句话、哪个词会赢。
5. 合上源码重写核心流程：分词 + 频次 + 最长词，输出格式自定。
