# Java 第 k 大与降序插入排序：简介与学习建议

## 1. 文件基本信息

- **源码**：`P3_KthLargest.java`
- **分类**：`Java/09_算法练习`
- **程序用途**：评测题——读入 n、k 和 n 个整数，输出第 k 大的数。
- **核心知识点**：降序插入排序（本仓库首次出现）、"第 k 大"的下标换算（`arr[k - 1]`）、短路与 `&&` 如何防止 `arr[-1]` 越界。
- **前置知识**：数组、嵌套循环、布尔表达式的求值顺序、评测题输入格式（22 号）。
- **相关练习**：22 号"第二大不同值"与本题语义不同：22 号把重复值跳过（`9 9 7` 中第二大是 7），本题每个重复值单独占位（`9 9 7` 中第二大还是 9）。42、43 号完成后做本题。

## 2. 程序功能说明

思路是"先从大到小排序，第 k 大就是排好后的 `arr[k - 1]`"。排序用的是**插入排序**：像整理扑克牌——左边的牌始终有序，每次拿起右边一张新牌，从右往左把比它小的牌右移一格，再把新牌插进空位。

以 `[3, 9, 4]` 降序为例：拿起 9，比 3 大则 3 右移，9 插最前 → `[9, 3, 4]`；拿起 4，3 右移、9 不动，4 插中间 → `[9, 4, 3]`。此时第 1 大是 `arr[0]`、第 2 大是 `arr[1]`。

与冒泡排序（43 号）对比：冒泡是"相邻比较、大数右浮"，插入是"拿一张、腾位置、放进去"。插入排序对基本有序的数据更快，且同样是稳定的。

## 3. 编译与运行

在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-algo3.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/09_算法练习/P3_KthLargest.java"
printf '5 2\n3 9 4 9 7\n' | java -cp "$java_dir" P3_KthLargest
```

已使用 OpenJDK 21.0.13 严格编译并实际运行，输出 `9`（降序后为 `9 9 7 4 3`，第 2 位是第二个 9）。

## 4. 学习重点与难点

- **两种"第 k 大"的定义**：重复值占位（本题）与不占位（22 号）。做错通常不是代码错，而是题意没对齐。附件注释也专门提醒了这一点。
- **`while (j >= 0 && arr[j] < key)` 的顺序不能反**：`&&` 先看左边，`j >= 0` 不成立时右边不再求值，因此永远不会访问 `arr[-1]`。写成 `arr[j] < key && j >= 0` 会先访问越界元素直接崩溃。这与 05 号 `&&` 短路、18 号循环边界一脉相承。
- **`key` 必须先存**：`arr[j + 1] = arr[j]` 的搬移会覆盖 `arr[i]` 的原值，所以进循环前先用 `key` 保存。
- **降序的判断方向**：要挪走的是比新牌**小**的牌（`arr[j] < key`）；如果照抄升序插入排序的 `>`，结果就反了。
- **`k` 的合法性前提**：题目保证 `1 <= k <= n`；若 `k` 越界，`arr[k - 1]` 抛 `ArrayIndexOutOfBoundsException`。评测题通常不为此加防护，但自己写工具类时应当考虑。

## 5. 推荐学习流程

1. 用 `[3, 9, 4]` 手工走两轮外层循环，画出每轮 `key`、`j` 的变化和数组状态。
2. 运行程序核对 `9`，再用 `5 3\n3 9 4 9 7\n`（第 3 大，预期 7）验证对题意的理解。
3. 对照 22 号：同一组数据 `3 9 4 9 7`，两题的"第 2 大"答案分别是 9 和 7，说清楚为什么。
4. 实验：`k = 1`（最大值）、`k = n`（最小值）、全负数数组。
5. 合上源码重写：先写升序版，再只改一个比较符号变降序版，验证理解了方向控制。
