# Java 字符串算法四题：简介与学习建议

## 1. 文件基本信息

- **源码**：`StringAlgorithms.java`
- **分类**：`Java/09_算法练习`
- **程序用途**：一组字符串算法练习——按单词反转句子、判断两段文本是否互为异位词（字母重排）、求最长连续相同字符长度、规范化多余空白。程序从键盘读两行，一次输出四个结果。
- **核心知识点**：`split` 与 `StringBuilder` 组合、`Locale.ROOT` 大小写转换、26 格计数数组的"加一减一抵消"技巧、单遍扫描维护连续段、`replaceAll` 正则压缩空白、`null` 防御。
- **前置知识**：`String` API（49 号）、`StringBuilder`（50 号）、数组计数（29 号）、双指针（28 号）。
- **相关练习**：27 号做过字符串倒序（整串），本题是"单词级"反转；29 号的 26 格计数在本题升级为"异位词判定"；54 号 `TextAnalyzer` 是本题的自然延伸（整段文本统计）。

## 2. 程序功能说明

四个方法各司其职：

1. `reverseWords(s)`：先 `normalize` 统一空白，再按空格切词，**从后往前**拼回——单词内部字符顺序不变，只反转单词顺序。空输入返回空串（循环中 `isEmpty` 防御）。
2. `isAnagram(a, b)`：规范化、去空格、统一小写后，若长度不同直接 `false`；否则用 26 格计数数组，第一个串每个字母 `++`、第二个串每个字母 `--`，最后全 0 就是异位词。遇到非 `a~z` 字符直接 `false`（约定只处理英文）。
3. `longestRun(s)`：单遍扫描，比较当前字符与前一个，相等则 `current++` 否则重置为 1，用 `best` 记录历史最大。`null` 或空串返回 0。
4. `normalize(s)`：`trim()` 去两端空白，`replaceAll("\\s+", " ")` 把中间连续空白压成一个空格；`null` 返回 `""`。

`main` 读两行文本后依次打印四个结果。

源码后半段保留附件注释教程。

## 3. 编译与运行

在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-algo4.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/09_算法练习/StringAlgorithms.java"
printf 'hello   world java\nworld hello java\n' | java -cp "$java_dir" StringAlgorithms
```

已使用 OpenJDK 21.0.13 严格编译并实际运行，输出：

```text
reverseWords=java world hello
anagram=true
longestRun=3
normalized=hello world java
```

三个空格被压成一个（`normalized`），同时 `longestRun=3` 说明**原始输入**里的三个连续空格被计入连续段——两个方法读的是同一份原文、各自做不同的事。

## 4. 学习重点与难点

- **两个方法对同一输入的不同处理**：`longestRun` 用原始 `s`（保留连续空格），`reverseWords` 用 `normalize(s)`（压缩空白）。改哪个方法用哪份文本，会直接改变结果——这是"函数边界"的具体训练。
- **异位词的"加一减一"抵消法**：比"分别统计两个数组再比较"省一半空间，也比排序后比较（O(n log n)）更快（O(n)）。它与 45 号"排序去重"、55 号"计数数组"同属"用下标当值"的思路。
- **`Locale.ROOT` 的意义**：`toLowerCase()` 不带参数会用系统语言环境，土耳其语环境下 `"I".toLowerCase()` 会得到 `ı`（无点 i），导致比较出错。`Locale.ROOT` 保证跨环境一致。
- **`replaceAll("\\s+", " ")` 的参数是正则**：`\s` 匹配空白（空格、制表、换行等），`+` 表示一次或多次；Java 字符串里要写 `"\\s+"`（双反斜杠）。
- **`longestRun` 的初值**：非空串至少有 1 个字符，所以 `best = current = 1`；循环从下标 1 开始，避免访问 `charAt(-1)`。
- **`null` 防御放在最前面**：`s == null || s.isEmpty()` 用短路 `||`，`null` 时不会继续调用 `isEmpty()`。

## 5. 推荐学习流程

1. 运行示例，核对四个结果；再试两组输入：全小写无空格、含标点。
2. 手工推演 `longestRun("hello   world java")`：逐字符记录 `current` 与 `best` 的变化。
3. 手工推演 `isAnagram` 的 26 格数组：先加后减，写出 4 个关键下标的变化。
4. 改动实验：把 `longestRun(s)` 改成 `longestRun(normalize(s))`，预测 `longestRun` 变几。
5. 合上源码独立重写四个方法，用同一组输入核对。

## 6. 易错点与测试用例

| 测试输入 | 预期结果 | 状态 |
| --- | --- | --- |
| `hello   world java` / `world hello java` | `java world hello`、`true`、`3`、`hello world java` | 已运行验证 |
| 两行都为空 | `reverseWords=`（空）、`anagram=true`、`longestRun=0`、`normalized=` | 已运行验证 |
| `abc` / `abd` | `anagram=false`（c 与 d 不抵消） | 预期结果，未运行验证 |
| `a a` / `aa` | `anagram=true`（去空格后都是 `aa`） | 预期结果，未运行验证 |
| `Hello` / `hello` | `anagram=true`（统一小写） | 预期结果，未运行验证 |
| `abc!` / `!cba` | `anagram=false`（含非字母直接 false） | 预期结果，未运行验证 |
| `aaa` | `longestRun=3` | 预期结果，未运行验证 |
| 只输入一行后 EOF | 第二个串按空串处理，`anagram` 由长度决定 | 预期结果（`hasNextLine` 保护） |

注意：`isAnagram` 对含数字、标点、中文的输入直接返回 `false`，这是"只处理英文字母"的约定，不是缺陷；若题目要求忽略标点，需先过滤字符再用本题逻辑。
