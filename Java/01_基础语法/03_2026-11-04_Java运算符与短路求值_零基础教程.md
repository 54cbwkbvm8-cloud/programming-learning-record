# Java 运算符与短路求值：零基础教程

这份教程配合 `OperatorsDemo.java` 使用，重点解释最容易卡住的四件事：整数除法、字符串拼接、短路求值和自增表达式。

## 一、把程序当成一组实验

程序没有读取用户输入，所有值一开始就固定了：

```java
int a = 17;
int b = 5;
```

可以把每一行 `System.out.println` 看成一次实验：先计算括号里的表达式，再打印结果。学习时不要急着背整段代码，先学会给变量做记录。

## 二、算术运算符

| 运算符 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加法或字符串拼接 | `17 + 5` | `22` |
| `-` | 减法 | `17 - 5` | `12` |
| `*` | 乘法 | `17 * 5` | `85` |
| `/` | 除法 | `17 / 5` | `3` |
| `%` | 求余 | `17 % 5` | `2` |

### 为什么 17 / 5 不是 3.4

两个操作数都是整数，结果也是整数。`17 / 5` 只能表示整数部分 `3`，小数部分被舍弃。

只要其中一边是小数，就会进行小数除法：

```java
17 / 5      // 3
17.0 / 5    // 3.4
```

### 负数取余

```java
-17 % 5     // -2
```

先把 `17` 除以 `5`，商是 `3`，余数是 `2`；被除数是负数时，余数也带负号。初学阶段先记住结果如何计算，再在需要时深入“商的舍入方向”。

## 三、字符串拼接

Java 的 `+` 有两个用途：

1. 两边都是数字时，做加法。
2. 遇到字符串时，做拼接。

### 左边先算

```java
1 + 2 + "3"
```

执行顺序是：

1. `1 + 2` 得到数字 `3`。
2. 数字 `3` 与字符串 `"3"` 拼接，得到字符串 `"33"`。

```java
"1" + 2 + 3
```

执行顺序是：

1. `"1" + 2` 得到字符串 `"12"`。
2. `"12" + 3` 得到字符串 `"123"`。

所以字符串出现的位置会影响结果。不要只看“有没有字符串”，还要看运算从哪里开始。

## 四、比较运算得到布尔值

```java
a > b
a >= 17
a == b
a != b
```

这些表达式的结果不是数字，而是 `true` 或 `false`。关系运算符常和 `if`、循环、三元表达式一起使用。

注意：

- `=` 是赋值。
- `==` 是比较是否相等。
- `boolean` 只有 `true` 和 `false`，不能用数字 `1` 或 `0` 代替。

## 五、短路逻辑

### `&&` 的规则

```java
d != 0 && 10 / d > 1
```

如果 `d != 0` 已经是 `false`，整个“与”表达式必然是 `false`，因此右边不再计算。

当 `d = 0` 时，右边包含 `10 / 0`。如果它被计算，程序会发生除零异常。这里因为左边先判断为 `false`，右边被跳过，所以程序安全地输出 `false`。

### `||` 的规则

如果左边已经是 `true`，整个“或”表达式必然是 `true`，右边不再计算。

### `&` 和 `|` 的区别

源码中还有：

```java
int n1 = 5;
boolean r1 = (n1 > 10) && (++n1 > 0);

int n2 = 5;
boolean r2 = (n2 > 10) & (++n2 > 0);
```

两者结果都是 `false`，但：

- `&&` 跳过了右边，`n1` 还是 `5`。
- `&` 计算了右边，`n2` 变成 `6`。

用一句话记：**短路运算符不仅控制结果，还可能改变副作用是否会执行。**

## 六、`i++` 和 `++i`

### 后缀自增

```java
int i = 5;
int j = i++;
```

顺序是：

1. `i++` 先把旧值 `5` 交给 `j`。
2. `i` 再加一，变成 `6`。

所以 `j = 5`，`i = 6`。

### 前缀自增

```java
int m = 5;
System.out.println(++m);  // 先加一，得到 6
```

前缀 `++m` 先改变变量，再把新值交出来。

### `t = t++` 为什么还是 5

假设 `t` 初值是 `5`：

| 步骤 | 发生了什么 | `t` 的值 | 表达式交出的值 |
| --- | --- | ---: | ---: |
| 1 | 执行右侧 `t++` | `6` | `5` |
| 2 | 把右侧旧值赋回 `t` | `5` | `5` |

最后赋值覆盖了刚才的自增结果。这个例子说明“变量已经加一”和“表达式把哪个值交给外面”是两件事。

### 混合表达式

```java
int s = 3;
int r = s++ + ++s;
```

Java 按操作数从左到右求值：

1. 左边 `s++` 交出 `3`，`s` 变成 `4`。
2. 右边 `++s` 先把 `s` 变成 `5`，再交出 `5`。
3. 两边相加，`r = 3 + 5 = 8`。
4. 最后 `s = 5`。

能解释它有助于理解求值顺序，但正式代码应拆成几条清晰语句。

## 七、三元运算符

```java
String result = score >= 60 ? "及格" : "不及格";
```

可以读成：

```text
如果条件成立，取冒号左边的值；否则取冒号右边的值。
```

三元表达式适合两种简单结果之间的选择。如果每个分支还要输出、计算或改变多个变量，应使用 `if / else`。

## 八、变量跟踪练习

先不要运行，填写下表：

| 代码片段 | 最终变量值 | 表达式结果 |
| --- | --- | --- |
| `int i = 5; int j = i++;` | `i = ?` | `j = ?` |
| `int m = 5; int n = ++m;` | `m = ?` | `n = ?` |
| `int t = 5; t = t++;` | `t = ?` | 赋值结果 |
| `int s = 3; int r = s++ + ++s;` | `s = ?` | `r = ?` |

填完后运行原程序核对。如果结果反直觉，要回到“旧值/新值”和“是否跳过右侧”这两个问题，而不是只看答案。

## 九、常见错误

1. 把 `17 / 5` 写成 `3.4`。两个整数相除得到整数。
2. 以为字符串在最后，所有前面的加法都会先做。实际上按从左到右结合。
3. 把 `&` 当作 `&&`。它们可能得到相同布尔结果，但右侧是否执行不同。
4. 认为 `t++` 一定让 `t` 最终变大。发生赋值覆盖时不一定。
5. 用复杂自增表达式追求简短。可读性差，也更容易算错。
6. 把 `=`、`==` 和 `!=` 混用。
