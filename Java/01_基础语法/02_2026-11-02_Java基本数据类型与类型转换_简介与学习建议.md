## 程序功能

程序分为六个部分：

2. 声明八种基本类型和一个 `String`。
3. 使用包装类的 `MIN_VALUE`、`MAX_VALUE` 查看整数范围。

## 学习重点

### 八种基本类型

`byte`、`short`、`int`、`long` 是四种整数；`float`、`double` 是两种小数；`char` 是字符；`boolean` 只有 `true` 和 `false`。`String` 不是基本类型，它表示一段字符串。

整数有固定范围。`int` 最大值是 `2147483647`，再加一不会变成更大的整数，而会回绕到最小值。

### 字面量后缀

- `1000000000L` 末尾的 `L` 表示 `long`。
- 小数默认是 `double`。
- 想把小数直接当作 `float`，通常要写 `3.14F`。
- 当前 `float floatNum = 3;` 能编译，是因为整数 `3` 可以宽化转换，打印结果为 `3.0`。

### 自动转换与强制转换

`int` 到 `long`、`int` 到 `double` 可以自动完成。`double` 到 `int` 会丢弃小数部分，必须明确写 `(int)`。`int` 到 `byte` 可能超出范围，也必须写 `(byte)`。

强转不是“检查后安全转换”，而是告诉编译器“按目标类型重新解释这个值”。因此 `(byte) 130` 可能产生负数。

### 整数除法

`7 / 2` 的两个操作数都是 `int`，结果是 `int` 的 `3`。`7 / 2.0` 中有一个 `double`，整个计算按小数进行，结果是 `3.5`。

### 运算发生时类型已经决定

```java
long wrongLong = 2147483647 + 1;
long rightLong = 2147483647L + 1;
```

第一行左侧虽然是 `long`，加法仍在两个 `int` 之间完成，结果先溢出，再赋值。第二行加入 `L` 后，加法才在 `long` 中进行。

## 学习难点

1. 看变量声明类型不够，还要看右侧表达式在什么类型中计算。
2. 强转截断小数与整数溢出是不同现象。
3. `char` 参与算术运算时会使用字符编码值，`'A' + 1` 得到整数 `66`。
4. `float` 是二进制浮点类型，不应和数学上的任意精度小数混为一谈。
5. 程序没有输入，所以它验证的是一组固定演示，不是完整的边界测试框架。

## 建议学习流程

1. 先运行并记录输出。
2. 把输出按“类型声明、范围、自动转换、强制转换、溢出”分组。
3. 在纸上写一个变量表：变量名、类型、初始值、输出值。
4. 先预测 `(byte) 130` 和 `(int) 3.99`，再看输出。
5. 单独比较 `long wrongLong` 与 `long rightLong`。
6. 修改一个数值并先预测结果，例如把 `intNum` 改为 `2147483647`。
7. 合上源码，自己写一个类型转换小练习。

## 拓展练习

1. 把 `longNum` 改为 `10000000000L`，观察输出。
2. 删除 `10000000000L` 的 `L`，记录编译错误。
3. 把 `floatNum` 改为 `3.14`，观察编译错误，再尝试加 `F`。
4. 比较 `(int) 3.99` 和 `Math.round(3.99)`。
5. 增加 `char letterCode = 66;`，观察它能否直接表示字符 `B`。
6. 写一个 `TypeBoundary.java`，只使用 `Integer.MIN_VALUE`、`Integer.MAX_VALUE` 做加减小实验。
