# Java 基本数据类型与类型转换：零基础教程

这份教程配合 `BasicTypes.java` 使用。源码后半部分已经带有很长的中文注释；本教程按程序结构重新组织关键概念，避免只把代码逐句翻译一遍。

## 一、先理解程序要回答什么

`BasicTypes.java` 想回答四类问题：

1. Java 有哪些基本类型？
2. 每种类型大概能装多大的数？
3. 一个类型的值放进另一个类型时发生什么？
4. 数字装不下时为什么会变成负数或其他意外结果？

程序不读取输入，所有值都写在代码里。运行一次就能看到预设结果。

## 二、阅读前必须知道的概念

### 1. 变量是带类型的存储位置

```java
int age = 18;
```

可以读成：创建一个名为 `age`、类型为 `int` 的变量，并把整数 `18` 放进去。变量名只是人使用的标签，类型决定能存什么值、能进行什么运算。

### 2. Java 源文件通常包含类

```java
public class BasicTypes {
```

因为类名是 `BasicTypes` 并使用 `public`，源文件名必须是 `BasicTypes.java`。编译后的类也从入口 `main` 开始执行。

### 3. Java 中的数值默认是什么类型

- 整数常量默认 `int`。
- 小数常量默认 `double`。
- 要明确写出 `long`，给整数加 `L`。
- 要明确写出 `float`，给小数加 `F`。

## 三、第一部分：变量和输出

程序先创建年龄变量：

```java
int age = 18;
System.out.println("年龄：" + age + "岁");
```

这里 `int` 表示整数，`18` 是整数字面量。`+` 与字符串组合时表示拼接，所以输出 `年龄：18岁`。

这条语句结束后有分号。分号属于 Java 语法，不是中文字符串的一部分。

## 四、第二部分：八种基本类型与 String

程序一次声明了：

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| `byte` | `byte byteNum = 100;` | 1 字节有符号整数 |
| `short` | `short shortNum = 30000;` | 2 字节有符号整数 |
| `int` | `int intNum = 2000000000;` | 4 字节有符号整数，最常用 |
| `long` | `long longNum = 1000000000L;` | 8 字节有符号整数 |
| `float` | `float floatNum = 3;` | 单精度小数，赋值时可由整数转换 |
| `double` | `double doubleNum = 3.14159265358979;` | 双精度小数，默认小数类型 |
| `char` | `char letter = 'A';` | 一个字符，使用单引号 |
| `boolean` | `boolean isOk = true;` | 只有 `true` 或 `false` |

`String text = "Java";` 中的 `String` 不属于八种基本类型。它表示一段文本，使用双引号。`'A'` 是字符，`"A"` 才是字符串。

`floatNum` 的值写成整数 `3` 也能编译，因为右侧值可以先转换成 `float`。打印出来会显示 `3.0`，让读者看到它现在按小数类型输出。

## 五、第三部分：查看整数范围

```java
System.out.println(Byte.MIN_VALUE + "~" + Byte.MAX_VALUE);
```

`Byte` 是基本类型 `byte` 的包装类，`MIN_VALUE` 和 `MAX_VALUE` 表示范围边界。程序打印出：

```text
byte范围：-128~127
short范围：-32768~32767
int范围：-2147483648~2147483647
```

不需要靠猜记住所有范围。先理解四个整数类型大小不同，知道 `int` 上限约 21 亿，知道越界可能出错即可。真实使用时还应结合业务范围选择类型。

## 六、第四部分：自动类型转换

```java
int small = 100;
long bigger = small;
double decimal = small;
```

把 `int` 变量赋给 `long` 或 `double`，目标类型能覆盖当前类型常见的整数范围，所以 Java 自动转换。`bigger` 输出 `100`，`decimal` 输出 `100.0`。

字符也能参与整数运算：

```java
int letterCode = 'A' + 1;
```

字符 `'A'` 的编码值是 65，加一得到整数 66。这里结果类型已经是 `int`，所以输出 `66`，不是 `B`。

整数除法要特别注意：

```java
System.out.println(7 / 2);    // 3
System.out.println(7 / 2.0);  // 3.5
```

第一行是 `int / int`，小数部分被舍弃。第二行有一个 `double`，另一个整数先提升成 `double`，再做小数除法。

## 七、第五部分：强制类型转换

### 小数转整数

```java
double price = 3.99;
int cut = (int) price;
```

`(int)` 明确要求把右边值转成 `int`。结果是 `3`，因为向整数窄化时丢弃小数部分，并不是四舍五入。

### int 转 byte

```java
int number = 130;
byte squeezed = (byte) number;
```

`byte` 范围是 `-128` 到 `127`，130 装不下。窄化时只保留与目标类型对应的低位，再按 `byte` 的有符号规则解释，得到 `-126`。

初学阶段可以先记住“超范围的强制转换可能改变值”，二进制解释放到下一步深入。

### 整数转 char

```java
char nextLetter = (char) ('A' + 1);
```

先算 `'A' + 1` 得到整数 66，再转换回字符，得到 `'B'`。输出中显示的是 `B`。

## 八、第六部分：溢出

### int 的最大值加一

```java
int maxInt = Integer.MAX_VALUE;
int overflow = maxInt + 1;
```

最大值 `2147483647` 加一，结果回绕成最小值 `-2147483648`。Java 的普通 `int` 运算不会因为这次溢出自动抛出异常。

### byte 的最大值加一

```java
byte maxByte = 127;
byte wrapped = (byte) (maxByte + 1);
```

`maxByte + 1` 先提升为 `int` 计算，得到 128。这个中间结果本身装得下；真正出问题的是把 128 强制转回 `byte`，于是得到 `-128`。

括号很重要。`(byte) maxByte + 1` 会先转换，再按另一套类型规则继续运算，与当前写法不同。

### long 的经典陷阱

```java
long wrongLong = 2147483647 + 1;
long rightLong = 2147483647L + 1;
```

错误行中两个操作数都是 `int`，加法完成后才把结果赋给 `long`。溢出已经发生，所以得到负数。

正确行中 `2147483647L` 是 `long`，整个加法提升为 `long`，可以表示 `2147483648`。

可以记成一句话：**右侧表达式先决定在哪种类型中计算，结果最后才进入左侧变量。**

## 九、变量跟踪示例

| 表达式 | 运算类型 | 中间结果 | 赋给目标类型后的值 |
| --- | --- | --- | --- |
| `int small = 100` | `int` | `100` | `100` |
| `long bigger = small` | `long` | `100` | `100` |
| `double decimal = small` | `double` | `100.0` | `100.0` |
| `'A' + 1` | `int` | `66` | `66` |
| `(int) 3.99` | `int` | 小数部分被丢弃 | `3` |
| `(byte) 130` | `byte` | 窄化并回绕 | `-126` |
| `Integer.MAX_VALUE + 1` | `int` | 溢出 | `-2147483648` |
| `2147483647L + 1` | `long` | 不溢出 | `2147483648` |

## 十、常见错误与调试方法

### 错误 1：把小数直接赋给 float

```java
float x = 3.14;  // 编译错误
```

小数默认是 `double`。可以写 `3.14F`，或者明确强转，但要理解精度含义。

### 错误 2：以为强转会四舍五入

```java
int x = (int) 3.99;  // 3
```

需要四舍五入时使用 `Math.round`，不要误用强转。

### 错误 3：只看左侧变量类型

```java
long x = 2147483647 + 1;
```

左侧是 `long` 不能挽救右侧已经按 `int` 发生的溢出。

### 错误 4：混淆单引号和双引号

- `'A'`：一个 `char`。
- `"A"`：一个 `String`。

### 错误 5：把程序能编译当成所有结果正确

`long wrongLong` 能编译，也能运行，但结果正因为它展示的是错误运算顺序。调试时要同时检查编译、运行和逻辑。

## 十一、练习顺序

1. 不运行程序，写出 `7 / 2`、`7 / 2.0`、`(int) 3.99` 的答案。
2. 运行验证后，用自己的话解释差别。
3. 画出 `byte`、`short`、`int` 的范围。
4. 预测 `(byte) 128`、`(byte) 129`、`(byte) 130`，再写小程序验证。
5. 把 `intNum` 改为 `Integer.MAX_VALUE`，观察输出。
6. 复制一份自己的练习文件，把 `long wrongLong` 改成 `int wrongLong`，记录类型变化。
7. 合上源码，独立写出一个“整数除法与强转”的程序。

## 十二、怎样判断自己真的理解了

如果能做到下面几项，说明不是只会看答案：

- 能分清变量声明类型和右侧表达式类型。
- 能解释整数除法和强制转换为什么不同。
- 能用 `L` 修正一个 long 溢出示例。
- 能说明 `float` 和 `double` 不是任意精度。
- 能预测一个小的窄化转换结果，并知道超范围可能不直观。

下一步建议学条件语句和循环。到那时，应把这些类型知识用在输入校验和计算程序中，而不是只停留在打印固定值。
