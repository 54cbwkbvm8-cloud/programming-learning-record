# Java 数学、数组与日期工具类：简介与学习建议

## 1. 文件基本信息

- **源码**：`CommonClasses.java`
- **分类**：`Java/10_常用类与异常`
- **程序用途**：集中演示四组常用工具类——`Math`（取最值、幂、开方、取整、随机）、`Random`（随机下标）、`Arrays`（排序、二分查找、复制、填充、比较）、`LocalDate` / `ChronoUnit`（日期与天数差）、`System.currentTimeMillis`（时间戳）。
- **核心知识点**：`Math.ceil` / `floor` / `round` 的区别、`Arrays.binarySearch` 找不到时的返回值约定、`Arrays.copyOf` 的独立复制、`LocalDate` 与 `ChronoUnit.DAYS.between` 的有符号天数、`Random.nextInt(bound)` 上界不含。
- **前置知识**：数组与下标（14 号）、冒泡排序和二分查找（14 号）、`import` 语句。
- **相关练习**：14 号手写过二分查找与排序，本题第一次使用 `Arrays` 的现成实现并对比返回值差异；13 号用过随机数。

## 2. 程序功能说明

程序是"一行一个 API"的演示清单：

```java
System.out.println("max=" + Math.max(10, 20));      // 20
System.out.println("ceil=" + Math.ceil(3.14));      // 4.0 向正无穷
System.out.println("floor=" + Math.floor(3.14));    // 3.0 向负无穷
System.out.println("round=" + Math.round(3.14));    // 3   最接近整数
```

`Arrays` 部分：`sort` 升序排 `[8, 3, 5, 1]` 为 `[1, 3, 5, 8]`；`binarySearch(data, 5)` 返回下标 2；**`binarySearch(data, 4)` 返回 `-3`**（找不到时返回 `-(插入点) - 1`，不是 -1）；`copyOf` 复制后 `fill(copy, 0)` 只影响副本；`Arrays.equals` 比较内容。

日期部分：`LocalDate.now()` 与 `LocalDate.of(2020, 12, 15)` 用 `ChronoUnit.DAYS.between` 求天数差，结果是**有符号的**（目标在过去则为负）。`System.currentTimeMillis()` 给出毫秒时间戳。

末尾的 `manualSearch` 是手写线性查找，用于与 `Arrays.binarySearch` 的结果对照。

源码后半段保留附件注释教程。

在仓库根目录执行：

```bash

javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/10_常用类与异常/CommonClasses.java"
```

已使用 OpenJDK 21.0.13 严格编译并实际运行。**注意输出不完全固定**：`mathRandom=` 每次不同、`name=` 三个名字随机、`days=` 随运行日期变化、`millis=` 每次不同。稳定部分为：

## 4. 学习重点与难点

- **三种取整不是一回事**：`ceil` 向正无穷（3.14→4.0）、`floor` 向负无穷（3.14→3.0）、`round` 四舍五入（返回 `long`）。对负数结果不同：`Math.round(-3.5)` 是 `-3`（平局向正无穷）。
- **`binarySearch` 的返回值是"双义"的**：找到返回下标（≥0）；找不到返回 `-插入点-1`。`-3` 表示"若插入应放在下标 2"。若代码里写 `if (index < 0)` 判断"没找到"是对的，但把它当普通下标用会错。
- **前提仍是排序**：`binarySearch` 要求数组升序，和 14 号手写版本完全一致。
- **`copyOf` 才是复制**：`int[] b = a` 只是别名；`copyOf` 生成独立数组，所以 `fill(copy, 0)` 不影响 `data`。
- **`Random.nextInt(bound)` 上界不含**：`nextInt(names.length)` 取 `0~2`，正好覆盖三个下标。
- **日期差有符号**：调换 `between` 的两个参数，符号随之改变；不是"总是正数"。
- **`Math.random()` 范围**：`[0, 1)` 的 `double`，转整数下标要自己乘再加。

## 5. 推荐学习流程

1. 先运行一次，标出哪些输出每次都一样、哪些会变（随机、时间、天数差）。
2. 手工算 `ceil / floor / round` 对 `-3.14` 的结果，再改源码验证（改完恢复）。
3. 用 `[1,3,5,8]` 手算 `binarySearch` 查 4 的插入点，解释 `-3` 的来历。
4. 对比 14 号：手写版本"找不到返回 -1"，工具版本返回负数编码，两种约定各有什么优缺点。
5. 合上源码写一个小程序：随机抽 5 个 1~100 的数，排序、查一个目标、打印日期差。
