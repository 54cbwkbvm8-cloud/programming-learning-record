# Java 字符串核心 API：简介与学习建议

## 1. 文件基本信息

- **源码**：`StringLesson.java`
- **分类**：`Java/10_常用类与异常`
- **程序用途**：把 `String` 最常用的 API 集中演示一遍——去空白、取长度、取字符、截子串、查位置、判断包含/相等、替换、切分、转字符数组，再用一个真实输入做字符分类统计；末尾附一个未被调用的 `isPalindrome` 方法。
- **核心知识点**：`String` 不可变、`trim` / `length` / `charAt` / `substring` / `indexOf` / `contains` / `equals` / `equalsIgnoreCase` / `replace` / `split` / `toCharArray`、`==` 与 `equals` 的区别、ASCII 字符区间判断。
- **前置知识**：变量与字符串字面量、`for` 循环、`Scanner` 读行、数组下标。
- **相关练习**：27 号练过 `StringBuilder` 倒序、29 号练过 26 格字母统计；本题是它们的"API 全景版"，后续 50 号进入 `StringBuilder` 与包装类。

## 2. 程序功能说明

程序分两段。第一段用固定字符串 `" Hello Java "` 演示 12 个 API：`trim()` 去掉两端空格得到 `Hello Java`（长度 10）；`substring(0, 5)` 取 `Hello`（**结束下标不包含**）；`indexOf("Java")` 返回 6；`split(" ")` 按空格切成 2 段；`toCharArray()` 得到 10 个字符。还对比了 `String a = "Java"` 与 `new String("Java")`：内容相同但 `==` 为 `false`（两个对象）、`equals` 为 `true`（内容相同）。

第二段从键盘读一行，遍历每个字符分成四类计数：英文字母、数字、空格、其他。这段把"字符比较"落到 `c >= 'a' && c <= 'z'` 这样的区间判断上——字符本质是编码，比较是编码比较。

源码后半段保留附件注释教程（逐行讲解），注释不影响编译执行。

## 3. 编译与运行

在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-core.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/10_常用类与异常/StringLesson.java"
printf 'Hello World 123!\n' | java -cp "$java_dir" StringLesson
```

已使用 OpenJDK 21.0.13 严格编译并实际运行，输入 `Hello World 123!` 时输出：

```text

substring=Hello
indexOf=6
contains=true
equals=true
equalsIgnoreCase=true
replace=Hello World
split length=2
toCharArray length=10
toCharArray=H
a==b=false

```

字母 10 个（HelloWorld）、数字 3 个、空格 2 个、其他 1 个（感叹号），与手工统计一致。

## 4. 学习重点与难点

- **`String` 不可变**：每个"修改"方法都返回**新字符串**，原对象不变。`s.trim()` 不写返回值等于白做——后面 `BuilderLesson` 会对比可变版本。
- **`substring(start, end)` 左闭右开**：`substring(0, 5)` 是下标 0~4 的 5 个字符；写 `substring(0, 4)` 得到 `Hell`。
- **`==` 比引用、`equals` 比内容**：`a == b` 为 `false` 不是因为内容不同，而是 `new` 造了新对象。33 号讲过同一规则，这里在字符串常量池场景再复现一次。
- **`split` 参数是正则**：`split(" ")` 只按单个空格切；连续多个空格会产生空串元素——54 号 `TextAnalyzer` 用 `[^a-z]+` 和 `" +"` 解决这个问题。
- **`length` vs `length()`**：字符串用方法 `length()`，数组用属性 `length`，本程序三种写法都出现，注意区分。
- **字符区间判断是编码比较**：`c >= 'a' && c <= 'z'` 能成立的前提是 ASCII 编码连续；中文、全角字符都会落入 `others`。

## 5. 推荐学习流程

1. 先运行程序，对照固定字符串逐条核对 12 个 API 的输出。
2. 手工改 `substring(0, 5)` 为 `substring(3)`、`indexOf` 为 `lastIndexOf`，预测后运行。
3. 打开附件注释，按"方法一个、注释一段"的顺序精读；重点看 `==` 与 `equals` 的解释。
4. 换几组输入统计字符：空行、纯中文、`a1 b2`，核对四类计数。
5. 合上源码独立重写字符统计，再写一个"统计元音字母个数"的小变式。
