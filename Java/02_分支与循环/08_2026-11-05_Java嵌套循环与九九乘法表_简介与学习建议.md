# 嵌套循环与九九乘法表简介

- 源码：[MultiplicationTable.java](MultiplicationTable.java)
- 首次整理日期：2026-11-05
- 所属分类：`Java/02_分支与循环`
- 程序用途：用两层 `for` 循环输出九九乘法表。
- 主要问题：怎样让第 1 行打印 1 个算式，第 2 行打印 2 个，直到第 9 行打印 9 个。
- 核心知识点：嵌套循环、外层与内层变量分工、字符串拼接、乘法表达式、制表符 `\t`、行末换行。

## 程序功能说明

外层变量 `i` 表示第几行，也作为第二个乘数；内层变量 `j` 从 1 数到 `i`，作为第一个乘数。每打印一个算式后不换行，而是输出一个制表符留出间隔。内层循环结束后，才执行一次 `System.out.println()` 换到下一行。

因此第 3 行会输出三个算式：

```text
1*3=3	2*3=6	3*3=9
```

整个程序共输出 9 行、45 个乘法算式。

## 运行方式

```bash
java_dir=$(mktemp -d /tmp/java-table.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/02_分支与循环/MultiplicationTable.java"
java -cp "$java_dir" MultiplicationTable
```

程序不需要输入。实际运行的前三行是：

```text
1*1=1
1*2=2	2*2=4
1*3=3	2*3=6	3*3=9
```

最后一行以 `9*9=81` 结束。

## 学习重点

1. 外层循环执行一次，内层循环会完整执行一遍。
2. 当 `i = 3` 时，内层条件是 `j <= 3`，所以 `j` 取值 1、2、3。
3. `j + "*" + i` 中的 `*` 是字符串，只是乘号符号；`(i * j)` 才进行真正的乘法。
4. `\t` 是制表符，用来让列之间留出空间。
5. `print` 负责同一行的多个算式，`println()` 负责一行结束后的换行。

## 学习难点

- 内层循环变量为什么写 `j <= i`，而不是永远写 `j <= 9`。如果写 9，每一行都会有 9 个算式，结果变成方形表。
- 为什么 `System.out.println()` 放在内层循环外面。如果放在里面，每个算式都会单独占一行。
- 怎样从两个循环变量的值判断当前是第几行第几列。
- 制表符只能改善对齐，不保证在所有字体、终端宽度下完全等宽。

## 学习流程

1. 先只输出前 3 行，手写每轮 `i` 和 `j`。
2. 运行完整程序，确认 9 行和最后一项 `9*9=81`。
3. 把 `j <= i` 改成 `j <= 9`，观察方形输出后恢复。
4. 把 `\t` 改成空格，比较可读性。
5. 把行序改成倒三角，先写出外层初始化、条件和更新。
6. 合上源码，从空白文件重写前 3 行。

## 易错点与测试

| 目标 | 测试方法 | 预期结果 |
| --- | --- | --- |
| 基本输出 | 原程序 | 9 行，第 9 行 9 项 |
| 行数 | 数 `println()` 之后的行 | 恰好 9 行 |
| 算式总数 | 累加 1 到 9 | 45 项 |
| 循环边界 | 检查内层 `j <= i` | 第 `i` 行恰好 `i` 项 |
| 换行位置 | 临时把换行移入内层 | 每个算式单独一行，说明位置错误 |

## 拓展练习

1. 输出倒九九乘法表。
2. 输出只有对角线的乘法表。
3. 把乘数顺序改成 `i * j`，比较显示效果。
4. 不使用制表符，用空格补齐固定宽度。
5. 用同样的嵌套思路打印矩形和直角三角形。

完成本练习后，应能用一句话解释：**外层控制行，内层控制每行打印多少次**。
