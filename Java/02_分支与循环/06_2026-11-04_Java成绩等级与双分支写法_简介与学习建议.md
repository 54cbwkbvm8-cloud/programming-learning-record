# Java 成绩等级与双分支写法：简介与学习建议

## 文件基本信息

- 源码：`GradeLevel.java`
- 所属分类：`Java/02_分支与循环`
- 首次整理日期：2026-11-04
- 程序用途：读取 0 到 100 的整数成绩，同时用 `if / else if` 和 `switch` 输出等级
- 核心知识点：`Scanner`、输入校验、多分支、边界条件、整数除法、`switch` 复用 case
- 前置知识：`if / else`、比较运算、`switch / case / break`
- 相关练习：`SwitchBreakDemo.java`、`LeapYear.java`

源码与上传附件保持字节一致。两种写法得到相同等级，便于直接比较。

## 程序功能

程序先检查输入是否为整数，再把成绩限制在 0 到 100。合法成绩分别交给两套结构：

### 写法一：从高到低判断

```text
90 及以上 -> A
80 到 89 -> B
70 到 79 -> C
60 到 69 -> D
60 以下 -> E
```

因为 `if / else if` 从上到下执行，前一个条件不成立才检查下一个，所以每个分支可以只写下界。

### 写法二：把区间变成整数入口

```java
switch (score / 10)
```

整数除法把分数压到较小的范围：

| 成绩范围 | `score / 10` | 等级 |
| --- | ---: | --- |
| 90 到 100 | 9 或 10 | A |
| 80 到 89 | 8 | B |
| 70 到 79 | 7 | C |
| 60 到 69 | 6 | D |
| 0 到 59 | 0 到 5 | E |

`case 10` 和 `case 9` 相邻且共用 A 分支，这是有意的 case 复用，不是意外穿透。

## 学习重点

### 边界值

多分支最容易在 `>=` 和 `>` 上出错。当前规则包含下界：

- 90 分属于 A，不是 B。
- 80 分属于 B。
- 60 分属于 D。
- 59 分属于 E。

测试至少应包含 59、60、89、90、100。

### 输入验证先于业务判断

`101` 是整数，但超出成绩范围，所以不能进入等级计算。`abc` 连整数都不是，应更早被拦住。

这种“先类型、再范围、后业务”的顺序可以避免错误数据进入后面的分支。

### if 链与 switch 的适用场景

- 区间条件适合 `if / else if`。
- 离散的固定值适合 `switch`。
- 当前 `switch` 先把区间压缩成 `score / 10`，所以也可以使用，但前提是理解整数除法和边界处理。

如果区间不是整齐的十位一段，例如“85 分以上为优秀”，直接写 `if` 往往更清楚。

## 学习难点

1. 忘记 `score / 10` 对 100 得到 10，因此必须为 `case 10` 单独提供入口。
2. 把 `case 9` 后面的语句写在 `case 10` 中，导致重复。
3. 把 89 判成 A，或把 60 判成不及格。
4. 先计算等级、后检查范围，导致非法分数也进入分支。
5. 只测一个正常值，没有测试阈值和非法输入。

## 建议学习流程

1. 先只看题目，自己写出五个等级区间。
2. 用 59、60、89、90、100 做边界表，先预测。
3. 阅读 `if / else if`，确认从高到低判断为什么只需写下界。
4. 再阅读 `switch (score / 10)`，逐个写出分数对应的整数。
5. 运行合法输入，再测试 101 和非整数。
6. 合上源码，独立重写至少一种写法。
7. 把一种写法改成另一种，比较可读性和边界处理。

## 拓展练习

1. 增加 80、70 和 0 三组边界测试，确认 B、C 和 E。
2. 写一个只使用 `switch` 的范围程序，处理 85、75、65 等不是十位整段的条件。
3. 把成绩合法性和等级计算分别写成两个方法。
4. 增加输入重试，让用户输错后可以继续输入。
5. 改成 A、B、C、D、F 五级，并重新设计边界，不要改变原始源码，另建自己的练习文件。
6. 用 `boolean` 表达式实现“60 到 89 为中等”的统一判断，再比较它和逐级判断的阅读差异。
