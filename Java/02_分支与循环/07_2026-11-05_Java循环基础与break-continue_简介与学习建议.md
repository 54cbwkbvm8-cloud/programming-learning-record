# Java 循环基础与 break/continue 简介

## 程序功能说明

程序分成五段：

1. `for` 从 1 数到 5，并把数字打印在同一行。
2. `while` 也从 1 数到 5，同时把每个数字加到 `sum`，最后输出 15。
3. 把 `k` 设为 10 后，先用 `while (k < 5)`。条件一开始就是假，所以循环体一次也不执行。
4. 随后用 `do-while`。程序先执行一次循环体，再判断 `k < 5`；因此 `k = 10` 仍会打印一次，之后 `k` 变成 11，条件为假，循环结束。
5. `break` 在 `i == 4` 时结束整个循环；`continue` 跳过偶数，只打印奇数。

`while` 与 `do-while` 的核心区别不是“哪个更新”，而是判断时机：`while` 先判断后执行，`do-while` 先执行后判断，所以 `do-while` 至少执行一次。

## 学习重点

| 知识点 | 需要理解什么 | 为什么重要 |
| --- | --- | --- |
| `for (初始化; 条件; 更新)` | 初始化只做一次，条件每轮先检查，更新在循环体后执行 | 适合次数明确的循环，也是后面遍历数组的基础 |
| `while (条件)` | 只负责在每轮开始前检查条件，变量必须由程序员主动更新 | 适合“还不知道要循环几次，只知道什么时候停” |
| `do-while` | 先执行循环体，再检查条件 | 适合至少要做一次的操作，例如先显示菜单再询问是否继续 |
| `break` | 立即结束离它最近的一层循环 | 能在找到答案或遇到特殊条件时提前结束 |
| `continue` | 跳过本轮剩余语句，进入下一轮 | 能简化“满足条件就不处理”的过滤逻辑 |
| `print` / `println` | `print` 不换行，`println` 输出后换行 | 循环打印同一行内容时，两者会产生完全不同的结果 |

## 学习难点

### 难点一：循环为什么不会自己停

`while (j <= 5)` 只负责检查条件，不会自动修改 `j`。如果循环体里没有 `j++`，`j` 一直是 1，条件一直为真，就形成无限循环。

定位方法：在循环体末尾临时打印 `j`，观察它是否向结束条件靠近。

### 难点二：更新语句放在什么位置

把 `j++` 放在打印前和打印后，输出并不相同。读循环时不要只看条件，要按“判断条件 → 执行循环体 → 更新 → 再判断”的顺序整理执行路径。

### 难点三：`while` 与 `do-while` 的最小执行次数

当条件第一次就是假时：

- `while` 执行 0 次。
- `do-while` 至少执行 1 次。

本题把 `k` 设为 10，正是为了让这个差异直接可见。

### 难点四：`break` 和 `continue` 不是一回事

`break` 结束整个循环；`continue` 只结束当前这一轮。理解时要问两个问题：

1. 后续循环还会不会开始？
2. 循环变量的更新还会不会执行？

在本题的 `for` 循环里，`continue` 后仍会执行 `i++`，所以不会卡在同一个偶数上。

## 适合初学者的学习流程

1. 不运行程序，先说出每一段输出大致是什么。
2. 重点跟踪 `for` 的 `i` 和 `while` 的 `j`，每轮都写下来。
3. 运行程序，对照真实输出。
4. 把 `for` 的结束值从 5 改成 7，预测后再运行。
5. 把 `while` 里的 `j++` 临时注释掉，观察无限循环；看到效果后立即恢复。
6. 把 `break` 条件从 4 改成 7，重新运行。
7. 把 `continue` 条件改成 `i % 2 == 1`，思考为什么输出会变成偶数。
8. 合上源码，独立写一个“打印 1 到 10，但跳过 3 的倍数”的程序。

## 易错点与测试建议

- 漏写循环变量更新：程序可能一直运行。
- 把 `i == 4` 写成 `i = 4`：后者是赋值，不是比较。
- 把 `do-while` 末尾的分号漏掉：语法错误。
- 把 `print` 写成 `println`：每个数字会占一行。
- 误以为 `break` 会跳到程序末尾：它只是结束当前循环，循环后面的语句仍会继续。

| 测试目标 | 修改或输入 | 预期现象 |
| --- | --- | --- |
| 正常单层循环 | 保持原文件 | 1 到 5 正常打印，求和为 15 |
| 条件一开始不成立 | 保持 `k = 10` | `while` 执行 0 次，`do-while` 执行 1 次 |
| 提前结束 | 把 break 条件改为 `i == 7` | 输出 `1 2 3 4 5 6` |
| 筛选 | 把 continue 条件改为偶数 | 只输出奇数 `1 3 5` |
| 边界 | 让 `for` 从 5 数到 1 | 初始条件为假，循环体不执行 |
