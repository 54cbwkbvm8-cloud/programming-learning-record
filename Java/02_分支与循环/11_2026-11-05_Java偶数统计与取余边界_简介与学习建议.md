# Java 偶数统计与取余边界简介

## 文件基本信息

- 源码：[CountEven.java](CountEven.java)
- 首次整理日期：2026-11-05
- 所属分类：`Java/02_分支与循环`
- 程序用途：读取一组整数，统计其中偶数的个数。
- 主要问题：在固定次数循环里检查每个数，并用计数器累计满足条件的元素数量。
- 核心知识点：固定次数循环、计数器 `count`、取余 `%`、偶数判断、输入校验、负数余数。
- 前置知识：`for`、`while`、`Scanner`、`if`、整数运算。
- 相关练习：[求和](10_2026-11-05_Java循环求和与输入累加_简介与学习建议.md) 使用累加器；本篇改用计数器，只关心“满足条件几次”，不关心数值大小。

## 程序功能说明

程序先得到正整数 `n`，随后循环 `n` 次读取有效整数。每读到一个 `x`，判断 `x % 2 == 0`。条件为真时让 `count++`；条件为假时不做任何事。最后输出偶数个数。

这里的计数器初始值必须是 0。每发现一个偶数只增加 1，这里累计的是次数，不是偶数本身的和。

## 运行方式

```bash
java_dir=$(mktemp -d /tmp/java-even.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/02_分支与循环/CountEven.java"
printf 'abc\n0\n3\n10\nabc\n-5\n0\n' | java -cp "$java_dir" CountEven
```

本次实际测试：

- 个数先输入 `abc` 和 `0`，两者都被拒绝。
- 输入 `3` 后读取三个有效整数。
- 第一项输入 `10`。
- 第二项先输入 `abc`，被拒绝后输入 `-5`。
- 第三项输入 `0`。
- 偶数是 `10` 和 `0`，最终输出 `这3个数字中偶数个数为2个`。

## 学习重点

1. `x % 2` 得到 `x` 除以 2 的余数。
2. 判断偶数用 `x % 2 == 0`，比判断“奇数余数等于 1”更稳妥。
3. 0 是偶数，`0 % 2 == 0`。
4. `-4` 是偶数，`-4 % 2 == 0`。
5. 负奇数的余数可能是负数，例如 `-3 % 2 == -1`，所以不能只用 `x % 2 == 1` 判断所有奇数。
6. 非法输入不增加 `i`，也不会改变 `count`。

## 学习难点

- 把 `count++` 放在 `if` 外面，会让所有数都被计数。
- 把判断写成 `x / 2 == 0`，会混淆商和余数。
- 把 `==` 写成 `=`，编译无法通过，因为 `int` 不能作为条件。
- 只测正数，就很容易忽略负数余数和 0 的边界。

## 建议学习流程

1. 输入 `1` 个数 `4`，预测并验证结果为 1。
2. 输入 `3` 个数 `10`、`-5`、`0`，预测结果为 2。
3. 手工写出每个数的余数和 `count` 的变化。
4. 把判断改为所有奇数，再测试负数。
5. 合上源码，改成统计能被 3 整除的数的个数。

## 易错点与测试用例

| 输入序列 | 预期结果 | 检查目标 |
| --- | --- | --- |
| `1`，`0` | 偶数 1 个 | 0 是偶数 |
| `1`，`-4` | 偶数 1 个 | 负偶数 |
| `1`，`-3` | 偶数 0 个 | 负奇数不误判 |
| `3`，`10`，`-5`，`0` | 偶数 2 个 | 混合正负和零 |
| `abc`，`1`，`2` | 先拒绝非整数，再得到 1 个偶数 | 输入类型 |
| `0`，`2`，`2`，`3` | 先拒绝非法个数，再得到 1 个偶数 | 个数边界 |

## 拓展练习

1. 同时统计奇数和偶数。
2. 统计正数、负数和零。
3. 求和所有偶数。
4. 统计能被 3 或 5 整除的数的个数。
5. 不预先输入个数，输入负数时结束统计。

完成本练习后，应能解释“余数、条件、计数器”三者在每一轮怎样配合。
