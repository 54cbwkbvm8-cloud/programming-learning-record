# 星号三角形与输入校验简介

## 文件基本信息

- 源码：[StarTriangle.java](StarTriangle.java)
- 首次整理日期：2026-11-05
- 所属分类：`Java/02_分支与循环`
- 程序用途：读取正整数行数，打印由星号组成的直角三角形。
- 主要问题：既要验证输入，又要根据输入值控制嵌套循环的行数和列数。
- 核心知识点：`Scanner`、`hasNextInt()`、输入缓冲区、无限循环加 `break`、正数范围校验、双层循环。
- 前置知识：`Scanner` 输入、`if`、`while`、`for`、`print` 与 `println`。
- 相关练习：双层结构与 [九九乘法表](08_2026-11-05_Java嵌套循环与九九乘法表_简介与学习建议.md) 相同；输入重试方式可与前面闰年、成绩等级程序对照。

## 程序功能说明

程序先反复询问行数，直到得到合法正整数。`hasNextInt()` 检查下一个输入能否按 `int` 读取；能读取时再用 `n >= 1` 检查业务范围。输入不是整数时，`sc.next()` 会把错误内容取走，避免它一直留在输入缓冲区。

得到合法 `n` 后，外层 `for` 处理每一行，内层 `for` 在每行打印与行号相同数量的星号。内层结束后才换行。

## 运行方式

```bash
java_dir=$(mktemp -d /tmp/java-star.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/02_分支与循环/StarTriangle.java"
printf 'abc\n0\n3\n' | java -cp "$java_dir" StarTriangle
```

本次实际输入为 `abc`、`0`、`3`。前两个输入会被拒绝，第三次得到合法行数，输出：

```text
请输入三角形的行数（正整数）：
你输入的不是整数，请重新输入！
请输入三角形的行数（正整数）：
行数必须大于等于1，请重新输入！
请输入三角形的行数（正整数）：
*
**
***
```

## 学习重点

1. 输入类型错误与数值范围错误是两种不同问题。
2. `sc.next()` 在拒绝非法输入时负责清理缓冲区。
3. `n` 是用户输入，决定外层循环次数。
4. `i` 同时表示行号和该行星号数量。
5. 内层 `j` 每处理新的一行都从 1 开始。
6. 换行位于内层循环外、外层循环内。

## 学习难点

- 不清理非法输入会造成反复提示同一段错误内容。
- 输入 0 或负数时，原需求不明确；本程序明确要求重试，而不是静默结束。
- 如果换行写错位置，星号可能全部挤在一行，或者每个星号单独一行。
- `n` 很大时，输出量快速增长；三角形总星号数约为 `n(n+1)/2`。

## 建议学习流程

1. 先输入 3，观察并数清每行星号。
2. 输入 1，确认最少合法行数。
3. 输入 `abc` 再输入 2，观察输入重试。
4. 输入 0 再输入 2，比较两种错误提示。
5. 手工列出 `n = 4` 时每轮的 `i`、`j` 和星号数量。
6. 修改为倒三角形，再独立重写正三角形。

## 易错点与测试用例

| 输入序列 | 预期结果 | 检查目标 |
| --- | --- | --- |
| `1` | 只有一个 `*` | 最小合法行数 |
| `3` | 三行，分别为 1、2、3 个星号 | 正常输入 |
| `0` 后 `2` | 提示行数至少为 1，再输出 2 行 | 正数范围 |
| `-2` 后 `1` | 提示后输出 1 行星号 | 负数处理 |
| `abc` 后 `2` | 提示非整数，再输出 2 行 | 类型校验 |
| `3.5` 后 `1` | `hasNextInt()` 无法把 `3.5` 当整数，提示后继续 | 小数边界 |

## 拓展练习

1. 打印每一行同样宽度的正方形。
2. 打印倒直角三角形。
3. 打印前面带空格的等腰三角形。
4. 加入最大行数限制，例如只接受 1 到 20。
5. 设置最多重试次数；失败后给出明确退出原因。

完成本练习后，应能区分“输入是否合法”和“循环怎样根据输入值执行”这两个问题。
