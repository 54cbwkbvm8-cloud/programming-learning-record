# Java 循环求最大值最小值简介

## 文件基本信息

- 源码：[MaxMin.java](MaxMin.java)
- 首次整理日期：2026-11-05
- 所属分类：`Java/02_分支与循环`
- 程序用途：读取一组整数，在同一次遍历中求最大值和最小值。
- 主要问题：怎样在没有数组的情况下，只保存当前最重要的两个值。
- 核心知识点：首个元素初始化、单次遍历、条件更新、输入校验、全负数测试、一次循环维护多个状态。
- 前置知识：`for` 循环、比较运算、`Scanner`、变量更新。
- 相关练习：阅读 [求和](10_2026-11-05_Java循环求和与输入累加_简介与学习建议.md) 后再学本篇，比较“累计和”和“当前极值”在循环中的不同更新方式。

## 程序功能说明

程序先读取合法个数 `n`，再读取第一个整数。第一个数同时赋给 `max` 和 `min`，因为此时至少有一个数据，它既是目前最大值，也是目前最小值。

从第二个数开始，每读取一个 `x`：如果 `x > max`，更新最大值；如果 `x < min`，更新最小值。两个 `if` 都要检查，因为新数既可能成为最大值，也可能成为最小值。循环结束后输出两个结果。

## 运行方式

```bash
java_dir=$(mktemp -d /tmp/java-maxmin.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/02_分支与循环/MaxMin.java"
printf 'abc\n0\n4\n-3\n-9\n-1\n-7\n' | java -cp "$java_dir" MaxMin
```

本次实际测试先输入 `abc` 和 `0`，两者都被拒绝；随后输入 `4` 个数 `-3`、`-9`、`-1`、`-7`，输出：

```text
最大值为：-1
最小值为：-9
```

## 学习重点

1. 极值初值不能凭空写 0。若全是负数，用 0 初始化最大值会得到错误结果。
2. 用第一个输入值初始化 `max` 和 `min`，能自然处理单个数据和全负数数据。
3. 从第 2 个数开始循环，是因为第 1 个数已经先读取。
4. `max` 只负责记录当前最大值，`min` 只负责记录当前最小值，两者互不替代。
5. 不需要保存所有输入，也能求极值，因此空间开销很小。

## 学习难点

- 只写一个 `else if`，会导致一个数只能更新最大值或最小值之一。
- 应从 1 开始循环却又重复读取第一个数，会让数据位置错乱。
- 初始化 `max = 0` 或 `min = 0`，在全负数或全正数数据上容易出错。
- 输入校验框架与求和、偶数统计相似，要区分“非法输入”和“合法但极小/极大的数”。

## 建议学习流程

1. 输入 `1` 个数 `5`，确认最大值和最小值都为 5。
2. 输入 `1` 个数 `-8`，确认初值策略对负数有效。
3. 输入 `4` 个数 `-3`、`-9`、`-1`、`-7`，手工跟踪。
4. 想一想若用 `max = 0` 初始化，这组数据会怎样错。
5. 改写成同时求总和、最大值和最小值。
6. 再学习数组后，用数组重写并比较两种方法。

## 易错点与测试用例

| 输入序列 | 预期结果 | 检查目标 |
| --- | --- | --- |
| `1`，`5` | 最大 5，最小 5 | 单元素 |
| `1`，`-8` | 最大 -8，最小 -8 | 全负数初值 |
| `3`，`0`，`0`，`0` | 最大 0，最小 0 | 全部相等 |
| `4`，`-3`，`-9`，`-1`，`-7` | 最大 -1，最小 -9 | 一般负数序列 |
| `5`，`1`，`2`，`3`，`4`，`5` | 最大 5，最小 1 | 递增序列 |
| `5`，`5`，`4`，`3`，`2`，`1` | 最大 5，最小 1 | 递减序列 |

## 拓展练习

1. 同时求平均值。
2. 统计最大值出现了几次。
3. 找出第二大的值，并先想清楚重复最大值该怎样处理。
4. 把输入改成“输入 0 时结束”，再判断是否有有效数据。
5. 学完数组后，把“边读边更新”与“先存入数组再遍历”进行比较。

完成本练习后，应能解释为什么“第一个有效数作为初值”比固定写 0 更可靠。
