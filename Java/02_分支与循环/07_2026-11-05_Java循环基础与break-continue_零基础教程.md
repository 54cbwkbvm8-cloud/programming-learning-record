# Java 循环基础零基础教程

本教程配合 [LoopBasics.java](LoopBasics.java) 使用。目标不是背下三种循环，而是能沿着执行顺序回答：“现在执行哪一行？变量是多少？下一轮还会不会开始？”

## 先理解重复执行

假设要输出 1、2、3：

```java
System.out.println(1);
System.out.println(2);
System.out.println(3);
```

这里重复写了三段相似代码。如果改成输出 1 到 100，手动复制就不合理。循环把“重复规则”写成一段可重复执行的代码。

一个循环通常需要回答四件事：

1. 从哪个值开始？
2. 什么条件下继续？
3. 每轮具体做什么？
4. 每轮结束后怎样靠近停止条件？

## `for` 循环的三部分

源码：

```java
for (int i = 1; i <= 5; i++) {
    System.out.print(i + " ");
}
```

可以拆成：

| 部分 | 代码 | 执行时机 |
| --- | --- | --- |
| 初始化 | `int i = 1` | 循环开始前只执行一次 |
| 条件 | `i <= 5` | 每一轮循环体之前检查 |
| 更新 | `i++` | 每一轮循环体之后执行 |

执行轨迹：

| 轮次 | 判断前的 `i` | 条件结果 | 输出 | 本轮后的 `i` |
| --- | ---: | --- | --- | ---: |
| 1 | 1 | true | `1 ` | 2 |
| 2 | 2 | true | `2 ` | 3 |
| 3 | 3 | true | `3 ` | 4 |
| 4 | 4 | true | `4 ` | 5 |
| 5 | 5 | true | `5 ` | 6 |
| 结束检查 | 6 | false | 不输出 | 不执行更新 |

实际结果是 `1 2 3 4 5 `。最后的空格看起来不明显，但确实被打印了。

`i` 在 `for` 中声明，因此只在这个 `for` 的范围内可用。循环结束后，不能再直接使用这个 `i`。

## `while` 循环

源码：

```java
int j = 1;
int sum = 0;

while (j <= 5) {
    System.out.print(j + " ");
    sum += j;
    j++;
}
```

`while` 本身只包含条件。初始化和更新要写在循环外面和循环体里面。

执行轨迹：

| 轮次 | `j` | `sum` 执行前 | 输出 | `sum` 执行后 | `j++` 后 |
| --- | ---: | ---: | --- | ---: | ---: |
| 1 | 1 | 0 | `1 ` | 1 | 2 |
| 2 | 2 | 1 | `2 ` | 3 | 3 |
| 3 | 3 | 3 | `3 ` | 6 | 4 |
| 4 | 4 | 6 | `4 ` | 10 | 5 |
| 5 | 5 | 10 | `5 ` | 15 | 6 |
| 结束 | 6 | 15 | 不进入循环 | 15 | 不执行 |

关键句是 `j++`。如果删掉它，`j` 一直是 1，`j <= 5` 一直为真，程序不会结束。

## `do-while` 为什么至少执行一次

源码先执行一次，再检查条件：

```java
do {
    System.out.println("do-while执行了，k = " + k);
    k++;
} while (k < 5);
```

当 `k = 10`：

| 步骤 | 动作 | `k` 的值 |
| --- | --- | ---: |
| 1 | 不检查条件，先进入循环体 | 10 |
| 2 | 输出 `k = 10` | 10 |
| 3 | 执行 `k++` | 11 |
| 4 | 检查 `11 < 5`，结果为 false | 11 |
| 5 | 结束循环 | 11 |

所以 `do-while` 适合“先做一次，再决定要不要继续”的操作。

## `while` 与 `do-while` 对照

同一个条件 `k < 5`，初始值 `k = 10`：

| 循环 | 是否先检查 | 循环体次数 |
| --- | --- | ---: |
| `while` | 是 | 0 |
| `do-while` | 否 | 1 |

不要把“至少执行一次”理解为“每次都会执行很多次”。它只是保证第一次不检查就进入。

## `break` 的执行路径

源码：

```java
for (int i = 1; i <= 10; i++) {
    if (i == 4) {
        break;
    }
    System.out.print(i + " ");
}
```

执行到 `i = 4` 时，先判断 `i == 4` 为真，于是执行 `break`。整个 `for` 立即结束，所以后面的 4 到 10 都不会执行。

输出为：

```text
1 2 3
```

## `continue` 的执行路径

源码：

```java
for (int i = 1; i <= 6; i++) {
    if (i % 2 == 0) {
        continue;
    }
    System.out.print(i + " ");
}
```

偶数进入 `if` 后执行 `continue`，跳过本轮后面的打印语句；然后执行 `for` 的 `i++`，进入下一轮。

执行轨迹：

| `i` | `i % 2 == 0` | 动作 | 是否打印 |
| ---: | --- | --- | --- |
| 1 | false | 执行打印 | 是 |
| 2 | true | `continue` | 否 |
| 3 | false | 执行打印 | 是 |
| 4 | true | `continue` | 否 |
| 5 | false | 执行打印 | 是 |
| 6 | true | `continue` | 否 |

输出为 `1 3 5`。

## `break` 与 `continue` 对照

```text
break    → 整个循环结束
continue → 只跳过当前这一轮
```

判断时看两个问题：

1. 本次循环后面的语句还会执行吗？
2. 下一轮循环还会开始吗？

`continue` 的答案是“本次后面的不执行，下一轮仍然开始”。`break` 的答案是“本次后面的不执行，下一轮也不开始”。

## 嵌套循环先看一个小例子

嵌套循环就是循环体里还有循环：

```java
for (int row = 1; row <= 3; row++) {
    for (int star = 1; star <= row; star++) {
        System.out.print("*");
    }
    System.out.println();
}
```

执行结果：

```text
*
**
***
```

外层 `row` 控制第几行，内层 `star` 控制这一行打印几个符号。换行必须写在内层循环结束之后、外层循环结束之前。

## 常见错误

### 错误一：漏写更新

```java
while (j <= 5) {
    System.out.print(j + " ");
}
```

`j` 不变，循环无法结束。

### 错误二：在循环条件后误加分号

```java
while (j <= 5);
```

这个分号会变成空循环体，后面的代码可能完全不按预期执行。`do-while` 才必须在 `while (...)` 后写分号。

### 错误三：`=` 与 `==` 混用

```java
if (i = 4) {
```

这是赋值，而且 `int` 不能直接作为 `if` 条件，应写成 `i == 4`。

### 错误四：把 `print` 写成 `println`

同一行的数字会变成多行。先明确“每个数字要换行，还是整行结束后换行”。

### 错误五：误判 `continue` 后的变量更新

在 `for` 循环中，`continue` 后仍会执行 `i++`。在 `while` 中，如果更新语句写在 `continue` 后面，它可能被跳过，需要特别检查。

## 独立练习

1. 用 `for` 输出 1 到 10，并把结果排成一行。
2. 用 `while` 求 1 到 10 的和。
3. 用 `do-while` 让一段提示至少输出一次。
4. 打印 1 到 20，遇到 12 时停止。
5. 打印 1 到 20，跳过 5 的倍数。
6. 画表写出一个双层循环每次外循环和内循环的变量值。

## 怎样判断自己真的会了

不要只看懂输出。尝试完成下面三个检查：

1. 关闭源码，手写一个 1 到 10 的循环。
2. 看到新循环时，能立刻指出初始化、条件、循环体和更新分别在哪里。
3. 给你初始值和条件，能预测循环体执行多少次，并解释是否会执行 0 次或至少 1 次。

做到这三点后，再进入九九乘法表。那里会把“外层循环一行、内层循环一行中的多个算式”组合起来。
