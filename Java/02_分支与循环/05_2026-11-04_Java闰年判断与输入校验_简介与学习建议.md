- 所属分类：`Java/02_分支与循环`
- 首次整理日期：2026-11-04
- 程序用途：读取年份，判断闰年或平年，并输出二月天数
- 核心知识点：`Scanner`、输入类型校验、范围校验、布尔表达式、优先级、三元表达式

## 程序功能

程序先提示输入正整数年份，然后分三步处理：

1. `hasNextInt()` 检查输入是否为整数。
2. 检查年份是否大于 0。
3. 用闰年条件判断，并输出该年 2 月是 28 天还是 29 天。

闰年条件：

```java
(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)
```

可以记成：

- 能被 4 整除；
- 并且不能被 100 整除；
- 或者能被 400 整除。

括号保证“能被 4 整除且不能被 100 整除”作为一个整体，再与“能被 400 整除”做“或”运算。

## 学习重点

### 输入校验的顺序

先检查 `hasNextInt()`，只有确认下一个 token 是整数后才调用 `nextInt()`。如果直接对 `abc` 调用 `nextInt()`，程序会抛出输入类型异常。

获得整数后还要检查正数范围，因为 `0`、负数和较大的负数都不符合题目要求。

### 两个层面的错误

- `abc` 的错误是“类型不对”。
- `0` 的错误是“类型对，但范围不对”。

两者需要分开处理，不能把所有非法输入都混成同一条消息。

### 闰年边界

最容易错的是 1900 和 2000：

- 1900 能被 4 和 100 整除，但不能被 400 整除，所以是平年。
- 2000 能被 400 整除，所以是闰年。

只写 `year % 4 == 0` 会把这两个年份判错。

### 三元表达式

```java
int febDays = isLeap ? 29 : 28;
```

`isLeap` 为 `true` 时取 29，否则取 28。它只负责在两种值之间选择，不替代前面的完整闰年判断。

## 学习难点

1. 记得 `&&` 的优先级高于 `||`，但这里最好用括号清楚表达分组。
2. 不要混淆“能被 100 整除”和“不能被 100 整除”。
3. 1900 和 2000 必须单独测试。
4. `Scanner` 读取 token 后通常由 `close()` 关闭；当前程序只读一次，流程简单。
5. 当前程序只验证一个年份，不提供错误后重新输入的循环。循环版本需要额外设计。

## 建议学习流程

1. 先写普通闰年规则，再补整百和整四百规则。
2. 用 2023、2024、1900、2000 四个年份画一张条件判断表。
3. 自己写出 `% 4`、`% 100`、`% 400` 三个余数。
4. 运行正常年份和两个特殊整百年。
5. 再分别测试输入 0 和非数字。
6. 合上源码，独立写出“类型校验 → 范围校验 → 业务判断”的三层结构。
