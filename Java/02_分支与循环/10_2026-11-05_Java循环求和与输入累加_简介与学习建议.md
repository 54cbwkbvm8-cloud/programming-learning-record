# Java 循环求和与输入累加简介

## 文件基本信息

- 源码：[Sum.java](Sum.java)
- 首次整理日期：2026-11-05
- 所属分类：`Java/02_分支与循环`
- 程序用途：先读取要输入多少个整数，再逐个读取并求总和。
- 主要问题：怎样在固定次数循环中持续累加，同时拒绝非整数输入。
- 核心知识点：`for` 循环、累加器 `sum`、复合赋值 `+=`、`long`、`Scanner`、`hasNextInt()`、输入重试。

## 程序功能说明

程序先检查数据个数 `n`，要求它至少为 1。之后把 `sum` 初始化为 0，循环 `n` 次。每次先确认输入是整数，再把整数 `x` 加到 `sum`。非法输入不会占用一次有效数据位置，必须继续输入，直到当前第 `i` 个数合法。

程序最后输出有效数字个数和总和。`sum` 使用 `long`，比只用 `int` 更能容纳多次相加后的累计结果。

## 运行方式

```bash
java_dir=$(mktemp -d /tmp/java-sum.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/02_分支与循环/Sum.java"
printf 'abc\n0\n3\nabc\n10\n-5\n2\n' | java -cp "$java_dir" Sum
```

本次实际测试中：

- 数据个数先输入 `abc`，被拒绝。
- 再输入 `0`，因为不是正整数被拒绝。
- 输入 `3` 后开始读取三个有效整数。
- 第一个数据位置输入 `abc`，被拒绝后重新输入 `10`。
- 其余有效数据为 `-5` 和 `2`。
- 最终输出 `3个数字的和为：7`。

## 学习重点

1. `sum = 0` 是累加器的正确初始值。
2. 每次循环只处理一个数，循环结束后才输出总和。
3. `sum += x` 等价于 `sum = sum + x`。
4. 非法输入后 `i` 不会增加，因为还没有得到当前这一项的有效值。
5. 负数可以参与求和，输入校验只拒绝非整数，不拒绝负整数。
6. `long` 的选择要结合累计范围理解，不是“用了 `long` 就永远不会溢出”。

## 学习难点

- 忘记初始化 `sum` 会无法编译。
- 把 `sum += x` 写在输入校验之前，可能用到未确认的值。
- 只检查 `hasNextInt()` 却忘记 `nextInt()`，会导致程序没有真正读取数字。
- 拒绝非法输入时忘记 `sc.next()`，可能陷入重复提示。
- 把“数字个数” `n` 和“当前第几个” `i` 混为一谈。

## 建议学习流程

1. 先输入最简单序列 `1`、`5`，预期和为 5。
2. 再输入 `3`、`10`、`-5`、`2`，预期和为 7。
3. 在一项中输入 `abc`，确认它不会计入 `i`。
4. 手工填写每轮的 `i`、`x`、执行前的 `sum`、执行后的 `sum`。
5. 把输入改成三个 0，确认结果为 0。
6. 独立重写为“求平均值”，并在计算前考虑除以 0 的风险。

## 易错点与测试用例

| 输入序列 | 预期结果 | 检查目标 |
| --- | --- | --- |
| `1`，`5` | 和为 5 | 最小数据个数 |
| `3`，`10`，`-5`，`2` | 和为 7 | 正数、负数和零边界 |
| `3`，`0`，`0`，`0` | 和为 0 | 全零输入 |
| `0`，`2`，`1`，`2` | 先拒绝 0，再求两个数 | 个数范围校验 |
| `abc`，`1`，`7` | 先拒绝非整数，再处理一个数 | 类型校验 |

## 拓展练习

1. 同时计算平均值和总和。
2. 统计正数、负数和零的个数。
3. 不预先输入个数，改为输入 0 时结束求和。
4. 当累计和超过某个阈值时给出提示。
5. 将固定次数循环改为“反复输入直到退出”，比较两种设计。

完成本练习后，应能手工跟踪一个累加器在每一轮前后的值。
