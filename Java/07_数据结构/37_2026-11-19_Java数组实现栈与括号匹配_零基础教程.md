# 数组实现栈与括号匹配零基础教程

本教程配合 [37_2026-11-19_Java数组实现栈与括号匹配_简介与学习建议.md](37_2026-11-19_Java数组实现栈与括号匹配_简介与学习建议.md) 和 [StackDemo.java](StackDemo.java) 使用。建议先复习数组下标、方法调用和 `try-catch`。

## 一、栈是什么

栈是一种“后进先出”的容器：

- 最后放进去的元素，最先拿出来。
- 只能在一端放入和取出，这一端叫“栈顶”。
- 另一端叫“栈底”，不能直接从栈底取元素。

最形象的例子是一摞盘子：

```text
     ← 只能从这里放和取
  ┌─────┐
  │ 30  │  ← 栈顶
  ├─────┤
  │ 20  │
  ├─────┤
  │ 10  │  ← 栈底
  └─────┘
```

放入 10、20、30 后，最先取出的是 30，然后才是 20、10。

栈的基本操作：

| 操作 | 含义 |
| --- | --- |
| `push(x)` | 入栈，把 `x` 放到栈顶 |
| `pop()` | 出栈，取走并返回栈顶元素 |
| `peek()` | 只看栈顶元素，不取走 |
| `isEmpty()` | 栈是否为空 |
| `isFull()` | 栈是否已满（数组实现有固定容量） |
| `size()` | 栈里有多少个元素 |

## 二、用数组和 top 表示栈

`MyStack` 内部只有两个字段：

```java
private int[] data;
private int top;
```

- `data` 是真正存放元素的数组。
- `top` 是“栈顶元素在数组里的下标”。

数组左边是栈底，右边是栈顶：

```text
下标：   0      1      2      3
      ┌──────┬──────┬──────┬──────┐
data  │ 10   │ 20   │ 30   │ 0    │
      └──────┴──────┴──────┴──────┘
                      ^
                     top = 2
```

此时栈里有效元素是下标 `0～2`，共 3 个；下标 3 是空闲格子。

空栈时：

```text
top = -1
data = [0, 0, 0, 0]
```

`-1` 不是合法下标，正好表示“没有元素”。

### top 与 size 的关系

| 状态 | `top` | `size()` |
| --- | --- | --- |
| 空栈 | -1 | 0 |
| 1 个元素 | 0 | 1 |
| 3 个元素 | 2 | 3 |
| 容量 4 且满 | 3 | 4 |

所以：

```java
size = top + 1
```

## 三、`MyStack` 逐段读

### 1. 字段与构造方法（第 3～10 行）

```java
class MyStack {
    private int[] data;
    private int top;

    public MyStack(int capacity) {
        data = new int[capacity];
        top = -1;
    }
```

`private` 让外部不能直接改 `data` 和 `top`，只能通过 `push`、`pop` 等方法操作，保证栈的规则不被绕过。

`new int[capacity]` 创建数组，元素默认值是 0。`top = -1` 表示一开始没有元素。

### 2. 判空与判满（第 12～18 行）

```java
public boolean isEmpty() {
    return top == -1;
}

public boolean isFull() {
    return top == data.length - 1;
}
```

空栈是 `top == -1`。

满栈是栈顶已经到数组最后一个格子。数组长度 `data.length`，最后一个下标是 `data.length - 1`。

例如容量 4：

```text
满栈时 top = 3
data.length - 1 = 3
```

### 3. 入栈（第 20～25 行）

```java
public void push(int value) {
    if (isFull()) {
        throw new RuntimeException("栈已满，无法 push");
    }
    data[++top] = value;
}
```

先判满。满了再写会超出数组范围。

`data[++top] = value;` 分两步：

1. `++top`：`top` 先加 1。
2. 把 `value` 写入 `data[top]`。

空栈时：

```text
top: -1 → 0
data[0] = value
```

### 4. 出栈（第 27～34 行）

```java
public int pop() {
    if (isEmpty()) {
        throw new RuntimeException("栈为空，无法 pop");
    }
    int value = data[top];
    top--;
    return value;
}
```

三步：

1. 取出 `data[top]`。
2. `top--` 下移一格。
3. 返回取出的值。

注意顺序：先取再减。如果先 `top--`，取到的就是下面一个元素，栈顶元素被跳过。

### 5. 查看栈顶（第 36～41 行）

```java
public int peek() {
    if (isEmpty()) {
        throw new RuntimeException("栈为空，无法 peek");
    }
    return data[top];
}
```

只返回 `data[top]`，不修改 `top`。所以 `peek` 之后栈的内容不变。

### 6. 元素个数（第 43～45 行）

```java
public int size() {
    return top + 1;
}
```

空栈 `-1 + 1 = 0`；`top = 2` 时 `2 + 1 = 3`。

### 7. 显示状态（第 47～56 行）

```java
public void show() {
    System.out.print("栈（底->顶）：[");
    for (int i = 0; i <= top; i++) {
        System.out.print(data[i]);
        if (i < top) {
            System.out.print(", ");
        }
    }
    System.out.println("] top=" + top + " size=" + size()
        + " 底层数组=" + Arrays.toString(data));
}
```

循环只打印 `0～top`，也就是真正属于栈的部分。后面的 `0` 或旧值不打印。

最后再用 `Arrays.toString(data)` 打印整个底层数组，方便观察“出栈后旧值还在”的现象。

## 四、push 和 pop 时发生了什么

以容量 4 为例：

### 初始

```text
data = [0, 0, 0, 0]
top = -1
栈 = []
```

### push(10)

```text
top: -1 → 0
data[0] = 10
data = [10, 0, 0, 0]
栈 = [10]
```

### push(20)

```text
top: 0 → 1
data[1] = 20
data = [10, 20, 0, 0]
栈 = [10, 20]
```

### push(30)

```text
top: 1 → 2
data[2] = 30
data = [10, 20, 30, 0]
栈 = [10, 20, 30]
```

### pop()

```text
value = data[2] = 30
top: 2 → 1
返回 30
data = [10, 20, 30, 0]   ← 30 还在数组里
栈 = [10, 20]
```

`data[2]` 没有被清零，只是 `top` 变成 1，栈的有效范围缩小到 `0～1`。

### 再 pop()

```text
value = data[1] = 20
top: 1 → 0
返回 20
data = [10, 20, 30, 0]
栈 = [10]
```

## 五、为什么异常是必要的

假设 `pop` 不检查空栈：

```java
public int pop() {
    int value = data[top];   // top = -1
    top--;
    return value;
}
```

`data[-1]` 会抛 `ArrayIndexOutOfBoundsException`。错误信息只告诉你“下标 -1 越界”，不如“栈为空，无法 pop”直观。

同样，满栈继续 `push` 会写到 `data[data.length]`，也是越界。

所以入栈前判满、出栈和查看前判空，是栈实现的基本契约。

### try-catch 怎样接住异常

```java
try {
    emptyStack.pop();
    System.out.println("没有报错（这一行不应该出现）");
} catch (RuntimeException e) {
    System.out.println("空栈 pop 抛出异常: " + e.getMessage());
}
```

执行顺序：

1. `emptyStack.pop()` 抛出 `RuntimeException`。
2. `try` 块中后面的 `println` 不会执行。
3. 跳到 `catch`，`e.getMessage()` 取出异常文字。
4. 程序继续执行 `catch` 后面的代码。

如果没有 `try-catch`，异常会一路向上抛，最终终止程序。

## 六、括号匹配

### 1. 题目规则

给定一个只包含 `(`、`)`、`[`、`]`、`{`、`}` 的字符串，判断是否有效：

1. 每个左括号都要有同类型的右括号配对。
2. 括号必须按正确顺序关闭：后打开的先关闭。

有效示例：

```text
()
()[]{}
{[]}
```

无效示例：

```text
(]
([)]
())
(
]
```

### 2. 为什么用栈

“后打开的先关闭”就是“后进先出”。

处理规则：

- 左括号：入栈，等以后配对。
- 右括号：看栈顶那个“最近打开、还没配对”的左括号。
  - 栈空：没有左括号可配，无效。
  - 类型不匹配：无效。
  - 匹配：弹出栈顶，继续。
- 全部处理完：栈必须为空。

### 3. 手工走两个例子

#### 例 1：`([)]`

| 字符 | 操作 | 栈（底->顶） | 结果 |
| --- | --- | --- | --- |
| `(` | 入栈 | `(` | 继续 |
| `[` | 入栈 | `( [` | 继续 |
| `)` | 栈顶是 `[`，不配对 | `( [` | 返回 `false` |

#### 例 2：`{[]}`

| 字符 | 操作 | 栈（底->顶） | 结果 |
| --- | --- | --- | --- |
| `{` | 入栈 | `{` | 继续 |
| `[` | 入栈 | `{ [` | 继续 |
| `]` | 配对 `[`，弹出 | `{` | 继续 |
| `}` | 配对 `{`，弹出 | 空 | 继续 |
| 结束 | 栈空 | 空 | 返回 `true` |

#### 例 3：`())`

| 字符 | 操作 | 栈 | 结果 |
| --- | --- | --- | --- |
| `(` | 入栈 | `(` | 继续 |
| `)` | 配对，弹出 | 空 | 继续 |
| `)` | 栈空，没有左括号 | 空 | 返回 `false` |

#### 例 4：`(`

| 字符 | 操作 | 栈 | 结果 |
| --- | --- | --- | --- |
| `(` | 入栈 | `(` | 继续 |
| 结束 | 栈非空 | `(` | 返回 `false` |

### 4. 代码对应（第 67～87 行）

```java
static boolean isValid(String s) {
    if (s == null) {
        return false;
    }
    MyStack stack = new MyStack(s.length() + 1);
    for (int i = 0; i < s.length(); i++) {
        char c = s.charAt(i);
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);
        } else {
            if (stack.isEmpty()) {
                return false;
            }
            char left = (char) stack.pop();
            if (!isPair(left, c)) {
                return false;
            }
        }
    }
    return stack.isEmpty();
}
```

几个细节：

- `s == null` 必须先判断，否则 `s.length()` 会抛空指针。
- 容量 `s.length() + 1` 保证最坏情况也不会满。
- 不是左括号的字符都走 `else`，当作右括号处理。
- `isPair` 判断三种配对。
- 最后返回 `stack.isEmpty()`，不是直接 `return true`。

### 5. `isPair`（第 63～65 行）

```java
static boolean isPair(char a, char b) {
    return (a == '(' && b == ')')
        || (a == '[' && b == ']')
        || (a == '{' && b == '}');
}
```

`&&` 是“并且”，`||` 是“或者”。三组括号任意一组成立，就是一对。

### 6. char 与 int

`MyStack` 只能存 `int`：

```java
stack.push(c);
```

`char` 会自动转换成它的编号，例如 `'('` 是 40。取出来时：

```java
char left = (char) stack.pop();
```

`pop()` 返回 `int`，用 `(char)` 强制转换回字符，才能和 `c` 比较。

## 七、测试裁判

```java
static void check(String s, boolean expected) {
    total++;
    boolean actual = isValid(s);
    String shown = (s == null) ? "null" : "\"" + s + "\"";
    if (actual == expected) {
        passed++;
        System.out.println("[通过] ...");
    } else {
        System.out.println("[失败] ...");
    }
}
```

`expected` 是“应该得到的结果”，`actual` 是程序实际返回的结果。两者相同就通过。

`shown` 用三元运算符处理 `null`：

```java
(s == null) ? "null" : "\"" + s + "\""
```

`null` 时不加引号，避免看起来像字符串 `"null"`。

`main` 最后打印 `total` 和 `passed`，方便一眼看出有多少项失败。

## 八、常见错误与排查

### 错误 1：`data[top++] = value`

空栈时 `top = -1`，`top++` 先用 -1 当下标，直接越界。入栈必须用 `++top`。

### 错误 2：`pop` 先减再加

```java
top--;
int value = data[top];   // 错：取到的是下面一个
```

应先 `int value = data[top];` 再 `top--`。

### 错误 3：`peek` 修改 `top`

如果 `peek` 里写了 `top--`，它就不是“只看不取”了。`peek` 只能读取。

### 错误 4：忘记判空

空栈 `pop` 会访问 `data[-1]`，抛数组越界。虽然也是异常，但语义不如主动抛“栈为空”清楚。

### 错误 5：`isValid` 最后直接 `return true`

这样 `"("` 会被误判为有效，因为循环结束后栈里还剩一个左括号。必须 `return stack.isEmpty();`。

### 错误 6：只判断栈空，不判断类型

```java
if (stack.isEmpty()) return false;
stack.pop();   // 错：没有检查是不是同一类括号
```

`([)]` 会因此被误判为有效。

### 错误 7：忘记判断 `null`

对 `null` 调用 `s.length()` 会抛 `NullPointerException`。应先返回 `false`。

### 错误 8：以为 `pop` 会清空数组

`pop` 只移动 `top`。底层数组里旧值还在，这是正常现象，不是内存泄漏。

## 十、自测题

1. 为什么空栈用 `top = -1`，不用 `top = 0`？
2. `data[++top] = value` 和 `data[top++] = value` 有什么区别？
3. `pop` 之后数组里的旧值为什么还在？这算错误吗？
4. `peek` 和 `pop` 的区别是什么？
5. 栈满时继续 `push` 会发生什么？为什么要在写入前检查？
6. 为什么括号匹配适合用栈？
7. `"([)]"` 为什么无效？栈在哪一步发现错误？
8. `"("` 为什么无效？最后检查了什么？
9. `isValid` 为什么先把容量设成 `s.length() + 1`？
10. `char` 怎样存进 `int` 栈，又怎样取出来比较？

参考要点：

1. 0 是合法下标，无法区分空栈和“下标 0 有一个元素”。
2. 前者先加后用，后者先用后加；入栈必须用前者。
3. 因为只移动 `top`，没有清零；旧值不属于栈，不算错误。
4. `peek` 只读，`pop` 取走并移动 `top`。
5. 会数组越界；主动检查后抛出更清楚的异常。
6. 括号“后开先闭”，符合后进先出。
7. 遇到 `)` 时栈顶是 `[`，类型不匹配。
8. 循环结束后栈里还剩 `(`，`isEmpty()` 返回 false。
9. 最坏情况全是左括号，需要 `s.length()` 个格子；多留 1 个保证不满。
10. `char` 自动转 `int` 入栈，`pop` 后用 `(char)` 转回。

能回答这些问题，并能独立写出 `MyStack` 和 `isValid`，才算真正掌握这一课。
