## 程序功能说明

### 1. 用数组和 `top` 表示栈

```java
private int[] data;
private int top;
```

数组左边是栈底，右边是栈顶。`top` 保存栈顶元素的下标：

```text
空栈：
data = [0, 0, 0, 0]
top = -1

push(10)、push(20)、push(30) 后：
data = [10, 20, 30, 0]
top = 2
栈（底 -> 顶）：10, 20, 30
```

`top = -1` 不是合法下标，正好表示“一个元素也没有”。

### 2. 入栈：先移动栈顶，再写入

```java
public void push(int value) {
    if (isFull()) {
        throw new RuntimeException("栈已满，无法 push");
    }
    data[++top] = value;
}
```

`data[++top] = value;` 的顺序是：

1. `++top`：先让 `top` 加 1。
2. 再执行 `data[top] = value`。

例如空栈 `top = -1` 时，先变成 0，再写入 `data[0]`。

如果写成 `data[top++] = value;`，会先用旧的 `top` 当下标，再加 1，第一次入栈就会写到 `data[-1]`，直接越界。

### 3. 出栈：先取值，再下移

```java
public int pop() {
    if (isEmpty()) {
        throw new RuntimeException("栈为空，无法 pop");
    }
    int value = data[top];
    top--;
    return value;
}
```

`pop` 只把 `top` 往下移，并不擦除数组里的旧值。例如：

```text
data = [10, 20, 30, 0]
top = 2

pop() 返回 30 后：
data = [10, 20, 30, 0]
top = 1
```

`data[2]` 仍然是 30，但栈认为下标 2 已经不属于栈。下次 `push` 会直接覆盖它。程序里的 `show()` 特意打印整个底层数组，方便观察这一点。

### 4. 查看栈顶与容量

`peek()` 返回 `data[top]`，不修改 `top`，所以“只看不取”。

`isFull()` 判断：

```java
return top == data.length - 1;
```

数组长度是 `data.length`，最后一个合法下标是 `data.length - 1`。

`size()` 返回 `top + 1`：

- 空栈 `top = -1`，`size = 0`。
- `top = 2`，说明下标 0、1、2 三个位置有元素，`size = 3`。

### 5. 错误处理

栈空时 `pop` 或 `peek`、栈满时 `push`，都会抛出 `RuntimeException`：

```java
throw new RuntimeException("栈为空，无法 pop");
```

`throw` 会立刻结束当前方法。如果调用处没有 `try-catch`，程序会停止并打印异常信息；有 `try-catch` 时，可以捕获并继续执行。

演示 2 用 `try-catch` 分别验证：

- 空栈 `pop`。
- 空栈 `peek`。
- 满栈 `push`。

### 6. 括号匹配

`isValid` 的规则：

1. 遇到左括号 `(`、`[`、`{`：入栈，等待配对。
2. 遇到右括号：
   - 栈为空：没有左括号可配，返回 `false`。
   - 弹出栈顶左括号，和当前右括号不是一对：返回 `false`。
3. 全部字符处理完，栈必须为空，否则说明还有左括号没关闭。

例如 `([)]`：

```text
'(' 入栈       栈：(
'[' 入栈       栈：( [
')' 是右括号   栈顶是 '['，不配对 → false
```

例如 `{[]}`：

```text
'{' 入栈       栈：{
'[' 入栈       栈：{ [
']' 配对 '['   弹出，栈：{
'}' 配对 '{'   弹出，栈：空
结束，栈空 → true
```

`isValid` 先处理 `null`：

```java
if (s == null) {
    return false;
}
```

否则对 `null` 调用 `s.length()` 会抛 `NullPointerException`。

创建栈时容量是 `s.length() + 1`：

```java
MyStack stack = new MyStack(s.length() + 1);
```

最坏情况是整个字符串全是左括号，最多同时放 `s.length()` 个元素，多留 1 个格子保证不会满。

### 7. 字符与整数

`MyStack` 存的是 `int`，而 `isValid` 处理的是 `char`：

```java
stack.push(c);              // char 自动转换为 int
char left = (char) stack.pop();   // int 强制转换回 char
```

`char` 本质上是字符的编号（例如 `'('` 是 40），所以可以自动转成 `int`。取出时再用 `(char)` 转回去，才能和右括号比较。

### 8. 测试裁判

`check` 每次把 `total` 加 1，调用 `isValid` 得到实际结果，再和 `expected` 比较：

- 相同：`passed++`，打印 `[通过]`。
- 不同：打印 `[失败]`。

`main` 最后打印：

```java
System.out.println("共 " + total + " 项测试，通过 " + passed + " 项");
```

## 学习重点

1. 栈是“后进先出”（LIFO），只能在一端进出。
2. 用数组实现栈时，`top` 是栈顶元素的下标，不是元素个数。
3. `top = -1` 表示空栈；`size = top + 1`。
4. `push` 必须先判满，并用 `++top` 先移动再写入。
5. `pop` 必须先判空，先取值再 `top--`。
6. `pop` 不擦除数组旧值，旧值只是“不再属于栈”。
7. 栈空 `pop` / `peek`、栈满 `push` 必须报错，不能悄悄返回错误值。
8. 括号匹配利用“最近打开的括号最先关闭”，正好符合 LIFO。
9. 处理完所有字符后栈必须为空，否则有左括号没关闭。
10. `char` 可以自动转 `int`，取出时要强制转回 `char`。

## 学习难点

### 为什么用 `-1` 表示空栈

数组下标从 0 开始，`0` 已经是第一个合法位置。如果空栈用 0 表示，就无法区分“空栈”和“有一个元素在下标 0”。用 -1 既不是合法下标，又能让 `size = top + 1` 自然得到 0。

### `++top` 和 `top++`

```java
data[++top] = value;   // 先加 1，再用新值当下标
data[top++] = value;   // 先用旧值当下标，再加 1
```

入栈必须用前者。空栈时 `++top` 把 -1 变成 0，写入 `data[0]`；`top++` 会先拿 -1 当下标，直接越界。

### `pop` 后旧值为什么还在

`pop` 只改变 `top`，数组内容没有变。栈的“有效范围”是 `0～top`，`top` 之外的值虽然还在内存里，但不再被视为栈的一部分。这样实现简单，也让下次 `push` 可以直接覆盖。

### 为什么括号匹配要用栈

括号规则是“后打开的先关闭”。例如 `{[]}` 中，`[` 比 `{` 后打开，却先关闭。栈的栈顶正好是“最近打开、还没配对”的左括号，所以每次遇到右括号，只需要检查栈顶。

### 为什么最后要判断栈空

只检查中途配对还不够。例如 `"("`：

- 遇到 `(`，入栈。
- 没有右括号。
- 循环结束，栈里还剩一个 `(`。

如果不检查 `stack.isEmpty()`，就会错误地返回 `true`。

### 非括号字符会怎样

`isValid` 把所有“不是左括号”的字符都当成右括号处理。因此字符串里如果混入字母，会被判为无效。这是力扣第 20 题的约定（输入只包含六种括号），不是通用文本校验器。

## 当前边界与改进方向

- 栈容量固定，满了就抛异常，不能自动扩容。
- 只能存 `int`，不能存 `String`、`Student` 等对象；`char` 是通过自动转 `int` 存进去的。
- 使用通用的 `RuntimeException`，没有自定义异常类型。
- `isValid` 只适用于六种括号字符；混入字母、数字或空格会被判为无效。
- `check` 只打印结果，不改变进程退出码；测试失败时命令仍然返回 0。
- `MyStack` 是包级类，只在当前文件内使用；真实项目应拆成独立文件。
- 没有实现动态扩容、迭代器、`toString`、`equals`，也没有队列或双端队列。
- `MyStack(0)` 会创建容量为 0 的栈，任何 `push` 都会抛“栈已满”；当前没有专门测试这个边界。
- 演示程序只覆盖固定数据，没有读取用户输入。

## 拓展练习

1. 把 `MyStack` 改成泛型 `MyStack<T>`，让它能存任意对象。

6. 用栈计算后缀表达式（逆波兰表达式），例如 `3 4 + 5 *`。
