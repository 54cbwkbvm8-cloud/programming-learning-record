## 程序功能说明

### Student 类

可执行代码是第 1～18 行，第 19 行以后是详细历史注释。

```java
int id;
String name;
double score;
```

这是三个成员变量，也叫字段或属性。每个 `Student` 对象都有自己独立的一份。

无参构造：

```java
public Student() {
}
```

执行 `new Student()` 后，成员使用 Java 默认值：

```text
id = 0
name = null
score = 0.0
```

有参构造：

```java
public Student(int id, String name, double score) {
    this.id = id;
    this.name = name;
    this.score = score;
}
```

参数名与成员变量同名。`this.id` 表示当前对象的成员变量，右侧 `id` 表示参数。

`printInfo()` 没有 `static`，所以它是实例方法。调用 `s1.printInfo()` 时，方法中的 `id`、`name`、`score` 属于 `s1`；调用 `s2.printInfo()` 时属于 `s2`。

### StudentTest 类

可执行代码是第 1～16 行。

`s1` 调用无参构造，所以打印默认值。`s2` 调用有参构造，打印传入值。

```java
Student s3 = s2;
```

没有创建第三个对象。它只是把 `s2` 保存的引用复制给 `s3`，两个变量指向同一个对象。随后：

```java
s3.name = "张三";
```

修改的是共同对象，所以通过 `s2` 也能看到姓名变化。

`s2 == s3` 比较两个变量是否指向同一个对象，结果为 `true`。`s1 == s2` 指向不同对象，结果为 `false`。

## 分类理由

本练习第一次把数据和方法组织进自定义类，并创建多个对象，不再只是“一个类里堆 `static` 方法”。主要学习目标是类与对象、构造方法和引用关系，因此放入 `Java/05_面向对象`，不继续留在方法或综合项目目录。

## 运行方式

本程序不需要键盘输入。在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-object.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/05_面向对象/Student.java" \
  "Java/05_面向对象/StudentTest.java"
java -cp "$java_dir" StudentTest
```

已在 OpenJDK 21.0.13 下实际通过严格编译并运行，真实输出为：

```text

学号：0 姓名：null 成绩：0.0
--- 第二个对象 s2（有参构造，成员是传入值）---
学号：20260202 姓名：蔡徐坤 成绩：98.6
--- s3 只是 s2 的另一个名字（引用赋值，没有创建新对象）。实验：通过 s3 改名后，用 s2 查看 ---

s2 == s3 ? true

```

## 学习重点

| 知识点 | 需要理解什么 | 为什么重要 |
| --- | --- | --- |
| 类 | 描述一类对象有哪些字段和方法 | 类是创建对象的模板 |
| 对象 | `new Student(...)` 在运行时创建出的具体实例 | 每个对象有独立字段 |
| 构造方法 | 名字等于类名，没有返回类型，在 `new` 时自动执行 | 负责初始状态 |
| 构造重载 | 参数列表不同，可以选择无参或有参版本 | Java 根据参数个数和类型选择 |
| `this` | 当前对象自身，用来区分同名字段和参数 | 漏写会变成参数给自己赋值 |
| 实例方法 | 必须通过对象调用，能访问该对象字段 | `printInfo` 打印对应对象 |
| 引用 | 对象变量保存对象地址，不是整块对象副本 | 决定赋值、传参和比较行为 |

## 学习难点

### 为什么写了有参构造还要写无参构造

如果类里完全不写构造方法，编译器会自动提供无参构造。但一旦写了有参构造，默认无参构造就不再自动生成。当前源码显式写出 `public Student()`，所以 `new Student()` 仍然合法。

### this 左右两边是什么

```java
this.name = name;
```

- 左边 `this.name`：当前对象的字段。
- 右边 `name`：构造方法参数。

如果写成：

```java
name = name;
```

两边都会解析成参数，成员变量仍是 `null`。这就是另一个 26 号练习中 `NoThisStudent` 的反例。

### 变量、引用和对象要分开

```text
s2 ──┐
     ├──> [id=20260202, name=张三, score=98.6]
s3 ──┘
```

系统中只有两个 `Student` 对象：`s1` 指向一个，`s2` 和 `s3` 共同指向另一个。

### == 比较的不是字段内容

`Student` 没有重写 `equals`，`s2 == s3` 只判断引用是否相同。两个对象即使字段一样，也可能得到 `false`。当前测试通过同一个引用比较，所以为 `true`。

## 已知边界

- `id`、`name`、`score` 没有写 `private`，外部可以直接修改。
- 有参构造没有检查学号、姓名或成绩范围，可以创建 `score = -999` 的对象。
- 没有 getter/setter，也没有 `toString()` 或 `equals()`。
- 本练习重点不是安全数据模型，而是先认识类和对象。封装由 26 号 `EncapsulationStaticDemo` 演示。
- `s3.name = "张三"` 会直接修改字段，这是源码有意展示引用共享，不代表推荐的正式设计。

## 易错点与测试用例

| 测试或修改 | 实际或预期结果 | 检查目标 |
| --- | --- | --- |
| `new Student()` | 字段为 0、null、0.0 | 默认值和无参构造 |
| `new Student(20260202, "蔡徐坤", 98.6)` | 三个字段为传入值 | 有参构造 |
| `Student s3 = s2` | 没有创建新对象 | 引用复制 |
| 通过 `s3.name` 改名 | `s2` 看到同一变化 | 共同引用 |
| `s2 == s3` | true | 相同引用 |
| `s1 == s2` | false | 不同引用 |
| 删除 `public Student()` | `new Student()` 编译失败 | 有参构造会取消默认无参构造 |
| 把 `this.name = name` 写成 `name = name` | 字段仍为 null | 变量遮蔽 |

`Student` 的字段是包级可见，当前没有验证非法成绩。不要根据当前源码声称已经实现封装或输入校验。
