# Java 类、对象、构造方法与引用零基础教程

本教程配合 [Student.java](Student.java) 和 [StudentTest.java](StudentTest.java) 使用。目标不是背会两段代码，而是能解释：

1. 类与对象分别是什么。
2. `new` 创建对象时发生什么。
3. 两个构造方法怎样被选择。
4. `this` 为什么不能漏。
5. 为什么 `Student s3 = s2` 没有创建第三个对象。

## 一、类是一张图纸

`Student` 类规定每个学生对象有三项数据：

```text
id    学号
name  姓名
score 成绩
```

以及一个动作：

```text
printInfo() 打印自己的三项数据
```

类本身不是某个具体学生。它更像“学生信息表应该包含哪些栏目”的模板。

运行：

```java
Student s1 = new Student();
```

才根据模板创建了一个具体对象，并把对象引用保存到变量 `s1`。

## 二、对象变量保存的是引用

不要画出“变量里装了一整个对象”。更接近真实情况的画法是：

```text
s1 ──> [id=0, name=null, score=0.0]
```

`s1` 里保存对象的地址，对象本体在堆内存中。Java 不允许直接打印地址数值，但引用关系可以通过 `==` 和字段变化观察。

## 三、成员变量和默认值

```java
int id;
String name;
double score;
```

这些变量定义在类中、方法外，属于每个对象：

| 类型 | 默认值 |
| --- | --- |
| `int` | 0 |
| `double` | 0.0 |
| `String` 等引用类型 | null |

所以 `new Student()` 后：

```text
学号：0 姓名：null 成绩：0.0
```

`null` 表示没有指向任何字符串对象，不是内容为两个字母的文本。

## 四、构造方法

### 构造方法的两个外观特征

```java
public Student() {
}
```

- 方法名和类名 `Student` 完全相同。
- 名字前面没有 `int`、`void` 等返回类型。

构造方法在 `new` 创建对象时自动执行，不需要手动调用 `s1.Student()`。

### 无参构造

```java
public Student() {
}
```

没有接收初始值，字段保持默认值。

### 有参构造

```java
public Student(int id, String name, double score) {
    this.id = id;
    this.name = name;
    this.score = score;
}
```

调用：

```java
Student s2 = new Student(20260202, "蔡徐坤", 98.6);
```

参数按顺序匹配：

| 构造参数 | 实参 |
| --- | --- |
| `int id` | 20260202 |
| `String name` | `"蔡徐坤"` |
| `double score` | 98.6 |

### 为什么两个同名构造不冲突

Java 根据参数列表区分它们：

```text
Student()                          -> 无参版本
Student(int, String, double)       -> 有参版本
```

这叫构造方法重载。

### 只写一个有参构造会怎样

如果一个类完全没有写构造方法，编译器会自动提供无参构造。但只要手写了任意构造方法，这个自动无参构造就不再赠送。因此当前源码主动写了 `public Student()`，保证 `new Student()` 仍可编译。

## 五、this 解决同名问题

```java
public Student(int id, String name, double score) {
    this.id = id;
    this.name = name;
    this.score = score;
}
```

参数和字段同名。方法内部直接写 `name` 时，离得最近的局部名称是参数，不是字段。

```text
this.name  当前对象的字段
name       构造方法参数
```

所以赋值方向是：

```text
参数 -> 当前对象字段
```

如果写：

```java
name = name;
```

左右两边都是参数，字段没有被修改。Java 可能不报错，但逻辑错误。

## 六、实例方法

```java
public void printInfo() {
    System.out.println("学号：" + id + " 姓名：" + name + " 成绩：" + score);
}
```

方法没有 `static`，属于具体对象：

```java
s1.printInfo();
s2.printInfo();
```

同一个方法代码被执行两次，但两次使用的字段来自不同对象。

| 调用 | `id` | `name` | `score` |
| --- | ---: | --- | ---: |
| `s1.printInfo()` | 0 | null | 0.0 |
| `s2.printInfo()` | 20260202 | 蔡徐坤 | 98.6 |

如果 `printInfo` 写成 `static`，它不能直接访问 `id`、`name`、`score`，因为这些字段属于具体实例。

## 七、创建两个对象

```java
Student s1 = new Student();
Student s2 = new Student(20260202, "蔡徐坤", 98.6);
```

内存关系：

```text
s1 ──> 对象 A [0, null, 0.0]
s2 ──> 对象 B [20260202, 蔡徐坤, 98.6]
```

两个 `new` 各创建一个对象。

## 八、引用赋值不是对象复制

```java
Student s3 = s2;
```

执行步骤：

1. 读取 `s2` 中保存的对象地址。
2. 把地址复制给 `s3`。
3. 没有执行 `new`。

结果：

```text
s2 ──┐
     ├──> 对象 B
s3 ──┘
```

然后：

```java
s3.name = "张三";
```

通过 `s3` 找到对象 B，修改对象 B 的字段。再调用 `s2.printInfo()`，自然看到姓名“张三”。

“一个人有两个称呼”仍是同一个对象。

## 九、== 比较引用

```java
s2 == s3
```

比较两个变量是否保存同一个地址：

```text
true
```

```java
s1 == s2
```

比较对象 A 与对象 B 的地址：

```text
false
```

`==` 不会逐个比较 `id`、`name`、`score`。如果两个不同对象的字段完全相同，`==` 仍可能是 `false`。

## 十、完整执行轨迹

```text
new Student()
-> 调用无参构造
-> s1 指向对象 A

new Student(20260202, 蔡徐坤, 98.6)
-> 调用有参构造
-> this 字段赋值
-> s2 指向对象 B

s1.printInfo()
-> 打印对象 A 默认值

s2.printInfo()
-> 打印对象 B 传入值

s3 = s2
-> s3、s2 指向对象 B

s3.name = 张三
-> 修改对象 B

s2.printInfo()
-> 打印张三

s2 == s3
-> true

s1 == s2
-> false
```

## 十一、常见错误

### 把类当成对象

`Student` 是类型；`new Student()` 才是对象。

### 以为变量赋值会复制对象

基本类型赋值复制数值；对象变量赋值复制引用值，不会自动复制对象。

### 以为 == 比较内容

当前 `Student` 未重写 `equals`，`==` 比较引用。需要内容比较时应实现专门的 `equals`。

### 两个构造方法写成相同参数

参数列表相同就不是重载，而是重复定义。

### this 写成大写

Java 区分大小写，`THIS` 不是关键字。
