# Java 继承、构造顺序与重写：简介与学习建议

## 1. 文件基本信息

- **源码**：`InheritanceDemo.java`
- **分类**：`Java/08_继承与多态/01_继承与重写演示`
- **程序用途**：用一个包含 `Person` 和 `Student` 的完整演示，观察继承、父类构造方法、方法继承与重写、`toString` 和 `Object`。
- **核心知识点**：`extends`、`super(name, age)`、`private` 字段、getter、方法重载与重写、`@Override`、`Object`。
- **前置知识**：类与对象、构造方法、`this`、方法参数与返回值、基本输出。
- **相关练习**：建议先完成 25、26、32、33 号，再学习本题；39 号在此基础上继续讲多态。

## 2. 程序功能说明

`Person` 保存姓名和年龄，`Student` 继承 `Person`，再增加学号和成绩。`main` 分五部分验证：

1. 创建 `Student` 时先执行 `Person` 构造方法，再执行 `Student` 构造方法。
2. `Student` 没有重复编写 `getName` 和 `sayHello`，却能直接调用继承来的方法。
3. 两个类都定义了 `introduce()`，对象会执行自己实际类型的版本。
4. `println(对象)` 自动调用重写后的 `toString()`。
5. 没写 `extends` 的 `Person` 仍默认继承 `java.lang.Object`；未重写的 `equals` 使用引用相等语义。

源码后半段保留了附件中的大段注释教程。注释不会影响编译和执行。

## 3. 编译与运行

在仓库根目录执行：

```bash
java_dir=$(mktemp -d /tmp/java-inheritance.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/08_继承与多态/01_继承与重写演示/InheritanceDemo.java"
java -cp "$java_dir" InheritanceDemo
```

程序不需要输入。已使用 OpenJDK 21.0.13 严格编译并实际运行，退出码为 0。关键输出顺序为：

```text

Student 构造方法执行：studentId=20260125, score=92.5
...

Person 的父类: java.lang.Object
s.equals(s) = true
s.equals(p) = false
```

## 4. 学习重点与难点

- **`super(name, age)` 必须在子类构造方法第一行**：父类没有无参构造方法，不能依赖编译器自动加入的 `super()`。
- **继承不等于能直接访问私有字段**：`Student` 通过 `getName()`、`getAge()` 读取父类的 `private` 数据。
- **重载与重写不同**：两个 `sayHello` 参数不同，是重载；子类与父类的 `introduce()` 签名相同，是重写。
- **`toString` 只返回描述文本**：换行由 `println` 负责，不应由 `toString` 暗自添加。
- **默认 `equals` 不是字段比较**：本程序没有重写 `equals`，所以 `s.equals(s)` 为 `true`，不同对象之间为 `false`。

## 5. 推荐学习流程

1. 先画出 `Person → Student` 的继承箭头，标出各自字段。
2. 手工预测创建 `Student` 时两条构造输出的先后顺序，再运行核对。
3. 在 `Student` 中找出哪些方法是继承的、哪些是新增的、哪些是重写的。
4. 对照 32、33 号，解释 `toString` 与默认 `equals` 的行为。
5. 关闭源码，独立写一个 `Animal` 父类和 `Dog` 子类，要求子类增加字段并重写方法。

## 6. 易错点与测试用例

| 操作或场景 | 预期结果 | 状态 |
| --- | --- | --- |
| 当前固定演示 | 先父类构造、后子类构造；各方法输出与对象类型一致 | 已运行验证 |
| 删除 `super(name, age)` | 编译失败，因为父类没有无参构造方法 | 预期结果，未修改源码测试 |
| 把 `@Override` 的方法名改错 | 编译器提示没有可重写的方法 | 预期结果，未修改源码测试 |
| 在 `Student` 中直接写 `name` | 编译失败，因为父类字段是 `private` | 预期结果，未修改源码测试 |
| 新建两个字段完全相同的 `Student` 后调用 `equals` | 当前仍为 `false`，因为未重写 `equals` | 预期结果，可另写测试类验证 |

当前程序不接受外部输入，因此没有“空输入”测试；应通过新增对象和修改测试类来覆盖不同字段值。
