# Java 继承、构造顺序与重写：零基础教程

## 一、先用一句话理解题目

“学生是一种人”：学生有人的姓名和年龄，也有自己特有的学号和成绩。`Student extends Person` 就是把这种关系写成代码。

本程序不是让学生背 `extends`，而是用五组可观察的输出回答五个问题：对象怎样初始化、方法怎样继承、重写怎样生效、对象怎样打印、`Object` 从哪里来。

## 二、开始前必须知道

- **类与对象**：类是设计图，`new` 才创建对象。
- **字段与方法**：字段保存对象数据，方法描述对象行为。
- **构造方法**：创建对象时执行，名字与类名相同，没有返回类型。
- **私有字段**：`private` 不允许子类直接访问，继承关系也不会绕过这条规则。

可以把子类对象想成“父类部分 + 子类新增部分”。创建时必须先把父类部分准备好。

## 三、按程序结构阅读

### 1. `main` 的第一部分：构造顺序

```java
Student s = new Student("张三", 18, "20260125", 92.5);
```

进入 `Student` 构造方法后，第一句是：

```java
super(name, age);
```

它把姓名和年龄交给 `Person` 构造方法。因此真实输出先出现：

```text
Person 构造方法执行：name=张三, age=18
Student 构造方法执行：studentId=20260125, score=92.5
```

不能交换这两条语句所代表的执行顺序。父类初始化完成后，才继续执行子类字段赋值。

### 2. `Person` 的字段与 getter

```java
private String name;
private int age;
```

`Student` 虽继承这些字段，却不能在自己的方法里直接写 `name`。因此使用：

```java
getName();
getAge();
```

这不是多此一举，而是在保留封装边界。

### 3. 方法继承与重载

`Student` 没有编写 `getName()` 和 `sayHello()`，但 `s` 可以调用它们，因为它们从 `Person` 继承而来。

下面两个方法同名、参数列表不同，属于**重载**：

```java
sayHello()
sayHello(String to)
```

调用 `s.sayHello("李老师")` 时，编译器根据一个字符串参数选择第二个版本。

### 4. 方法重写

`Person` 和 `Student` 都有无参数、返回 `void` 的 `introduce()`。子类版本使用 `@Override`，要求编译器检查它确实重写了父类方法。

```java
s.introduce();  // Student 的版本
p.introduce();  // Person 的版本
```

这里 `s` 和 `p` 的真实对象类型不同，所以输出不同。39 号会进一步使用父类变量保存子类对象。

### 5. `toString` 与 `Object`

`System.out.println(s)` 需要把对象转成文本，会调用 `s.toString()`。本类已经重写，所以看到字段内容，而不是默认的“类名@十六进制值”。

`Person` 没写 `extends`，仍自动继承 `Object`。因此：

```text
Student 的父类: Person
Person 的父类: java.lang.Object
```

本程序没有重写 `equals`，所以默认语义是“是否为同一个对象”：`s.equals(s)` 为 `true`，`s.equals(p)` 为 `false`。

## 四、变量与执行轨迹

创建 `s` 时可记录为：

| 步骤 | 执行位置 | 已准备的数据 |
| --- | --- | --- |
| 1 | 进入 `Student` 构造方法 | 四个参数已经传入 |
| 2 | `super(name, age)` | 转入 `Person` |
| 3 | `this.name = name; this.age = age` | 父类部分完成 |
| 4 | 回到 `Student` | 写入 `studentId`、`score` |
| 5 | 构造结束 | 引用 `s` 指向完整学生对象 |

注意：`new Person("王五", 40)` 是另一个独立对象，不与 `s` 共用字段。

## 五、常见错误与调试

1. **漏写 `super(name, age)`**：编译器会尝试 `super()`，但父类没有无参构造，因而编译失败。
2. **把重载当重写**：重写要求方法名和参数列表相同；参数不同通常是重载。
3. **直接访问父类私有字段**：改用父类提供的公开方法，不要为图省事把字段改成公开。
4. **在 `toString` 末尾加换行**：返回文本与输出换行是两个职责。
5. **认为字段相同就 `equals` 为真**：只有重写内容比较后才可能如此。

调试时先读编译器的首条错误及行号；运行结果不符合预测时，一次只改一个条件。
