# Java 多文件学生继承与构造顺序：简介与学习建议

## 1. 文件基本信息

- **源码**：`Person.java`、`Student.java`
- **分类**：`Java/08_继承与多态/03_多文件学生继承`
- **程序用途**：把父类和子类拆到两个源文件，练习继承、封装、构造顺序、方法重载与重写。
- **前置知识**：25、26 号的类、构造方法、`this` 和封装；38 号的继承基础。
- **与其他版本的关系**：这是只有两个类的多文件版本；38 号把类写在演示文件内部，41 号则使用另一组只有姓名字段的 `Person`，并增加 `Teacher`。三组不能混在同一次编译中。

## 2. 程序功能说明

`Person` 是公开父类，包含私有姓名、年龄，提供 getter、两个重载的 `sayHello`、可重写的 `introduce` 和 `toString`。`Student` 是公开子类，增加学号与成绩，通过 `super(name, age)` 初始化父类部分，并通过 `super.introduce()` 复用父类介绍。

两个文件都只有类定义，没有 `main`，因此可以编译，但不能直接作为程序启动。源码后半段保留附件中的注释教程。

## 3. 编译与运行

```bash
java_dir=$(mktemp -d /tmp/java-person-student.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/08_继承与多态/03_多文件学生继承/Person.java" \
  "Java/08_继承与多态/03_多文件学生继承/Student.java"
```

已使用 OpenJDK 21.0.13 严格编译通过，无警告。**未执行运行测试**，原因是本组没有 `main` 方法；不能把“编译通过”写成“功能已运行验证”。

如需运行，可另建自己的 `Main.java`，创建 `Student` 并调用 `introduce()`、`sayHello()` 和 `toString()`。不要把其他分组的同名 `Person` 或 `Student` 加进来。

## 4. 学习重点与难点

- 两个公开类的文件名必须分别为 `Person.java`、`Student.java`；原附件中较长的导出名已按 Java 规则恢复。
- `Student` 构造方法先执行 `super(name, age)`，再初始化学号和成绩。
- 父类字段为 `private`，子类的 `toString()` 使用 `getName()` 和 `getAge()`。
- `super.introduce()` 是复用父类实现，不等于重新创建父类对象。
- 两个 `sayHello` 是重载，`introduce` 和 `toString` 是重写。

## 5. 推荐学习流程

1. 对照 38 号，找出“单文件多类”和“多文件多类”的结构差异。
2. 画出创建 `Student("张三", 18, "20260125", 92.5)` 时的构造调用顺序。
3. 自己编写最小 `Main.java`，预测输出后再运行。
4. 删除 `super.introduce()`，观察子类介绍少了哪部分，再恢复自己的练习副本。

## 7. 拓展与后续学习

先完成 41 号，比较两种字段设计；再为当前组写独立入口和固定输出测试。之后可尝试把 `score` 的合法性校验集中到构造方法与 setter，避免非法对象。
