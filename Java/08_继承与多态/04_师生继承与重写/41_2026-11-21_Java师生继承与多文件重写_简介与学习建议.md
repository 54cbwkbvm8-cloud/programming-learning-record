# Java 师生继承与多文件重写：简介与学习建议

## 1. 文件基本信息

- **源码**：`Person.java`、`Student.java`、`Teacher.java`
- **分类**：`Java/08_继承与多态/04_师生继承与重写`
- **程序用途**：用三个文件表示一个父类和两个子类，练习构造方法复用、私有字段访问、方法重写和子类特有行为。
- **前置知识**：类与对象、封装、构造方法、`super`；建议先学 38、39 号。
- **与其他版本的关系**：这里的 `Person` 只有姓名，`Student` 增加学号，`Teacher` 增加科目。与 40 号字段不同，不是完全重复文件。

## 2. 程序功能说明

`Person` 提供 `getName()` 和普通自我介绍。`Student` 与 `Teacher` 都通过 `super(name)` 把姓名交给父类保存，分别重写 `introduce()`，并新增 `study()` 或 `teach()`。

这组类没有 `main`，适合作为多文件类定义练习。`Person` 和 `Student` 是包级类，`Teacher` 是公开类，因此 `Teacher.java` 的文件名必须与公开类名一致。

## 3. 编译与运行

```bash
java_dir=$(mktemp -d /tmp/java-person-student-teacher.XXXXXX)
javac -encoding UTF-8 -Xlint:all -Werror -d "$java_dir" \
  "Java/08_继承与多态/04_师生继承与重写/Person.java" \
  "Java/08_继承与多态/04_师生继承与重写/Student.java" \
  "Java/08_继承与多态/04_师生继承与重写/Teacher.java"
```

已使用 OpenJDK 21.0.13 严格编译通过，无警告。**未执行运行测试**，因为三个文件均没有程序入口。

可自行另建 `Main.java`，用 `Person[]` 保存学生和老师并调用 `introduce()`；这与 39 号的多态数组形成呼应。

## 4. 学习重点与难点

- **两个子类共享父类实现，但彼此不是父子关系**：不能把 `Teacher` 当作 `Student`。
- **构造方法必须先初始化父类部分**：两个子类都使用 `super(name)`。
- **私有字段通过公开 getter 访问**：子类不直接访问 `Person.name`。
- **子类特有方法不属于父类接口**：父类引用要调用 `study()` / `teach()` 时，需要安全向下转型；应复习 39 号。
- **同名类隔离**：不要和 38～40 号或仓库其他 `Student.java` 混合编译。

## 5. 推荐学习流程

1. 画出 `Person` 指向 `Student`、`Teacher` 的继承图。
2. 逐个标记字段和方法属于哪个类，区分继承、重写和新增。
3. 自建 `Main.java`，分别创建两个子类对象并预测介绍文本。
4. 再把对象放入 `Person[]`，用 39 号的 `instanceof` 方法安全调用特有行为。

## 7. 拓展与后续学习

- 为两个子类各写一个固定测试，比较真实对象类型与输出。
- 思考能否把公共介绍格式留在 `Person`，同时保留子类扩展。
- 后续进入接口、组合和集合时，再比较“继承”与“拥有一个对象”分别适合什么关系。
