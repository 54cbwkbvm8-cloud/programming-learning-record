# Java 校园人员管理系统：零基础教程

> 配合 [CampusManager.java](CampusManager.java) 和 [48 号简介](48_2026-11-21_Java校园人员管理系统_简介与学习建议.md) 使用。建议先跑通简介第 3 节的脚本，再按本文顺序拆解；每节末尾有动手任务。

## 0. 这个项目要解决的问题

一个能"装人"的菜单程序：按 1 录入（还分学生/教师/其他）、按 2 查姓名、按 3 按年龄排序、按 4 全部显示、按 0 退出。看起来和 24 号成绩管理系统差不多，但**本题的主角是三个类的继承体系**：

```text
        Person（姓名 name、年龄 age）
        ↑            ↑
     Student       Teacher
   （+学号 studentId）（+工号 teacherId）
```

要看懂的核心一句话：**数组格子的类型是 `Person`，格子里的对象可以是任何一种人**。

## 1. 类的骨架：先看 Person

```java
class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge()    { return age; }

    @Override
    public String toString() {
        return name + "（" + age + " 岁）";
    }
}
```

- `private` + getter：外界只能读不能改（25、26 号封装知识）。
- `toString` 规定"这个对象变成文字时长什么样"。`println(对象)`、`"文字" + 对象` 都会自动调用它（32 号）。

## 2. 子类：只写"多出来的部分"

```java
class Student extends Person {
    private String studentId;

    public Student(String name, int age, String studentId) {
        super(name, age);              // ① 先把姓名年龄交给父类处理
        this.studentId = studentId;    // ② 再存自己新增的学号
    }

    @Override
    public String toString() {
        return super.toString() + "，学号：" + studentId;
    }
}
```

`Teacher` 完全对称（工号）。两个细节：

1. `super(name, age)` 必须是构造方法第一行——子类对象里包含"父类的那部分"，要先把它建好（38 号）。
2. `super.toString()` 先借父类的 `"张三（20 岁）"`，再拼上自己的学号——**不重复造轮子**。

## 3. 全局状态：入口类的"工作台"

```java
public class CampusManager {
    static final int MAX = 5;                          // 容量：常量，改需求只改这里
    static final int MAX_AGE = 150;                    // 年龄上限常量
    static Person[] people = new Person[MAX];          // 5 个格子，暂时都是 null
    static int count = 0;                              // 实际存了几人
    static Scanner sc = new Scanner(System.in);        // 全局共用的键盘
    static boolean running = true;                     // 主循环开关
}
```

理解 `count` 的角色：数组长度固定是 5，但"有效数据"只有前 `count` 格。`count = 3` 意味着下标 0、1、2 有人，3、4 是 `null`。**因此所有遍历都写 `i < count`，写 `i < MAX` 会对 `null` 调方法直接崩溃**（34 号 NPE 复习）。

为什么这些都 `static`？因为 `main` 是 static 的，只能直接用 static 成员。这是小项目的常见写法；规模变大时，36 号示范了把状态封装进 `StudentManager` 对象的做法。

## 4. 主循环：菜单的"问-读-办-再问"

```java
while (running) {
    printMenu();                          // 打印菜单
    if (!sc.hasNextLine()) break;         // 输入枯竭则退出（防崩溃）
    int choice = toInt(sc.nextLine().trim());
    switch (choice) {
        case 1: addPerson(); break;       // 录入
        case 2: findByName(); break;      // 查找
        case 3: sortByAge(); break;       // 排序
        case 4: showAll(); break;         // 显示
        case 0: running = false; break;   // 关开关，本轮结束后退出
        default: System.out.println("无效选择，请重新输入。");
    }
}
```

`toInt` 是"文字转整数，失败给 -1"的安全阀：

```java
static int toInt(String text) {
    try {
        return Integer.parseInt(text);   // "42" → 42
    } catch (NumberFormatException e) {  // "x"、"3.5"、空串都会进这里
        return -1;                       // -1 不与任何合法菜单项冲突
    }
}
```

于是"输入 `abc`"不会崩溃，只会走 `default`。`ask(prompt)` 同理先 `hasNextLine()` 再读，管道喂空时返回空串。

## 5. 录入：本题的"多态入口"

```java
Person person;                                   // 父类变量，先不指向任何对象
if (type == 1) {
    person = new Student(name, age, studentId);  // 分支①：学生
} else if (type == 2) {
    person = new Teacher(name, age, teacherId);  // 分支②：教师
} else if (type == 3) {
    person = new Person(name, age);              // 分支③：普通人员
} else {
    System.out.println("类型输入有误。");
    return;
}
people[count++] = person;                        // 入库：先存后加一
```

三个观察点：

1. **同一个变量 `person`，三种对象**——这就是"向上转型"：子类对象交给父类变量保管，自动完成。
2. `people[count++] = person`：先以当前 `count` 为下标存入，再 `count` 加一。`count=3` 时存进 `people[3]`，随后 `count=4`。若写成 `++count`，会先加一变成 4、存进 `people[4]`，**错位且丢格**。
3. 顺序先校验后入库：姓名空、年龄越界、学号空、类型非法都提前 `return`，**失败时不会留下半条记录**。

## 6. 使用：多态的"出口"

```java
// findByName / showAll 里都有这一类代码：
System.out.println("找到：" + people[i]);
```

`+ people[i]` 会自动调用 `toString`，而**执行哪个版本由对象的真实类型决定**：

- `people[i]` 是 `Student` → `张三（20 岁），学号：2026001`
- `people[i]` 是 `Teacher` → `李四（35 岁），工号：T001`
- 普通人员 → `王五（28 岁）`

一行代码，三种输出。录入时"分化"、使用时"统一"——这就是继承体系在项目里的红利。查找用 `getName().equals(name)`（内容比较，33 号：字符串不能用 `==`），且遍历**全程**统计 `found`，重名的人全部列出。

## 7. 排序：对象版冒泡

```java
for (int i = 0; i < count - 1; i++) {
    for (int j = 0; j < count - 1 - i; j++) {
        if (people[j].getAge() > people[j + 1].getAge()) {
            Person temp = people[j];          // ① 引用先存
            people[j] = people[j + 1];        // ② 引用对调
            people[j + 1] = temp;             // ③ 回填
        }
    }
}
```

和 43 号整数冒泡**结构完全相同**，只换了两处：

- 比较用 `getAge()`（年龄在私有字段里，只能隔着 getter 读）；
- 交换的是**引用**（门牌号），对象本体在内存里纹丝不动。

边界照旧：外层 `count - 1`、内层 `count - 1 - i`，且全程只用 `count`——`null` 格子绝不参与比较。

## 8. 一个文件四个类

Java 规则：一个 `.java` 文件最多一个 `public` 类，且**文件名必须等于它**。本题 public 的是 `CampusManager`，所以文件叫 `CampusManager.java`；`Person/Student/Teacher` 是包级"配角"。

推论：本文件与 `05`、`06`、`08` 各分组、以及 `StudentManagementSystem.java` 都定义了同名类，**任何两组都不能放进同一次 `javac` 调用**，否则报 `duplicate class`。仓库的规则是"一组一个目录、逐组编译"（见 [开发环境与 Git 操作指南](../../docs/开发环境与Git操作指南.md)）。

## 10. 自我检查

1. `people` 的类型是 `Person[]`，为什么能存 `Student`？——子类对象可放入父类格子（向上转型）。
2. 显示时为什么学生自动带学号？——`+` 拼接自动调用真实类型的 `toString`（多态）。
3. 遍历为什么用 `i < count`？——后面的格子是 `null`，调用其方法会 NPE。
4. `people[count++] = person` 若写成 `++count` 会怎样？——先加一导致下标错位、跳过一格。
5. 排序交换的是什么？——引用（地址），对象本体不动。
6. 这题和 36 号的最大差别？——本题用继承多态管理"同一体系的人员"，36 号用对象+管理器管理"同类的学生"；小项目用 static 全局状态，大项目封装进管理器对象。
