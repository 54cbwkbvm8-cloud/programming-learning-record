# 01 Python 基础练习

本目录收录 Python 入门阶段的短脚本，重点是**变量、列表、字典、循环、条件判断、内置统计函数和基础算法**。这里的每个文件都很短，可以直接运行、随意修改，最适合用来打牢语法基础。

大多数旧练习带中文注释和文件头说明。本次为了保留真实学习过程，`09` 号保留最初提交的简短版本，`10` 号则是在同一道题上增加逐行中文注释并优化效率的版本。

## 每个文件在学什么

**`01_2026-08-23_输出偶数.py`** 是最短的循环练习。重点在 `range(0, 101, 2)` 这三个参数的含义：起点包含、终点不包含、步长决定间隔。把终点改成 100 会少输出一个数，改步长会改变输出序列，这是理解 `range` 边界最快的实验。

**`02_2026-08-23_九九乘法表.py`** 第一次把循环套在循环里。外层 `i` 管行，内层 `j` 管列，`j <= i` 决定了三角形的形状。跑通之后试着把内层改成 `range(1, 10)`，乘法表会变成 9×9 方阵。

**`03_2026-08-23_星号三角形.py`** 的核心是"字符串可以乘数字"，`"* " * 3` 会得到 `"* * * "`。行数由 `height` 控制，想输出 10 行三角形，只改这一个变量就行。

**`04_2026-08-23_成绩等级判断.py`** 是分支结构的入门题。多个 `elif` 从高到低排列，只要前面的条件不成立才会继续往下判断。用 59、60、89、90 四个分数各测一次，就能看清边界归属。低于 60 分时程序输出的是一个趣味提示，可以按自己的喜好改成正式文字。

**`05_2026-08-30_成绩统计与及格人数.py`** 开始处理"一批数据"。先用 `sum` 和 `len` 算平均分，再用 `max`、`min` 拿极值，最后用循环把成绩分成及格和不及格两组。它演示了"遍历一次可以做好几件事"的思路。

**`06_2026-08-27_列表增删与索引.py`** 是列表方法练习。`append` 在末尾加、`remove` 按值删除、下标读取指定位置、`len` 统计人数。注意删除不存在的元素会报错，这是列表操作的第一个坑。

**`07_2026-09-09_字典成绩统计与查询.py`** 从列表升级到字典：键是姓名、值是成绩。文件里用列表推导式把字符串成绩转成整数，再用 `sorted` 按姓名排序输出，最后支持输入姓名查询成绩。查询时要处理"查不到"的情况，这点很有实用价值。

**`08_2026-09-28_复习题_成绩录入与统计.py`** 是本目录的综合复习。它用 `while` 循环反复录入，成绩不在 0～100 之间就提示并 `continue` 重新输入，录完后再统一计算等级和统计结果。通过了这一份，就可以进入下一个目录。

**`09_2026-10-18_两数之和_暴力枚举.py`** 开始把列表和循环用于一个明确的小算法：检查每一对不同下标，找到和等于 `target` 的两个数。重点看内层为什么从 `i + 1` 开始，以及函数为什么返回下标而不是元素值。

**`10_2026-10-18_两数之和_哈希表优化.py`** 用字典保存“已经见过的数字和下标”。每读一个数，就查它的补数 `target - current` 是否存在。两份代码解决同一道题，可以直接比较嵌套循环和哈希表查表在思路上、时间复杂度上的差别。完整说明见 `09_2026-10-18_两数之和_暴力枚举_简介与学习建议.md`。

## 推荐学习顺序

1. `01_2026-08-23_输出偶数.py`、`03_2026-08-23_星号三角形.py`：先把 `for` 循环和 `range` 用熟。
2. `02_2026-08-23_九九乘法表.py`：进入嵌套循环。
3. `04_2026-08-23_成绩等级判断.py`：练习多分支判断。
4. `06_2026-08-27_列表增删与索引.py`、`05_2026-08-30_成绩统计与及格人数.py`：从单个数据走向一批数据。
5. `07_2026-09-09_字典成绩统计与查询.py`：认识字典这种"一对一"的存储方式。
6. `08_2026-09-28_复习题_成绩录入与统计.py`：把上面学的全部串起来，作为本目录的基础阶段检查。
7. `09_2026-10-18_两数之和_暴力枚举.py`：先用最直观的双层循环写出答案。
8. `10_2026-10-18_两数之和_哈希表优化.py`：再用字典查补数，对比两种解法的效率。

## 学习方法建议

- 每个文件先**读一遍注释再运行**，运行前猜一下输出，运行后对照。
- 每改一个地方就重新运行一次。改条件、改边界、改初始化，是理解代码最快的三种方式。
- 遇到不认识的函数（比如 `len`、`sum`、`max`），在文件里只改一个参数观察结果变化，比查文档更容易记住。
- 本目录的题目都很短，适合**默写**：关上文件，凭记忆写一遍，再对照原文找差距。

运行方式（在仓库根目录执行）：

```bash
python3 "01_Python基础练习/01_2026-08-23_输出偶数.py"
python3 "01_Python基础练习/04_2026-08-23_成绩等级判断.py"
python3 "01_Python基础练习/09_2026-10-18_两数之和_暴力枚举.py"
python3 "01_Python基础练习/10_2026-10-18_两数之和_哈希表优化.py"
```
