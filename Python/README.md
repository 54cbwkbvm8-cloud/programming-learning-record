## 运行方式

在仓库根目录运行普通脚本：

```bash
python3 "Python/01_基础语法/01_2026-08-23_输出偶数.py"
python3 "Python/13_综合项目/02_2026-09-09_简易计算器_函数版.py"
```

文件操作练习会读写同目录数据文件，建议进入脚本目录执行：

```bash
cd "Python/08_文件操作"
python3 "01_2026-09-13_文件读写复习_成绩统计.py"
```

可视化环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 "Python/14_可视化项目/01_2026-09-09_3D莲花动画.py"
```

## 项目阅读方法

1. 先梳理功能和菜单选项。
2. 列出每个函数接收什么、返回什么、修改哪些数据。
3. 用一个最小输入跟踪一次完整流程。
4. 对比不同版本解决了什么问题，例如列表版为什么改成字典版，函数版为什么增加输入校验。
5. 修改需求后先写测试输入，再改动自己复制出来的练习版本。
