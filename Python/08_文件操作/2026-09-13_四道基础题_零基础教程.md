## 第一部分：开始前先认识基础概念

### 1. 什么是代码注释

注释是写给人看的说明，Python 不会执行它。

Python 里使用 `#` 写注释：

```python
# 这一整行都是注释，Python 会忽略它  # 这是第二个注释
score = 80  # 这一行前面是代码，后面是注释
```

- `#` 后面的内容不会被当成代码运行。
- 注释用来解释代码，方便自己以后看懂，也方便别人看懂。
- 完整代码中，几乎每一行非空代码后面都有注释。

### 2. 什么是变量

变量可以理解成一个“贴了名字的盒子”，用来保存数据。

```python
score = 80  # 创建一个名为 score 的变量，把 80 放进去
```

- `score` 是变量名。
- `=` 不是“相等”，而是“把右边的值保存到左边的变量里”。
- 以后写 `score`，就会得到 `80`。

### 3. 什么是列表

列表可以把多个数据按顺序放在一起。

```python
scores = [78, 90, 45, 88, 92, 56]  # 创建包含 6 个成绩的列表
```

- 外面的 `[]` 表示列表。
- 里面的数字用逗号隔开。
- 列表中的每一个数据叫“元素”。
- 第一个元素的下标是 `0`，不是 `1`。
- `scores[0]` 是 `78`。
- `scores[1]` 是 `90`。
- `scores[-1]` 是最后一个元素 `56`。

### 4. 什么是函数

函数是一段可以重复使用的代码。

```python
def find_max(numbers):  # 定义一个名为 find_max 的函数
    return max(numbers)  # 返回 numbers 中的最大值
```

- `def` 是 define，意思是“定义”。
- `find_max` 是函数名。
- `numbers` 是函数的参数，用来接收外面传入的数据。
- 函数里面的代码必须缩进。
- `return` 表示把结果交给调用函数的人。

### 5. 什么是字典

字典用“键: 值”的方式保存一条信息。

```python
student = {  # 创建一个字典
    "姓名": "小明",  # 键是“姓名”，值是“小明”
    "年龄": 18,  # 键是“年龄”，值是 18
    "成绩": 92.5,  # 键是“成绩”，值是 92.5
}  # 字典结束
```

- `{}` 表示字典。
- `"姓名"` 是键。
- `"小明"` 是与键对应的值。
- 字典适合描述一个对象，例如一个学生。

### 6. 什么是缩进

Python 用缩进表示代码之间的从属关系。

```python
if 80 >= 60:  # 判断 80 是否达到 60
    print("及格")  # 这一行属于 if，必须缩进
```

- 冒号 `:` 后面通常表示“下面还有一组代码”。
- 常见的缩进是 4 个空格。
- 不应该把空格和 Tab 混在一起使用。
- 缩进错了，Python 会报错。

### 二、题目 1：写一个函数，输入列表，返回最大值

对应完整代码：

```python
# 定义题目 1 的函数，numbers 表示调用函数时传进来的列表。  # 定义求最大值函数
def find_max(numbers):  # numbers 是函数的形式参数
    # 判断列表中是否一个元素都没有。  # 检查空列表
    if len(numbers) == 0:  # len(numbers) 得到列表长度
        # 如果列表为空，就主动报错，防止后面访问第一个元素时出错。  # 报告错误
        raise ValueError("列表不能为空")  # ValueError 表示数值或数据不合适

    # 先把第一个数字当成目前看到的最大值。  # 设置初始最大值
    max_number = numbers[0]  # 列表下标从 0 开始

    # 从第二个数字开始，逐个取出列表中的数字。  # 遍历剩余数字
    for number in numbers[1:]:  # numbers[1:] 表示从第 2 个元素到末尾
        # 判断当前数字是否比已经记录的最大值更大。  # 比较大小
        if number > max_number:  # > 表示“大于”
            # 如果更大，就更新目前记录的最大值。  # 更新最大值
            max_number = number  # 把更大的数字保存起来

    # 把找到的最大值交还给调用函数的地方。  # 返回结果
    return max_number  # return 表示函数的结果
```

逐行解释：

1. `def find_max(numbers):` 定义一个函数。
2. `find_max` 是函数名，表示“找到最大值”。
3. `numbers` 是形式参数，调用函数时传进来的列表会交给它。
4. 函数名后面的小括号 `()` 用来放参数。
5. 行尾的冒号 `:` 表示函数体从下一行开始。
6. `if len(numbers) == 0:` 判断列表是不是空的。
7. `len(numbers)` 取得列表元素个数。
8. `==` 表示比较两边是否相等。
9. 如果列表长度为 `0`，说明列表里没有数据。
10. `raise ValueError("列表不能为空")` 主动抛出一个错误。
11. 如果不提前报错，后面写 `numbers[0]` 会失败，因为空列表没有第一个元素。
12. `max_number = numbers[0]` 把列表第一个元素暂时当成最大值。
13. `numbers[0]` 表示列表里下标为 `0` 的元素，也就是第一个元素。
14. `for number in numbers[1:]:` 开始循环检查剩余数字。
15. `numbers[1:]` 是列表切片，表示从下标 `1` 一直取到最后。
16. 如果列表是 `[78, 90, 45]`，`numbers[1:]` 就是 `[90, 45]`。
17. 每循环一次，`number` 会变成列表中的一个数字。
18. `if number > max_number:` 比较当前数字和目前最大值。
19. `>` 表示“大于”。
20. 如果当前数字更大，就执行缩进的下一行。
21. `max_number = number` 把当前数字保存成新的最大值。
22. 循环结束后，`max_number` 中就是整个列表的最大值。
23. `return max_number` 把最大值返回给调用函数的地方。
24. `return` 执行后，函数结束并把结果交出去。

使用示例：

```python
result = find_max([3, 9, 2])  # 调用函数，把返回值保存到 result
print(result)  # 输出 9
```

执行过程：

```text
一开始：max_number = 3
看到 9：9 比 3 大，max_number 变成 9
看到 2：2 不比 9 大，max_number 保持 9
最终返回：9
```

### 三、题目 2：统计最大值、最小值、平均值、及格人数

对应完整代码：

```python
# 定义题目 2 的函数，scores 表示成绩列表。  # 定义成绩统计函数
def count_scores(scores):  # scores 是函数的形式参数
    # 调用题目 1 的函数，找出成绩最大值。  # 计算最大值
    maximum = find_max(scores)  # 把函数结果保存到 maximum

    # 使用 Python 内置的 min 函数找出最小值。  # 计算最小值
    minimum = min(scores)  # min 会返回列表中的最小元素

    # 计算所有成绩的总和，再除以成绩个数，得到平均值。  # 计算平均值
    average = sum(scores) / len(scores)  # / 表示普通除法

    # 及格人数一开始是 0 人。  # 设置及格人数初始值
    pass_count = 0  # 计数器从 0 开始

    # 逐个取出每一个成绩。  # 遍历全部成绩
    for score in scores:  # 每循环一次，score 就是其中一个成绩
        # 判断这个成绩是否大于或等于 60 分。  # 判断是否及格
        if score >= 60:  # >= 表示“大于或等于”
            # 如果及格，就让及格人数增加 1。  # 增加及格人数
            pass_count = pass_count + 1  # 把原人数加 1 后保存回去

    # 一次返回四个统计结果，外层会用四个变量分别接收。  # 返回全部统计结果
    return maximum, minimum, average, pass_count  # 逗号隔开后形成元组
```

逐行解释：

1. `def count_scores(scores):` 定义统计成绩的函数。
2. `scores` 用来接收完整的成绩列表。
3. `maximum = find_max(scores)` 调用题目 1 的函数计算最大值。
4. `maximum` 是变量名，表示最大值。
5. `minimum = min(scores)` 使用 Python 内置函数 `min()` 求最小值。
6. `min()` 是 Python 已经准备好的工具，不需要自己编写。
7. `average = sum(scores) / len(scores)` 计算平均分。
8. `sum(scores)` 把列表中的所有成绩加起来。
9. `len(scores)` 得到成绩个数。
10. `/` 表示普通除法，结果是小数。
11. 对 `[78, 90, 45, 88, 92, 56]` 来说，总和是 `449`，个数是 `6`。
12. `449 / 6` 得到 `74.83333333333333`。
13. `pass_count = 0` 创建及格人数计数器。
14. 一开始没有人被统计，所以必须从 `0` 开始。
15. `for score in scores:` 逐个取出成绩列表中的每个成绩。
16. 每次循环，变量 `score` 会保存当前这个成绩。
17. `if score >= 60:` 判断当前成绩是否及格。
18. `>=` 的意思是“大于或等于”。
19. 如果成绩是 `60`，也会被认为及格。
20. `pass_count = pass_count + 1` 让及格人数增加 `1`。
21. 等号右边的 `pass_count + 1` 先计算。
22. 计算后的新结果再保存回左边的 `pass_count`。
23. 循环会依次检查 `78、90、45、88、92、56`。
24. 其中不及格的是 `45` 和 `56`，所以及格人数是 `4`。
25. `return maximum, minimum, average, pass_count` 一次返回四个结果。
26. 四个结果之间用逗号隔开，会形成一个“元组”。
27. 函数外面可以按顺序接收这四个结果。

题目 2 的调用代码：

```python
# 准备题目 2 要统计的成绩列表。  # 创建成绩列表
scores = [78, 90, 45, 88, 92, 56]  # 方括号表示列表

# 调用统计函数，并用四个变量接收返回的四个结果。  # 调用统计函数
maximum, minimum, average, pass_count = count_scores(scores)  # 左边按顺序接收四个结果
```

逐行解释：

1. `scores = [...]` 把题目给出的 6 个成绩保存到列表。
2. `maximum, minimum, average, pass_count = count_scores(scores)` 调用统计函数。
3. 括号里的 `scores` 是实际传进去的数据，叫“实际参数”。
4. 等号左边有四个变量，会按顺序接收函数返回的四个结果。
5. `maximum` 接收最大值。
6. `minimum` 接收最小值。
7. `average` 接收平均值。
8. `pass_count` 接收及格人数。

输出题目 2 的代码：

```python

print("题目 2：成绩统计")  # print 会把括号里的内容显示到屏幕

# 显示最大值。  # 输出最大值
print(f"最大值：{maximum}")  # f 字符串可以把变量放进大括号中

```

逐行解释：

1. `print()` 会把括号里的内容显示到屏幕上。
2. 第一句 `print()` 输出标题“题目 2：成绩统计”。
3. `f"最大值：{maximum}"` 是一个 f 字符串。
4. 字符串前面的 `f` 表示可以在字符串中放入变量。
5. `{maximum}` 会被替换成变量的实际值。
6. 如果 `maximum` 是 `92`，最终输出就是“最大值：92”。
7. `{minimum}` 的用法与 `{maximum}` 相同。
8. `{average:.2f}` 表示把平均值保留两位小数。
9. `.2` 表示保留两位。
10. `f` 表示按小数格式显示。
11. `74.83333333333333` 会显示成 `74.83`。
12. `{pass_count}` 会显示及格人数 `4`。

### 四、题目 3：读取一个文本文件

示例文本文件 `学生成绩示例.txt` 的内容是：

```text
张三 85
李四 92
王五 76
赵六 58
```

读取文件的函数：

```python
# 定义题目 3 的函数，file_path 表示要读取的文件路径。  # 定义读取文本函数
def read_text_file(file_path):  # file_path 是文件所在位置
    # 打开文件："r" 表示只读，encoding="utf-8" 表示按 UTF-8 编码读取中文。  # 打开文本文件
    with open(file_path, "r", encoding="utf-8") as file:  # with 会在用完后自动关闭文件
        # 读取文件里的全部文字，并保存到 content 变量中。  # 读取全部内容
        content = file.read()  # read() 返回整个文件的字符串

    # 把读取到的文字返回给调用函数的地方。  # 返回文件内容
    return content  # 函数外部可以接收这段文字
```

逐行解释：

1. `def read_text_file(file_path):` 定义读取文本文件的函数。
2. `file_path` 用来接收文件的完整路径。
3. `open(file_path, "r", encoding="utf-8")` 打开目标文件。
4. `open()` 是 Python 内置的打开文件函数。
5. `"r"` 表示 read，也就是只读模式。
6. 只读模式不会修改文件内容。
7. `encoding="utf-8"` 指定文字编码。
8. UTF-8 可以正确读取中文。
9. `with` 用来管理打开的文件。
10. 当 `with` 里面的代码执行完毕后，Python 会自动关闭文件。
11. `as file` 把打开的文件对象命名为 `file`。
12. `content = file.read()` 一次性读取文件中的全部文字。
13. `read()` 的结果是一个字符串。
14. 这时 `content` 中保存了文件的所有内容。
15. 离开缩进的 `with` 代码块后，文件已经被自动关闭。
16. `return content` 把读取到的文字返回出去。
17. 函数外可以用变量接收这段文字。

调用读取函数：

```python
# 显示题目 3 标题。  # 输出题目 3 标题
print("\n题目 3：读取文本文件")  # \n 表示先换一行

# 调用读取函数，读取同目录下的示例文本文件。  # 调用读取文件函数
text_content = read_text_file(TEXT_FILE)  # 把读取结果保存到 text_content

# 显示从文件中读到的全部内容。  # 输出文件内容
print(text_content)  # 打印文本字符串
```

逐行解释：

1. `"\n题目 3：读取文本文件"` 中的 `\n` 表示换行。
2. 加了 `\n` 后，输出标题前会先空出一行。
3. `read_text_file(TEXT_FILE)` 调用读取函数。
4. `TEXT_FILE` 是前面准备好的文本文件路径。
5. 函数返回的文字会保存到 `text_content`。
6. `print(text_content)` 把文件内容显示到屏幕。
7. 文件里原本的换行也会一起显示出来。

如果文件不存在，Python 会提示：

```text
FileNotFoundError
```

这表示没有找到要读取的文件。解决方法是检查：

- 文件名是否写对。
- 文件是否和 Python 文件放在同一个文件夹。
- 扩展名是否是 `.txt`。

14. 整体结构可以理解为“一个学生列表，里面装着多个学生字典”。

保存 JSON 的函数：

```python
# 定义题目 4 的函数，students 是学生列表，file_path 是保存位置。  # 定义保存 JSON 函数
def save_students_to_json(students, file_path):  # students 保存多个学生字典
    # 以写入模式打开 JSON 文件，"w" 表示写入；文件不存在时会自动创建。  # 打开 JSON 文件
    with open(file_path, "w", encoding="utf-8") as file:  # 每次运行都会重写这个文件
        # 把 students 数据写成 JSON；ensure_ascii=False 可以保留中文。  # 写入 JSON 内容
        json.dump(students, file, ensure_ascii=False, indent=4)  # indent=4 让内容更易读
```

逐行解释：

1. `def save_students_to_json(students, file_path):` 定义保存 JSON 的函数。
2. `students` 接收要保存的学生列表。
3. `file_path` 接收 JSON 文件的保存路径。
4. `open(file_path, "w", encoding="utf-8")` 打开目标文件。
5. `"w"` 表示 write，也就是写入模式。
6. 如果文件不存在，写入模式会自动创建文件。
7. 如果文件已经存在，写入模式会清空旧内容再写入新内容。
8. `encoding="utf-8"` 保证中文可以正常保存。
9. `with` 会在写完后自动关闭文件。
10. `json.dump(...)` 把 Python 数据转换成 JSON 并写入文件。
11. 第一个参数 `students` 是准备写入的数据。
12. 第二个参数 `file` 是准备写入的文件对象。
13. `ensure_ascii=False` 允许直接保存中文。
14. 如果不写这一项，中文可能变成 `\u5c0f\u660e` 这样的编码。
15. `indent=4` 让 JSON 每层缩进 4 个空格。
16. 加缩进后，生成的文件更容易阅读。

调用保存函数：

```python
# 调用保存函数，把学生信息写入 JSON 文件。  # 调用保存 JSON 函数
save_students_to_json(students, JSON_FILE)  # 传入学生数据和保存路径

# 显示题目 4 的完成提示和保存位置。  # 输出保存成功信息

```

逐行解释：

1. `save_students_to_json(students, JSON_FILE)` 调用保存函数。
2. 第一个参数 `students` 是学生信息列表。
3. 第二个参数 `JSON_FILE` 是保存路径。
4. 函数执行后，同目录下会出现 `学生信息.json`。
5. `print(...)` 输出保存成功提示。
6. `\n` 让提示前面先空一行。
7. `{JSON_FILE}` 会显示 JSON 文件的完整路径。

## 第四部分：常见错误和解决方法

### 错误 1：缩进错误

错误提示可能是：

```text
IndentationError
```

原因通常是小括号后面或 `if` 后面的代码没有正确缩进。

正确写法：

```python
if score >= 60:  # 冒号后开始一个代码块
    pass_count = pass_count + 1  # 必须缩进 4 个空格
```

### 错误 2：找不到文件

错误提示可能是：

```text
FileNotFoundError
```

解决方法：

- 检查 `学生成绩示例.txt` 是否存在。
- 检查文件名是否完全一致。
- 如果代码中用到了 `TEXT_FILE`，确保文本文件和 Python 文件在同一个文件夹。

### 错误 3：空列表求最大值

调用 `find_max([])` 时会看到：

```text
ValueError: 列表不能为空
```

这是程序主动给出的提示，因为空列表中没有最大值。

### 错误 4：JSON 中文显示成编码

如果 JSON 中的中文变成类似下面的内容：

```text
\u5c0f\u660e
```

原因是 `json.dump()` 没有设置 `ensure_ascii=False`。

正确写法：

```python
json.dump(students, file, ensure_ascii=False, indent=4)  # 保留中文并增加缩进
```
