# Python 学生成绩管理程序：文件简介与学习建议

## 文件简介

- **源码文件：** `Python 学生成绩管理程序10 月 3 日.py`
- **类型：** Python 菜单式综合项目
- **功能：** 用字典保存学生和成绩，支持添加、删除、修改、查询学生，录入成绩，显示全部学生，并计算平均分。
- **主要知识点：** 字典嵌套、函数拆分、`while True` 菜单循环、`try / except ValueError`、f-string 格式化、`continue` 与 `return` 控制流程。

程序用 `students` 字典保存数据，键是学生姓名，值是 `{"score": ...}` 这样的字典。每个功能都写成一个函数，主循环只负责显示菜单和分发选项。成绩输入部分用了 `try / except`，把非数字输入挡在外面，并限制分数必须落在 0～100 之间。和仓库里的 `学生成绩管理系统.py` 相比，本文件只把数据放在内存里，没有写文件，方便先把菜单结构练熟。

## 建议运行数据

第一次运行可以按下面的顺序操作：

```text
1          添加学生，姓名输入 张三
7          录入成绩，姓名 张三，成绩 88
1          添加学生，姓名 李四
7          录入成绩，姓名 李四，成绩 95
6          计算平均成绩
5          显示所有学生信息
8          退出
```

主要预期结果：

```text
平均成绩为：91.50
姓名：张三,成绩：88.0,等级：B
姓名：李四,成绩：95.0,等级：A
```

## 零基础学习建议

1. 先跑一遍菜单，再对照代码找出每个选项对应哪个函数，理解“菜单程序 = 循环 + 分支 + 函数”这个结构。
2. 在 `show_all_students` 里加一句 `print(students)`，观察整个字典长什么样，再理解 `students[name]["score"]` 为什么要两级取值。
3. 故意把 `abc` 当作成绩输入，看 `except ValueError` 怎么拦截；再输入 `120`，看范围检查怎么要求重新输入。
4. 先查一个不存在的学生，再删一个不存在的学生，比较 `search_student` 和 `delete_student` 是怎样用 `if name not in students` 提前返回的。
5. 注意 `get_grade` 的定义写在 `search_student` 之后，程序仍然能正常运行：Python 在真正调用时才去查找函数名，所以定义顺序可以靠后。

## 常见易错点

- 按姓名取值前必须先判断存在，否则会触发 `KeyError`。
- 成绩用 `float` 保存，显示时用 `f"{score:.2f}"` 才能固定两位小数；直接打印 `88.0` 会带一位小数。
- 平均分只统计已经录入成绩的学生，`score is None` 的学生会被 `continue` 跳过；如果一个成绩都没录，程序会提示而不是除以 0。
- `while True` 里每个分支处理完都会回到菜单，只有选择 8 才会 `break` 退出。
- 数据只存在内存中，退出程序就没了。想要长期保存，可以参考 `学生成绩管理系统.py` 用 `json` 读写文件的做法。

## 进阶练习

1. 给每个学生增加学号和班级，比较“用姓名做主键”和“用学号做主键”各自的优缺点。
2. 用 `json` 把 `students` 保存到文件，退出前自动写入、启动时自动读取。
3. 增加“按成绩排序显示”和“统计各等级人数”两个功能，练习 `sorted`、`key` 参数和字典计数。
4. 把 `input_score` 和 `modify_student` 里重复的成绩输入逻辑抽成一个 `read_score()` 函数。
5. 增加输入校验：姓名不能为空，也不能只有空格。
